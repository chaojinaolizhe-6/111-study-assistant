# 党内材料用语规范（AI 引用版 v1.0（2026-11-04 编制））

把本文件作为参考资料或系统提示的一部分。写入党材料、思想汇报、党课心得、自评材料、
半年动态时，**下列用词按原文执行，不得改写**。

## 一、身份与流程

- 动词是「**确定**」入党积极分子，不是「确立」：写「被确定为入党积极分子」。
- 流程五个阶段，顺序固定：入党申请 → 入党积极分子的确定和培养教育 → 发展对象的确定和考察 →
  预备党员的接收 → 预备党员的教育、考察和转正。
- 「入党积极分子」经一年以上培养教育考察才可列为「发展对象」；发展对象要有**两名**正式党员作「入党介绍人」。
- 「预备党员」预备期**一年**，从支部大会通过其为预备党员之日算起。
- 「**入党时间**」＝支部大会通过其为预备党员之日；「**党龄**」＝预备期满转为正式党员之日。两者不能混。
- 文书名：《中国共产党入党志愿书》（不是「入党申请书」）；《中国共产党发展党员工作细则》。
- 写「**党员组织关系**」，不写「党组织关系」。
- 支部层面的会议是「**支部党员大会**」，不是「党员大会」；支部开的是「**组织生活会**」，不是「民主生活会」（后者是县以上党员领导干部的）。

## 二、会议与文件

- 首次出现写全：「党的二十届五中全会」（2026 年 10 月 26—29 日）、「党的二十届四中全会」（2025 年 10 月）、
  「党的二十大」（2022 年 10 月）、「党的二十一大」（2027 年下半年召开）。
- 「全国两会」；「《中国共产党章程》」首次用全称；「全面从严治党」不简写成「从严治党」。
- 结构层次：党支部 → 党总支 → 党委；职务按层级写「党支部书记 / 党总支书记 / 党委书记」，
  不笼统写「党组织书记」。

## 三、纪律与作风

- 六项纪律：政治纪律、组织纪律、廉洁纪律、群众纪律、工作纪律、生活纪律。
- 五种处分（由轻到重）：警告、严重警告、撤销党内职务、留党察看、开除党籍。注意「察看」不是「查看」。
- 「中央八项规定」「中央八项规定精神」「四风」「三严三实」「一体推进不敢腐、不能腐、不想腐」。
- 中央和省级叫「巡视」，市县叫「巡察」。

## 四、理论表述（照抄，不改字、不改顺序）

- 「两个确立」「四个意识」「四个自信」「两个维护」。
- 伟大建党精神：坚持真理、坚守理想，践行初心、担当使命，不怕牺牲、英勇斗争，对党忠诚、不负人民。
- 入党誓词 80 字：我**志愿**加入中国共产党……（不是「自愿」）
- 党的性质：中国工人阶级的先锋队，同时是中国人民和中华民族的先锋队，是中国特色社会主义事业的领导核心。
- 中国式现代化五个特征：人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、
  人与自然和谐共生、走和平发展道路。

## 五、绝对不要出现的写法

| 错误 | 正确 |
|---|---|
| 被确立为入党积极分子 | 被确定为入党积极分子 |
| 政治占位 | 政治站位 |
| 党组织关系 | 党员组织关系 |
| 入党宣誓词 | 入党誓词 |
| 我自愿加入中国共产党 | 我志愿加入中国共产党 |
| 留党查看 | 留党察看 |
| 开除出党 | 开除党籍 |
| 从严治党 | 全面从严治党 |
| 反腐倡廉建设 | 党风廉政建设和反腐败斗争 |
| 二十届四中全会（首次出现） | 党的二十届四中全会 |
| 建国以来 | 新中国成立以来 |
| 民主生活会（支部层面） | 组织生活会 |
