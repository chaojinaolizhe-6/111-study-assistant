# 党的名词规范（资料包）

供写材料、也给其它 AI 引用。**只改这个文件夹里的东西，别处不留副本。**

## 里面有什么

| 文件 | 给谁看 | 说明 |
|---|---|---|
| `AI-引用规则.md` | **给 AI** | 一页规则，直接粘进系统提示或作为附件上传 |
| `规范表.md` | 给 AI / 给人 | 完整 95 条 + 20 条易错，markdown 表格 |
| `规范表.csv` | 给程序 | UTF-8 BOM，Excel / pandas 直接读 |
| `易错对照.csv` | 给程序 | 「错→对」两列，适合做自动校对词表 |
| `党的常用名词规范表.xlsx` | 给人 | 工作版，可筛选、可续加 |
| `党的常用名词规范表-阅读版.docx` | 给人 | 横向 5 页，手机翻阅 |

## 让其它 AI 引用，怎么说

> 这是党内材料用语规范，写党课心得、思想汇报、自评材料、半年动态时必须遵守：
> 附件 `AI-引用规则.md` 优先，遇到表里没有的词，查 `规范表.md`。

或者把 `AI-引用规则.md` 的内容直接写进系统提示。

## 口径与依据

- 依据：党章、中央办公厅《中国共产党发展党员工作细则》（2014）、《中国共产党支部工作条例（试行）》、
  《中国共产党纪律处分条例》（2023 修订）、党的二十届五中全会公报（2026-10-29）。
- 「释义与使用要点」是按原文压缩的用法提示，**不是原文**；引用原文请回到出处。
- 标注「党内通行做法」的条目，以学校党组织具体要求为准。
