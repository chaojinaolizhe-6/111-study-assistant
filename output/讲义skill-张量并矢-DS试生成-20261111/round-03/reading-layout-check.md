## 3. 主线阅读路径

主线顺序未变：§0.1 矢量 → §0.2 线性映射 → §0.3 矩阵账本 → §0.4 换基 → §0.5 迹/行列式/特征多项式 → §1 二次型/谱定理 → §2 张量与并矢 → §3 旋转算子 → §4 惯量张量 → §5 欧拉方程/对称陀螺 → §6 应力张量 → §7 P1--P12 → 附录 A。

本轮只需复查受改位置及相邻上下文：

1. **§6.4 均匀场**：线性例算出 ∂1σ11=σ0/L 后，读者现在会看到“把例子换成另一个应力场”，不会把常数系数 σ0 误当成整个分量不变；紧接着的平衡方程仍从同一段继续。
2. **P9 归一化**：真实 J 与错误 J′ 都带 m；读者先看到 J′=mA，再看到 A 的特征方程，最后看到 J′ 主值 m,m,4m，取出因子、解方程、恢复主值三步不再混用对象。
3. **§8 速查**：第 3 条与三句话总结不再给出“任何输入都左右不同”的一概判断；只翻速查也不会拾回首轮过强结论。
4. **图 2**：图与关键图注同页，读者不需要从 p14 翻到 p15 才能读到“投影到 b、沿 a 放大”和“b 为单位矢量”。
5. **P4 续页**：p40 开头有“P4 续解”，并重列 n、J、I(n)=145/18 与“本页验证 ω·L=2K”，单看续页也能辨认题目与目标。
