三句话总结
1. 张量是对象，矩阵是账本。换基时账本变、对象不变；迹、行列式、特征值是账本里不随基变的数。
2. 并矢只是二阶张量的另一种写法。作用规则(a ⊗b) · x = a(b · x) 一条就够；左右作用作为算子
一般不对称，只有张量对称时才对所有输入相同；双点积吃掉两个指标、谱分解是三个投影并矢相
加。
3. 理论力学里三处落点用的是同一台机器。惯量张量给出L = J · ω，欧拉方程是它在体坐标系里的
求导，应力张量是“面力对法向线性”的商法则产物。

详解
题干（自编概念题，承旧稿附录B 第1 问）判断并说明：(a) (a ⊗b) · c 与a(b · c) 是否相同？(b)
(a ⊗b) · c 与(a · b)c 是否相同？
(a) 相同。按右作用规则(a ⊗b) · c = a(b · c)；读法是“先把c 投影到b 上得到数b · c，再沿a 放大”。
(b) 一般不同。左边是“投到b、沿a 放大”；右边是“先算a · b 这个数，再沿c 放大”。取a = e1、
b = e1、c = e2：
(e1 ⊗e1) · e2 = e1(e1 · e2) = 0,
(e1 · e1)e2 = e2.
一个为零，一个不为零，所以不相同。两者只有在特殊输入下才碰巧相等。例如让c 沿a，即c = ka：
(a ⊗b) · (ka) = ka(b · a),
(a · b)(ka) = ka(a · b),
两边相同（数乘可以交换）。这说明“一般不同、特殊输入可以相同”，但不能因此把两个表达式当成
同一个。
