# 课件精讲讲义

输入指定资料与范围，输出可独立阅读的 `.tex`、`.pdf`。默认中文讲解、紫色花卉主题、LaTeX 原生公式。篇幅由内容决定，不设页数比例、缺口条数、每题页数或证明公式行数指标。

核心目标是学习者能顺着讲解理解并完成当前任务。学习者于 2026-11-11 明确：制作前先简短了解相关基础，补齐欠缺的前置；补充区分当前必需内容与可跳过的拓展。来源齐全、算式正确和编译通过仍须检查，但不能据此认定讲义已经容易理解。

## 内容用途与答案位置

沿用 `.tutor/config/study-mode.yml` 的讲义自学模式。学习者 2026-11-09 确认以下区分：

- **教学小例**解释概念、前提和方法，紧跟正文，给必要演算；可先建立直觉再一般推导。不能把理解所需的唯一示范移到附录。
- **独立练习**是需要学习者先做的例题、作业、自测：正文只放完整题干、考点、附录页码，不给关键步骤、中间结果或答案。附录详解自带完整条件或足够摘要。课件例题用作正文教学示范时须明示用途，不同时声称它是未曝光练习。
- **实验预习问答**按本次资料逐题给可理解、可使用的答案，双语要求见实验子规则，不自动套用隐藏答案方式。

讲义交付不等于已学/已验收，不修改能力事实。保存与收尾遵循当次授权，本技能不授予对外发送、提交或推送权限。

本项目采用 **DSH 执行、外部协调器审核** 的委派方式时，讲义正文、解答、图示、验证脚本、编译排版及返工均由 DSH 完成；协调器修改 skill、提供问题证据并验收，不直接改成品。学习者于 2026-11-10 明确要求以此检验 DS 的能力。委派或评测时读 [独立生成与审核返工](references/generation-review-loop.md)。

## 共同质量原则

1. **来源与覆盖可核对**：范围内定义、定理、例题、作业、实验必做项有落点；合并重复内容仍列对应。来源结论带文件/页码，新增结论给推导或依据。课件结论也要核验，不用口算错误判课件错，不臆造考点。
2. **按读者基础补桥梁**：先简短了解本章相关基础，再在首次使用处补足必要概念和操作。条件说明针对哪个对象、本题怎样判断、通过后允许哪一步；新增解释中的术语同样检查。补到读者能继续当前理解或操作为止，具体判据见[讲解与例子](references/worked-examples.md)。
3. **局部自足，允许跨页**：读者能辨认问题、目标、关键条件与记号。短题干与开头相邻；长证明/解答自然分页，续页补题号或目标、本页所需条件/记号，必要时重列关键式。不重抄全部前文，也不能只有“同上”“同一题”。图与解释相邻，跨页补必要简图。
4. **例子有明确用途**：小例建立直觉、演示操作或对比条件；数值核对检查结果。有限例子不能冒充一般证明。顺序服务理解，不规定例子只能在结论后，不按数量或公式行数判质量。
5. **一步一因、对象准确**：关键变换说明依据与目标。审查“因为—所以”是否针对同一对象；区分一点/区间、充分/必要、标量/向量/矩阵、精确/近似。记号一致，常数和归一化因素交代来源。
6. **图表解释本步**：图中对象、标记与当前公式逐项对应；有图不等于合适。表汇总已解释内容，不能代替未讲推导；承载计算时给生成式与必要读法，分段结果不漏边界。
7. **检查不冒充证明**：程序查结构、引用、编译；内容审校与页面检查另做，不用“脚本通过”代替正确性和可读性判断。

## 流程

### 1. 核读资料
确认课程、版本、范围、页码体系。有效章节地图可复用，引用的例题、公式和图仍核对原页。

```powershell
python -B .dsh/skills/lecture-deepdive/scripts/read_slides.py <资料.pdf> --pages 1-8 --map
python -B .dsh/skills/lecture-deepdive/scripts/read_slides.py <资料.pdf> --pages 1-8
```

默认输出所选页全文；显式限长只用于定位，截断后补读。提取/渲染不等于读图，图片和混合页中的关键公式/装置需看原页。实验先把目的、仪器、预习、操作和数据表逐项对应来源，避免抽取漏项。

### 2. 目标、相关基础与缺口
先明确本章要支持的理解或操作，从中筛出关键前置。制作前用简短交流了解这些基础：优先复用学习者近期明确反馈，只询问会改变本次讲解深度的未知项；必要时用一个很短的相关操作澄清，避免全科测验或逐项盘问。自述、实际作答和“讲义曾覆盖”分别看待，不把覆盖当作会用，也不把未知当作不会。

委派时把已确认基础、需回顾/补学项、尚未知项随任务交给 DSH。缺少影响正文深度的回答时，可继续核读来源和准备内容，但先返回简短问题，不编造学习者答案；若学习者明确要求先生成，则说明采用的假设与待确认处。

定义/结论/例题/作业映射至讲义位置，题号和来源可追溯。真实缺口记为 `类型｜来源页与短语｜当前理解/操作缺什么｜补在哪里`，允许没有发现缺口，不凑数。写完再查新增术语及其依赖，按[讲解与例子](references/worked-examples.md)确定必要补充与选读边界。

### 3. 组织讲解
按本章需要组织问题/记号、概念/方法、小例、练习、详解、速查与来源对照；这些是组件，不强制固定节数、两条方法或例题长度。依据已了解的基础和具体阅读断点选择概念解释、操作小例、中间式或局部图；把它们接回当前问题。主线保留完成当前任务所需的信息，拓展须能真正跳过；不按术语是否高级直接判为必读或选读。

### 4. 题块与排版
```latex
\documentclass[11pt]{ctexart}
\input{<相对源文件的路径>/assets/theme-violet}
\settags{讲义标题}{课程}
\begin{document}
\doctitle{主标题}{副标题}{来源文件与页码}
% 教学小例写在相关正文，不用独立练习宏。
\practice{P1}{课件 p12}{完整题干}{检验的知识}{ans:P1}
\clearpage
\appendix
\hdr{附录}{练习详解}
\answerstart{P1}{课件 p12}{重述对象、条件与目标}
% 推导、答案、自检可跨页。
% 确认需要续页时在合理段落处换页后使用：
% \answercontinue{P1}{本页条件、目标或关键式}
\end{document}
```

`\qbreak` 只保护短题干和开头；`\answercontinue` 须在实际续页处使用，不能只定义。长表可跨页并重复表头，不把超过一页的内容包进 `minipage` 或不可分框。保持字号可读，不缩小整页规避溢出。

按编译后的实际断页补续页摘要，同页后续段落不反复重述题号和全部条件；下一题能自然接排时不强制新页。主题中的 `\callout{...}`、`\qstem{...}`、`\warnbox{...}` 是命令，使用前核对参数，不当作环境。

### 5. 验算、编译、审校
- 用 `tools/verify_math.py`、符号运算或可复现计算核验数值/推导，同时查条件、量纲、边界与解释句。
- 计算脚本须汇总实际执行的断言，任一断言失败以非零退出码报告；仅打印数值不能宣称验算通过。
- 两遍 `xelatex -halt-on-error -interaction=nonstopmode`，确认 PDF/log 属于本轮，无错误、可见缺字、溢出和未解析引用。
- 运行 `python -B .dsh/skills/lecture-deepdive/scripts/check_handout.py <讲义.tex> --mode appendix --log <讲义.log>`。实验用 `--mode lab`；无独立练习的理论讲解可用 `--mode theory`。修复错误后重查；警告逐项判断，不为消警告删必要内容。
- 对源资料核覆盖，正文练习不泄露步骤，附录条件完整，实验双语/图表实际落实。
- 渲染看页面，重点新概念、图表、练习/详解、跨页、长公式和末页；修改后复查。说明实际审查范围，不能固定抽几页便保证其余全合格。
- 若当前会话不支持图像输入，保存渲染页并做可用的文字/坐标检查，明确「尚未目视验收」；由支持看图的审核者只读反馈布局或几何问题，再由 DSH 改稿。不能把像素占比、边界检查或编译通过称为已目视读图，也不反复尝试已确认不可用的看图能力。
- 按[讲解与例子](references/worked-examples.md)做阅读路径检查：只使用本轮明确采用的基础范围和讲义此前已给出的信息，沿主线到具体例题/操作，指出实际卡住的术语、推理或动作；已确认基础与用户要求先生成时采用的假设分开，依赖假设的判断仍待试读。跳过选读后仍应能继续。覆盖、正确性、理解支持分别报告，审核者不能用自己的额外知识补齐讲义缺口，也不能声称模拟审核等于学习者已理解。
- 收到外部问题单后，由 DSH 核实证据、完成返工，再复查受影响内容与页面；反馈中的猜测不自动当作事实，未解决项如实报告。没有新变化、失败或未决疑点时，不重复已通过的同一检查。

## 交付与本机约束

通常写 `subjects/<课程>/讲义/`；对比试读用指定独立目录，保留旧稿。交付 PDF 与源文件，说明覆盖、补充、验证、页面审查范围和未解决项；页数/缺口数只作描述。

使用 XeLaTeX、已安装中文字体和紫花主题。`colortbl` 与 `array` 曾有兼容问题，优先三线表。裁剪/重绘标来源，扫描转写须核对，未知参数不自动填值。
