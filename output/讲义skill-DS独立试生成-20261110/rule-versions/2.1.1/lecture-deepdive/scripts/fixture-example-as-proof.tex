\subhdr{1.3\quad 换基：账本变，机器不变}

\textbf{二维例子。}机器 $T$ 是“沿 $x$ 轴拉伸两倍”。转了 $45^\circ$ 之后逐项投影：

\[
T\vect n_1\cdot\vect n_1=\frac{2+1}{2}=\frac32
\]

于是同一台机器的账本变成

\[
\ten T'=\begin{pmatrix}3/2&-1/2\\-1/2&3/2\end{pmatrix}.
\]

两个账本长得完全不一样。判断“是不是同一台机器”，不能看数字，要看数字怎么变。这条换算规则是

\[
\boxed{\;\ten T'=\ten R^{\mathsf T}\ten T\ten R\;}
\]
