# 独立生成与审核返工

用于外部协调器委派 DSH 生成讲义，或验证本 skill 的实际效果；普通单次讲义不额外制造评测流程。

## 分工与输入
- DSH 是成品执行者：独立读源资料、组织讲解、求解、制图、写验证脚本、编译、检查页面，并处理返工。
- 协调器维护 skill、给任务范围、只读审稿与报告结果。发现错误时给出「位置—问题—证据—验收目标」，不直接替换正文、解答、图代码或排版，不用自己的成稿冒充 DSH 结果。
- 首轮独立试生成只提供原始资料、本次 skill 和任务范围，不提供先前由协调器修过的讲义、答案脚本、具体替换段落或已知漏洞清单。可把真实错误归纳为可复用的规则，但不能把当前样题的整套答案藏进规则。

## 留档与返工
- 首稿输出在独立目录。外部反馈前保存首稿及其源文件、PDF、验证说明和文件哈希；首稿与反馈后版本分开，不覆盖首稿。
- 返工任务给原始资料、DSH 自己的上一版和问题单。DSH 自行核实、选择解法并修改，记录各问题的处理位置及未解决项，不能仅复述已修复。
- 修改公式后复核它的条件、计算与引用；修改布局后复看实际受影响页及续页，不为消除警告而删掉必要内容。出现相同错误时回看根因和适用规则，不只局部换字。
- 进程超时或失败时保留已生成产物及具体状态，由新的 DSH 任务按已完成进度继续；不能把协调器代写视为兜底成功，也不能在没有新证据时无限重试。

## 如实验收
区分「DSH 首稿」「收到审核意见后的 DSH 返工稿」「协调器直接修订稿」。只有前两者能用于说明 DSH 执行效果；后者如存在必须另标，不能混入独立生成对照。首稿反映无外部反馈的表现，返工稿反映带审核闭环的表现。

交付说明实际执行的检查、仍存问题与产物版本，不把进程退出成功、脚本通过或审核通过当作学习效果已经提高。审核仍有实质问题时继续交 DSH 处理；外部条件确实阻断时报告阻断与现有产物。
