# 缺口勘探手册

资料可能省略前提、推导或读图方法，也可能存在笔误。这份手册帮助定位**当前读者实际缺少的理解环节**，核对来源后决定补什么；不能先假定资料有错，也不能把任何简写都判成缺口。

以下十二类是查找线索，不是每章都要完成的项目（见 [SKILL.md](../SKILL.md)「共同质量原则」）。判断依据是：读者在这里能否辨认对象、判断条件、理解并执行下一步。分类可合并，数量据实，允许没有发现缺口。

前十一类可用于原资料和讲义；第十二类专门提醒复查自己的新增解释。补写引入的术语、前提或跳步，同样需要检查。

先用 `read_slides.py` 定位并读所选页全文，关键公式和图核对原页。可暂记疑点，但确认前不要宣称“课件漏讲/写错”；应核对相邻页和已给引用，避免把提取丢字或另一页已有的说明误判为原资料缺口。

下文的历史案例、页码、步骤数与措辞只用于解释对应问题，**不形成当下讲义的额外指标或固定写作顺序**。补法按内容选用；学科细节以主技能链接的对应参考文件为准。

## 一、机制缺口（最常见，也最致命）

**特征**：课件直接给出一个公式/替换/结论，前一页没有任何铺垫。

**识别信号**
- "By (20) we have…" / "we use the substitution…" / "it is easy to see that…"
- 一个式子突然出现，前文没有它怎么来的

**典型例子**（L7 p30）
> The order of DE (17) is reduced by unity by the substitution $y=y_p\int z\dd x$ (18).

替换给了，为什么降阶没说。补法：展开 $L[y_pv]$，指出 $v$ 项系数恰为 $L[y_p]\equiv0$。

**补法模板**
1. 把替换代进去，逐项写出；
2. 指出哪一项因为"$y_p$ 是解"而必然为零；
3. 一句话点破机制（"不是凑出来的，是线性的必然"）。

## 二、代数跳步

**特征**：两步之间省掉了合并/约分/移项，或者用一句话概括了一屏代数。

**识别信号**
- "the terms containing $v$ cancel"
- "after simplification"
- 上下两页的式子对不上（先核对条件、记号与提取结果，再判断是否省略了必要变换）

**典型例子**（L7 p34→p35）
> $v''+2v'+v+xv'+xv-xv-v=0$ … "The terms containing $v$ cancel:" … $v''+(x+2)v'=0$

四个 $v$ 项怎么两两抵消，课件不给。补法：用 `\underbrace` 逐项标注来源（来自 $y''$ / 来自 $xy'$ / 来自 $-(x+1)y$），摆出来。

**补法模板**：把被吞的那一行**显式写出来**，最好标注每一项的来源，再宣布结果。

## 三、平凡解与常数的放开

**特征**：先假设某量 $\neq0$ 做除法，几行之后又把常数放宽到 $\mathbb{R}$，中间不解释。

**识别信号**
- "For $z\neq0$, …" 之后紧跟 "It is easy to see that $z\equiv0$ is a solution. Therefore, $C\in\mathbb{R}$."
- 常数从 $C_3\neq0$ 变成 $C_4\in\mathbb{R}$

**典型例子**（L7 p35–p36）
> For $z\neq0$: $z=C_3\exp(\cdot)$, $C_3\neq0$. … $z\equiv0$ is a solution … so $C_4\in\mathbb{R}$.

补法：说明 $z\equiv0\iff v'\equiv0\iff y=Cy_p$，**正是通解里已有的那一支**，所以放开常数既不增解也不丢解。

**补法模板**：把"被除掉的零"翻译回原变量，看它对应哪个解；若对应已有解，就是"补回"，不是"新增"。

## 四、拼接缺口（跨讲、跨材料的缝）

**特征**：一整条逻辑需要 A 页的结论 + B 页的定理，但没有一页把它们接起来。

**识别信号**
- 两处结论形式相似（都有 $\exp(-\int a_1)$，都有 $W$）
- 课件分属不同 lecture 编号
- 老师口头说过"这两块可以连起来"但没写在胶片上

**典型例子**：L7 的降阶替换 + L8 的 Abel 定理 → 可以合成 $y_2=y_p\int W/y_p^2\dd x$，课件两讲都没写。

**补法模板**：并排写出两条路的中间结果 → 指出只差一个常数 → 说明常数被通解吸收 → 给出合并式。**必须证明等价，不能只说"类似"**。

---

## 五、适用区间与前提

**特征**：定理有前提（$y_p\neq0$、系数连续、区间 $I$），课件全程默认成立，不点明。

**识别信号**
- 出现 $1/y_p$、$\ln|y_p|$、除以系数
- "on an interval $I$"

**补法参考**：在使用条件处说清对象、本题如何判断、判断后允许哪一步。降阶例中可检查 $y_p=0$ 与系数奇点，说明可用区间；其它内容按实际条件处理，不机械增加奇点清单。

## 六、答案形态（为什么停在这里）

**特征**：答案保留积分形式 / 保留级数 / 保留隐式，课件不说为什么。

**识别信号**
- 最终答案里还有一个积不出来的 $\int$
- "It is" 之后没有下文

**补法参考**：说明当前形式是否已满足题目要求、怎样代入初值或计算。只有具备依据时才称“无初等原函数”；必要时说明可用特殊函数或数值方法，不把“暂时未算出”写成“不可能算出”，也不为解释停步引入本章不需要的高阶理论。

## 七、形式改写（定理被写成了推论）

**特征**：资料使用某个等价形式或特例，当前推导却需要另一种形式；读者不知道两者如何联系，或未能辨认适用条件。给积分形式本身不是缺口，是否补转换取决于理解需要。

**识别信号**
- 定理的结论里有一个 $\int$ 或一个初值 $x_0$，而引言句里出现过"微分方程/导数"字样
- 定理名与常见叫法对不上（如叫"定理"却写成公式结果）
- 定理陈述是"某量等于某个显式表达式"，而不是"某量满足某个关系"

**典型例子**（L8 p50）
> 引言句：the Wronskian … satisfies **a some differential equation of first order**
> 定理块：(43) $W(x)=\exp\left(-\int_{x_0}^{x}a_1\right)W(x_0)$

在这个案例中，微分形式 $W'+a_1W=0$ 能解释积分形式 (43) 的来源，适合把两者接起来。积分形式本身也可作为完整定理陈述；不能仅因先后顺序判定讲解有误。

**补法参考**：完整给出本次使用的对象、条件与结论；如果另一形式有助理解，补连接两者的必要变换（如积分因子、代入、化简），并标明资料给的是哪一种。可从问题、常用式或一般关系起讲，不强制固定顺序。详细原则见 [数学与理论推导](math-and-physics.md)。

> 注意：这不是"课件写错了"，而是"课件写的是成品"。补它，是为了让读者知道成品是从哪个零件车出来的。

## 八、压缩缺口（把多步推理压成表、图或一句"综上"）

**特征**：讲义（或课件）把本该逐情形展开的推理，压成一张表或一句"综上"，只留结论。

**识别信号**
- 表格列头是结论量（`sgn`、`F(ω)`、`结果`），单元格里没有中间代数
- "于是""综上""归纳可得"后面直接接分段答案或一串数
- 读者能背下表，却复算不出来；要回答"为什么这一格是这个值"就得自己重推

**典型例子**（第五章 p34–p35）
> 三个情形（$|\omega|<\omega_0$、$\omega>\omega_0$、$\omega<-\omega_0$）被压成四列表，表里出现 $\frac12-(-\frac12)=1$，但 $\frac12\operatorname{sgn}(\omega+\omega_0)-\frac12\operatorname{sgn}(\omega-\omega_0)$ 这个式子始终没写。

**补法参考**：让读者知道表格由哪个式子、判断或数据生成；在容易误读的位置示范如何得到一行或一格。分段结果交代端点，必要时补闭式；台账、记号表和已解释内容的速查表不额外添加推导。是否有缺口取决于能否理解表内关系，不由行数决定。

> 注意：压缩不是"补缝"，而是"把缝重新盖回去"。能逐格复算的表才算补；不能复算的表等于删掉了推导。

## 九、边界与端点（答案形态的单列子类）

**特征**：答案写成 `|ω|<ω₀` / `|ω|>ω₀` 两段，端点既不在 `>` 内也不在 `<` 内，没有值，也不解释为什么可以没有。

**识别信号**
- 分段答案里出现严格不等号，且没有一条带 `=`
- 用 sgn／阶跃／δ／主值／极限得到的答案
- 曲线在端点跳变，但正文不画出来

**补法参考**：按本题定义和适用的定理判断端点，给出点值或说明为何当前任务可不指定。傅里叶型例子中半值可能来自左右极限的平均，须说明条件；不能把“端点都取半值”当通则。“单点不影响积分”也只解释相应积分问题，不自动免除点值、边界条件或逐点等式的要求。

## 十、原形缺口（词形排了一串，没有一个能查词典）

**特征**：同一个词的几个形式排在一起，却没有可查词典的完整原形，或没说明如何识别它。下面保留的是俄语案例；其它语言按该语言的词典收词方式处理，不套用俄语规则。

**识别信号**
- 逐行读法写成 `но́вый／но́вая／но́вое／но́вые`，四个形式齐全，没一个标着"原形"
- 表头是 `-ый`、`-ая`、`-ий`、`-ое` 这类**裸词尾**，或 `но́в-`、`си́н-` 这类**残词干**
- 族名写成"软词干 -ний""词尾重音 -о́й"，整段没出现一个完整单词
- 读者会写这个词，却说不出"这个词叫什么"（打开词典查哪个形式）

**典型例子**（本技能实际踩过，2026-10-25，俄语讲义 §4.2）
> 五列词尾总表：表头是 `硬词干 | г／к／х | ж／ш／ч／щ | 软词干 -ний | 词尾重音`；表下逐行读法 `но́вый／но́вая／но́вое／но́вые`、`высо́кий／…` 共五串四形式。
> 形式一个不缺，却没有任何一处写"原形是 но́вый"——读者手里没有一个能查词典的词。读者批注原话：「没有原形，写啥呢」。

**补法参考**：标明完整原形，并让读者能从当前形式找到查词入口。俄语名词用**自身单数第一格**，仅复数词按实际；形容词通常用阳性单数第一格，动词用不定式。不能把阴性、中性名词硬改成阳性。

表头或首列可放完整示范词，裸词尾只作辅助；根据实际词形解释退回原形的方法。历史例里的换尾规律有拼写、重音和不规则形式限制，不是任意词都能机械替换。持续维护的规则见 [俄语词形](russian-morphology.md)，这里不另设一套要求。

> 注意：这不是"词尾写错了"，而是"词丢了主体"。词尾表回答"怎么变"，原形回答"这是哪个词"——两个问题都得答。

## 十一、图缺/图替（图没有解释当前关系）

**特征**：当前结论依赖连接、方向、路径、受力或几何关系，但这些关系没画出来，或现有图只展示整机，无法支持这一步。读者看到了结论，却找不到它对应的对象与关系。

**识别信号**
- 正文用到器件连接、光程投影或受力方向，读者却无法从附近图示找到对应关系；仅出现学科词或某种 LaTeX 环境不能据此判定
- 表格列头是"导通/截止""开关状态""电流方向""输出"，却没有一张图让读者逐行对照
- 图和解释相隔较远，跨页后缺少本步需要的关系或标记，读者必须反复翻回才能继续
- 文字里的 a、b、+、−、D1、D2 在图上找不到

**典型例子**（本技能实际踩过，2026-10-27，实验 4 §2.3）
> 正文先给一个"桥式整流 D1"方框，再给"u2>0: D1,D4 / u2<0: D2,D3"的导通表，最后给 0.9U2；没有桥的接线图，也没有正/负半周两条电流路径。读者知道"哪两只导通"，却不知道"从哪进、从哪回、负载电流为什么不变向"。

**补法参考**：画出本步需要的对象和关系，符号与公式对应。结论确实比较两种状态时，把两种状态区分清楚；可用两幅小图，也可用带文字和线型标识的路径。表格可总结已经解释的状态，不强制每次同时增加表、波形或固定段落。

**检查方法**：沿当前公式逐项在图中找对象、路径段、角度、距离、方向或连接。例如推导光程差时，整机图不能代替斜入射路径和投影比较线。不是“遮住图能不能脑补”，而是“看着图能不能解释这一项为什么出现”。允许长推导跨页，必要时重复局部简图；不每页重画整机。详见 [技术图示](technical-diagrams.md)。

## 十二、自造缺口（补写时自己新开的口子）

**特征**：讲义自己的补写引入了新的跳步或未解释前置。常见情形是**以例代证**：算一个 2×2／45°／$n=3$ 的例子，就把一般式宣布为已证明，却没有足以支持一般性的推导或来源。例子先于一般式出现本身没有问题。

**识别信号**
- 结论框（`\boxed`、`\fcolorbox` 定义框、突然出现的一般式）前面最近的段落是"数字例子／例如／$n=2$ 时"
- 例子后出现一般式，但没有说明一般性的依据（加一句“一般地”也不能代替依据）
- 结论框旁的注写"代入验证一致""这里不重证"——**"验证一致"是核对，不是证明**
- 把例子整段删掉，剩下的文字只剩一句断言

**典型例子**（本技能实际踩过，2026-11-04，《专题·从张量到并矢》§1.3）
> 45° 旋转基逐项投影，算出 $\ten T'=\begin{pmatrix}3/2&-1/2\\-1/2&3/2\end{pmatrix}$；紧接着黑框 $\ten T'=\ten R^{\mathsf T}\ten T\ten R$ 与 $T'_{ij}=\sum_{k,l}R_{ki}R_{lj}T_{kl}$，中间没有一个字说"为什么是两个 $R$"；旁注只写"代入得一致"。
> 学习者原话：「这里编得太跳跃了……能编出这么跳跃的一个地方」。

**补法参考**：检查去掉具体数字后，一般结论还有没有有效依据；若只有断言，补必要推导，或完整引用并解释所用结论。来源坐标能说明出处，不能自动消除读者的理解困难。

上述张量案例可从“新分量在算什么”起步，用旧基展开，再把两次变换读成矩阵乘法：右乘 $R$ 管输入，左乘 $\ten R^{\mathsf T}$ 管输出。这是该案例的可用讲法，不要求其它结论也拆成三步。

教学小例可先建立直觉，核对例可检验结果；按内容需要安排顺序。只要一般性另有有效依据，就不因例子的位置、框前公式行数或证明步骤数判错。

> 例子可帮助理解或核对，推导说明一般结论为何成立。按内容需要选用，不能互相冒充。

## 记录格式

记录足以回查和修订的信息即可，通常包括：

```
类型 | 来源文件、页码与短语 | 缺了什么 | 补法/讲义位置
```

例：
```
代数跳步 | L7 p34-p35，“the terms containing v cancel” | 四个 v 项如何两两抵消 | 降阶推导处用 underbrace 标来源
```

讲义自身的新缺口标“新增解释＋讲义位置”，不要伪造课件原文。尚未确认的疑点单列，处理后再决定是否进入交付清单。

## 交付时的用法

- 按本讲结构放在来源/补充说明或缺口清单中，写清来源与实际补法；不规定章节号、每条行数，也不让审核说明挤占核心讲解。
- 数量据实：记录已核范围内真实发现的缺口，允许没有发现；是否读透看范围覆盖与解释质量，不凑条目。
- 表格只有在省略必要关系、计算或判断，导致当前读者无法读懂时，才登记“压缩缺口”；已有说明的汇总表不为行数补条目。
- 结论框前有数值例子只是复核线索；检查一般结论是否另有有效依据。只有缺少依据时才登记“以例代证”，不按先后位置定罪，不强制三步。
- 图只有在本步所需关系缺失或不对应时，才登记“图缺/图替”；裁剪、重绘或沿用来源图本身不等于发现缺口。图的来源页与处理方式仍应标明。
- 同类障碍反复出现时，可合并补一个共用前置说明；是否在开篇提醒，取决于它是否影响后续阅读，不按出现次数推断整门课的系统性问题。
