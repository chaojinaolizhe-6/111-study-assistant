# DSH 讲义独立试生成

本目录是学习者授权的隔离试生成，不是学习记录会话。学习者为课程初学者，目标是独立读讲义理解并解题。

- 你（DSH）负责讲义、题解、配图、验证脚本、编译排版、检查及后续返工。外部协调器只维护规则和只读审核。
- 先加载 .dsh/skills/lecture-deepdive/SKILL.md，按内容路由参考。规则与 inputs 均只读。
- 仅使用本目录 inputs 的原始PDF、当前skill与任务指定资料，不读取父项目旧讲义、20261109修订稿、审核答案脚本、其他代理的成品。
- 仅写任务指定输出子目录；不要修改共同输入、规则或其他任务输出。中间脚本/渲染图也写自己的输出子目录。
- 不运行任何 git、学习记录入账、全局收尾、同步、微信或其他对外发送。生成讲义不等于学习者已掌握。
- 遇到审核意见自行核实与返工；检查通过且无未决问题后及时返回交付路径与事实，不反复重跑相同检查。
