§1
静态工作点：四组偏置，一次算完，再判区域
1.1 为什么非要设一个工作点
放大电路在没有输入信号时也不能” 关着”。因为三极管只在发射结正偏、集电结反偏（放大区）时才
有IC = βIB 这个线性关系；输入的交流信号只是在这个直流工作点上下摆动。工作点取得太低（靠
近截止），信号的下半周把管子推进截止；取得太高（靠近饱和），上半周被削平。两种情况都会让输
出波形削顶，也就是教材说的” 非线性失真”。
教材p.148 给的判据是一句很实用的话：管压降UCE 约等于电源电压UCC 的一半，工作点就基本合
适。这句话的道理在§1.4 讲（它与交流负载线的对称摆幅是一回事），本节先把四组偏置的数算出来，
你到现场才有” 应该读到多少” 的参照。

§2
交流通路与小信号模型：三个公式从哪来
2.1 画交流通路的三条规则
教材p.149 说” 动态是指有输入信号时的工作状态”，课件C4-3 p19–p23 用三页把” 原电路怎么变成
交流通路” 讲完了。规则只有三条：
1. 耦合电容短路：C1、C2 的容抗在中频段近似为零，交流信号直接通过；它们的作用只是” 隔直流”，
不让偏置被信号源和负载改掉。
2. 旁路电容短路：CE 把RE1 两端交流短路，所以RE1 上有直流压降、没有交流压降。
3. 直流电源置零：UCC 对交流是” 恒压”，置零后就是一根接地线；于是RC 的上端在交流上接地，
RC 变成从集电极到地的电阻。
按这三条画出来：输入口看进去是RB1、RB2 并联再并上管子的rbe；输出口看进去是RC 与RL 并
联；S1 断开时，发射极到地还多一个RE2 没有被旁路。

§5
测量方法：每一项读什么、为什么这样读
5.0 进场第一件事：认管子
教材§5.2.4 要求先用万用表电阻挡判管型与管脚（b、c、e），并记在报告里。判断法：用二极管挡测
两个结，b–e、b–c 都应单向导通（NPN 时红表笔接b、黑表笔接e 或c 读数小）；两次都通的那只脚
是b，剩下两脚中与b 组成结压降略大的通常是e。报告里要写出你测到的管脚排列，别只写” 已测”。
5.1 静态：三条规则+ 三个电位
1. 输入短路：ui = 0 才叫” 静态”，所以测量前把输入端对地短接（教材p.148 原话：” 应先将放大
电路的输入端与地短接”）。
2. 共地：所有仪表的黑夹子接同一根地线（端子c），电压表只能测” 某点对地” 的电压，不能跨接两
点测。
3. 不拆线测电流：电流不直接测，而是测UB、UC、UE 三个对地电位再推算。

A.1
为什么设静态工作点？三种调法，哪种对动态影响最小
题干（教材p.147 第1 问）放大电路为何要设置合适的静态工作点？静态工作点有哪几种调整方法？
一般采用哪种方法对动态放大影响最小？为什么？
考点：工作点—失真—摆幅三者的关系；三种调法各自改的是” 直流” 还是” 交流”。
关键一步：先承认” 放大区才线性”，再看工作点偏移时哪半周先被削。
详解：三极管只在放大区（发射结正偏、集电结反偏）才有IC = βIB 的线性关系。交流信号是叠加
在直流工作点上的摆幅：工作点定得合适，正负半周都留有余量，输出才不失真；定得太高（UCE 小）
则信号一摆就进饱和，输出下半周被削平；定得太低（UCE 大）则一摆就进截止，输出上半周被削平；
两种失真合称非线性失真。合适的位置是让UCE ≈UCC/2，并且正好落在交流负载线的中点（这样正
负半周同时到达边界，摆幅最大）。
调法有三种：1) 调基极偏置电阻RB（本实验用RB1、RB2 与RP1）；2) 调集电极电阻RC；3) 调电
源电压UCC。调RB 对动态影响最小，因为RB 在交流通路上与信号源并联、且通常远大于ri，改变
它对Au 的中频值几乎没有影响（Au = −βR′
L/rbe 里没有RB）；而RC 直接进R′
L、UCC 直接改直流
负载线，两者都会同时改变动态指标。所以工程上调工作点优先调基极偏置。
答案（英文可抄）：The quiescent point must be set inside the active region so that the transistor stays
linear over the whole signal swing. Three methods are available: adjusting the base bias resistor, the
collector resistor, or the supply voltage. Adjusting the base bias resistor is preferred because it changes
the dc operating point while leaving the mid-band voltage gain almost unchanged.
自检：若有人问” 为什么调RC 不行”，答”RC 同时在R′
L 里，改它会改增益”；若问”UCE = UCC/2 是
不是绝对标准”，答” 在交流负载线与直流负载线接近时是；接上RL 后严格标准是交流负载线中点”。

A.3
负反馈对动态指标的影响
题干
（教材p.148 第3 问）负反馈对放大电路的动态性能指标有什么影响？
考点：S1 断开引入的是电流串联负反馈，判断它对五个量各自的方向。
关键一步：负反馈的通则是” 以增益换性能”：Au 降、ri 升（串联）、ro 升（电流取样）、失真降、带
宽增。
详解：S1 断开后RE2 串在发射极，发射极电流的交流分量在RE2 上产生压降，使ube = ui −ieRE2
减小——这是电流串联负反馈。定量：Au = −βR′
L/[rbe + (1 + β)RE2]，分母变大，增益下降（本实验
约降到1/9）。串联反馈使输入电阻升高：ri = RB ∥[rbe + (1 + β)RE2]，从2.25 kΩ升到13.1 kΩ。电流
取样使输出电阻升高（ro 略大于RC）。反馈还使非线性失真减小（同样的输出摆幅下所需输入更大，
工作点相对摆幅更小）、通频带展宽（增益下降而带宽乘积近似不变）。
答案（英文可抄）：Negative feedback lowers the voltage gain, raises the input resistance, slightly raises
the output resistance, reduces nonlinear distortion and widens the bandwidth. In this experiment the
gain falls from about 62 to about 6.6 while the input resistance rises from 2.25 kΩto 13.1 kΩ.
自检：能说清” 为什么ro 升高”（电流取样把输出电流的变化反馈回来，抑制了电流变化，等效内阻变
大）。
A.4
功率放大电路与交越失真
题干（教材p.148 第4 问）功率放大电路有哪几种工作方式？什么是交越失真？怎样消除交越失真？
OTL 功率放大电路与OCL 功率放大电路有什么区别？
考点：甲类/乙类/甲乙类的导通角；交越失真的成因与消除；OTL 与OCL 的电源与输出电容差异。
详解：按导通角分：甲类（360◦，管子全程导通，失真小、效率低，最高约50%）；乙类（180◦，正负半周
各一只管子，效率高但交界处失真）；甲乙类（180◦∼360◦，给一点静态偏置，兼顾效率与失真）。交越
失真出现在乙类：信号过零附近两只管子都还没真正导通（uBE 小于死区电压），输出出现一段” 平”
的失真。消除办法是给输出级加一点正向偏置，让它工作在甲乙类（二极管或UBE 倍增电路）。OTL
（Output TransformerLess）单电源供电、输出端串一个大电容隔直；OCL（Output CapacitorLess）双
电源供电、输出直接接负载、没有输出电容。二者都不带输出变压器。
答案（英文可抄）：Power amplifiers are classified as class A, class B and class AB according to the
conduction angle. Crossover distortion occurs in class B because neither transistor conducts near the
zero crossing; it is removed by adding a small forward bias so that the stage works in class AB. An
OTL circuit uses a single supply and an output coupling capacitor, whereas an OCL circuit uses a
dual supply and no output capacitor.
自检：能说出” 为什么乙类效率高而失真大”（导通角小、静态电流小；但交界处死区）。
