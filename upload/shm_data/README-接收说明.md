## 3. 为什么没有直接取回（结论：卡在百度侧的下载鉴权）

- 匿名会话能：① 用提取码通过校验；② 列目录（`/share/list`，`root=1&view_mode=1`；子目录要带 `dir=/我的资源/shm_data`）。
- 匿名会话拿不到下载直链：页面 `loginstate=0`、`bdstoken` 为空、`sign`/`timestamp` 不下发；
  `/api/sharedownload`（带 `extra={"sekey":…}`）返回 `errno 2 请求失败`。
- 百度网页端对未登录用户的下载按钮走「**调端**」（唤起客户端）→ 属于平台策略，不是网络或沙箱问题。
- 另：即便拿到直链，1.37 GB 经本环境的代理链路下载也不现实。
