# 评分参照（rubrics）— 工作用摘要

> **用途**：`ielts-session` 的评分参照。给分时**逐条对照可观察行为**，不要凭整体印象给一个数。
> ⚠ 本表是按公开版评分标准整理的**工作用摘要**；与官方原文冲突时**以官方为准**。
> ⚠ 导师给的分是**估算**，不是官方分；需要可靠水平判断时按需外部校准，不设固定购买频率。

---

## 一、总分算术（最容易被搞错的一步）

总分 = **四科平均**，取最近的 0.5 档（.25 进、.75 再进一档）。

> **总分至少7.5 ⟺ 四科之和 ≥29**；恰好总分7.5对应四科之和29–30.5（满分36）。算术平均与取整后总分分别说清。

| 组合 | 之和 | 均分 |
|---|---|---|
| 8.0 + 8.0 + 6.5 + 7.0 | 29.5 | **7.5** ✅ |
| 8.0 + 8.0 + 7.0 + 7.0 | 30 | 7.5 |
| 7.0 + 7.0 + 7.0 + 7.0 | 28 | **7.0** ❌ |

→ **四科各考 7.0 不够。** 本项目的目标形态：听力 8 + 阅读 8 + 写作 6.5→7 + 口语 7。

**听力原始分**：官方公开的平均参考为5分16题、6分23题、7分30题、8分35题，均满分40题；具体卷次略有浮动。不补未经核对的完整半分换算表。
[官方评分说明](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail)。

## 二、写作四项（Task 2 口径；Task 1 的 TR 换成 Task Achievement）

| 档 | TR 任务回应 | CC 连贯衔接 | LR 词汇 | GRA 语法 |
|---|---|---|---|---|
| **6.0** | 各部分都回应，但深浅不一；立场相关，结论可能含糊或重复 | 有组织、有总体推进；连接词使用**可能过多或不当** | 词汇够用；尝试非常用词但**不准确**；拼写/构词错误不碍理解 | 简单句与复杂句混用；**错误不少**但很少影响理解 |
| **6.5** | 介于 6 与 7 之间 | | | |
| **7.0** | 回应各部分；**立场贯穿全文**；主要观点有展开与支撑，但可能过度概括 | 逻辑清晰、推进自然；衔接手段**用得恰当**（偶有过度/不足）；每段中心明确 | 词汇量**足以灵活、精确**表达；有非常用词，**搭配与语域基本得当**；偶有选词/拼写错误 | **句式多样**；**无错句频繁出现**；语法与标点控制良好，仍有少量错误 |
| **7.5** | 介于 7 与 8 之间 | | | |
| **8.0** | 充分回应各部分；**展开充分**，观点相关、有支撑 | **管理全部衔接手段**；分段充分且恰当 | **流畅使用广博词汇**；**熟练使用非常用词**，偶有不准确；拼写/构词错误**罕见** | **句式范围广**；**绝大多数句子无错**；偶有失误 |

**常见误判**：把"用了高级词/复杂句"当成 LR/GRA 高分。真正的分界是**准确性**（7 分要求"无错句频繁出现"，8 分要求"绝大多数句子无错"）。

**CC 的常见误判**：**不是"连接词多就扣分"**。band 6 原文是衔接手段"**可能用得不当或过度**"——扣分点是**不当／过度**，不是"用得多"。
CC 真正考的是**段落推进、指代清楚、信息组织是否自然**；通篇 however／furthermore 反而暴露衔接手段单一。
**连接词是症状，不是诊断。**

## 三、口语四项

| 档 | FC 流利与连贯 | LR 词汇 | GRA 语法 | PR 发音 |
|---|---|---|---|---|
| **6.0** | 愿意展开说，但**重复、自我纠正、犹豫**会打断连贯 | 够讨论话题，但**用得不精确** | 简单与复杂结构混用，**有错误** | 总体可懂；**个别音/词发音错误会降低清晰度** |
| **7.0** | 能**不费力地**长段表达；犹豫多与**内容**有关；偶有重复/自我纠正 | 有一定灵活性；能用非常用词，**偶有不恰当** | 复杂结构有一定范围；**无错句频繁**；仍有错误 | **总体易懂**；母语口音可见但**不妨碍理解**；能用一些语音特征 |
| **8.0** | **流畅**，只有偶尔重复/自我纠正；犹豫是**找内容**不是找语言 | **广博、灵活、精确** | 结构范围广；**绝大多数句子无错** | **全程易懂**；口音对可懂度**影响极小** |

**关键区分（7 vs 8 的 FC）**：7 分是"不费力，但犹豫可能来自语言"；8 分是"**犹豫只来自内容**"。
→ 所以流利度的训练目标是**把犹豫从"找词/找语法"变成"找观点"**。

## 四、给分前自检（三条）

1. **每一项都指到具体证据了吗？**（写"GRA 6.5"必须能指出是哪几句、哪类错误）
2. **四项是否分开评？** —— 不允许"整体感觉 7 分"然后四项都填 7。
3. **是否受"内容好不好"影响？** —— 观点平实但语言准确，LR/GRA 仍可 7+；观点精彩但错误多，TR 高而 GRA 不高。

## 应用边界（2026-10-04）
本表只作概括，不替代官方原文；官方公开分档描述按整数档，不发明“官方5.5逐项描述”。仅完整作文才给四项参考估分；单段反馈不套全篇分。没有音频时口语FC的时间表现和PR未测，转写只支持文字组织/词汇/语法线索。写作例证允许相关个人经历；四段、TEEL、反方段、每段一个地名案例、句首禁用And/So均不是评分要求。
