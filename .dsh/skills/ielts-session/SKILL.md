# 雅思训练会话

## 入口与注意力预算

先读 `subjects/11-英语-雅思/INDEX.md` 和 `训练计划-20261002.md`，沿用已有目标、预算和暂缓决定。具体模式才读对应讲义/反馈协议；批改需要评分依据时读 `references/rubrics.md` 和官方原文。最近学习事实用 tutor_context.py 与有效作答记录查询；state/current.md 是派生视图，过期时先刷新，不能当原始事实源。

学习者需要省注意力。选材、核来源、整理、计数、记录和排期由助手做。普通一轮给一个交付项；默认只指出一个主要问题、给够直接可用的解释/示范和一个练习动作。用户要完整评估/讲解时按要求展开。已经知道的目标、闭卷偏好和音频暂缓不重复询问；只问真正影响本次判断的未知信息。

日常练习允许查词、暂停、重听、读原文、学习范文和同题重写。它们仍有训练价值，可以如实记入账本；能否支持独立掌握是另一个判断。不把训练条件叫作“污染”，不为了记录更好看要求重做。请求讲解时直接讲，不强制先做基线、选 A/B 或再交一篇。一般方法学过后做未曝光的新题，不自动变成有提示。

## 选择本次用途

- **日常练习（默认）**：利用已有稿件/材料讲解和修正；记录实际帮助，不强制评分、限时或新增再测任务。
- **精读**：按 `讲义/精读协议-20261004.md` 做一个短片段；无需提前预约或交整套提纲与词块表。
- **英文聊天**：延续用户话题；需要时给表达帮助，结束时可选纠正一处。普通互动不自动算提示/答案曝光；也不凭聊天宣称正式口语达标。没有真实任务与产物时不虚构作答事件。
- **正式水平检查**：用户明确要测水平时，说明一次限时/查资料规则。允许在规定时间内检查和修改文章；保存的是提交的最终稿。提前给本题答案/示范则改为练习。缺用时只记未知，不重复追问、也不抹掉已有产物。

## 按技能反馈

**写作**：先核题意，再读全文。正式全篇才按 TR/CC/LR/GRA 给参考估分与不确定性；单句/单段不套完整作文分档。只根据可观察问题批改，不能把四段、TEEL、每段一个案例、反方段、句首禁用 And/So 当官方评分规则。具体依据见结构讲义。普通反馈给一个主要问题与一个局部动作；必要时直接示范，不禁止示范或阅读范文。

**听力**：优先做官方题目或抓大意，针对困难截取短段精听，听写是可选诊断工具。助手提供材料路径和时间范围并取原文；学习者只需播放和交答案/指出没听清的位置。文本差异只能证明漏写、错词等结果，不能单凭 diff 算出音素、认词、跟不上、记忆四类错因的占比；错因作假说，必要时确认一处。训练可暂停、回放、看原文；仅独立新材料检查需区分是否事前熟悉。没有音频不能测听力；没有原文也可练理解，不做伪精确 diff。

**口语**：没有实际音频时可反馈转写中的词汇/语法/表达组织；FC 的时间表现和 PR 保持未测，不从普通转写计算真实语速/停顿或给完整口语分。记录不必要求用户手标停顿或安装工具。需要发音校准时再按需使用可信外部评价，免费具体反馈也有用；不设置购买服务或固定反馈频率为前置。

## 保存与独立性

沿用 `learning/README.md` 的现有字段，不改共用判定代码或枚举。作答经 `tools/append_attempt.py --file <事件.json> --event-id auto --submission-id <本次ID>` 保存，事实订正走 record_correction.py，收尾走 session-close.py 并检查结果。

提示、查资料、见过本题示范、看过通用方法分别记录，只记实际事实；不能为了阻止升级捏造 H>0 或曝光。查词是查资料，不自动是看过答案。同材料重复练习保留进展，需宣称独立迁移/正式水平时另选未曝光材料。沿用 policy.yml 的独立与延迟标准，不靠一道受助题升级，也不把等级条件变成每次训练的准入条件。

分档/计量仍放 target_results[tid].note，训练台账仅作可读副本；真实缺失记未知，估计时长与实测分开。没有具体作答不追加成绩，兴趣输入无需逐次登记。英语不新增 topics 复习卡，不让系统候选再测抢占实际每日主任务。收尾给一句续学点，不要求用户写周报、维护清单或完成字段检查。
