# 详解标准与习题三档

这份文件解决两件事：**例题写成什么样才算"详解"**，以及**课件里的习题／作业怎么收**。两个问题在第五章讲义上都出过一次事故，模板就是从那次事故里提炼的。

---

## 一、详解四问

一道例题的解答写完后，要能回答下面四个问题。缺一个，就还是"把课件重打了一遍"。

1. **这一步为什么是这一步？**（动机）不写"由某某得"，要写"因为要消掉 X，所以两边乘 Y"。
2. **系数从哪来？**（来源）½、1/2π、2π、π 各自指回半留数／正交性／归一化约定。**数学来源与约定来源分开写**；两处同时出现时，补一句"这两个因子分工不同"。
3. **边界怎么办？**（定义域）`<`、`>` 之外的点，要么给值，要么说明为什么可以不给。
4. **答案长什么样、怎么自查？**（形态）闭式还是分段、量纲、极限、偶性、端点——挑两条能当场算的，写出来。

常见退化：只做第 2 步（把系数算对）而跳过 1、3、4，读者得到的是"能验算的答案"，不是"能复用的方法"。

### 好例 / 坏例（都出自第五章 §6）

坏例（原版）：

> 把它记成一句话：∫ e^{iβt}/(2iπt) dt = ½ sgn β。
> 三个区间，一张表：`|ω|<ω₀ | + | − | ½−(−½)=1` … 于是 F(ω) = {1/2π, |ω|<ω₀; 0, |ω|>ω₀}。证毕。

读者能背下这三行，却答不出"为什么是 ½ 而不是 1""ω=±ω₀ 时等于几""两个 sgn 为什么只有三种组合"。

好例（修订版）的骨架：

1. **先写被制表的式子**：∫f e^{iωt}dt = ½sgn(ω+ω₀) − ½sgn(ω−ω₀)；
2. **再解释两个 sgn 各读什么数**（两次比较，不是两只开关）；
3. **再列五行表**（含两条边界行），每格按表头的小式子可当场算；
4. **再给闭式** F = (1/4π)[sgn(ω+ω₀) − sgn(ω−ω₀)]，分段只是它的读数；
5. **最后给边界值** 1/(4π) 与理由（sgn 0 = 0，主值），并说明题面留空为何不算错。

## 二、表格三件套

（与 SKILL.md 硬性约束 9 配套；写表时逐项打勾）

- [ ] **表前一句**：这张表是把哪个式子在哪几段上读了一遍？（式子必须写出来）
- [ ] **逐行读法**：每行的符号／数值为什么是这个？（一行一句即可）
- [ ] **边界行**：端点单独成行，或明说端点归哪段、值多少。
- [ ] **列头是最终量还是中间量**：若是中间量，列头要写成 `最终量 = c₁×列1 ± c₂×列2` 的形状，让读者能倒推。

判断标准：**读者能不能逐格复算？** 能，才叫压缩；不能，就是删掉的推导。

## 三、习题三档

| 类型 | 判断依据 | 放哪 | 给多少 |
| --- | --- | --- | --- |
| 课上例题 | 课件正文有"例 n"且已给解 | 正文对应节 | 全解（过一遍四问） |
| 课后习题／作业 | 课件"习题／作业"页，或有题号无解 | 题面与详解**同一节相邻**（题面成组在前，详解紧随其后） | 五段式详解 + 答案 + 自检；用户要求"先做后看"时才挪到章末附录 |
| 无解答的思考题 | 有题无解，或明写"留给学生" | 正文对应节 | 只给"从哪一步想起"（关键一步），不给全解 |

### 每题详解的固定格式（五段，控制在一页内；放正文或附录都一样）

```latex
\subhdr{第 n 题（pXX）：一句话概括}
\textbf{考点}：对应本讲义哪一节、考什么。
\textbf{关键一步}：为什么这么想（不代算）。
\textbf{详解}：完整推导，关键代换显式写出。
\textbf{答案}：单独一行，写清适用范围（区间、端点、参数条件）。
\textbf{自检}：一个能当场算的检查（代入、极限、偶性、端点）。
```

硬要求：

- 题号、页码与课件一一对应；题面照抄时缺字要标 `[待确认]`，不许猜。
- 答案先用 `python -B tools/verify_math.py` 或数值积分复核（本技能踩过的坑：手推的 §6 三个区间值没错，但边界值从来没写）。
- 详解默认**紧跟题面**（同一节内，题面在前、详解在后），不许丢到文末让读者来回翻；只有用户明确要"先做后看"时才挪到章末附录，并在题面处写明位置。
- "完整"指每一步都能自己复算：分部积分的边界项、奇数项为什么为零、积化和差的中间一行、极限里的峰面积，都要写出来。答案本身只占一行，但支撑它的推导不能省。
