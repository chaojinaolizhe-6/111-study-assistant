# 生成、内容审核与委派返工

内容审核适用于讲义生成；以下独立留档与委派流程用于外部协调器委派 DSH 或验证 skill 效果，普通单次讲义不额外制造评测轮次。

## 内容验收：走过实际主线

依据备课记录和原材料核对核心问题、主要概念、重要结论及其关系；然后按讲义实际推荐的顺序（含最短路线）读到证明和应用。仅使用已确认基础与这条路线此前讲清的信息，不用审核者自己的知识补空白。用户授权先生成时采用的假设另标；依赖假设的结论不能说成已适配本人。

| 检查 | 需要的实际证据 | 需返工的情形 |
|---|---|---|
| 材料与基础 | 从原页识别主体、关系与依赖，再提出与本次有关的具体问题；复用确认信息并保留未知 | 未核材料就泛问基础；把课件出现、讲义覆盖或未回答当作掌握 |
| 前置严谨且足够 | 在首次依赖前能找到定义、对象、条件、适用范围和必要逻辑；复杂缺口有范围明确的模块及返回点 | 用未解释词解释新词；只补一句/一层；必要内容列为选读或以后再问；本节正式概念被重复补两遍 |
| 小例解决卡点 | 实际沿小例辨认对象、执行关键操作、理解它连接的概念/定理；检查原材料是否有合适例可复用 | 只有答案或数值核对；输入不激活所讲现象；难度过高；以例代定义或一般证明 |
| 重要证明完整 | 核条件到结论的真实印出链条及相关概念，逐步查关键依据、一般性和必要分支；详见数学子规则 | 重要定理仅陈述/外链/列选读；推导暗用未建立结果；用脚本通过冒充证明 |
| 主体及联系清楚 | 不依赖彩色标题也能从正文说清“当前问题—得到什么—怎样推进下一步”；逐段指认补充支持哪一步、结束后实际接回哪里 | 补充各自完整却切断主线；必要联系只剩箭头或口号；通过压薄前置突出主体；重复/无关支线占据解释重心 |
| 习题技巧适度 | 在实际使用步找到方法、用途和足够的局部说明；本节核心方法仍认真讲；题干与答案位置保持 | 为独立简单技巧另开理论分支；只写技巧名称却看不懂变换；把复杂必要依赖降为技巧；在正文泄露练习解法 |

遮住选读再走一次，主线仍能成立并用于约定应用。补充变长本身不是问题，页数、条目数和术语出现次数不是合格证据。选取有代表性的实际段落记录 `来源/讲义位置—当前任务—已提供信息—能否继续及依据—需修什么`；没有发现问题照实写，不硬凑。

返工后查受影响的前后依赖、证明、小例、返回主线处与实际分页；新解释不能再引入未说明术语。没有新变化或未决疑点时不重复已通过的检查。

分别报告来源覆盖、数学/事实正确性、阅读支持和学习者实际试读。审核可说“在声明的基础范围内未发现这个断点”，不能说“学习者已理解/学习效率已提高”。前后对比要核旧稿相邻页及已有说明，区分本轮目标变化与旧稿在原目标下的缺陷，不夸大成旧稿完全没讲。

## 分工与输入
- DSH 是成品执行者：独立读源资料、组织讲解、求解、制图、写验证脚本、编译、检查页面，并处理返工。
- 协调器维护 skill、给任务范围、只读审稿与报告结果。发现错误时给出「位置—问题—证据—验收目标」，不直接替换正文、解答、图代码或排版，不用自己的成稿冒充 DSH 结果。
- 首轮独立生成提供原始资料、本次 skill 和任务范围；用户要求旧稿返工或片段对比时，可提供指定旧稿并如实标为“基于旧稿的独立改写”。不提供协调器的替换正文、答案脚本或本轮已知漏洞清单。可把真实错误归纳为可复用规则，不能把当前样题整套答案藏入规则。
- 依据主流程先核材料再了解基础，随后把相关信息交给 DSH，区分自述、真实操作、未知和试验假设。关键未知项由协调器向学习者澄清，DSH 可先核资料但不编造回答。用于规则验证的假设性读者只检验相应条件下的行为，不冒充学习者诊断。

## 留档与返工
- 首稿输出在独立目录。外部反馈前保存首稿及其源文件、PDF、验证说明和文件哈希；首稿与反馈后版本分开，不覆盖首稿。
- 返工任务给原始资料、DSH 自己的上一版和问题单。DSH 自行核实、选择解法并修改，记录各问题的处理位置及未解决项，不能仅复述已修复。
- 修改公式后复核它的条件、计算与引用；修改布局后复看实际受影响页及续页，不为消除警告而删掉必要内容。出现相同错误时回看根因和适用规则，不只局部换字。
- 进程超时或失败时保留已生成产物及具体状态，由新的 DSH 任务按已完成进度继续；不能把协调器代写视为兜底成功，也不能在没有新证据时无限重试。

## 如实验收
区分「DSH 首稿」「收到审核意见后的 DSH 返工稿」「协调器直接修订稿」。只有前两者能用于说明 DSH 执行效果；后者如存在必须另标，不能混入独立生成对照。首稿反映无外部反馈的表现，返工稿反映带审核闭环的表现。

交付说明实际执行的检查、仍存问题与产物版本，不把进程退出成功、脚本通过或审核通过当作学习效果已经提高。审核仍有实质问题时继续交 DSH 处理；外部条件确实阻断时报告阻断与现有产物。

内容判断使用上面的统一标准，讲解深度依 [主线、前置与教学小例](worked-examples.md)，不另建一套计数门槛。反馈给问题证据和验收目标，不给可直接粘贴的替换稿；修改由 DSH 完成。
