# 电路、光路、装置与受力图

解释连接、路径、极性、方向或状态变化时加载，不限课程名。图中节点/元件/端口、方向、角度、距离、参数与本步计算逐项对应。整机图不能替代局部光程差、受力分解或电流路径图。

- 电路：连接、参考方向、电源极性清楚；依赖的导通/开关状态实际呈现。
- 光路：推导投影/光程差时标法线、倾角、比较平面、路径段与距离；分清实镜/等效镜、路程/光程。
- 标出的交点、投影点须落在相应线段或比较平面的实际交会处，相关线段画至正确端点；去回程用方向或线型区分，文字标签避开路径。
- 受力：对象、坐标轴、约束和力的方向清楚；轨迹图不能替代受力图。
- 两状态用两幅小图或可区分路径，配色之外加文字/线型。

图与解释相邻；长推导跨页可重复必要简图，不每页重画装置。检查时沿当前式子在图中逐项找对应；不要把遮图后无法脑补几何误判成图不合格。

对承载推导的自绘图，用图中的坐标或几何关系复算所用距离、角度和中心/对称极限，再与正文公式比较；文字说出的轴向、分离方向或正负约定必须在图中成立。

裁剪/重绘标来源页与方式，保留必要连接、极性、参数。题目要画图，答案实际给图；表可总结状态但不能替代拓扑。
