# lecture-deepdive —— 课件精讲讲义

输入：老师的课件 PDF（可多份）+ 章节范围。
输出：一份 `.tex` 与一份编译好的 `.pdf`，紫色花卉主题，公式由 LaTeX 原生排版，**每处课件跳步都有对应补齐**。

## 何时用 / 不用

- **用**：手上有一章课件，要把它变成能脱离课件自学的一份讲义；或已有讲义要按新主题重排并补逻辑。
- **不用**：出题、改卷、做 PPT、写摘要；课件本身没有的内容不要凭空讲。

## 硬性约束

下面十五条是**同一条规则的十五次落地**。先记那条规则，再记条文——条文会漏，规则不会：

> **局部自足**：读者翻到任意一处（一页、一节、一张表、一道题的详解），都应该**不回头**就能读懂这一处。凡是这一步要用到的对象——前提、结论的完整形式、题干、词的原形、常数从哪来——都必须出现在这一步的视野内，或者有一个不离开本页就能拿到的入口。**引用可以，悬空引用不行。**

判据只有一句：**把 PDF 随便翻到一页，这一页讲的是哪个词、哪道题、哪个式子，读者能不能一句话说出来？** 说不出来，就有一处信息还飘在别页上。

反方向同样要防：自足**不是**把前面全抄一遍。旁注给"陈述 + 本题记号"不给重证，题干复述条件不复述整章，原形给一个词不给整个词表。

十五条里六处最常漏的落点：约束 7（推导的前提供旁注）、约束 8（定理给完整原形式）、约束 9（表格配表前一句与逐行读法）、约束 13（详解块自带题干）、约束 14（词形表挂原形）、约束 15（器件级结论缺拓扑图）。其余各条的毛病都是同一个：读者手里缺了一个本来该有的东西。

1. **数学零臆造**。每个结论要么能回指课件页码（给出 `L7 p30，式(18)` 这样的坐标），要么给出完整独立推导。两者都做不到的，不写。
2. **缺口必须点名**。说"课件跳步"必须写出**页码 + 原文短语**（例：p35 的 "the terms containing $v$ cancel"），并说明本讲义补了什么。不点名 = 等于没补。
3. **只增不删**。课件里出现过的定义、定理、例题都要在讲义里有落点；合并可以，消失不行。
4. **不臆造考点**。没有往年题依据的，只写"基于本页内容的推断"。
5. **记号先统一**。开篇声明一次（如 $y_p$ vs $y_1$），全文不得混用。
6. **必须能编译**：两遍 `xelatex`，无 `Overfull \hbox`，无未解析引用，无缺字警告。
7. **前提旁注：把"回忆"改写成"认出"**。推导每走一步，凡所依赖的前提**不在本屏**（跨小节、跨页、跨讲，或前面是结论后面才使用），就在这一步旁边用小字给一条旁注（`\aside{}`）。旁注内容 = **陈述 + 代入本题的记号**，绝不重证；有前提条件（如 $y_p\neq0$、区间 $I$）一并写。判据只有一条：**读者读完这一步，能不能不离开这一页就执行下一步？**
   - **只在讲理处给**：推导、定理陈述、为什么成立。**题面（习题、例题的题干、作业）一律不给**——那是考回忆的地方。
   - 反例：写「由 Abel 定理得 $W=e^{-x^{2}/2}$」；正例：写「$a_1=x$，故 $W=e^{-x^{2}/2}$」并附旁注给出恒等式原文。
8. **定理写完整、写原形式**。定理块给**完整陈述**（对象、条件、结论三样俱全），并优先给出**原形式**；若原形式与常用形式不同（如 Abel 的微分形式 $W'+a_1W=0$ 与积分形式 (43)），先写原形式，再由它推出常用形式，并标明**课件给的是哪一个**。不得只写"由某某定理"就跳过陈述。
9. **表格不许替代理推导（压缩缺口）**。表格只有两类合法：① 三行以内、每行都能由上一行的代数得到（单位换算之类）；② 台账表（页码对照、记号表、性质速查），本来就不承载推导。**其余任何表都必须配三件套**：
   - **表前一句**：写出被制表的那个式子（"这张表只是把式 X 在三段上读了一遍"）；
   - **表后逐行读法**：每行的符号／数值为什么是这个；
   - **边界行**：端点单独成行，或明说端点归哪一段、值是多少。

   判据只有一条：**读者能不能逐格复算？** 不能复算的表 = 删掉的推导，不是压缩的推导。反例（本技能实际踩过）：把三个情形压成 `区间 | sgn(ω+ω₀) | sgn(ω−ω₀) | ½−(−½)=1` 四列表，而 `½sgn(ω+ω₀) − ½sgn(ω−ω₀)` 这个式子从头到尾没写。
10. **每个常数报户口**。答案里出现的每个数（½、1/2π、2π、π、±1）都要能指回"从哪来"：**数学来源**（半留数、正交性、高斯积分）与**约定来源**（归一化、正逆变换的取名）必须分开写。两处来源同时出现时，明说"这两个因子分工不同"。
11. **边界点不许留空**。答案里出现 `<`、`>` 而不带 `=` 时，要么给出端点值（用 sgn／阶跃／δ／主值得到的答案，端点通常是半值），要么明说"按惯例留空、不影响任何积分"并给出理由。不许既不写值也不解释。
12. **术语第一次出现就要落到本题**。禁造行话。"相容""平凡""可积""良态"这类词第一次出现时，用一句人话说明它在这一步指什么；能不用就不用。反例：把 p35 的"两个不等式无解"写成"两个符号必须相容"——后者听起来像新原理，其实只是空集。
13. **详解自带题干（一题一块）**。每道例题／作业的详解块，第一行必须是 `\qstem` 复述题干（含课件页码），并且题干与详解落在同一页；题块前加 `\qbreak`。判据只有一条：**把 PDF 翻到任意一页，能不能不回头就说出这一页在解哪道题、条件是什么？** 只有题面成组、详解另起的写法一律判不合格。反例（本技能实际踩过，2026-10-25）：七道作业的题面集中在一页，详解从下一页逐题展开，读者翻到第 4 题时只看到"考点／关键一步"，等于一道没有题干的题目。
14. **词形表以原形为锚（语言课：变格、变位、性数变化都算）**。这是"局部自足"在词形上的落地：纯词尾表只回答"怎么变"，回答不了"这是哪个词"，等于让读者去别处找一个本该在本页的原词——和"用结论却不给结论"是同一种悬空。凡把**同一个词的不同形式**排在一处（名词变格、形容词三性数、代词四列、动词六人称），必须同时给三样：
    - **原形排第一，并明写「原形」**：名词／形容词＝阳性单数第一格，动词＝不定式。再用一句话点明"**词典和词表只收这一个形式**"，以及"看到别的形式怎么退回它"（例：阴性 -ая／中性 -ое／复数 -ые 一律退回 -ый／-ий；-а́я／-о́е／-ы́е 退回 -о́й）。
    - **表头不许是裸词尾或裸词干**：每一列先挂一个**完整的原形词**，词尾另起一行（`\thead{硬词干\newline но́вый}`、`\thead{软词干\newline си́ний}`）。`но́в-`、`си́н-`、`-ый／-ий／-о́й` 这类半截记法只能出现在正文解释句里，**不能当表头**——读者拿它查不了词典。
    - **逐行读法从原形起手，顺序固定**：形容词"原形（阳）→ 阴 → 中 → 复"，名词"单数（原形）→ 复数"，动词"不定式 → 六个人称"。顺序本身就是信息，不许按"看起来好排"重排。

    判据只有一条：**读者只看这一段，能不能说出这个词的原形是哪一个、能不能拿它去词典里查？** 反例（本技能实际踩过，2026-10-25，俄语 §4.2）：逐行读法写了 `но́вый／но́вая／но́вое／но́вые` 等五串四形式，一个不少，却没标哪个是原形；表头只有 `-ый／-ий／-о́й` 三组裸词尾，族名用 `но́в-`、`си́н-` 这种残词干——读者手里没有一个能查词典的词。注意它连约束 9 的三件套都"通过"了，所以**三件套之外还必须有这一条**：表前那句要顺带说清"这张表是在哪个**原形词**上读的"。

15. **工程图先行：器件级/电路级结论先给拓扑图，表格只能做图的摘要。** 凡结论涉及"哪只管子导通""电流往哪走""开关通断""正反接""光往哪偏""力往哪分解""信号从哪一级到哪一级"，本页必须先有一张**拓扑/示意图**，再给表或公式。
    - **图的最低要求**：对象（元件、器件、节点）、端口/连接、极性/参考方向、关键参数；节点和元件要有名字（a、b、+、−、D1--D4），正文里的每个符号都能在图上找到。
    - **两个状态**：若结论依赖正/负半周、开关开/合、正接/反接、加载/空载，必须给至少两个状态图，或一张图 + 两条颜色不同的路径；不能只给一个状态让读者脑补另一个。
    - **表只是摘要**：先图后表；表前一句"这张表只是把图 X 的两条路径读了一遍"；表后逐行读法。**不允许用"D1 桥式整流"一个方框 + 导通表代替桥的接线图**。
    - **图必须在本页**：图放到下一节或附录，读者读到结论时看不到图，仍算局部自足破了。
    - 判据：**把本页的图遮住，读者还能不能从文字 + 表还原出连接/路径/极性？** 不能 → 图缺，必须补图。
    - 图可以重绘（TikZ/circuitikz）或从课件/教材裁剪；裁剪图标"裁剪"，重绘图标"重绘"，都要保留端口、极性、参数。不能拿一张没有标注的实物照片代替原理图。

## 工作流程

### 步骤 1 · 取材（先摸清课件结构）

```powershell
python .dsh\skills\lecture-deepdive\scripts\read_slides.py <课件.pdf> --pages 28-38 --map
```

`--map` 给出「页 → 首行」速查表，用来定范围；再去掉 `--map` 逐页读正文。
**纯图片页**（无文字层）会在表里标 ⚠️：引用页码前先确认，别拿 OCR 猜的内容当原文。

### 步骤 2 · 缺口勘探

按 [references/gap-checklist.md](references/gap-checklist.md) 的十一类逐页扫，每条记成：

> `类型 | 页码 | 课件原文短语 | 缺了什么 | 补法`

十一类：机制缺口 / 代数跳步 / 平凡解 / 拼接缺口 / 适用区间 / 答案形态 / **形式改写**（定理被换成推论形式陈述，如把 Abel 恒等式写成积分式 (43)）/ **压缩缺口**（多步推理被压成表、图或一句"综上"）/ **边界缺口**（答案的端点没有值）/ **原形缺口**（同一个词的形式排了一串，没有一个标着原形，也没有一个能拿去查词典）/ **图缺/图替**（器件级结论只有表或方框，没有拓扑图；或图在别页）。
**这一步是这份技能的核心**——没有缺口清单，就只是把课件重打了一遍。

### 步骤 2.5 · 习题勘探（例题与作业都要点名）

把课件里每一处「例 n」「习题」「作业」找出来，列一张表：`页码 | 题号 | 课件有没有解答 | 本讲义放哪`。三档处理：

- **课上例题** → 正文**全解**。全解不是答案，是把"为什么这么拆"讲透，四问标准见 [references/worked-examples.md](references/worked-examples.md)。
- **课后习题／作业** → 重写为**一题一块**：`\qbreak` + 标题 + `\qstem` 题干（带课件页码）+ 考点 + 关键一步 + 详解 + 答案 + 自检，六样同块同页。**禁止把若干题的题面集中放在一页、详解另起几页**——读者翻到某一题的详解时看不到条件，那就是一道没有题干的题目。只有用户明确要求"先做后看"时，才把详解挪到章末附录，并在每题题干下写清"详解见附录第几页"。
- **无解答的思考题** → 只给"从哪一步想起"（关键一步），不给全解。

**本工作区默认口径（2026-10-29 起，学习者指定「先做后看」）**：作业与例题的详解统一移到**章末附录**，按题号连排；正文题块只留 `\qstem` 题干 + 考点，并在题干下写一行「详解见附录第 X 页」。这样学习者可以先独立做、再回头对答案。附录里的详解块仍按「考点／关键一步／详解／答案／自检」写全，块首可用「（题干见正文第 X 页第 N 题）」——但前面必须有一句条件摘要，不能只有题号没有条件。**答案不得与题干同页**（否则等同于边做边看）。

只要有一题落在三档之外（例如只抄了题面、没给答案），交付前必须补。**"作业汇总（题面照抄）"这种写法不合法**：题面 + 无解 = 把课件那一页又抄了一遍。

### 步骤 3 · 搭骨架

按下面的顺序写，除非课件结构强烈不同（那就在 `§0` 里说明为什么改）：

```
§0  课件坐标：讲了在哪几页、哪些内容、哪几处是拼接
§1  机制/原理：课件直接给结论的那一步，补推导
§2–§3  两条主线（方法 A / 方法 B）
§4  两条线为什么等价（若课件分属两讲，这里就是拼接）
§5  主例题全程演算（补代数跳步 + 平凡解讨论）
§6  主例题里那个"算不下去"的地方为什么算不下去
§7  其余例题，一例半页，只写与主线不同的地方；末节收课件作业：一题一块（题干 + 五段详解）
§8  公式卡 / 四步用法（可执行的 checklist）
§9  易错点（每条都要能指回某个例子的某一步）
§10 缺口清单（步骤 2 的结果，逐条列出）
§11 三句话总结
§12 与课件的页码对照表
```

**作业详解的形态**：**一题一块，题干随题走**。块首用 `\qstem{（课件 pXX 第 N 题）题干…}` 复述条件，再接五段：考点／关键一步／详解／答案／自检；块前加 `\qbreak`，让整块落在同一页。作业若分几批布置（例如 p39 四道级数 + p63 三道变换），**必须按 1--7 连排后一次收齐**，并在块前的引导句里写明每批的页码与题型，别让读者以为后一批不存在。

### 步骤 4 · 写 `.tex`

```latex
\documentclass[11pt]{ctexart}
\input{../../../.dsh/skills/lecture-deepdive/assets/theme-violet}
\settags{<页眉左：本文标题>}{<页眉右：课程名>}
\begin{document}
\doctitle{<主标题>}{<副标题>}{<依据：课件文件名 + 页码 + 日期>}
...
\end{document}
```

可用宏（详见 theme 文件头注释）：

| 宏 | 用途 |
| --- | --- |
| `\hdr{§0}{标题}` | 带紫底编号徽章的节标题 |
| `\subhdr{...}` | 小节标题 |
| `\callout{...}` / `\warnbox{...}` | 浅紫框（档案/说明）/ 米白框（易错/边界） |
| `\tabtop` `\tabmid` `\tabbot` `\thead{}` | 三线表（本机 colortbl 不可用，勿用 `\rowcolor`） |
| `\gapitem{类型}{内容}` | 缺口条目（花饰项目符号） |
| `\aside{...}` | **前提旁注**：小字、紫灰、缩进，紧跟在需要它的那一步之后 |
| `\flowerrule` | 居中花饰分隔线 |
| `\qstem{...}` | **题干框**：详解块开头复述题干与页码，浅紫底、紫细边 |
| `\qbreak` | 一题一块的起页保护：剩余空间不足 0.92 页时先换页 |

**公式一律用 LaTeX**：行内 `$...$`、行间 `\[...\]`，积分号 `\int`、分式 `\frac`、`\dd` 是已定义的微分符。
不要用图片贴公式，也不要用 Unicode 上下标凑（`y″`、`C₁` 这类写法在讲义里一律禁止）。

**语言课的词形表**（硬性约束 14 的落地形态）：`\thead` 里换行用 `\newline`（**不能用 `\\`**——它在表格里是换行分隔符，会直接报 `Missing } inserted`），第一行写族名、第二行写**完整的原形词**：

```latex
\thead{硬词干\newline но́вый} & \thead{г／к／х\newline высо́кий} & \thead{软词干\newline си́ний}
```

更省事的写法是**把原形做成第一列、一行一个词**（族名放最后一列）：每格都是整词，读者一眼就能看出原形、也能直接拿去查词典——这类表不必再另附"词尾一栏"，词尾从整词对比里自然看出来。**不许**写成 `\thead{-ый} & \thead{-ая} & \thead{-ое}` 这种纯词尾表头。

**定理块的标准写法**（硬性约束 8 的落地形态）：

```latex
\subhdr{Abel 恒等式（原形式）}
设 $y_1,\dots,y_n$ 是 $y^{(n)}+a_1(x)y^{(n-1)}+\cdots+a_n(x)y=0$ 在区间 $I$ 上的 $n$ 个解，
则其朗斯基行列式满足
\[ W'+a_1(x)W=0 . \]
用积分因子 $e^{\int a_1\dd x}$ 解这个一阶线性方程，取 $W(x_0)$ 作初值，得
\[ W(x)=W(x_0)\exp\left(-\int_{x_0}^{x}a_1(t)\dd t\right). \]
\aside{课件 L8 p50 直接给出的是积分形式（式 43）；微分形式只出现在该页引言句
“satisfies a differential equation of first order” 里，未单独编号。}
```

顺序固定：**原形式在前 → 常用形式由它推出 → 旁注说明课件给的是哪一个**。
