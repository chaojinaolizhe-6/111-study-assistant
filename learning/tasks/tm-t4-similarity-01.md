## 一、[课件原文] 起手式（p30）

1. **拉氏量乘以任意常数不改变运动方程** ⟹ 可以由此得到运动性质的结论，**而不必积分运动方程**。
2. 适用情形：**势能是坐标的齐次函数**
   ```
   U(α r⃗ₐ) = α^λ U(r⃗ₐ)          λ = 齐次度
   ```
3. 同时变换**坐标与时间**（p30 的 EXERCISE）：`r⃗ₐ → α r⃗ₐ`，`t → βt`
   ```
   L′ = Σ_a m (d(α r⃗ₐ)/d(βt))²/2 − U(α r⃗ₐ)
      = (α²/β²) · Σ_a m ṙ⃗ₐ²/2 − α^λ U(r⃗ₐ)
   ```
   要求 `L′ = C·L`（仍为原 L 的常数倍）⟹ `α²/β² = α^λ` ⟹
   ```
   β = α^(1−λ/2)        ← 时间标度指数
   ```
   ⟹ **运动方程不受该变换影响**（两个系统"力学相似"）。

## 二、[课件原文] 缩放律（p31）

- 所有坐标按同一因子缩放 ⟺ 轨道换成**几何相似、尺寸不同**的轨道；
- 对应点之间的时间间隔比：`t′/t = (l′/l)^(1−λ/2)`（`l′/l` = 线度比）
- **任意**力学量在对应点的比值 = 线度比的幂：

  | 量 | 比 |
  |---|---|
  | 速度 | `v′/v = (l′/l)^(λ/2)` |
  | 能量 | `E′/E = (l′/l)^λ` |
  | 角动量 | `\|L⃗′\|/\|L⃗\| = (l′/l)^(1+λ/2)` |

## 三、[课件原文] 三个例子（p32）—— 关键是先读出 λ

| 系统 | U | λ | 结论 |
|---|---|---|---|
| 小振动 | `kx²/2` | **2** | `t′/t = 1` ⟹ **周期与振幅无关** |
| 均匀力场 | `mgz` | **1** | `t′/t = √(l′/l)` ⟹ 自由落体时间 ∝ √(初始高度) |
| 牛顿引力 | `−α/r` | **−1** | `(t′/t)² = (l′/l)³` ⟹ **开普勒第三定律** |

## 四、[课件原文] Virial 定理（p34，也标 EXERCISE）

```
2T̄ = k Ū            （k 即上面的 λ，符号不同、含义相同）
```
配合 `T̄ + Ū = E` ⟹
```
Ū = 2E/(k+2)        T̄ = kE/(k+2)
```
- 小振动 `k = 2` ⟹ `T̄ = Ū`
- 牛顿引力 `k = −1` ⟹ `2T̄ = −Ū`，`E = −T̄`；且**只在总能量为负时**运动才局限在有限区域
