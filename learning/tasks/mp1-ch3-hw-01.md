## 题目

**1. 计算下列级数的收敛半径**
1) Σ_{n≥1} (1/n²) zⁿ
2) Σ_{n≥1} nⁿ zⁿ
3) Σ_{n≥1} (n!/nⁿ) zⁿ

**2.** 在 |z| < 1 的圆内，将 f(z) = e^z/(1−z) 展开成泰勒级数。

**3.** 将下列函数在指定的区域内展成洛朗级数
1) (z+1)/(z²(z−1))，　0 < |z| < 1；　1 < |z| < ∞
2) e^z/(z(z²+1))，　0 < |z| < 1

**4.** 确定下列函数在有界区域内的孤立奇点，并指出奇点的类型（对于极点，要指出它的阶）
1) (z−1)/(z(z²+1)²)
2) (1−cos z)/z³
3) 1/(z²+i)²
4) e^z/(e^z−1)
