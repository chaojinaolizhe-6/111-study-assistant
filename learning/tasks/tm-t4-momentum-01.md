# Topic 4 ③ 动量守恒（空间均匀性 Homogeneity of Space）

> **课件范围**：`subjects/01-理论力学/课件/TM_Topic_04_2026_student.pdf` **p13–p19**（已**渲染读图**核对，2026-09-30）。
> 其中 **p14、p15 标了 `EXERCISE`** —— 这两页的推导**课件要求自己完成**，正好当本块的练习。
> 下面标 **[课件原文要点]** 的是读图所得；标 **[教学归纳]** 的是导师整理。

## 一、[课件原文要点] 主线（p14）

对变化量的一般写法：`δL = Σ_a (∂L/∂r⃗ₐ)·δr⃗ₐ + Σ_a (∂L/∂v⃗ₐ)·δv⃗ₐ`

**考虑"把系统在空间中整体平移"**：`δr⃗ₐ ≡ ε⃗`（各质点同一个位移）、`δv⃗ₐ = 0`

⟹ `δL = ε⃗ · Σ_a ∂L/∂r⃗ₐ`

**封闭力学系统**（closed）下平移不改变 L ⟹ `δL = 0` ⟹ `Σ_a ∂L/∂r⃗ₐ = 0`

再由拉格朗日方程 `d/dt(∂L/∂q̇ᵢ) − ∂L/∂qᵢ = 0`（即 p14 右下角那个式子）⟹ `d/dt Σ_a ∂L/∂v⃗ₐ = 0`

## 二、[课件原文要点] 动量（p15–p16）

- 定义 `P⃗ ≡ Σ_a ∂L/∂v⃗ₐ`，课件把它叫 **momentum of the system**，并给了三条理由：
  ① 量纲就是动量；② 对**封闭**系统是常量；③ 对本情形还可写成 `P⃗ = Σ_a p⃗ₐ`
- p15 的 **EXERCISE**（给了 Hint：从 `L = Σ_b m_b v_b²/2 − U(r⃗_b)` 出发）就是要你从 L 出发验证 `P⃗ = Σ p⃗ₐ`
- **可加性**：即使质点间有相互作用，`P⃗` 仍是可加的运动积分（因为它的值不依赖相互作用细节）
- p15 末：`Σ_a ∂L/∂r⃗ₐ = −Σ_a ∂U/∂r⃗ₐ = Σ_a f⃗ₐ = 0`；**N = 2 特例**：`f⃗₁ + f⃗₂ = 0` = **作用与反作用**（p16 标注：**牛顿第三定律**）
- p16 的把两条串起来：`Σ∂L/∂r⃗ₐ = 0` ⟹ `d/dt Σ∂L/∂v⃗ₐ = 0` ⟹ **牛顿第一定律**；"动量守恒"的条件写作 **封闭系统**

## 三、[课件原文要点] 非封闭系统（p17–p18）

- 非封闭系统**动量一般不守恒**，但**沿某方向的投影可能守恒**：`dP_n/dt = n⃗ · Σ_a f⃗ₐ = n⃗ · F⃗`
- 课件给三条**等价**可能性：① 合力在该方向的投影为 0；② 势能沿该方向的导数为 0；③ 拉格朗日量沿该方向的导数为 0
- 例子（课件配图）：斜面上的滑块——外力 `F`、支持力 `R`、重力 `mg`
- p18：**若某方向受力为零 ⟹ 该方向动量守恒；相应的广义坐标叫循环坐标**，可直接得到运动积分

## 四、[教学归纳] 与本块相关的前置

- `pᵢ = ∂L/∂q̇ᵢ`（广义动量）在 Topic 3 已学；`P⃗ = Σ ∂L/∂v⃗ₐ` 就是它在**直角坐标整体平移**下的形式
- **循环坐标**（L 不显含某 q）⟹ 对应的 `p = ∂L/∂q̇` 守恒（Topic 3 的结论），这正是"某方向对称 ⟹ 该方向动量守恒"的拉格朗日版本

## 五、诊断（2026-09-30，教学式）

三问（不给方法提示，答不出写"不会"）：

3. 非封闭系统动量一般不守恒，但**某方向**仍可能守恒：判据是什么？

## 六、核验要点（导师用，作答前勿看）

| 问 | 期望要点 |
|---|---|
| 1 | 整体平移 `δr⃗ₐ = ε⃗`、`δv⃗ₐ = 0` ⟹ `δL = ε⃗·Σ∂L/∂r⃗ₐ`；封闭系统 ⟹ `δL = 0` ⟹ `Σ∂L/∂r⃗ₐ = 0`；再用拉格朗日方程 ⟹ `d/dt Σ∂L/∂v⃗ₐ = 0`。**关键不是背结论，而是"空间均匀 ⟹ 整体平移不改变 L"这一步** |
| 2 | 量纲是动量 / 封闭系统下是常量 / 等于 `Σp⃗ₐ`（任一条即可，最好能说"从 `L = Σ½mv² − U` 出发可验证"） |
| 3 | `n⃗·F⃗ = 0`（合力在该方向投影为零）或等价地 `∂U/∂该方向 = 0`、`∂L/∂该坐标 = 0`；并能说出**该坐标是循环坐标** |

⚠ **验收须用应用题**（不是复述）：例如给一个外力沿 z 的系统，问哪两个方向的动量守恒并写出对应的 `P_x`、`P_y` 表达式与守恒理由；⚠ 不得复用 `attempt-4`/`attempt-7` 已全曝光的题。
