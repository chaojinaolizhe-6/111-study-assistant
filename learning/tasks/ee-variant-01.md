## 题 A｜直流电路：节点法 + 稳态 + 电源/负载判定

**电路**（请自己画图）：取电源负极公共端为参考点（地），所有支路并到**节点 A**：

- 支路 1：理想电压源 `E₁ = 12 V`，正极经 `R₁ = 100 Ω` 接到节点 A
- 支路 2：理想电压源 `E₂ = 6 V`，正极经 `R₂ = 100 Ω` 接到节点 A
- 支路 3：`R₃ = 200 Ω`，从节点 A 到地
- 支路 4：`C = 10 μF`，从节点 A 到地

**求**：
1. 列出节点 A 的 **KCL 方程**（用节点电位 `V_A` 表示；注意支路 4 怎么处理）

3. 求三条电阻支路的电流 `I₁`（规定"从 E₁ 经 R₁ 流向 A"为正）、`I₂`、`I₃`
4. 电容支路的稳态电流 `I_C = ?` 为什么？
5. **判定 `E₂` 此时是电源还是负载**（给依据）
6. 用数值**验证功率平衡**（发出 = 吸收）

## 核验要点（导师用，作答前勿看）

### 题 A

| 步 | 答案 |
|---|---|
| KCL | `(V_A − 12)/100 + (V_A − 6)/100 + V_A/200 + 0 = 0`（C 支路稳态**开路**，电流 0，不参与） |
| V_A | ×200：`2(V_A−12) + 2(V_A−6) + V_A = 0` ⟹ `5V_A = 36` ⟹ **V_A = 7.2 V** |
| I₁ | `(12 − 7.2)/100 = 48 mA`（**流入** A） |
| I₂ | `(6 − 7.2)/100 = −12 mA` ⟹ 实际 **12 mA 从 A 流入 E₂ 正极** |
| I₃ | `7.2/200 = 36 mA` |
| KCL 校验 | `48 − 12 = 36` ✓ |
| I_C | **0**（直流稳态电容相当于**开路**；电感才是短路） |
| E₂ 判定 | **负载**：电流从 A 流进 E₂ 的**正极** ⟹ E₂ **吸收** `6 V × 12 mA = 72 mW`（不是发出） |
| 功率平衡 | 发出：E₁ `12 × 48 mA = 576 mW`；吸收：E₂ `72` + R₁ `4.8²/100 = 230.4` + R₂ `1.2²/100 = 14.4` + R₃ `7.2²/200 = 259.2` = **576 mW** ✓ |

> ⚠ **数字设计事故与订正（2026-09-30）**：题 A 最初取 `R₂ = 200 Ω`、`R₃ = 300 Ω` ⟹ `V_A = 90/11 V`（循环小数，
> 旧答案：`I₁ = 38.18 mA`、`I₂ = −10.91 mA`、`I₃ = 27.27 mA`、功率 458.2 mW）。

### 题 B

| 量 | 答案 |
|---|---|
| ω | `2π × 1000 = 6283 rad/s` |
| X_L | `ωL = 6283 × 0.040 = 251.3 Ω` |
| X_C | `1/(ωC) = 1/(6283 × 5×10⁻⁶) = 31.8 Ω` |
| X | `X_L − X_C = 219.5 Ω` |
| \|Z\| | `√(50² + 219.5²) = 225 Ω` |
| I | `U/\|Z\| = 10/225 = 44.4 mA`（有效值） |
| φ | `arctan(219.5/50) = 77.2°`，**感性**，电流**滞后**电压 77.2° |
| f₀ | `1/(2π√(LC)) = 1/(2π√(2×10⁻⁷)) = 356 Hz` |
| Q | `(1/R)√(L/C) = (1/50)×89.44 = 1.79`（＝谐振时 `X_L/R`，自检一致） |
| 调到 f₀ | `X_L = X_C` ⟹ `\|Z\| = R = 50 Ω` 最小 ⟹ `I = 10/50 = 200 mA` **变大**（谐振时电流最大） |

**常见错点**：① 忘了 `X_L − X_C` 要**相减**直接相加；② 用**幅值** 14.14 V 当有效值算 I；③ `Q` 与 `f₀` 的单位（Hz / 无量纲）；④ 电源/负载只看"有没有电源符号"而不看**电流方向相对正极**。
