## 第 1 组（p28）利用留数定理，计算如下积分

1. `∮_C dz / ((z² + 1)² (z − 1))`，其中 `C: |z − 1| = 2`
2. `∮_C (cos z)/z³ dz`，其中 `C: |z| = 1`
3. `∮_C 1/(z sin z) dz`，其中 `C: |z| = 1`
4. `∮_C e^(2z)/(z² + 1) dz`，其中 `C: |z| = 2`

## 第 2 组（p62）计算如下实变函数的积分（**有理三角 ∫₀^{2π}**）

1. `∫₀^{2π} dθ/(2 + cos θ)`
2. `∫₀^{2π} dθ/(1 + ε cos θ)²`，`0 < ε < 1`
3. `∫₀^{2π} dθ/(1 + sin²θ)`
4. `∫₀^{2π} dθ/(1 + cos²θ)`

## 第 3 组（p62）计算如下实变函数的积分（**有理函数的无穷积分**）

1. `∫_{−∞}^{∞} x² dx/((x² + 1)(x² + 4))`
2. `∫₀^{∞} x² dx/(x⁴ + a⁴)`，`a > 0`
3. `∫_{−∞}^{∞} x² dx/(x² + a²)²`，`a > 0`

## 第 4 组（p78）计算如下实变函数的积分（**含三角的无穷积分，用约当引理**）

1. `∫_{−∞}^{∞} cos(mx) dx/((x² + 1)(x² + 4))`，`m > 0`
2. `∫_{−∞}^{∞} x sin x/(x² + 1) dx`
3. `∫_{−∞}^{∞} x sin(mx)/(x² + a²)² dx`，`m > 0`，`a > 0`
