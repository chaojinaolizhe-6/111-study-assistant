# C00-01 解释器、终端与项目目录

> **性质**：单元短验（baseline）。学习者自评「路径 3、终端/环境 2」，单元设计允许「短验后跳过已有能力」，因此本任务不整章重讲，而是用**只读命令**先确认项目实际使用哪个 Python，再逐步加一个输出。
> **未学门禁**：C00-01 在此前 0 次作答，属【未学】。概念不清时先讲「脚本 / 解释器 / 工作目录 / 第三方环境」四者关系，并给一个平行小例子，再动手。
> **帮助约定**：本课允许查资料与用 AI。查了什么、AI 生成了什么、学习者解释/验证/修改了什么，分别记录。

## 步骤（一次只做一个，做不了就如实说）

1. **只读确认解释器**（不建文件、不改环境）：在练习目录打开终端，运行

   ```powershell
   python -c "import sys; print(sys.executable)"
   ```

   说出输出那一行**指向的是什么文件**，以及它和你编辑器里选中的解释器是否同一个。

2. **写一个小脚本** `练习/c00-01/whoami_env.py`，打印三件事：

   ```python
   import os, sys
   print("解释器：", sys.executable)
   print("代码文件：", __file__)
   print("工作目录：", os.getcwd())
   ```

   用自己的话解释这三个输出为什么可能各不相同。

3. **换目录启动**：从**另一个目录**用同一个解释器运行同一脚本，比较哪些输出变了、哪些没变；再故意写一个用相对路径读文件的例子，说明它在哪个目录下会失败、怎么改。

4. **变式**：给出另一条启动路径（例如 `python 练习/c00-01/whoami_env.py` 与先 `cd` 再运行），判断代码文件在哪、工作目录在哪。

## 验收依据

- 能指出实际解释器（不是「应该是某个版本」）。
- 换运行目录后能解释相对路径变化。
- 自述会路径时，允许用现成输出直接验证，不重复讲基础。
