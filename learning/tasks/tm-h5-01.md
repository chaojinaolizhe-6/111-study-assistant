> 英文原文（已读图核对）：**all constants are positive**

Obtain the law of motion for a point particle moving in the potential

```
U(x) = A(e^(−2αx) − 2e^(−αx))          （Morse 势）
```

Initial conditions: `x(0) = x₀`，`ẋ(0) = ẋ₀ > 0`

**Subtasks**

1. plot the sketch of the potential;
2. obtain the allowed **E** values（分别讨论 E > 0、E = 0、E < 0）;
3. find the turning points as the function of **E**. Define the possible types of motion;
4. find the law of motion depending on the particle's total energy.

## 核验要点（导师用，不对学习者展示）

- **草图**：`U′ = 2Aα(e^{αx} − 1)e^{−2αx}` ⟹ 唯一驻点 `x = 0`；`U(0) = −A`；`U″(0) = 2Aα² > 0`（极小）；`x → −∞` 时 `U → +∞`，`x → +∞` 时 `U → 0⁻`；零点 `x = −ln2/α ≈ −0.693/α`。（sympy 复核 ✓ `_scratch/h51-check2.py`）
- **允许能量**：`E ≥ −A`。
  - `E = −A` ⟹ 静止于 `x = 0`（稳定平衡）；
  - `−A < E < 0` ⟹ 两个转向点，**束缚周期振荡**；
  - `E = 0` ⟹ 一个有限转向点 `x = −ln2/α`，另一端 `x → +∞` 且速度 → 0（**临界**，无穷远处趋于静止）；
  - `E > 0` ⟹ 一个转向点（在 `x < 0` 侧），**无界运动**（粒子被"反射"后逃向 `+∞`）。
- **转向点**：令 `u = e^{−αx} > 0`，则 `A(u² − 2u) = E` ⟹ `u = 1 ± √(1 + E/A)`，`x = −(1/α)·ln u`。
  `E > 0` 时 `u₋ < 0` 无效（只剩一个转向点）；`E = 0` 时 `u₋ = 0` 对应 `x → +∞`。
- **运动规律**：`t = ±∫ dx/√((2/m)(E − U(x)))`；配方 `E − U = (E + A) − A(e^{−αx} − 1)²`，换元 `u = e^{−αx}` 可积出解析式；符号分支与积分常数由 `x₀`、`ẋ₀ > 0` 定。
- **自检点**：`α` 的量纲 1/长度；小振动极限 `E → −A` 时周期 `T → 2π/ω`，`ω = α√(2A/m)`（由 `U″(0) = 2Aα²` 得）；`E → 0⁻` 时周期 → ∞。
