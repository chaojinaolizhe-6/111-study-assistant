# 有效势换函数变式（2026-10-19 建立）

> 用途：H5.2 已看过全解（全曝光），不能当独立证据；用**换势函数**的新题检验 `tm.t5.effective-potential` 与 `tm.t5.central-motion-types` 是否真的能迁移。
> 数量级与数字从简：取 `k = m = 1`、`L = 1` 时 `r* = 1`、`E_min = 1`、`E = 5/4` 的两个转向点是 `√2` 与 `1/√2`。

## 题目

一个质量为 `m` 的质点在有心力场

  U(r) = ½kr²　（k > 0，三维各向同性谐振子）

中运动，角动量为 `L`。三个子任务：

1. 写出有效势 `U_eff(r)`；说清 `r → 0⁺` 与 `r → +∞` 两端各由哪一项主导、极限分别是多少；画出草图，并判断**本题要不要按参数比值分档**（要或不要，都要给理由）。
2. 给出允许的 `E` 值，以及最小能量 `E_min` 是多少；`E = E_min` 时是什么运动。
3. 把转向点写成 `E` 的函数（本题能解出闭式），并逐段说明运动类型；特别说明：**在这道题里会不会出现「落向中心」或「无限运动」**，为什么。

（建议先取 `k = m = L = 1` 代入核对：`r* = 1`、`E_min = 1`；`E = 5/4` 时两个转向点为 `r = √2` 与 `r = 1/√2`。）

## 核验要点（导师用，不对学习者展示）

- `U_eff = ½kr² + L²/(2mr²)`。两端都是 `+∞`：`r→0⁺` 由离心项 `L²/(2mr²)` 主导（∝ r⁻²），`r→+∞` 由 `½kr²` 主导。
- **不按参数分档**：两端极限与单调性结构不随 `k, m, L` 改变（始终是单一口袋），只有极小点位置 `r* = (L²/(km))^(1/4)` 与高度 `E_min = L√(k/m) = Lω` 随参数变。答「要分档」＝没抓住「H5.2 需要分档是因为 `−γ/r³` 与离心项争主导权」这一点。
- 驻点：`kr − L²/(mr³) = 0 ⟹ r* = (L²/(km))^(1/4)`；`U_eff''(r*) = 4k > 0`（极小，稳定圆轨道）。
- 转向点：`km r⁴ − 2mE r² + L² = 0 ⟹ r² = [E ± √(E² − (Lω)²)]/k`，`ω = √(k/m)`。要求 `E ≥ Lω` 才有根。
- 运动类型：`E < Lω` 无运动；`E = Lω` 圆轨道 `r = r*`；`E > Lω` 两个转向点 `r_min < r* < r_max`，环内（有限）运动。三维谐振子的有限轨道是**闭合椭圆**（与 `1/r` 势同为唯二闭合的中心力场）。
- 不会出现「落向中心」：`r→0⁺` 端是 `+∞`，离心项无法被压过（没有 `−γ/r³` 那样的负幂吸引项）；也不会出现「无界」：`r→+∞` 端也是 `+∞`。
- 量纲自检：`Lω` 是能量；`(L²/(km))^(1/4)` 是长度。
