## 题目

1. `f(z) = (e^z − 1 − z) / z³`，`z = 0`
2. `f(z) = 1 / (e^z − 1 − z)`，`z = 0`
3. `f(z) = (ln(1+z) − z) / z²`，`z = 0`
4. `f(z) = e^(1/z) / z`，`z = 0`

## 核验要点（导师用，作答前勿看）

工具：`e^z = 1 + z + z²/2! + z³/3! + …`；`ln(1+z) = z − z²/2 + z³/3 − …`

| # | 分子零点阶数 | 分母零点阶数 | 答案 | 陷阱 |
|---|---|---|---|---|
| 1 | **2**（`e^z − 1 − z = z²/2 + z³/6 + …`） | 3 | **一阶极点**（`= 1/(2z) + 1/6 + …`） | 必须展开到**第二项**才看得见 `z²`；只看"分母 z³" → 误答三阶 |
| 2 | 0 | **2**（分母本身即 `z²/2 + …`） | **二阶极点** | 分母的零点阶数**不是 1**——`e^z − 1` 才是 1 阶，减去 `z` 后剩 `z²/2` |
| 3 | **2**（`ln(1+z) − z = −z²/2 + z³/3 − …`） | 2 | **可去奇点**（极限 −1/2） | 分子分母同为 2 阶 → 0 个负幂项；不要因为"分母也是 z²"就答极点 |
| 4 | — | — | **本性奇点**（`= z⁻¹ + z⁻² + 1/(2z³) + …`，负幂项无限） | 乘以 `1/z` 不改变"本性"；易误答"某阶极点" |

**记录要求**：initial / final 分开；`hint_level` 必须为 0 才算 H0；错题记错因假设（因子未展开 / 分母阶数数错 / 可去误判为极点 / 本性误判为极点）。
