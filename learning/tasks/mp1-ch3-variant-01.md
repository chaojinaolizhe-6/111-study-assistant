## 题目（两小题 + 一问）

**A**：`f(z) = 1 / ((z − 2)(z − 3))`
1. 在 **`|z| < 2`** 内展成级数（并说明这里为什么可以用**泰勒**、收敛半径是多少）；
2. 在 **`|z| > 3`** 内展成级数（写清 `w` 怎么选、通项、**别忘了提出来的因子**）。

**B**：`f(z) = 1 / ( z² (z + 1) )`
1. 在 **`0 < |z| < 1`** 内展成洛朗级数（写出通项）；
2. 在 **`|z| > 1`** 内展成洛朗级数（写出通项）；
3. 指出 `z = 0` 与 `z = −1` 各是哪一类奇点、**几阶**。

> 数值按 `teaching-conventions.md` §7 选得干净（2、3、1）。

## 核验要点（导师用，作答前勿看）

### A：`1/((z−2)(z−3)) = 1/(z−3) − 1/(z−2)`（部分分式）

**① `|z| < 2`（泰勒区）**：两个极点都在 2、3 处 ⟹ 以 0 为中心的泰勒收敛半径 **R = 2**（到最近奇点）。
```
1/(z−3) = −(1/3)·1/(1 − z/3) = −Σ_{n≥0} zⁿ/3^(n+1)      （|z| < 3）
1/(z−2) = −(1/2)·1/(1 − z/2) = −Σ_{n≥0} zⁿ/2^(n+1)      （|z| < 2）
⟹ f = Σ_{n≥0} ( 1/2^(n+1) − 1/3^(n+1) ) zⁿ              （|z| < 2）
```
（也可直接说：`|z|<2` 内 f 解析 ⟹ 泰勒；负幂项全 0。）

**② `|z| > 3`（外部洛朗区）**：**必须提出因子**（这就是 attempt-19 丢过的那一步）
```
1/(z−3) = (1/z)·1/(1 − 3/z) = Σ_{n≥0} 3ⁿ / z^(n+1)      （|z| > 3）
1/(z−2) = (1/z)·1/(1 − 2/z) = Σ_{n≥0} 2ⁿ / z^(n+1)      （|z| > 2）
⟹ f = Σ_{n≥0} (3ⁿ − 2ⁿ) / z^(n+1)                      （|z| > 3）
```
⚠ **判分要点**：把 `(1/z)` 提出来之后**必须乘回通项**（写成 `Σ(3ⁿ−2ⁿ)/z^(n+1)` 或 `(1/z)Σ(3ⁿ−2ⁿ)/zⁿ` 都对；**漏掉 `1/z` 即错**）。

### B：`1/(z²(z+1))`，极点 `z = 0`（**二阶**）、`z = −1`（**一阶**）

**① `0 < |z| < 1`**（把 `1/(z+1)` 展开，`|z| < 1`）
```
1/(z+1) = 1 − z + z² − z³ + …  = Σ_{n≥0} (−1)ⁿ zⁿ
⟹ f = (1/z²)·Σ_{n≥0}(−1)ⁿ zⁿ = Σ_{n≥0} (−1)ⁿ z^(n−2)
     = 1/z² − 1/z + 1 − z + z² − …                       （0 < |z| < 1）
```
**② `|z| > 1`**（提出 `1/z³`）
```
1/(z²(z+1)) = (1/z³)·1/(1 + 1/z) = (1/z³)·Σ_{n≥0} (−1)ⁿ / zⁿ
            = Σ_{n≥0} (−1)ⁿ / z^(n+3)                     （|z| > 1）
```
**③ 奇点判定**：`z = 0`：分母 `z²` 二阶零点、分子不为零 ⟹ **二阶极点**；`z = −1`：分母一阶零点 ⟹ **一阶极点**。
