# HW：Solve the following homogeneous systems Y′ = AY

| # | A |
|---|---|
| (1) | `[[1, 1, −3], [3, 2, −3], [1, 0, 1]]` |
| (2) | `[[−2, 1], [−5, 2]]` |
| (3) | `[[−2, −1, 1], [−3, −3, 2], [−4, −3, 2]]` |
| (4) | `[[1, 1], [9, 1]]` |

**截止**：2026-10-18（第七周周日）23:59。题面截图：`upload/20261012-ODE-Lecture14-15-Q1.jpg`。

## 核验要点（导师用，不对学习者展示；全部用 sympy 复核 ✓ `_scratch/ode-hw-solve.py`、`ode-hw-grade-check.py`）

| # | 特征多项式 | 特征值（m, g） | 特征向量 / 广义链 | 通解 |
|---|---|---|---|---|
| (1) | `(λ−1)²(λ−2)` | λ=1（m=2, g=1）；λ=2（m=1, g=1） | V₁=(0,3,1)ᵀ（λ=1）；广义 V₂=(1,0,0)ᵀ；V₃=(1,4,1)ᵀ（λ=2） | `Y = c₁(0,3,1)ᵀe^x + c₂[(0,3,1)ᵀx + (1,0,0)ᵀ]e^x + c₃(1,4,1)ᵀe^{2x}` |
| (2) | `λ²+1` | λ=±i（各 m=1, g=1） | V=(1, 2+i)ᵀ（λ=i） | `Y = c₁(cos x, 2cos x − sin x)ᵀ + c₂(sin x, 2sin x + cos x)ᵀ` |
| (3) | `(λ+1)³` | λ=−1（m=3, **g=1**） | V₁=(0,1,1)ᵀ；链 V₂=(−1,1,0)ᵀ、V₃=(−3,4,0)ᵀ | `Y = c₁V₁e^{−x} + c₂(V₁x+V₂)e^{−x} + c₃(V₁x²/2 + V₂x + V₃)e^{−x}` |
| (4) | `(λ−4)(λ+2)` | λ=4；λ=−2（各 m=1, g=1） | V=(1,3)ᵀ；(1,−3)ᵀ | `Y = c₁(1,3)ᵀe^{4x} + c₂(1,−3)ᵀe^{−2x}` |

**典型错误（2026-10-12 首次作答就踩了）**：重根情形把解写成 `x·V e^(λx)`、`x²·V e^(λx)` ——
**这不是解**（代入得 `Y′ − AY = V e^(λx) ≠ 0`）。正确形式是**多项式**：`(V₁x + V₂)e^(λx)`、`(V₁x²/2 + V₂x + V₃)e^(λx)`，
其中 `V₂, V₃` 由广义特征向量链 `(A−λE)V_{k+1} = V_k` 解出（`(1)` 的 `V₂=(1,0,0)`、`(3)` 的 `V₂=(−1,1,0)`,`V₃=(−3,4,0)`）。
