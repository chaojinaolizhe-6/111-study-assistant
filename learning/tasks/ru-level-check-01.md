# 俄语定位诊断（2026-10-08）

> **起因**：学习者 2026-10-08 自述「УРОК 7（形容词）要搞定，但它前面几节课的知识点我现在又忘记了，可能得再学」，并给出期限「10-13 前跟上最新课件」→ 先用本诊断**定位遗忘点**，再决定回补范围。
> **条件**：闭卷（沿用长期约定）、不查词典、不查课件；不确定就写「不确定」。
> **范围**：УРОК 1–7（字母/问候 → 名词的性 → 复数 → 物主代词 → какой → 形容词词尾）。

## 题目（20 题）

**一、名词的性**（УРОК 4）——写出 阳／阴／中
1. тетра́дь　2. слова́рь　3. такси́　4. де́душка　5. ночь　6. окно́　7. портфе́ль　8. пло́щадь

**二、复数**（УРОК 5）——写复数形式
9. стол　10. кни́га　11. окно́　12. слова́рь　13. тетра́дь

**三、物主代词「我的」**（УРОК 6）——填 мой／моя́／моё／мои́
14. ___ дом　15. ___ кни́га　16. ___ окно́　17. ___ кни́ги　18. 「她的书」= ___ кни́га

**四、какой 与形容词**（УРОК 7 / 练习 1）——填 како́й／кака́я／како́е／каки́е
19. ___ э́то го́род?　20. ___ э́то кни́га?　21. ___ э́то мо́ре?　22. ___ э́то кни́ги?
23. 把「这是新书」写出来：Э́то ___ кни́га.

**五、基础问答**（УРОК 1–3）
24. 问「这是谁？」（指着一个人）
25. 问「老师在哪儿？」
26. 说「这是安娜」和「这是城市」

## 核验要点（导师用，作答前勿看）

| # | 答案 | 考点 |
|---|---|---|
| 1 | **阴性**（она́） | `-ь` 词 → 阴（**上次错成 он**） |
| 2 | 阳性（он） | `-арь` → 阳 |
| 3 | **中性**（оно́，不变格外来词） | **上次答成 они／какие** |
| 4 | 阳性（он，`-а` 结尾的例外） | дедушка/дядя/мужчина/па́па |
| 5 | 阴性（ж/ш/ч/щ + ь） | `ночь` |
| 6 | 中性（-о） | окно́ |
| 7 | 阳性（-фель） | **上次留空** |
| 8 | 阴性（-дь，同 тетрадь） | пло́щадь |
| 9 | столы́ | 阳·硬辅音 → -ы |
| 10 | кни́ги | г 后只能写 -и |
| 11 | о́кна | 中 -о → -а |
| 12 | словари́ | 阳 -ь → -и |
| 13 | тетра́ди | 阴 -ь → -и |

| 15 | моя́ кни́га | 阴 |
