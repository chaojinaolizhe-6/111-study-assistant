## 题面（p39 原文抄录）

**1.** 将函数 **f(x) = cos³x** 表示成傅里叶级数的形式。

**2.** 将函数 **f(x) = x/3** 在 **(−l, l)** 区间内展开成傅里叶级数。

**3.** 将函数 **f(t) = A|sin ωt|** 在 **(0, T)** 区间内展开成傅里叶级数，其中 A 为常数。

**4.** 将矩形波

```
        ⎧ 0        −T/2 ≤ t < −T₀/2
f(t) =  ⎨ H        −T₀/2 ≤ t ≤ T₀/2
        ⎩ 0         T₀/2 < t ≤ T/2
```

在区间内展开为**复数形式**的傅里叶级数，其中 H 为常数。

## 题面（p63 原文抄录，2026-10-21 读图核对）

**5.** 求锯齿波

```
        ⎧ 0        t < 0
f(t) =  ⎨ t        0 ≤ t ≤ T
        ⎩ 0        t > T
```

的**复数形式**的傅里叶变换。

**6.** 求函数

```
        ⎧ 0        (t < 0)
f(t) =  ⎨
        ⎩ e^(−αt)   (t ≥ 0)
```

的复数形式的傅里叶变换，其中 α 为：**(1)** 有限大小的正数，即 α > 0；**(2)** 无穷小的正数，即 α → 0⁺。

**7.** 求如下函数：**(1)** f(x) = cos(αx²)；**(2)** f(x) = sin(αx²) 的复数形式的傅里叶变换，其中 α > 0。

## 备注

- ⚠ 第 1 题的 `cos³x` 是幂（读图确认为上标 3，不是 |cos x|）。
- 第 3 题注意：|sin ωt| 的**周期是 T = π/ω**（不是 2π/ω），展开区间 (0, T) 正好一个周期。
- 第 4 题的矩形波在**一个周期 T 内**只有中间 T₀ 宽度取 H。
- ⚠ 第 5–7 题（p63）是 **2026-10-21 备课时**才补进来的：此前只登记了 p39 的 4 题，整页 p63 处于漏登状态。做作业时按 **7 题** 计。
- 第 5 题的积分要分部积分，且结果一般带 1/ω 与 e^(−iωT) 项；第 6 题的 (2) 问是 (1) 问取极限，会牵出 1/(iω) 与 δ(ω) 的配对，属于符号函数型结论，课件是否讲到待核。
- 第 7 题是**复高斯型**（菲涅耳类）积分，与前面 1–6 题的查表/分部积分不是一个套路；若老师没讲过，按「未学」处理，先讲后做。
