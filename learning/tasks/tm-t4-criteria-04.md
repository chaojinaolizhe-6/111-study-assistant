## 第 A 题｜平移斜面上的物块（含非零 T₁、非零 T₀，U 随坐标变）

**系统**：水平地面（光滑）上有一个**形状固定**、倾角为 α 的斜面体。斜面体在**外力**作用下以**恒定速度 v₀ 向右平移**。
质量 m 的物块在该斜面的表面上无摩擦滑动。**研究系统只有物块 m**（斜面体由外力维持匀速，不计入 L）。

**坐标约定**（写清以免歧义）：

- x 轴水平向右，y 轴竖直向上；
- 取 **s = 物块沿斜面向下、相对斜面滑过的距离**；
- 物块沿斜面下滑时，它相对斜面的速度方向 = (cos α, −sin α)。

**已知（不必再建模）**：

- 物块相对地面的速度平方：`v² = ṡ² + 2 v₀ ṡ cos α + v₀²`
- 动能：`T = ½mṡ² + m v₀ cos α · ṡ + ½m v₀²`
- 势能：`U = −mg s sin α`（x 轴所在水平面为零点）
- `L = T − U`

**请作答（不要查资料、不要问我方法）**：

- **A1**　`L` 显含时间 t 吗？据此，`E = ṡ ∂L/∂ṡ − L` 守恒吗？用一句话说依据。
- **A2**　把 `T` 写成 `T = T₂ + T₁ + T₀`，分别写出三项。
- **A3**　`E` 等于 `T + U` 吗？写出 `E` 的表达式。
- **A4**　算 `E − (T + U)`，结果等于什么？
- **A5**　`T₁` 出现在 `E` 里吗？出现在 `T + U` 里吗？

## 第 B 题｜显含时间的弹簧（T 只有二次项——用来和 A 题对照）

**系统**：质量 m 的物块在光滑水平面上，被一根**刚度随时间变化**的弹簧拴在墙上：
`k(t) = k₀(1 + εt)`，`k₀ > 0`、`ε ≠ 0` 为常数。

**已知**：`L = ½mẋ² − ½k₀(1 + εt)x²`。

**请作答**：

- **B1**　`E = ẋ ∂L/∂ẋ − L` 守恒吗？依据。
- **B2**　`T₂`、`T₁`、`T₀` 分别是多少？
- **B3**　`E` 等于 `T + U` 吗？（本题 `U = ½k₀(1 + εt)x²`）

## 核验要点（导师用，不作答前勿看）

### A 题

`L = ½mṡ² + m v₀ cos α · ṡ + ½m v₀² + mg s sin α`

| 问 | 正确答案 | 常见错答（要区分） |
|---|---|---|
| A1 | **不显含 t**（m、g、v₀、α 都是常数，s 是坐标不是 t）⟹ `∂L/∂t = 0` ⟹ **E 守恒** | 看到"斜面在动"就说不守恒（把"约束在动"与"显含 t"混为一谈）；说"因为 v₀ 在变" |
| A2 | `T₂ = ½mṡ²`、`T₁ = m v₀ cos α · ṡ`、`T₀ = ½m v₀²` | T₁ 与 T₂ 互换；把 ½mv₀² 当成 U；把 T₁ 写成常数 |
| A3 | **不等于**。`E = T₂ − T₀ + U = ½mṡ² − ½m v₀² − mg s sin α` | 直接写 `E = T + U`（旧口诀）；把 E 写成 `L − ṡ∂L/∂ṡ`（符号反，2026-09-26 曾犯） |
| A4 | `E − (T + U) = −(T₁ + 2T₀) = −(m v₀ cos α · ṡ + m v₀²)` | 忘了 2T₀ 的因子 2；漏掉负号 |
| A5 | T₁ **不在 E 里**（`1·T₁` 与 `−T` 中的 `−T₁` 相消），**在 T+U 里** | 说"T₁ 不存在"／"T₁ 被欧拉定理消掉了，所以哪都没有" |

⚠ 数值自检（导师可用）：令 α = 0（斜面变水平面）⟹ 退化为**传送带**，`T₁ = m v₀ ṡ`、`(T₁+2T₀) = m v₀ ṡ + m v₀²`；
令 v₀ = 0 ⟹ 退化为**固定斜面**，`T₁ = T₀ = 0`、`E = T + U`（判据二成立）。
⚠ 本题**与 `criteria-03` 题 1（传送带 `T = ½m(ẋ+v₀)²`）结构同源**（α→0 即退化到它），但**L 不同**（本题 U ≠ 0 且随 s 变），且 T₁ 系数含 `cos α`、U 含 `sin α`——
**这正是"系数与正负号不敏感"（`state/mistakes.md` 2026-09-28 confirmed）的检查点**：量纲 + 退化极限两句自检必须落地。

### B 题

| 问 | 正确答案 |
|---|---|
| B1 | **显含 t**（k(t) 里有 t）⟹ `∂L/∂t = −½k₀εx² ≠ 0` ⟹ **E 不守恒** |
| B2 | `T₂ = ½mẋ²`、`T₁ = 0`、`T₀ = 0` |
| B3 | **等于**（T 只有二次项）——但 **E 不守恒** |

⚠ **B 题是本题的判读核心**：它证明"守恒（判据一）"与"E 是否等于 T+U（判据二）"是**两件独立的事**
（A：守恒但 E ≠ T+U；B：不守恒但 E = T+U）。若学习者把两者绑在一起（"不守恒所以 E ≠ T+U"或反之），
即使 A 题代数全对，**`tm.t4.energy-criteria` 仍不能升级为独立通过**。
