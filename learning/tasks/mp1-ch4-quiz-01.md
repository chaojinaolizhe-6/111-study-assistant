# 第四章 §4.1 留数定理 —— 学习成果核对（2026-10-01）

## 题目（六项）

1. **留数是什么**？—— 用洛朗展开说清它是**哪个系数**；并说明**为什么偏偏是这一项**（要给出**积分**层面的理由）。
2. `f(z) = 1/z²` 在 `z = 0` 的**留数** = ?
3. `f(z) = e^z / z³` 在 `z = 0` 的**留数** = ?（只用手上的展开，不查公式）
4. 写出**留数定理**的式子，并说清：围道 `C` 的条件、以及"对哪些奇点求和"。
5. **留数定理的证明思路**用一句话说（关键词即可）：为什么能把大围道上的积分换成几个小圆上的积分？
6. **应用**：用留数定理求 `∮_{|z|=2} 1/(z²−1) dz`。

## 核验要点（导师用，作答前勿看）

| # | 答案 |
|---|---|
| 1 | 留数 = 洛朗展开里 **`(z−z₀)⁻¹` 的系数 `a₋₁`**；理由：`∮_C (z−z₀)ⁿ dz = 0 (n ≠ −1)`、`= 2πi (n = −1)` ⟹ **逐项积分后只有 −1 次项存活**（这才是"为什么是它"） |
| 2 | **0**（`1/z² = z⁻²`，压根没有 `z⁻¹` 项）—— 专治"有极点 ⟹ 留数非零"的错觉 |
| 3 | **1/2**：`e^z/z³ = z⁻³(1 + z + z²/2! + z³/3! + …) = z⁻³ + z⁻² + 1/(2z) + 1/6 + …` ⟹ `a₋₁ = 1/2` |
| 4 | `∮_C f(z) dz = 2πi Σ_k Res f(z_k)`；条件（**课件 p6 原文要点**）：f 在闭合围道 `C` **内**除**有限个孤立奇点** `z₁,z₂,…` 外**单值解析**，且 **C 上没有奇点** |
| 5 | 以每个 `z_k` 为心作**互不相交的小圆** `c_k`（全在 C 内），用**复连通区域的柯西定理**把沿 C 的积分化为 `Σ_k ∮_{c_k}`；每个小圆上逐项积分只剩 `a₋₁` ⟹ `2πi Σ Res` |
| 6 | `1/(z²−1) = ½[ 1/(z−1) − 1/(z+1) ]`；`\|z\|=2` 内**两个**一阶极点 `z=1`、`z=−1`；`Res(1) = ½`、`Res(−1) = −½` ⟹ 和为 **0** ⟹ **积分 = 0** |
