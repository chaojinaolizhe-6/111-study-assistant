## 题 1｜传送带上的滑块（v₀ 恒定；x 为滑块相对传送带的位移）

`T = ½m(ẋ + v₀)²`

答：`T₂ = ½mẋ²`、`T₁ = m v₀ ẋ`、`T₀ = ½m v₀²`
→ 学习者 2026-09-28 **三项全对**（**首次独立分出非零 T₁**）

## 题 2｜移动悬点的单摆（摆长 l；悬点以恒定速度 v₀ 水平移动）

`L = ½m(l²θ̇² + 2v₀lθ̇cosθ + v₀²) + mgl cosθ`，已知 `U = −mgl cosθ`

答：`T₂ = ½ml²θ̇²`、`T₁ = m v₀ l θ̇ cosθ`、`T₀ = ½m v₀²`、**`U = −mgl cosθ`**

学习者 2026-09-28 澄清原意：「**U 提供负号中和了那一项本身的负号**」⟹ `−U = +mgl cosθ` ⟹ **`U = −mgl cosθ`，判断正确**。
导师先前的"符号错"系对**压缩答语**（"展开式每项顺序对应…加号是从 U 来的"）的**误读**。

## 学习者 2026-09-28 提出的关键问题（已答）

> "按照欧拉定理，T₁ 对 E 的贡献不是没有吗？不是在做减法时被消掉了吗？现在怎么又说有了？"

**答案**：T₁ **确实不在 E 里**（1·T₁ 与 −T 中的 −T₁ 相消 ⟹ `E = T₂ − T₀ + U`），**但 T₁ 在 T+U 里**。
判据二比的是"E"与"T+U"**两个东西**，T₁ 只出现在其中一个 ⟹ 相减时它冒出来：

```
E         = T₂ − T₀ + U
T + U     = T₂ + T₁ + T₀ + U
────────────────────────────
E − (T+U) = −(T₁ + 2T₀)
```
