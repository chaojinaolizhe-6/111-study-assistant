## 题目（五项；每项一句话：哪一类，极点给阶数）

1. `f(z) = sin(1/z)`，中心 `z = 0`
2. `f(z) = ( e^z − 1 − z − z²/2 ) / z⁴`，中心 `z = 0`
3. `f(z) = 1 / ( z (e^z − 1) )`，中心 `z = 0`
4. `f(z) = e^(1/z) / (z − 1)`，中心 `z = 0`
5. `f(z) = ( ln(1+z) − z + z²/2 ) / z³`，中心 `z = 0`

## 核验要点（导师用，作答前勿看）

| # | 答案 | 该题在考什么 |
|---|---|---|
| 1 | **本性奇点**（`sin(1/z) = 1/z − 1/(3! z³) + …`，负幂项无限；**无阶数**） | 有"本身在 z₀ 不解析"的因子 ⟹ 直接定性 |
| 2 | **一阶极点**：`e^z − 1 − z − z²/2 = z³/3! + z⁴/4! + …` ⟹ 分子 **3 阶**、分母 4 阶 ⟹ `4 − 3 = 1` | **减法消项**：必须展开到**第三项**才见 `z³` |
| 3 | **二阶极点**：分母 `z·(e^z − 1) = z·(z + z²/2 + …) = z²(1 + z/2 + …)` ⟹ 零点 **1 + 1 = 2** 阶 | **乘积分母：各因子阶数相加** |
| 4 | **本性奇点**（`e^(1/z)` 因子直接定性；乘 `1/(z−1)`（在 0 解析且非零）不改变本性） | **别去数零点**：有 `e^(1/z)` 就结束 |
| 5 | **可去奇点**（`ln(1+z) − z + z²/2 = z³/3 − z⁴/4 + …` ⟹ 分子 3 阶、分母 3 阶 ⟹ 无负幂项；极限 `1/3`） | **减法消项 + 可去判定**（须给"分子零点阶数 ≥ 分母"或极限有限） |

**判分**：五项全对＝通过；错项须记错因假设（未展开到首个非零项／分母阶数未相加／把本性当极点／可去误判为极点）。
