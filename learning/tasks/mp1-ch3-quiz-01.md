## 一、复习范围（照着看，别漫游）

### ① 级数基础（学习者自述"忘了"的就是这块）
- **收敛半径怎么求**：比值法 `R = lim|aₙ/aₙ₊₁|`；根值法 `R = 1/limsup|aₙ|^(1/n)`（柯西–阿达马）
- **必须背下来的五个展开**（都在 z = 0 附近）：
  - `1/(1−w) = 1 + w + w² + …`　（**`|w| < 1`**，这是所有题的发动机）
  - `e^z = Σ zⁿ/n!`
  - `sin z = Σ (−1)ⁿ z^(2n+1)/(2n+1)!`
  - `cos z = Σ (−1)ⁿ z^(2n)/(2n)!`
  - `ln(1+z) = Σ (−1)^(n+1) zⁿ/n`　（`|z| < 1`）
- **几何级数的适用条件**：`|w| < 1` 才收敛——**区域决定 w 能取什么**

### ② 两把刀：泰勒 vs 洛朗（核心判断）

> ⚠️ **2026-09-28 更正（两次），旧判据与旧口诀一并作废**：
> - 旧判据「看展开中心那一点 f **有没有有限值** → 有就用泰勒」——**不充分**（把"中心解析"偷换成"中心有有限值"）。
> - 更正稿里又写成「圆盘→泰勒、**去心圆盘→洛朗**」「可去奇点跟能不能泰勒是两件事」「换中心才换刀」——**这三句仍然是错的**，等于把两者教成**由区域形状决定的互斥选项**。下面是改正版。

**核心事实：泰勒是洛朗的特例，不是二选一的对手。**
- 洛朗展开在圆环 `r < |z − z₀| < R` 上成立；**泰勒展开就是负幂系数全为 0 的那个洛朗展开**。
- **在中心解析的圆盘内，泰勒展开有效；把范围限制到去心圆盘 `0 < |z − z₀| < R`，同一个泰勒展开仍然有效**，此时它同时也就是该去心圆盘上的洛朗展开（负幂系数全 0）。
- 所以**不存在**"圆盘用泰勒、去心圆盘用洛朗"这种按区域形状切开的互斥规则。

**什么时候"必然"出现负幂项？**

函数在**指定圆环内解析**时，就可以作**该圆环上的洛朗展开**；**是否有负幂项，不能由"区域是外部还是圆环"来判断**。

- **泰勒级数在其收敛圆盘内有效；限制到其中的任一圆环，它仍然有效**（此时它就是该圆环上的洛朗展开，负幂系数全 0）。
- 对**孤立奇点 z₀**，在**充分小的去心邻域** `0 < |z − z₀| < R` 中：
  - **不可去**的（极点 / 本性奇点）→ 洛朗展开**必有非零负幂项**；
  - **可去**的 → 负幂系数**全为 0**，**补定义后可以泰勒展开**。

**检验这条表述（关键）**：`e^z` 是整函数，`e^z = Σ zⁿ/n!` 的**收敛半径是 ∞**——
所以在 `|z| > 1` 这个"外部区域"上，**它仍然由同一个泰勒级数表示，一个负幂项都没有**。
→ 可见「区域是外部 ⟹ 必有负幂项」是**错的**：**负幂项来自函数在中心附近的奇性，不来自区域的形状。**

**可去奇点：补定义后可以泰勒。**
- 若 z₀ 是**孤立奇点**，要判它是否**可去**，必须看**去心邻域**：f 在 `0 < |z−z₀| < R` 内解析**且有界（存在有限极限）** → 可去。
- 可去时，补上 `f(z₀) = lim` 之后 **f 在 z₀ 解析，可以作泰勒展开**；而它在去心邻域上的洛朗展开**恰好就是这个泰勒级数**（负幂系数全 0）。
- ⚠ 唯一要小心的：**"单点代进去算出一个有限值"不等于"在去心邻域有界"，也不等于"f 在中心解析"**。所以判可去要看**去心邻域**，不是把 z₀ 代进去看一眼。

**对照实例：`1/(1−z)`**（中心 `z = 0`；f 在 0 **解析**，但 `z = 1` 是极点、距中心 1 → 以 0 为中心的泰勒收敛半径 **R = 1**）
- `|z| < 1`：`1 + z + z² + …`（泰勒；同时也是该圆盘上的洛朗展开，负幂系数全 0）
- `|z| > 1`：`−1/z − 1/z² − …`（**出现了负幂项**）
- ⚠ 为什么外区出现负幂项？**不是"因为区域是外部"**，而是因为**以 0 为中心的泰勒级数被最近的奇点 `z = 1` 挡在半径 1 以内**——它在 `|z| > 1` 上根本不收敛，只能改用该圆环 `1 < |z| < ∞` 上的洛朗展开（奇点 `z = 1` 正好落在这个圆环的**内边界**上，不在环内）。
- **与 `e^z` 对照**：`e^z` 没有奇点、收敛半径 ∞，所以 `|z| > 1` 上**照样是那个泰勒级数**。
  **同样是"外部区域"，结论相反 —— 区别在函数有没有奇性，不在区域。**

**"换中心"会换刀吗？** 不是"换中心"这个动作，而是**该中心是否解析**：
- `1/(z²−1)`：以 `z = 0` 为中心解析 → `|z| < 1` 内**泰勒**可用；
- 以 `z = 1` 为中心**不解析**（极点）→ 中心处没有泰勒展开，只能**洛朗**。
- 若换到另一个**解析点**，照样是泰勒。决定因素是「中心是否解析」+「要求的区域」，不是"换了中心"。

**一句话版**：**先问中心解析吗**（决定"能不能泰勒"）→ **再看要求的区域落在哪**（决定"这个泰勒收不收敛、要不要改用洛朗"）。

### ③ 洛朗实操（作业与考试的重点）

> ⚠ 这一节只是**凑级数的手法**。展开里出现负幂项，是因为**函数在该圆环内有奇性**，**不是因为"区域是外部"**（对照 §② 的 `e^z`）。下面的 `w` 是**为了在该区域满足 `|w| < 1` 而选的代换**。

- **一招**：凑成 `1/(1−w)`，`|w| < 1`
  - 区域是 `|z| < R`（圆盘内）→ 令 `w = z/常数`，得到**正幂项**
  - 区域是 `|z| > R`（外部）→ 令 `w = 常数/z`，得到**负幂项**
- **`w` 由区域决定，不由函数决定**。举例：
  - `1/(z−2)`，`|z| < 2`：`= −½·1/(1−z/2) = −Σ zⁿ/2^(n+1)`
  - `1/(z−2)`，`|z| > 2`：`= (1/z)·1/(1−2/z) = Σ 2ⁿ/z^(n+1)`
- 复杂函数先**部分分式裂项**，再逐项按区域变形

### ④ 孤立奇点分类
- 看洛朗展开里**负幂项的个数**：
  - **没有**负幂项 → **可去奇点**
  - **有限个**（最高是 `(z−z₀)^(−m)`）→ **m 阶极点**
  - **无限个** → **本性奇点**
- **阶数怎么数**：**极点阶数 = 分母零点的阶数**，前提是**分子在该点不为零**
  - 分子也为零时必须**先约掉/先展开**（例：`(1−cos z)/z³` 不是三阶极点，因为 `1−cos z ~ z²/2`，约掉后是**一阶**）
