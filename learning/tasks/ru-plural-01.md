## 第一组：阳性（课件 slide 5）
студе́нт、уро́к、нож、слова́рь、музе́й、санато́рий

## 第二组：阴性（课件 slide 6）
сестра́、кни́га、тетра́дь、пе́сня、аудито́рия

## 第三组：中性（课件 slide 7）
окно́、письмо́、мо́ре、по́ле、упражне́ние、зда́ние

## 核验要点（导师用）

| 阳性 | 复数 | 用哪行 |
|---|---|---|
| студе́нт | студе́нты | 硬辅音 → -ы |
| уро́к | уро́ки | к 后 → -и |
| нож | но́жи | ж 后 → -и |
| слова́рь | словари́ | -(ь) → -и |
| музе́й | музе́и | -(й) → -и |
| санато́рий | санато́рии | -(ий) → -ии |

| 阴性 | 复数 | 用哪行 |
|---|---|---|
| сестра́ | сёстры | -а → -ы（注意 ё） |
| кни́га | кни́ги | -га → -и |
| тетра́дь | тетра́ди | -(ь) → -и |
| пе́сня | пе́сни | -я → -и |
| аудито́рия | аудито́рии | -(и)я → -(и)и |

| 中性 | 复数 | 用哪行 |
|---|---|---|
| окно́ | о́кна | -о → -а |
| письмо́ | пи́сьма | -о → -а |
| мо́ре | моря́ | -е → -я |
| по́ле | поля́ | -е → -я |
| упражне́ние | упражне́ния | -(и)е → -(и)я |
| зда́ние | зда́ния | -(и)е → -(и)я |
