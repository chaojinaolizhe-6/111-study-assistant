# 基线题：一阶线性初值问题

解初值问题：y' + 2y = 3x，y(0) = 1。

要求（闭卷、无提示）：
1. 写下你的完整推导过程（拍照或文字都可以）；
2. 说明你选择该方法的理由（哪怕只写"因为看起来像一阶线性方程"）；
3. 把你的解代回原方程和初值条件验证；
4. 作答前先报一个把握度（0-100%）——这是元认知校准信号，不是成绩。
