## 题目

`f(z) = 1 / ( e^(2z) − 1 − 2z )` 在 `z = 0` 是**几阶极点**？
要求：先把分母展开到**首个非零项**，说出分母零点几阶，再给结论。

## 核验要点（导师用，作答前勿看）

```
e^(2z) = Σ_{n≥0} (2z)ⁿ/n!  ⟹  e^(2z) − 1 − 2z = Σ_{n≥2} (2z)ⁿ/n!
       = 2z² + (4/3)z³ + (2/3)z⁴ + …
       = z²·(2 + (4/3)z + …)          ← 括号在 z = 0 处等于 2 ≠ 0
⟹ 分母二阶零点 ⟹ f = 1/(z²·(2 + …)) = (1/2)z^(−2)·(1 + …)
⟹ 负幂最多到 z^(−2) ⟹ 二阶极点
复核：lim_{z→0} z² f(z) = 1/2（有限非零）✓
```
