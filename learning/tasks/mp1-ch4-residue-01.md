## 三、诊断（2026-09-30 晚，三问；只用手上已有的洛朗工具）

1. **"留数"是什么？** 用洛朗语言说：`f` 在孤立奇点 `z₀` 处，留数是洛朗展开里的**哪个系数**？
2. `f(z) = 1/z²` 在 `z = 0` **有极点** —— 它的**留数**是多少？
3. `f(z) = e^z / z³` 在 `z = 0`：**不查公式**，只用洛朗展开求留数。

## 四、核验要点（导师用，作答前勿看）

| 问 | 答案/期望 |
|---|---|
| 1 | 留数 = 洛朗展开里 **(z − z₀)⁻¹ 的系数 `a₋₁`**（等价 `Res f(z₀) = (1/2πi)∮ f dz` 取小圆） |
| 2 | **0**（`1/z² = z⁻²`，无 `z⁻¹` 项）—— 专治"有极点 ⟹ 留数非零"的错觉 |
| 3 | **1/2**：`e^z/z³ = z⁻³(1 + z + z²/2! + z³/3! + …) = z⁻³ + z⁻² + 1/(2z) + 1/6 + …` ⟹ `a₋₁ = 1/2` ✓ |
