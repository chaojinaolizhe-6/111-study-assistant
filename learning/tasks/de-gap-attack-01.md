| 1 | 准齐次（缺口 6） | `y′ = y/x + x/y²` | 算出尺度权重 b = 2/3；自己用齐次代换 y = zx 分离变量并积到最后一步 | 代换公式最初记混（草稿误写 u = y^β/x^(α−β)，代成 y = x^(1/3)u 而卡住），经「无量纲化／尺度不变量」提示才弄清标准代换为何是 y = x^b·u；经提示才明白本题能用 y = zx 是因为 y′ − y/x 凑成单项式（本质是 Bernoulli），并非所有准齐次都能这样；收尾**漏写积分常数 C** |
| 2 | 准齐次（缺口 6） | `y′ = y/x + x³/y` | 自己列出 b − 1 = 3 − b ⟹ b = 2；独立完成代换 y = x²u、分离变量、积分得 −½ln|1−u²| = ln x + C，并自觉标注 u ≠ ±1 的奇解讨论 | 积分后写成 1/√|1−u²| = Cx 就中断（嫌去绝对值与回代繁琐），经提示才掌握「两边同乘 −2 消掉分数系数、再用任意常数吸收正负号」的化简技巧；以及两边同乘 2y 直接凑 (y²/x²)′ = 2x 的 Bernoulli 秒杀法 |
| 3 | 缺口 7（降阶＋凑导数） | `y y″ − (y′)² = y² ln y` | 参考讲义「除以 y² 凑 (y′/y)′」的套路提示后，自己顺畅写出完整链条：(y′/y)′ = ln y ⟹ (ln y)″ = ln y ⟹ 令 p = ln y 得 p″ = p ⟹ y = exp(C₁e^x + C₂e^(−x)) | **最初的「除以 y² 凑对数二阶导」这一步灵感来自讲义总结**——推导链条本身已跑通，但「无提示下自己一眼识别」尚未检验 |
| 4 | 缺口 8（Clairaut 与奇解） | `y = xy′ − (y′)²` | 概念与两支求解目前自述「理解透彻」 | **完全依赖外部讲解**：特征识别、令 p = y′ 后对 x 求导消去 p、因式分解 (x + φ′(p))p′ = 0 分成「通解直线族 + 奇解包络线」的机制、以及为什么通解必须写成 φ(C) 而不是独立常数 C₂（一阶方程只有 1 个自由度，p = C 是直接代入原方程而非二次积分）——**且尚未独立动笔做过一道全新的 Clairaut 练习题** |
