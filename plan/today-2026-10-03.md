**A**：`f(z) = 1 / ((z − 2)(z − 3))`
1. 在 `|z| < 2` 内展成级数（并说明这里为什么可以用**泰勒**、收敛半径是多少）；
2. 在 `|z| > 3` 内展成级数（写清 `w` 怎么选、通项、**别忘了提出来的因子**）。

**B**：`f(z) = 1 / ( z² (z + 1) )`
1. 在 `0 < |z| < 1` 内展成洛朗级数（写出通项）；
2. 在 `|z| > 1` 内展成洛朗级数（写出通项）；
3. 指出 `z = 0` 与 `z = −1` 各是哪一类奇点、**几阶**。

**C（孤立奇点，每项一句话：哪一类；是极点就给阶数）**

1. `f(z) = sin(1/z)`，中心 `z = 0`
2. `f(z) = ( e^z − 1 − z − z²/2 ) / z⁴`，中心 `z = 0`
3. `f(z) = 1 / ( z (e^z − 1) )`，中心 `z = 0`
4. `f(z) = e^(1/z) / (z − 1)`，中心 `z = 0`
5. `f(z) = ( ln(1+z) − z + z²/2 ) / z³`，中心 `z = 0`
