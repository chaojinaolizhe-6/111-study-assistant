## 0. 先备好这四个公式（课件 Chapter Three-2 p24／p33／p34／p47）

| 电路形态 | 输出直流电压 | 二极管平均电流 | 二极管最大反向电压 |
|---|---|---|---|
| 半波（无 C） | `U_O = 0.45 U₂` | `I_D = I_O` | `U_RM = √2 U₂` |
| 全波／桥式（无 C） | `U_O = 0.9 U₂` | `I_D = ½ I_O` | `U_RM = √2 U₂` |
| **桥式 + C（有负载）** | **`U_O ≈ 1.2 U₂`** | `I_D = ½ I_O` | `U_RM = √2 U₂` |
| **桥式 + C（空载）** | **`U_O = √2 U₂`** | `0` | — |

> `U₂` 一律是**副边有效值**；中心抽头全波才用 `U_RM = 2√2 U₂`。
> 电容：容量 `C ≥ (1.5~2.5)/(R_L f)`，耐压 `U_CN ≥ √2 U₂`；二极管选型 `I_F ≥ 2 I_D`。

## 2. 开关波形题（完整解答）

**条件**：`R_L = 5 kΩ`、`C` 足够大、`U₂ = 30 V`（有效值）。
**电路读法**（把图放大读清楚了）：**S1 串在电容 C 支路**上，**S2 串在负载 R_L 支路**上。

### (1) S1、S2 都闭合（电容在、负载在）
```
U_O ≈ 1.2 U₂ = 1.2 × 30 = 36 V
I_O = U_O / R_L = 36 / 5000 = 7.2 mA
```
**u_o1 波形**：桥式整流 + 电容滤波后的**近似平直直流**。形状＝每半个周期有一个很窄的**充电尖峰**把电容充满，随后电容通过 R_L **缓慢放电**形成**小锯齿纹波**；纹波周期 = `T/2 = 10 ms`（全波，50 Hz → 100 Hz）。

### (2) S1 断开、S2 闭合（无电容，有负载）
```
U_O = 0.9 U₂ = 0.9 × 30 = 27 V
I_O = 27 / 5000 = 5.4 mA
```
（波形＝全波整流后的**脉动直流**：`|sin|` 形状，每个周期两个鼓包，最低到 0。）

### (3) S1 闭合、S2 断开（电容在、**空载**）
```
电容被充到峰值后没有放电回路 ⟹ U_O = √2 U₂ = 1.414 × 30 = 42.4 V
I_O = 0
```
**u_o2 波形**：从 0 迅速充电到峰值 **42.4 V**，之后是**一条水平线**（不是锯齿！因为没负载可放电）。

### (4) S1 断开、S2 闭合、**D2 断**
```
桥式里 D1D4 负责正半周、D2D3 负责负半周；D2 断 ⟹ 负半周没有通路
⟹ 退化成【半波】整流：U_O = 0.45 U₂ = 0.45 × 30 = 13.5 V
I_O = 13.5 / 5000 = 2.7 mA
```

## 4. 这两题背后的知识点（"后三道不会"要处理的就是它）

1. **四个系数**：半波 `0.45`、全波桥式 `0.9`、桥式+C `1.2`、空载 `√2` —— 判题第一步永远是先问"**有没有电容、有没有负载**"。
2. **二极管两个额定**：
   - 电流：`I_D`（**平均**电流）→ 桥式 `= ½I_O`；选型 `I_F ≥ 2 I_D`（留裕量）
   - 耐压：`U_RM = √2 U₂`（桥式/半波）
3. **电容两个参数**：容量 `C ≥ (1.5~2.5)/(R_L f)`；耐压 `U_CN ≥ √2 U₂`。
4. **开关/断路题的通法**：把电路拆成"**电容支路通不通、负载支路通不通、二极管还通不通**"三问 → 每问对应上表里的一行 → 再套公式。
