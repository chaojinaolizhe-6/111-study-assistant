# 二、Chapter Three-2 Q1（**半波整流**，无电容）

**题面**：`R_L = 100 Ω`、`u₂ = 20 sin(ωt) V`；求 `U_O`、`I_D`、`U_RM`。

```
U₂(rms) = 20/√2 = 14.14 V
U_O  = 0.45 U₂ = 0.45 × 14.14 = 6.36 ≈ 6.4 V        ← 半波系数 0.45
I_O  = U_O/R_L = 6.36/100 = 63.6 mA
I_D  = I_O = 63.6 mA                                 ← 半波：二极管承担全部负载电流
U_RM = √2 U₂ = 20 V                                  ← = u₂ 的峰值
```

**你的手写解答**：`I_D = 0.141 A`、`U_o = 14.14 V`、`U_RM = 20 V`
- ✅ `U_RM = 20 V` **对**
- ❌ `U_o = 14.14 V`：那是**副边有效值 U₂**，不是整流输出。**半波**要乘 0.45 ⟹ **6.4 V**
- ❌ `I_D = 0.141 A`：那是 `U₂/R_L`（有效值电流）。正确：`I_D = U_O/R_L = ` **64 mA**
- 💡 一句话记法：**先判电路形态（这里只有一只二极管 ⟹ 半波），再套系数 0.45。**

# 三、Chapter Three-2 Q3（桥式 + 电容：选二极管、选电容）

**题面**：`R_L = 1000 Ω`、`U_O = 60 V`、`f = 50 Hz`；(1) 选二极管；(2) 定电容。
**备选二极管**：2CP11（I_F = 100 mA，U_R = 50 V）／2CP12（100 mA，100 V）／2CP13（100 mA，150 V）。

**(1) 选二极管**

```
U₂   = U_O / 1.2 = 60 / 1.2 = 50 V            ← 桥式+电容的 1.2 系数反推
I_O  = U_O / R_L = 60 / 1000 = 60 mA
I_D  = ½ I_O = 30 mA                          ← 桥式：每管导通半周期
U_RM = √2 U₂ = 70.7 V                         ← 选型耐压要 ≥ 这个值
选型要求：I_F ≥ 2 I_D = 60 mA  且  U_R ≥ U_RM = 70.7 V
```
- 2CP11：U_R = 50 V **< 70.7 V** ✗
- **2CP12：100 mA ≥ 60 mA ✓，100 V ≥ 70.7 V ✓ ⟹ 选 2CP12**
- 2CP13 也能用（150 V），但**过裕、不经济**，标准答案取 **2CP12**

**(2) 电容**

```
C ≥ (1.5 ~ 2.5)/(R_L f) = (1.5 ~ 2.5)/(1000 × 50) = 30 ~ 50 μF
U_CN ≥ √2 U₂ = 70.7 V            ← 耐压至少 70.7 V，取 100 V 档
```

# 五、开关波形题（完整解答）

**条件**：`R_L = 5 kΩ`、`C` 足够大、`U₂ = 30 V`。
**读图**：**S1 串在电容支路**，**S2 串在负载支路**。

| 小问 | 状态 | U_O | I_O |
|---|---|---|---|
| (1) S1、S2 都闭合 | 电容 + 负载 | `1.2U₂ =` **36 V** | **7.2 mA** |
| (2) S1 断、S2 闭 | 无电容、有负载 | `0.9U₂ =` **27 V** | **5.4 mA** |
| (3) S1 闭、S2 断 | 电容、**空载** | `√2U₂ =` **42.4 V** | **0** |
| (4) S1 断、S2 闭、**D2 断** | 桥式缺臂 → **半波** | `0.45U₂ =` **13.5 V** | **2.7 mA** |

**波形**：
- **u_o1**（第 1 问）：有电容有负载 ⟹ 近似平直直流，每半周期一个窄充电尖峰 + 缓慢放电的**小锯齿纹波**，纹波周期 `T/2 = 10 ms`
- **u_o2**（第 3 问，空载）：充到峰值后**一条水平线**（42.4 V），**不是锯齿**（无放电回路）
- (4) 为什么退化成半波：桥式里 D1D4 走正半周、D2D3 走负半周；D2 断 ⟹ 负半周没有通路

# 六、这套题的知识点（"后三道不会"要处理的）

1. **四个系数**：`0.45`（半波）/`0.9`（全波·桥式）/`1.2`（桥式+C 有载）/`√2`（桥式+C 空载）—— 第一步永远先问"**有没有电容、有没有负载**"
2. **二极管两额定**：平均电流 `I_D`（桥式 `= ½I_O`，半波 `= I_O`）与耐压 `U_RM = √2U₂`；选型 `I_F ≥ 2I_D`、`U_R ≥ U_RM`
3. **电容两参数**：容量 `(1.5~2.5)/(R_L f)`、耐压 `√2U₂`
4. **选型题的做法**：先算"要求值"，再拿表里的型号逐个比 —— **两个条件都要满足**，够用且不过裕的那个就是答案
5. **开关/断路题**：拆成"电容支路通不通？负载支路通不通？二极管还通不通？"三问，每问对应 §0 表里的一行
