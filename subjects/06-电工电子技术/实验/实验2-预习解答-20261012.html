Q1　基尔霍夫定律与电路元件的性质（线性与非线性）有关系吗？电路中能否出现单纯由理想电压源构成的回路？能否出现单纯由理想电流源构成的结点？为什么？（＝册 p04 第 1 问前半）

答：基尔霍夫定律与元件是否线性无关；两种"纯理想源"的结构都不允许出现。

  • KCL 来自电荷守恒、KVL 来自能量守恒，只依赖电路的连接方式（拓扑）与参考方向，支路里装电阻、电容还是二极管都照样成立。
  • 单纯由理想电压源构成的回路不允许：KVL 要求沿回路 ΣU = 0，而理想电压源的电压由自身钉住、与电流无关，这样的回路一般写不出 ΣU = 0（等价说法：两个电压值不同的理想电压源不能并联）。
  • 单纯由理想电流源构成的结点不允许：KCL 要求结点上 ΣI = 0，而理想电流源的电流由自身钉住、与端电压无关，只有各源电流恰好相等且方向配合才可能（等价说法：两个电流值不同的理想电流源不能串联）。
EN — Q1

Kirchhoff's laws are independent of whether the elements are linear or nonlinear: KCL follows from conservation of charge and KVL from conservation of energy, so they depend only on the circuit topology and on the reference directions. A loop consisting only of ideal voltage sources cannot exist, because KVL would require the sum of the voltages around the loop to be zero, while each ideal voltage source fixes its own voltage independently of the current (equivalently, two ideal voltage sources of different values cannot be connected in parallel). A node connected only to ideal current sources cannot exist either, because KCL would require the sum of the currents at that node to be zero, while each ideal current source fixes its own current independently of the voltage (equivalently, two ideal current sources of different values cannot be connected in series).

Q2　理想电压源与实际电压源有什么区别？理想电流源与实际电流源有什么区别？理想电压源与理想电流源能否等效互换？实际电压源与实际电流源能否等效互换？为什么？（教材附加；册子未问）

元件模型外特性
理想电压源U_S（内阻 R₀ = 0）端电压恒为 U_S，与电流无关（水平线）
实际电压源U_S 与内阻 R₀ 串联U = U_S − I R₀，随电流增大而下降
理想电流源I_S（内阻 R₀ = ∞）输出电流恒为 I_S，与端电压无关（垂直线）
实际电流源I_S 与内阻 R₀ 并联I = I_S − U/R₀，随端电压升高而减小
  • 理想电压源 ⇄ 理想电流源：不能等效互换。一个是"电压恒定"，一个是"电流恒定"，外特性是两条不同的线（水平 vs 垂直）。
  • 实际电压源 ⇄ 实际电流源：能等效互换，条件是内阻相同且 U_S = R₀ I_S（书 p.26 原式）。此时两者端口的 U–I 关系完全相同 ⇒ 对外电路等效；对电源内部（内部电流、内部功率）不等效。
EN — Q2

An ideal voltage source keeps a constant terminal voltage U_S that is independent of the current (internal resistance R₀ = 0), whereas a real voltage source is an ideal source U_S in series with an internal resistance R₀, so its terminal voltage falls as the current increases: U = U_S − I·R₀. In the same way, an ideal current source delivers a constant current I_S independent of the terminal voltage (R₀ = ∞), whereas a real current source is an ideal source I_S in parallel with R₀, so its output current decreases as the terminal voltage rises: I = I_S − U/R₀.

An ideal voltage source and an ideal current source cannot be transformed into each other, because their external characteristics are completely different (constant voltage versus constant current). A real voltage source and a real current source can be transformed into each other if they have the same internal resistance and satisfy U_S = R₀·I_S; then the two models have exactly the same terminal U–I relation, i.e. they are equivalent as seen from the external circuit (but not internally).

Q3　电压源与电流源不使用时应该怎样处理？应该置于开路状态还是短路状态？为什么？（＝册 p04 第 2 问）

答：不使用的电压源应短路（移出电路并用短路线代替）；不使用的电流源应开路（移出电路）。

  • 书 p.25 原话：*"在验证叠加定理时，每测量一个电源作用时的响应，其余所有不作用的理想电压源应移出电路，并用短路线代替，切记不能将电压源短路；对于所有不作用的理想电流源也应移出电路，即用开路代替。"*
  • 理由：要把电源"置零"——理想电压源输出 0 V ⇒ 相当于一根导线（串联内阻 0）；理想电流源输出 0 A ⇒ 相当于断开（并联内阻 ∞）。
  • ⚠ 实验台操作：真实稳压电源不能把输出端直接短接；书上要求的是"移出电路＋用短路线代替（或用开关 S₁／S₂ 切换到另一侧，让它不接入电路）"。本实验正是用开关 S₁、S₂ 实现这一点。
EN — Q3

A voltage source that is not in use must be removed from the circuit and replaced by a short circuit, while a current source that is not in use must be removed from the circuit, i.e. replaced by an open circuit. Setting a source to zero means: an ideal voltage source gives 0 V, which is equivalent to a piece of wire (its internal resistance is zero), and an ideal current source gives 0 A, which is equivalent to a break (its internal resistance is infinite). In this experiment the two sources are set to zero by switching S₁ and S₂ so that the corresponding source is not connected to the circuit; the output terminals of a real stabilized supply must never be short-circuited directly.

Q4　简述叠加定理的应用条件，说明为什么功率不能用叠加方法计算。（＝册 p04 第 1 问后半）

  • 应用条件：电路必须是线性的（各元件伏安关系为过原点的直线），且可以含多个独立电源；求某个电源单独作用时把其余电源置零（Q3 的规则）。
  • 为什么功率不行：功率 P = I²R（或 U²/R）是电流（电压）的二次关系，(I₁ + I₂)² ≠ I₁² + I₂²，所以"各电源单独作用时的功率之和"≠"共同作用时的功率"。
EN — Q4

The Superposition Theorem applies only to linear circuits: for each source acting alone the other independent sources must be set to zero (unused voltage sources short-circuited, unused current sources open-circuited), and the total response is the algebraic sum of the individual responses. It cannot be used for power, because power is a quadratic function of current or voltage (P = I²R or U²/R) and (I₁ + I₂)² ≠ I₁² + I₂².

Q5　电流表应该与被测支路＿＿（a. 并联, b. 串联），电压表应该与被测支路＿＿（a. 并联, b. 串联）。（＝册 p04 第 3 问前半）

答：电流表 — b. 串联；电压表 — a. 并联。（电流表内阻很小，串联接入才不会改变支路电流；电压表内阻很大，并联接入才几乎不分流。）

EN — Q5

The ammeter must be connected in series with the branch being measured (b), and the voltmeter must be connected in parallel with it (a).

Q6　如果电压表与电流表接错了会产生什么后果？测量时若出现仪表指针反向偏转现象应该如何处理？（＝册 p04 第 3 问后半）

  • 电流表错接成并联：内阻极小 → 近似把被测支路短路，电流表过流、可能烧表，同时电路工作状态被破坏。
  • 电压表错接成串联：内阻极大 → 支路电流被压到近 0，电路等于断路，读数无意义。
  • 指针反向偏转：说明仪表极性接反（直流表"+"端应接高电位）。处理：断电 → 调换仪表两根表笔（接线极性）→ 重新测量；读数按参考方向取负值。数字式仪表可直接读出正负，不必调换。
EN — Q6

If an ammeter is connected in parallel by mistake, its very small resistance nearly short-circuits the branch: the meter is overloaded and may be damaged, and the circuit no longer works normally. If a voltmeter is connected in series by mistake, its very large resistance reduces the branch current almost to zero, so the circuit is effectively broken and the reading is meaningless. If the pointer deflects in the reverse direction, the polarity of the meter is reversed: switch the supply off, interchange the two leads of the meter (the "+" terminal must be connected to the higher potential) and measure again; the measured value is then recorded as negative with respect to the assumed reference direction. A digital meter reads the sign directly, so no interchange is needed.

Q7　相对误差怎么算？拿不到"真值"时怎么算？（＝册 p04 第 4 问）

答：γ =（测量值 − 真值）/ 真值 × 100%；真值拿不到时，用约定参考值（标称值／理论计算值）代替。

  • 绝对误差 Δ = 测量值 − 真值（带单位）；相对误差 γ = Δ / 真值 × 100%（工程上常取绝对值）。
  • 本实验的两类参考值：① 电阻测量 → 电阻的标称值（表 2.1.2 的"标称值/Ω"）；② 电流、电压 → 由电路理论计算出的值（表 2.1.3 的"计算值"）。写清参考值取自何处。
  • 数据保留一位小数；凡计算题写"公式 → 代入 → 结果 + 单位"（书 §2.1.7 与册 p08 均如此要求）。
EN — Q7

Relative error: γ = (measured value − true value) / true value × 100%, where the absolute error is Δ = measured value − true value (with a unit). Since the true value cannot be obtained in practice, a conventional reference value is used instead: the nominal value of the resistor for resistance measurements (Table 2.1.2) and the value calculated from circuit theory (nodal or mesh analysis) for currents and voltages (Table 2.1.3). Hence γ = |measured − reference| / |reference| × 100%, and the reference actually used must be stated in the report. Record measured data to one decimal place and write every calculation as formula → substitution → result with unit.

四、§2.1.5 电源外特性与"两种模型等效变换"的课前设计

4.1　书上的等效条件（p.26 原式）

实际电压源（US 串 R₀）与实际电流源（IS 并 R₀）等效 ⟺ US = R₀ IS，且两者内阻 R₀ 相同。
外特性同一条直线：U = US − I R₀（电压源式）＝ (IS − I) R₀（电流源式）。

白话版：从负载两端往里看，这两种接法是同一个东西 —— 测出来的 U–I 数据落在同一条直线上就是"等效"。
换算只有一句：IS = US / R₀（本设计：12 V ÷ 1 kΩ = 12 mA）。
⚠ 符号别混：IS ＝ 电流源自身的电流（定值）；I ＝ 流过负载的电流（随负载变，如 RL = 1 kΩ 时 I = 6 mA）。
