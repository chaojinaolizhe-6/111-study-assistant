## 第 1 件｜项目1：表1 的 9 个数 + 电路图

**要产出**：I1、I2、I3（mA）+ UAB、UCD、UAD、UDE、UFA（V）+ **铅笔直尺手绘电路图（标出所有元件数值）**

- V_F = V_E + 6 = **6 V**（U1 是理想电压源，钉死 F、E 的电位**差**）
- V_B − V_C = **12 V**（U2 钉死的是**差值**，不是各自的值）

**未知量 3 个**：V_A、V_C、V_D（V_B = V_C + 12）→ 需要 **3 个方程**：

| 方程 | 写法（离开节点的各支路电流之和 = 0；每条电流 = 电位差/电阻） |
|------|------|
| ① A 点 KCL | (V_A − 6)/510 + (V_A − V_B)/1000 + (V_A − V_D)/510 = 0 |
| ② D 点 KCL | (V_D − V_A)/510 + (V_D − 0)/510 + (V_D − V_C)/330 = 0 |
| ③ U2 支路（**2026-09-29 更正：原写"= "是错的**） | A–R2–B–U2–C–R5–D 是**一条串联支路**，同一个电流从 A 流到 D：**（V_A − V_B)/1000 = (V_C − V_D)/330**；等价于 (V_B − V_A)/1000 + (V_C − V_D)/330 = 0；且 V_B = V_C + 12。⚠ 原先把两边写成相等（等价于电流"反向也相等"），会解出错误电位 |

**解出 V_A、V_C、V_D 后，按下表算出 9 个数：**

| 量 | 公式 | 单位换算 |

## 第 3 件｜项目2：4 个数（Uab、IR、IC、IL）

**先记两条**（这是全部的关键）：V1、I1 都是**直流**；**直流稳态下电容支路电流 = 0（开路）、电感相当于短路（两端电压 = 0）**。

**算**：
1. **IC = 0**（稳态，电容不通直流）——直接写结论 + 一句理由
2. **V_a** 由 V1 直接给出（V1 接在 a 与地之间）→ 写出来
3. **V_b = 0**（L1 在直流稳态是短路，b 直接连到地）
4. **Uab = V_a − V_b**
5. **IR = Uab / R1**
6. **IL**：对 **b 点**写 KCL（流入 = 流出）——I1 注入 b、R1 的电流也进 b，两者之和从 L1 流出 → 解出 IL

## 第 4 件｜项目3：2 个判断（两个电流源各是电源还是负载）

**判据**：算每个电流源的**端电压 U** 与流过它的**电流 I**，用 **P = UI 的符号**：
**电流从 "+" 端流出 ⇒ 发出功率 ⇒ 电源**；**电流从 "+" 端流入 ⇒ 吸收功率 ⇒ 负载**。

**算的顺序**：
1. 对**节点 4** 写 KCL，先求出 R2 上的电流 → 得到 **V4**（这一步的结果可能出乎意料，别怀疑仿真坏了）
2. 由 R1 上的 5 A 得 **V3 = V4 + 5 A × 5 Ω**
3. 算 **I1 的端电压 = V3 − 0**、**I2 的端电压 = V4 − 0**
4. 各乘 5 A 得功率，按符号判"电源 / 负载"

**自查**：R1 消耗的功率（I²R）应当等于 I1 发出的功率。

## 第 5 件｜项目4：2 个判断 + 谐振频率

**公式**：XL = 2πfL，XC = 1/(2πfC)，谐振频率 **f₀ = 1/(2π√(LC))**。本题 V1 频率 **f = 1 kHz**，C1 = **1 μF**。

**要产出**：
1. 用 C1 与 f 算出 **XC**（一个数）
2. 分别算 **L1 = 25 mH 与 50 mH 的 XL**（两个数）
3. 各自与 XC 比较 → 判断**容性 / 感性 / 谐振**（XL < XC 容性；XL > XC 感性；XL = XC 谐振）
4. 用 C1 与 f₀ = 1 kHz 反推**与之谐振的电感值** → 看它落在 25 mH 还是 50 mH 附近（这解释为什么选这两个值）

**进机房后**：用示波器看**电压与电流波形的相位差**来验证上面的判断（波形图在机房截图，不占预习时间）。
