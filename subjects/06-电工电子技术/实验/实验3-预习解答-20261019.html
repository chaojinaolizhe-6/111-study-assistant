二、动手前先补三个要点（新知识，先讲透再用）

2.1 有效值不能代数相加：要按相量相加

仪表读出来的 U 和 I 都是有效值，而交流电路里各电压、电流的相位不同，所以教材明确写：这些值不能进行简单的代数和。

正确写法是相量形式的基本定律：

Σ U̇ = 0

Σ İ = 0

一个最直观的检验：荧光灯电路中灯管电压 U_R 约 100 V、镇流器电压 U_L 约 190 V，两者之和接近 290 V，可电源只有 220 V。这不是测量错了，而是两个电压相位差接近 90°，只能按直角三角形合成：

U² = U_R² + U_L²

代入 220 V 与 103 V 验算，可得 U_L ≈ 194 V，而算术和 103 + 194 = 297 V 远大于 220 V。"和大于总"就是相位不同的证据，这也正是后面讨论与第 6 题要用的材料。

2.2 三表法：一块表变出四个量

在正弦交流电路中，只要用交流电压表、交流电流表、功率表分别测出负载两端的 U、流过负载的 I 和有功功率 P，就能把整个负载模型算出来。这就是教材 §2.3.3 第 2 条的"三表法"。

|Z| = U / I

cos φ = P / (U I)

Z = R + jX = |Z| cos φ + j |Z| sin φ

R = P / I² = |Z| cos φ

φ > 0（感性）时 L = |Z| sin φ / ω

φ < 0（容性）时 C = 1 / (ω |Z| sin φ)

其中 ω = 2πf，我国工频 f = 50 Hz，所以

ω = 2π × 50 ≈ 314.16 rad/s

四条使用说明，每一条都会在明天真的用上：

  1. cos φ 的符号靠 P 的正负和负载性质判断。功率表读数 P 为正、且电流滞后电压，就是感性；纯电容的 P ≈ 0。

  2. R = P/I² 与 R = |Z|cos φ 是同一个式子的两种算法，现场算完互相校验一遍，能立刻发现抄错数。

  3. 电感线圈不是纯电感。40 W 荧光灯镇流器是有铁心的线圈，本身带电阻，所以它的 |Z| 里既有 ωL 也有 R；这就是表 2.3.3 里"电感线圈 L"那一行同时要算 R 与 L 的原因。

  4. 理想电容不消耗有功，所以电容器那一行 P 应该接近 0，cos φ 接近 0。如果 P 明显不为 0，先怀疑仪表量程或接线，而不是怀疑电容。

2.3 并联电容提高功率因数：为什么有效，为什么不是越大越好

这是本次实验最有"工程味"的一块，也是预习问题里最容易被问倒的地方。

为什么需要提高功率因数。 负载消耗的有功 P 是一定要送的，但电源和线路要按视在功率 S 供电：

S = P / cos φ

cos φ 越小，同样的 P 就要更大的 S，也就意味着更大的线路电流：

I = S / U = P / (U cos φ)

线路和变压器上的损耗按 I²R 走，所以 cos φ 低会直接烧在电费与设备容量上。荧光灯这类感性负载的 cos φ 通常只有 0.4~0.5，是最典型的补偿对象。

为什么并联电容有效。 电感性负载的电流滞后电压一个 φ 角；电容电流超前电压 90°。两者并联后，电容提供的超前无功正好抵消掉负载需要的滞后无功，电源只需再补剩下的部分：

Q_net = Q_L − Q_C，其中 Q_C = U² / X_C = ω C U²

无功互补之后，有功 P 一点没变，视在功率 S 变小，总电流自然变小。

为什么不用串联电容。 串联电容会改变负载两端电压：感性负载的感抗被容抗抵消后总阻抗下降，负载电压升高，荧光灯这类负载不能正常工作；若接近谐振还会出现过电压。并联电容则完全不改变负载自身的工作电压，负载仍旧接在 220 V 上。

补偿电容要多少。 把 cos φ 从 φ₁ 提到 φ₂，需要的电容为：

C = P (tan φ₁ − tan φ₂) / (ω U²)

要注意这个式子里的 P 是负载实际消耗的有功功率（含镇流器损耗），不是灯管的标称 40 W。

为什么不是越大越好。 当 Q_C 追平 Q_L 时：

cos φ = 1，I_min = P / U

此时总电流最小。再继续加电容就进入过补偿，Q_net 变负，电路整体呈容性，总电流反而回升，电容电流本身和线路损耗都在增加，还可能引发谐振过电压。工程上一般只补到 0.9~0.95。

3.1 理论知识 3 问

问 1　在并联交流电路中，支路电流如果大于总电流，是否正确？为什么？

答：正确。

交流并联电路里各支路电流是相量，相位互不相同，总电流等于各支路电流的相量和，不是算术和。相量相加服从三角形法则，合成相量的模完全可能小于其中某一条支路的模。

最典型的情形就是电感性支路与电容器并联：电容电流超前电压 90°，感性支路电流滞后电压 φ，两者相互抵消一部分无功分量，所以总电流反而小于电感性支路的电流。这正是荧光灯电路并联补偿电容后总电流下降的原因。

Correct. In an AC parallel circuit the branch currents are phasors with different phase angles; the total current is their phasor sum, not their algebraic sum. A phasor sum can be smaller than one of its components. When an inductive branch is paralleled by a capacitor, the leading capacitive current cancels part of the lagging reactive component, so the supply current becomes smaller than the current of the inductive branch itself.

问 2　电感性负载并联电阻能否提高功率因数？这种方法是否适用？为什么？

答：能把 cos φ 的数值做大，但没有真正提高功率因数，因此不适用。

设负载有功为 P、无功为 Q。并联电阻 R 之后，无功 Q 一点也没减少，只是多了一条消耗有功的支路：

cos φ′ = (P + P_R) / √((P + P_R)² + Q²)

P_R 越大，cos φ′ 越接近 1。但电源要输出的电流

I′ = √((P + P_R)² + Q²) / U

反而变大，线路损耗随之增加，还要多消耗有功功率。

提高功率因数的目的是"用更小的电流传输同样的有功功率"。并联电阻把电流做大了，方向正好相反，所以工程上不采用，只用并联电容（或同步补偿机）来补无功。

It does increase the numerical value of cos φ, but not by the intended mechanism. The reactive power Q is unchanged; the parallel resistor only adds real power, so cos φ′ approaches 1 while the supply current I′ actually increases. Since power-factor correction aims at reducing the current for the same real power, this method is not used.

问 3　提高电感性负载功率因数为什么采用并联电容的方法，而不采用串联电容的方法？是否并联的电容越大越好？为什么？

答：分三点。

（1）并联不干扰负载。 并联后负载仍直接接在 220 V 电源上，端电压、电流、功率都不变，荧光灯照常工作。电容只是额外向电源提供超前无功，与负载的滞后无功相互抵消，使电源输出的总电流减小。

（2）串联会改变负载电压。 串联电容后总阻抗变化，负载端电压被升高或降低，负载不能正常工作；若串联容抗接近抵消感抗，还会出现谐振过电压，对设备和人身都危险。

（3）不是越大越好。 当 Q_C = Q_L 时 cos φ = 1、总电流最小；继续增大电容即过补偿，电路转为容性，无功方向反转，总电流重新上升，电容电流增大、线路损耗增加，严重时引发谐振过电压。工程习惯补到 0.9~0.95 就停。

(1) A parallel capacitor leaves the load untouched: the load still runs at the supply voltage with unchanged current and power, and the capacitor only supplies leading reactive current that cancels part of the load's lagging reactive current. (2) A series capacitor changes the voltage across the load and may cause resonance overvoltage. (3) Bigger is not better: at Q_C = Q_L, cos φ = 1 and the current is minimum; beyond that the circuit becomes capacitive, the current rises again, and overcompensation with possible resonance overvoltage does harm.

3.2 实验内容 5 问

问 4　简述实验中用功率表测量有功功率时减小测量误差的方法。

答：五条。

① 按被测电流、被测电压选量程，不要按功率大小选。 教材 §8.4.2 明确：电流量程要略大于被测电流，电压量程要略高于被测电压。同时要让指针尽量落在满量程的 1/2 以上，读数才准。

② 遵守"发电机端"规则。 电流线圈和电压线圈的 *（或 +）端必须连到同一极性上（都接电源侧），否则转矩反向，指针反偏甚至被打弯。教材 §8.4.2 与图 8.4.3 给出标准接法。

③ 接法上选"电压线圈外接法"（教材 §2.3.5 的规定）。 功率表自身有两种损耗：电流线圈的 I²R_W 与电压线圈的 U²/R_V。本节 U = 220 V 很大、I ≈ 0.4 A 较小，电压线圈损耗占绝对主导，所以把电压线圈按图 8.4.3 外接到"电流线圈 + 负载"的外端，让电压线圈的损耗不进入读数，误差最小。

④ 读数按量程换算。 功率表通常有两个电流量程、两个以上电压量程，实际功率 = 分格数 × 每格瓦数；换了量程，每格瓦数也要跟着换。教材 §8.4.2 要求注意"量程和实际读数的换算关系"。

⑤ 三块表分别接入电路测量。 教材 §2.3.4 注意事项第 3 条：交流电压表、交流电流表和功率表应分别接入电路中，以减小测量误差——同时串在一起会让表内损耗互相叠加。

补充：功率表本身消耗功率较大，这是教材点明的固有误差来源。若接线正确而指针反偏，说明负载端实际上在向外输出功率，应换接电流线圈的接头使指针正转。

问 5　了解荧光灯的工作原理，说明镇流器和启辉器的作用。

答：按教材 §2.3.3 第 4 条的过程复述。

荧光灯由灯管、镇流器、启辉器三部分组成。灯管是内壁涂荧光物质的细长玻璃管，两端有灯丝电极，管内充稀薄的惰性气体与水银蒸气，灯丝上涂有受热易发射电子的氧化物。镇流器是带铁心的电感线圈。启辉器由一个小辉光管和一个小容量电容组成，装在一只圆柱形玻璃外壳内。

启辉过程（图 2.3.1）：

  1. 接通电源时灯管未点亮，电源电压全部加在启辉器的辉光管两个电极之间，辉光管产生辉光放电；

  2. 放电产生的热量使 U 形双金属电极受热趋于伸直，两电极（动触片与静触片）接触；

  3. 触片接触后，灯丝经此电极与镇流器、电源构成回路，灯丝通过启动电流（预热电流）而发热，氧化物发射电子；同时辉光管两极间电压为零，辉光放电停止；

  4. 双金属片温度下降而复原，两电极突然断开，回路电流被切断，于是镇流器两端产生一个比电源电压高得多的感应电压；

  5. 这个感应电压连同电源电压一起加在灯管两端，管内惰性气体电离产生弧光放电，管温升高后水银蒸气游离并猛烈碰撞惰性气体分子而放电，辐射出不可见的紫外线，紫外线激发灯管内壁荧光粉发出可见光——荧光灯被点亮。

点亮之后：灯管两端电压较低，启辉器两端电压不足以再辉光放电，启辉器不再起作用；此时镇流器起到降低荧光灯管端电压、限制其电流的作用，成为灯管的限流元件。

两个元件的作用，一句话概括：

元件 作用
启辉器 Starter 自动"接通—断开"：先让灯丝预热，再突然断开以让镇流器产生高压脉冲点燃灯管；点亮后自动退出工作
镇流器 Ballast 断开瞬间产生高压脉冲帮助起辉；点亮后作为串联电感限流、降压，使灯管工作在额定电流附近

The starter makes and breaks the preheat circuit: it preheats the electrodes and then opens abruptly so the ballast can generate a high-voltage pulse that strikes the arc. The ballast (an iron-core inductor) produces that pulse at the moment of opening and, once the lamp is lit, limits and drops the lamp current and voltage.

问 6　日常生活中的照明线路的开关应如何连接？为什么？试画图说明。

答：开关必须串接在相线（火线）上，绝不能接在零线（中性线）上。

原因：开关接在相线上，断开后灯具与相线脱离，灯具对地不带电，换灯泡、检修时人碰到也没事。若开关接在零线上，断开后灯具仍然与相线连通，只是回路在零线处断开；人一碰灯具就通过人体接地形成通路，实际等于没有断电，这是很典型的触电事故原因。

画图（用铅笔、直尺，标注 L / N / S / 灯）：

正确接法                             错误接法
L ──[ S ]──( 灯 )── N              L ──( 灯 )──[ S ]── N
相线上先断，灯不带电                  开关在零线，断开后灯仍带电

英文报告写法：

The switch must be connected in series with the live (phase) conductor, never in the neutral conductor. With the switch in the live line, opening it isolates the luminaire from the live side, so the luminaire is dead and safe to touch. If the switch were placed in the neutral line, the luminaire would remain connected to the live conductor after switching off, and touching it would complete a path to earth through the body — a classic electric-shock hazard.

问 7　选择题：在荧光灯电路中并联电容之后，随着电容的增加，电路的总电流逐渐减小到最小值，此时电路处于 __ 性负载电路；当电容超过一定值之后，电路的总电流 _，这时电路变成 ___ 性负载电路。

答：电阻；上升；电容。

即选 (a. 电阻)、(a. 上升)、(c. 电容)。

理由：并联电容的过程就是逐步抵消负载滞后无功的过程。当 Q_C = Q_L 时无功全部补偿掉，电路只剩有功，呈电阻性，总电流降到最小 I_min = P/U。电容继续增大则 Q_C > Q_L，无功反向多出来，电路整体变容性，总电流重新上升。

When the parallel capacitance is increased, the total current decreases to a minimum where the reactive power is fully compensated; the circuit then behaves as a resistive load. Beyond that point the circuit becomes capacitive and the total current rises again.

问 8　用相量图说明为什么在负载两端并联小电容可以判别负载的性质。

答：以电压 U̇ 为参考相量。

负载电流 İ_L 与电压的夹角是 ±φ；电容电流 İ_C 严格超前 U̇ 90°，模长 I_C = ωCU。并联后总电流

İ = İ_L + İ_C

关键在于 İ_C 与 U̇ 垂直，所以它对合成相量模长的影响方向取决于 İ_L 落在 U̇ 的哪一侧：

  • 若负载是感性的，İ_L 落在 U̇ 的右下方（滞后）。加上一个指向"更逆时针"的 İ_C 后，合成相量被拉向 U̇ 方向，模变小 → 总电流减小。

  • 若负载是容性的，İ_L 已经落在 U̇ 的右上方（超前）。İ_C 与它同侧，合成相量被推得更远，模变大 → 总电流增加。

于是判据成立：并小电容后电流减小 → 感性；电流增加 → 容性。

串联电容的对应判据（教材 §2.3.3 第 3 条）：串入适当电容后，感性负载的感抗被容抗抵消，总阻抗变小、电流变大，负载端电压上升；容性负载则容抗叠加、总阻抗变大，负载端电压下降。所以

操作 现象 结论
并联小电容 总电流减小 感性负载
并联小电容 总电流增加 容性负载
串联小电容 负载端电压下降 容性负载
串联小电容 负载端电压上升 感性负载

With the voltage taken as the reference phasor, the capacitive current İ_C leads U̇ by exactly 90°. Adding it to İ_L brings the resultant closer to U̇ when the load is inductive (the current drops) and pushes it further away when the load is capacitive (the current rises). Hence the sign of the current change identifies the nature of the load.

五、理论预演：用一组好算的数字把整套计算走一遍

下面的示例数字是为了算式好算而设计的（学习者偏好），现场测到的数会不一样，但公式与步骤完全一致。报告里必须用你实测的数重算一遍，不能抄这里的数。

5.1 白炽灯 R（教材要求 R 两端取 200 V）

15 W / 220 V 白炽灯的额定电阻

R ≈ U_额² / P_额 = 220² / 15 ≈ 3.23 kΩ

接到 200 V 上：

I = U / R = 200 / 3226.7 ≈ 62 mA

P = U I ≈ 200 × 0.062 ≈ 12.4 W

于是 |Z| ≈ 3.23 kΩ，cos φ ≈ 1.0，白炽灯是纯电阻性负载。

提醒：钨丝电阻随温度升高而增大，所以冷态用万用表量出的电阻会明显小于工作时的等效电阻，这不是测错。报告里两个数都写清楚，正好是一个很好的讨论点。

5.2 电感线圈 L（假设测到 U = 200.0 V、I = 0.400 A、P = 48.0 W）

|Z| = U / I = 200.0 / 0.400 = 500.0 Ω

cos φ = P / (U I) = 48.0 / (200.0 × 0.400) = 0.600

R = P / I² = 48.0 / 0.160 = 300.0 Ω，校验 |Z|cos φ = 500.0 × 0.600 = 300.0 Ω ✓

sin φ = √(1 − 0.600²) = 0.800

ωL = |Z| sin φ = 500.0 × 0.800 = 400.0 Ω

L = 400.0 / 314.16 ≈ 1.273 H ≈ 1273 mH

5.3 电容器 C（取 4.7 μF，在 200 V、50 Hz 下）

X_C = 1 / (ω C) = 1 / (314.16 × 4.7×10⁻⁶) ≈ 677.3 Ω

I = U / X_C = 200 / 677.3 ≈ 0.295 A ≈ 295 mA

P ≈ 0（理想电容不消耗有功），cos φ ≈ 0

反算校验：

C = 1 / (ω |Z| sin φ) = 1 / (314.16 × 677.3) ≈ 4.70 μF ✓

5.4 L 与 C 串联（把 5.2 与 5.3 的元件串起来）

Z = R + j(ωL − 1/(ωC)) = 300.0 + j(400.0 − 677.3) = 300.0 − j277.3 Ω

|Z| = √(300.0² + 277.3²) ≈ 408.5 Ω

φ = arctan(−277.3 / 300.0) ≈ −42.7°，即容性

在 200 V 下：

I = 200 / 408.5 ≈ 0.490 A

cos φ = 300.0 / 408.5 ≈ 0.734

这一步是表 2.3.3 最后一行存在的意义：单看 L 或 C 都是"感性/容性"，串起来之后谁的抗大谁说话，结果由 ωL 与 1/(ωC) 的大小关系决定，不由元件名字决定。

5.5 荧光灯功率因数补偿（假设测到 U = 220 V、I = 0.409 A、P = 45 W）

补偿前：

cos φ₁ = P / (U I) = 45 / (220 × 0.409) ≈ 0.50

要把 cos φ 提到 0.90。查得 tan φ₁ = tan 60° ≈ 1.732，tan φ₂ = tan 25.84° ≈ 0.484，于是所需电容

C = P (tan φ₁ − tan φ₂) / (ω U²)

C ≈ 45 × (1.732 − 0.484) / (314.16 × 220²) ≈ 3.69×10⁻⁶ F ≈ 3.7 μF

手边档位只有 1.0、2.2、3.2、4.7、5.7 μF，所以 3.2 与 4.7 分别在 0.9 的两侧，两档都要认真测，报告里说明哪一档更接近 0.9、差多少。

全补偿点（Q_C = Q_L）对应的电容：

Q_L = P tan φ₁ = 45 × 1.732 ≈ 77.9 var

C_全补偿 = Q_L / (ω U²) = 77.9 / (314.16 × 220²) ≈ 5.13 μF

也就是说 5.7 μF 那一档已经越过全补偿点进入过补偿，总电流会比 4.7 μF 那档略大、cos φ 略低。

按这组假设值算出的五档对照表（现场用来对照趋势，真实数字以你测到的 P 与 cos φ₁ 重算）：

C/μF I_C/A I/A cos φ
1.0 0.069 0.351 0.58
2.2 0.152 0.288 0.71
3.2 0.221 0.244 0.84
4.7 0.325 0.207 0.99
5.7 0.394 0.208 0.98

这张表读出来的三件事，正是表 2.3.5 要你总结的结论：

  1. I_C 随 C 单调增大，且 I_C = ωCU 是可直接算出来的；

  2. 总电流 I 先减后增，最小值落在 4.7 μF 附近（理论全补偿点 5.13 μF）；

  3. cos φ 先升后降，4.7 μF 处达到 0.99，5.7 μF 处已回落。

2) 根据表 2.3.4 的实验数据，计算荧光灯的功率因数。 → cos φ = P_LR /(U·I)。算完与功率表的直接读数对比，差值就是两台表引入的误差。

Calculate the power factor of the fluorescent lamp circuit from Table 2.3.4.

3) 完成表 2.3.5 中功率因数的计算，并根据表 2.3.5 的实验数据，总结在荧光灯电路中，随着电容值的改变，哪些物理量应随之改变？如何变化？哪些物理量应不变？

→ 应变的：I_C（随 C 线性增大）、I（先减后增）、cos φ（先升后降）、Q（先减小、过补偿后变负）。

→ 应不变的：U（电源仍 220 V）、P / P_LR（有功由负载本身决定，电容不消耗有功）、P_C ≈ 0、I_L（灯管—镇流器支路电流，由负载阻抗与端电压决定，不受并联电容影响）、U_R（灯管端电压）。

这张"变 / 不变"表是本题的得分点：它把"并联电容只改变无功分配、不改变负载工作状态"这句话变成了证据。

4) 用实验数据举例说明改善功率因数的意义，说明补偿电容的容值与电路等效功率因数的关系。

→ 意义：P 不变时 cos φ 越大，S = P/cos φ 越小，I = P/(U cos φ) 越小，线路与变压器损耗 I²R 下降，设备容量利用率提高。用补偿前后实测的 I 之差直接算一次"电流减少了百分之多少"，最有说服力。

→ 关系：cos φ 随 C 单调上升至 1（全补偿点 C = Q_L/(ωU²)），随后转为下降；所以存在一个最优电容值，不是越大越好。

5) 在日常生活中，如果缺少启辉器，在确保安全的前提下，通常采用什么办法将荧光灯点亮？

→ 用一段绝缘导线瞬间短接启辉器座的两个接线柱，随即迅速移开（或用绝缘柄螺丝刀的金属杆碰一下再离开）。这等于人工完成启辉器"先接通、再突然断开"的动作，镇流器在断电瞬间产生高压脉冲把灯管点亮。

⚠ 这一步是带电操作，必须在确保安全的前提下进行；实验中由老师演示，不要自己上手模仿。

6) 用实验数据验证电压、电流的相量关系。

→ 取表 2.3.4 的 U、U_R、U_L：若把灯管近似视为纯电阻、镇流器近似视为纯电感，三者应满足

U² ≈ U_R² + U_L²

算完比较一下 U 与 U_R + U_L 的差距，并把 |U − √(U_R² + U_L²)| 作为合成误差列出来。差距越大越说明"有效值不能代数相加"。

→ 电流侧同理：I ≠ I_L + I_C，而应满足

I² ≈ (I_L cos φ_L)² + (I_L sin φ_L − I_C)²

这一条正好把表 2.3.5 的 I、I_L、I_C 三列用起来。

7.2 通电与断电的铁律

  1. 接线前：调压器调到 0 V，所有电源开关断开。

  2. 接线后：先自查（电压表并联、电流表串联、功率表 * 端同侧），再请同组同学复核。

  5. 结束：先降压到 0 V，再断电源，最后拆线。
