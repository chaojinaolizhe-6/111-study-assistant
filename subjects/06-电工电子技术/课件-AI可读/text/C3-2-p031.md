图1：电路图（单相桥式整流＋电容滤波）。左侧变压器：一次绕组标 u₁ 并标出 +（上）−（下）参考极性，二次绕组标 u₂，同样标 +（上）−（下），说明 u₂ 与 u₁ 同相位的参考方向。二次绕组上端引出一条横线接到桥臂上端，下端接桥臂下端。四只二极管成桥：上臂左右两只标 VD₁（左）、VD₂（右），下臂左右两只标 VD₄（左）、VD₃（右）；图中二极管为三角形—横杠符号，可辨认 VD₁、VD₃ 为实心黑三角，VD₂、VD₄ 为空心三角，仅表示符号画法/或高亮状态，不改变桥式接法。桥的两个交流输入端分别接二次绕组上、下端，两个直流输出端为桥的上横线（正端）与下横线（负端）。上横线与下横线之间并联两条支路：电容 C（标 C，极板旁标 +，即上端为正极板）与负载电阻 R_L（标 R_L），两者并联，负载两端电压标 u_O；负载支路上有向下的电流箭头 i_O，上端标 +、下端标 −，说明 u_O 与 i_O 的参考方向为关联的正方向。②元件与标注：u₁、u₂、VD₁~VD₄、C、R_L、u_O、i_O、+／− 极性标记。③拓扑：全波桥式整流器输出端并接滤波电容 C，负载 R_L 与 C 并联，C 处在整流器与负载「之间」的并联位置（跨接在直流输出两端）。④坐标与极性：变压器标 +、− 表示 u₁、u₂ 的正方向；输出端 +、− 表示 u_O 正方向；C 极板 + 号表示充电极性与输出同向。⑤动作：桥式整流后的脉动直流给 C 充放电，把脉动电压削平。版面文字（图下方黄色高亮结论）：（R_L = ∞）：u_L = u_C = √2 u₂，即负载开路时电容充电到二次电压峰值。

图2：波形图（输出电压 u_O 随 ωt 变化，即电容滤波的充放电波形）。纵轴标 u_O，横轴标 ωt，原点标 O，横轴上有一段虚线标出并标注 √2 U₂，作为脉动电压的峰值参考线。图中蓝色粗实线段为电容充电段（沿整流后正弦上升），红色粗实线为电容放电段（近似斜直线缓慢下降），灰色虚线段为整流后正弦波形的其余部分（被电容电压高于它时截止而不出现）；红色竖向虚线把每个放电起点/终点标出，并以引线连到标注「Discharge」的方框。右侧有两个色块标注：黄色块 τ = R_L C（放电时间常数），粉色块 R_L → ∞。坐标轴上未给出 π/2π/3π 等刻度标值，只标出 √2 U₂ 一条峰值参考线。⑤动作：说明电容在整流电压上升时充电、在整流电压下降时向 R_L 放电，负载电压因此被抬高并变平滑；R_L → ∞ 时电容几乎不放电，u_O 保持 √2 U₂。版面文字：图左下两个绿色对话气泡「What happens when the output is open」「How much is the output voltage when the output is open?」，并配吉祥物插画；右下黄色高亮公式（R_L = ∞）：u_L = u_C = √2 u₂。

**读图要点**：这页用同一组桥式整流＋电容滤波电路与 u_O–ωt 波形对照，讲电容充放电把脉动电压抬高并削平，读图要盯住放电段（红色斜线）随时间常数 τ = R_L C 变化而决定平滑度，以及 R_L → ∞ 时输出保持 √2 U₂ 的极限。
