## 图区内容（AI 视觉通读）

- 图1

图1：正弦波形图与静止矢量图上下对照（左列，初相为零）。上图为橙色正弦曲线，纵轴标 i（斜体）、横轴标 ωt（斜体）、原点标 O（斜体），波形自原点开始按正弦规律起伏，绿色标注「ψ = 0°」。下图为十字坐标内的橄榄色圆，自圆心向右画出一根品红色水平箭头，箭头指向水平正向且不再画出旋转弧形箭头，表示把旋转矢量冻结在 t = 0 时刻得到的静止矢量（相量）。

图2：正弦波形图与静止矢量图上下对照（中列，初相为正）。上图波形相对纵轴整体左移，纵轴左侧用竖直虚线标出起始过零点，两根绿色水平箭头与 ψ 标在虚线一侧，绿色文字「0 < ψ < 180°」。下图圆内的品红色矢量指向右上方（第一象限），矢量旁未再重复标注 ψ，表示初相为正时相量停在水平正向转过正角的位置。

图3：正弦波形图与静止矢量图上下对照（右列，初相为负）。上图波形相对纵轴整体右移，纵轴右侧用竖直虚线标出起始过零点，绿色水平双箭头与 ψ 标在纵轴右侧，绿色文字「−180° < ψ < 0°」。下图圆内的品红色矢量指向右下方（第四象限，即水平正向转过负角的位置）。

图4（版面对照标注）：三列波形图的坐标约定相同，纵轴为电流 i（斜体）、横轴为相位 ωt（斜体）、原点标 O（斜体）；本页与前一页的区别只在下方圆内的矢量：前一页是带黑色弧形箭头的旋转矢量，本页是只有品红色箭头、不带旋转弧线的静止矢量；两页三列的绿色初相文字完全相同（ψ = 0°、0 < ψ < 180°、−180° < ψ < 0°），图中无元件符号与 Tr、D/VD、RL、C、L、u₂、uO、β、IB、UCE 等标注。

**读图要点**：这页在同一组初相下把「正弦波 ↔ 旋转矢量 ↔ 静止矢量」串起来：读图要盯住圆内那根不再旋转的品红相量所指的方向，它就是 t = 0 时刻旋转矢量的位置，方向由初相 ψ 的正负与大小决定，对应上方波形相对纵轴是左移还是右移。
