图1：电路图（参考方向的确定，Example 2）。左侧为直流电压源电池符号，元件旁标注 US；电池符号上方为长横线（正极）并标“+”，下方为短横线（负极）并标“−”，即 US 参考极性上正下负。右侧为一个灰色实心矩形方框代表待求元件/负载（框内无任何符号或文字），方框四周有黄色描边。电池与灰框用上下两条导线接成单一闭合回路：上端导线自电池正极向右接至灰框上端，下端导线自电池负极向右接至灰框下端。上端导线上方画一个向右的箭头并标注 I，表示电流 I 的参考方向为自电压源正极流出、经上端导线流入右侧灰框（即进入灰框的一端），再从灰框下端经下端导线流回电池负极。图中没有二极管 D（diode）、负载电阻 RL、电容 C、电感 L，也没有 u2、uO、β、IB、UCE 等标注；无坐标轴、无波形、无虚线。本页为纯示意图，不显示求解过程或电流路径的动态变化。版面文字：顶部黄色高亮标题「How to determine the reference direction?」（如何确定参考方向）；红色圆点编号「❸ Example 2:」；下方蓝色边框文本框三行说明——(1) Before solving the problem, assume a current direction as a reference direction.（求解前先假定一个电流方向作为参考方向）；(2) Do the calculation（进行求解计算）；(3) If the calculation result I is positive, the actual direction is consistent with the reference direction; If the calculation result I is negative, the actual direction is opposite to the reference direction.（若计算结果 I 为正，实际方向与参考方向一致；若 I 为负，实际方向与参考方向相反）。页眉：1.4 Reference point and reference direction，右栏 1.4.2 Reference direction；右上角校名「大连理工大学」。
