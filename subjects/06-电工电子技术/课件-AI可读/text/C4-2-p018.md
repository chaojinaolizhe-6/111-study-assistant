图2：波形图（横排 6 个面板，横轴均为时间 t、原点标 o）。ui 面板（黄底）：以横轴为零基准、自原点先向上的红色正弦波。uBE 面板：UBE 高度红色水平线上叠加红色正弦波，波形与红线之间绿色斜线阴影填充，低于红线的波谷段黄色高亮，黑箭头标注 UBE。iB 面板：IB 高度红色水平线上叠加同相正弦波，阴影与黄色高亮同上，黑箭头标注 IB。iC 面板：IC 高度红色水平线上叠加正弦波，波形与红线之间绿色斜线阴影填充，波谷段（波形低于红线处）黄色高亮，黑箭头标注 IC。uCE 面板：UCE 高度红色水平线，波形在红线上下摆动（先在红线以上，下摆成波谷，再上摆成波峰），波形与红线之间绿色斜线阴影填充，红线以上的左段连同其下波谷用黄色高亮，波谷处叠一个红色叉号（✗，页面未给出该叉号的文字说明），黑箭头标注 UCE。uo 面板：黑色纵轴 uo、原点 o 与横轴 t，红色正弦以横轴为零基准、自 o 点起先向下摆，与 ui 的起始方向相反（反相）。图形说明：交流输入使 iB、iC 围绕各自直流分量摆动，uCE 与 iC 反向变化，uo 是经 C2 取出的纯交流正弦。版面文字（同页）：右上粉色框列式 uBE = UBE + ube、iB = IB + ib、iC = IC + ic、uCE = UCE + uce；红框公式 uCE = UCC − iC RC；页码 18（本页右侧中部未出现 C2 隔直那句说明文字）。

**读图要点**：这页的图讲的是动态时各电极量交直流叠加、uCE 与 iC 反向变化并由此得到反相的 uo；读图要盯住 uCE 面板中带红叉的反相波形和 uo 面板中与 ui 起始方向相反的正弦。
