图1：电路图（同一张单管共射交流放大电路，动态分析用）。元件与标注：晶体管 Tr、RB、RC、C1、C2、+UCC、ui（标 +、−）、uo（标 +、−）。连接关系：RB 与 RC 上端并联接 +UCC 电源线，RB 下端接基极、RC 下端接集电极，发射极接公共端并接地；C1 串在信号源与基极之间，C2 串在集电极与输出之间；下端公共线为 ui 与 uo 的共同参考端。图形说明：说明交流信号经 C1 送入基极、放大后的交流量经 C2 从集电极取出送到输出端。版面文字（照录）：标题 4.2.3 Signal amplification process；② Dynamic；左侧绿框 There are DC and AC components except the input and output.；页码 17。

图2：波形图（横排 6 个面板，横轴均为时间 t、原点标 o）。ui 面板（黄底）：以横轴为零基准的红色正弦波，自原点起先向上到波峰再下摆过横轴。uBE 面板：红色水平线位于 UBE 高度，其上叠加红色正弦波，波形与红线之间用绿色斜线阴影填充，低于红线的波谷段用黄色高亮，右侧黑箭头标注 UBE。iB 面板：红色水平线位于 IB 高度，其上叠加同相位红色正弦波，波形与红线之间绿色斜线阴影填充，低于红线的波谷段黄色高亮，黑箭头标注 IB。iC 面板：红色水平线位于 IC 高度（直流分量），其上叠加红色正弦波；波形与红线之间的区域用绿色斜线阴影填充，波形低于红线的波谷段用黄色高亮；右侧黑箭头标注 IC。uCE 面板：红色水平线位于 UCE 高度，波形在红线上下摆动（先在红线以上，下摆成波谷，再上摆成波峰）；波形与红线之间绿色斜线阴影填充，红线以上的左段连同其下波谷用黄色高亮，波谷处叠一个红色叉号（✗，页面未给出该叉号的文字说明）；右侧黑箭头标注 UCE。uo 面板：黑色纵轴 uo、原点 o 与横轴 t，红色正弦波以横轴为零基准上下对称，自 o 点起先向下摆，与 ui 面板的起始方向相反（反相）。图形说明：交流输入使 iB、iC 在各自直流分量上下摆动，而 uCE 随 iC 增大而下降，波形方向与 iC 相反；C2 只把交流分量送到输出端，因此 uo 是围绕 0 的正弦。版面文字（同页）：右上粉色框列式 uBE = UBE + ube、iB = IB + ib、iC = IC + ic、uCE = UCE + uce；红框公式 uCE = UCC − iC RC；右侧文字 The capacitor C2 blocks the DC component.；页码 17。

**读图要点**：这页的图讲的是动态时各量都是直流分量加交流分量、且集电极电压随集电极电流反向变化；读图要盯住 uBE、iB、iC 三条红线上叠加的正弦、uCE 面板里方向相反并被打上红叉的波形，以及 uo 面板中以 o 为中心、与 ui 反相的正弦。
