### 3.6.1 zener voltage regulator

### 2. Parameters

（此位置版面为图，见整页扫描图）

$U _ { \mathbf { Z } }$ It is not a fix value. It’s a range. The voltage across the zener diode when it is working

$I _ { \mathrm { Z m i n } }$ If the reverse current is less than this value. There is no regulating effect. Because the reverse voltage is not big enough to force it breakdown.

If the reverse current is greater than this value. It will be damaged $I _ { \mathrm { Z m a x } }$ forever. Because the voltage is too big.

$$
r _ {\mathrm{Z}} = \frac {\Delta U}{\Delta I}
$$

$\Delta I = \frac { \Delta U } { r _ { \mathrm { Z } } }$ A small change of voltage will cause a great change of the current.
