### 4.1.2 Operation modes

Given $\beta = 1 0 0$ , $R _ { \mathrm { C } } { = } 5 { \mathrm { k } } \Omega , U _ { \mathrm { C C } } { = } 1 5 \mathrm { V } , U _ { \mathrm { B B } } { = } 5 \mathrm { V }$

（此位置版面为图，见整页扫描图）

$$
U_{\text{CE}} = 15\ \text{V}
$$

When S is at position c,

Both emitter junction and collector junction are reverse biased.

$$
I _ {\mathrm{B}} = I _ {\mathrm{C}} = I _ {\mathrm{E}} = 0
$$

$$
U_{\text{CE}} = U_{\text{CC}} = 15\text{V}
$$
