图1：表格——(3) Summary 整流与滤波参数汇总表（位于页面右下方）：表头两栏为 Half wave rectifier（半波整流器）与 Full wave rectifier（全波整流器），每栏下再分 No capacitor（无电容）与 With capacitor（有电容）两列；行分两组，Load Parameters 组给出 Uo=0.45U2（半波无电容）、Uo=U2（半波有电容）、Uo=0.9U2（全波无电容）、Uo=1.2U2（全波有电容），四列同为 Io=Uo/RL；Diode Parameters 组给出 ID=Io（半波两列）、ID=½Io（全波两列），以及 URm=√2U2（半波无电容、全波两列）、URm=2√2U2（半波有电容）。表内没有电路符号、连线或坐标轴，只是一个纯文字网格。版面文字：E1 Bridge rectifier, C filter circuit with a line frequency of 50 Hz, RL=100 Ω, output DC UO=30 V. Try to: ① Select the diodes; ② Select the capacitor; ③ Find the output voltage when the load is open circuit; ④ Find the output voltage when the capacitor branch is open.（页眉 3.5 Filter Circuit / 3.5.2 Capacitor filter circuit，页脚 大连理工大学电气工程学院，页码 44）
