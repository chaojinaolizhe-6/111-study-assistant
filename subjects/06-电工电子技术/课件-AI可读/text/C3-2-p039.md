图1：电路图（半波整流＋电容滤波电路的正半周状态，是页面并排两张电路图的左图）：变压器一次绕组两端注 +（上）、−（下），一次电压标 u1（红色斜体）旁画一周期正弦波；二次绕组上端引出线标 a 并注 +（蓝色）、下端标 b 并注 −（蓝色），二次电压标 u2（蓝色斜体）旁画一段红色向上凸的半个正弦（正半周）。二次上端 a 经水平导线串入二极管 D（diode，三角形顶点朝右、阴极竖杠在右侧，阳极接 a 侧、阴极朝负载侧），二极管右端向下接一条竖直公共线，该线上下并接两条支路：电容 C（capacitor，画成上下两条水平平行板，上板旁注 +、下板旁注 −）与负载电阻 RL（两端标 uO，上端 +、下端 −）；即 C 与 RL 并联在整流器输出端、处在二极管与负载之间的滤波位置。二次下端 b 经下方横导线接到 C 下板与 RL 下端的公共节点，构成回路。极性/参考方向照抄：二次 a 为 + b 为 −，电容上板为 +、下板为 −，负载上端为 +、下端为 −，uO 上正下负。动作/过程：u2 正半周时 D 正向导通，电流由 a→D 后分成两路，一路流过 RL，一路给 C 充电（电容充到接近 u2 峰值，极性上正下负）。

图2：电路图（同一半波整流＋电容滤波电路的负半周状态，是并排两张电路图的右图）：一次电压标 u1（红色斜体）旁的波形中，下降段半周被画成红色（强调此刻为负半周）；二次绕组上端 a 改注 −、下端 b 改注 +（蓝色），二次电压 u2 旁的红色波形改为向下凹的半个正弦（负半周），即二次电压极性相对图1翻转；二极管 D（三角形顶点朝右、阴极竖杠在右，方向与图1相同）、电容 C（上板旁注 +、下板旁注 −）、负载电阻 RL（两端标 uO，上端 +、下端 −）及它们的并联连接方式与图1完全一致；二次绕组、二极管、电容和负载这整个二次回路被一个青色/蓝色矩形框圈出（版面强调框）。动作/过程：u2 负半周时 D 反向截止，负载由电容 C 放电供电（放电电流方向与充电相反），输出靠 C 维持——与图1合起来就是「电容充放电削平输出脉动」。版面文字：左上角标题栏「Review」，右上角「大连理工大学 电气工程学院」，右下角页码 39；页面下方居中一个黄色高亮公式框，框内写 URm = 2√2 U2（半波整流加电容滤波时二极管承受的最大反向电压，属版面文字结论）。
