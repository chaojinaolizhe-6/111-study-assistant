## 图区内容（AI 视觉通读）

图1：π 型 LC 滤波电路电路图（combinated filter）。左侧并列两种复合滤波电路，图题为「(1) π - type LC Filter」。四条水平母线式画法：上导线与下导线为输入—输出公共线，输入端与输出端均用空心小圆圈表示接线端。上导线中串入电感 L（蓝色波浪线圈符号，标 L），L 的左端向上导线左侧节点、右端向右延伸；在 L 左侧的节点与下导线之间并接电容 C₁（两条平行横线，旁标红色 + 号），在 L 右侧的节点与下导线之间并接电容 C₂（同样标红色 + 号）；C₂ 之后上导线继续向右接负载电阻 R_L（空心矩形），R_L 与下导线相连。C₁ 与 C₂ 各自构成对下导线的并联支路，L 串在两并联电容之间的上导线上，整体输入侧电容—串联电感—输出侧电容构成 π 形（C₁—L—C₂，输出端再由 R_L 引出压降）。R_L 支路上方标注红色 I_O 并带向下箭头，表示输出电流自 R_L 上端流向下端；R_L 两端标 u_O，上端红色 +、下端红色 −，为输出电压参考极性。图中无输入电压符号标注，输入端子处于左侧、负载处于最右侧，即电容 C₁、C₂ 与电感 L 都处在整流器输出与负载 R_L 之间。版面文字：标题行「3.5 Filter Circuit」「3.5.4 Combined filter」，图题「(1) π - type LC Filter」与「(2) π - type RC Filter」，右上角「大连理工大学电气工程学院」，右下角页码 49。

图2：π 型 RC 滤波电路电路图，图题为「(2) π - type RC Filter」。拓扑与图1相同但串联元件换为电阻：上导线中串入电阻 R（空心矩形，旁标蓝色 R），R 上方另有一条蓝色波浪线符号与短线叠画（图中 R 处除矩形外还保留了波浪状标记）。R 左侧节点与下导线之间并接电容 C₁（红色 + 号），R 右侧节点与下导线之间并接电容 C₂（红色 + 号），C₂ 之后上导线接负载电阻 R_L，R_L 下端回下导线。R_L 支路标红色 I_O 带向下箭头，R_L 两端标 u_O，上端红色 +、下端红色 −。R 串在两个并联电容 C₁ 与 C₂ 之间、位于整流器输出与负载之间，与图1唯一的差别是串联元件由 L 改为 R。版面文字同图1标题区，右下角页码 49。

**读图要点**：这页把两种复合（π 型）滤波电路并排放置：整流后的脉动直流先经一只并联电容，再经串联的 L 或 R 降压/扼流，再由第二只并联电容和负载，讲的是用电容与串联元件组合进一步削平脉动、得到更平滑的直流——读图要盯住串联元件（L 或 R）夹在两只并联电容之间这一 π 形结构，以及输出电流 I_O 方向与 u_O 的 +/− 参考极性。
