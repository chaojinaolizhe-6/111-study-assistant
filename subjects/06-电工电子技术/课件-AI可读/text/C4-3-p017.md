图1：共射组态示意电路图（左上象限「❶ Common emitter configuration」）。元件与标注照抄：晶体管三端标注 B、C、E；i̇B（基极输入电流）、u̇BE（输入电压，标 +、−）、i̇C（集电极电流）、Uce（集电极—发射极电压，标 +、−）。连接关系：三极管被点划线框住，B—E 为输入端口、C—E 为输出端口，E 为公共端。参考方向：u̇BE 基极为正、发射极为负；Uce 集电极为正、发射极为负；i̇C 自集电极流出。图形说明：以端口方式表示共射组态，供下面建输入、输出模型引用。

图2：输入特性曲线与输出特性曲线并置的双坐标图（右上象限「❷ Input and output characteristics」）。左半坐标：纵轴 IB/μA，刻度 0、20、40、60、80；横轴 UBE/V，刻度 0、0.4、0.8，原点 O；曲线陡升段后近似线性，附 IB = 60 μA 水平虚线与竖直虚线交点约 0.7V。右半坐标：纵轴 IC/mA，刻度 0、1、2、3、4；横轴 UCE/V，刻度 0、1、2、3，原点 O；曲线族标注 IB = 100 μA、80 μA、60 μA、40 μA、20 μA、IB = 0，横轴与第一象限左下角有红色斜线阴影区，水平虚线交纵轴于 3.5 mA 附近。图形说明：与其上一页的同名图内容一致，用来支撑输入侧线性电阻、输出侧受控电流源的结论。

图3：小信号等效电路模型（右下象限「❹ Model」，左右两个版本）。左图：B—E 之间接电阻 rbe，C—E 之间为菱形受控电流源（标注 βi̇b），端标注 i̇b、i̇c、u̇be（+、−）、B、C、E。右图另标 u̇ce（+、−）与 i̇e。拓扑：输入口 rbe 与输出口受控源 βi̇b 共用发射极 E 端（共射）。图形说明：晶体管交流小信号等效模型，其版面文字与上一页相同：「Circuit model seen from the input is rbe」、「rbe = 200(Ω) + β·26(mV)/IC(mA)」、「Circuit model seen from the output is a Controlled current source.」，右下页码 17、右上「大连理工大学」，均为版面文字。
