### 3.5.2 Capacitor filter circuit

大连理工大学 电气工程学院

E1 Bridge rectifier, C filter circuit with a line frequency of 50 Hz ,$R _ { \mathrm { L } } { = } 1 0 0 \Omega$ , output DC $U _ { \mathbf { 0 } } = 3 \mathbf { 0 } \mathbf { V } .$ Try to ：

① Select the diodes；

$$
I _ {\mathrm{O}} = \frac {U _ {\mathrm{O}}}{R _ {\mathrm{L}}} = \frac {3 0}{1 0 0} \mathrm{A} = 0. 3 \mathrm{A}
$$

$$
I _ {\mathrm{D}} = \frac {1}{2} I _ {\mathrm{O}} = \frac {1}{2} \times 0. 3 \mathrm{A} = 0. 1 5 \mathrm{A}
$$

$$
U _ {2} = \frac {U _ {0}}{1 . 2} = \frac {3 0}{1 . 2} \mathrm{V} = 2 5 \mathrm{V}
$$

$$
U _ {\mathrm{Rm}} = \sqrt {2} U _ {2} \quad = \sqrt {2} \times 2 5 \quad \mathrm{V} = 3 5. 4 \mathrm{V}
$$

$$
I _ {\mathrm{F}} \geqslant 2 I _ {\mathrm{D}} \quad = 2 \times 0. 1 5 \quad \mathrm{A} = 0. 3 \mathrm{A}
$$

$$
U_{\mathrm{R}}\geqslant U_{\mathrm{Rm}} = 34.5\ \mathrm{V}
$$
