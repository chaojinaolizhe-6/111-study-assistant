### 4.1 Bipolar Junction Transistor 4.1.4 Main parameters

### ❷ Penetration current $I _ { \mathbf { C E O } }$

$I _ { \mathrm { C E } \mathbf { 0 } }$ is the reverse leakage current between the collector and emitter when the base of the transistor is open.
