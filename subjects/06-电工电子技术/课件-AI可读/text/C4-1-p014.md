Active mode

Characteristics:

$$
\mathbf{0}< U_{\mathrm{CE}} < U_{\mathrm{CC}}
$$

图1：电路图（放大模式共射偏置电路，与第 12 页同一张图）。中部 NPN 剖面示意：上 N（浅蓝）、中 P（浅黄）、下 N（浅紫），顶部引线 C、中间左侧引线 B、底部引线 E，E 处画接地短横线。基极支路：B 接可变电阻 RB、RB 接电池 UBB（符号上长下短），UBB 负极回下方公共线；集电极支路：C 经电阻 RC 接电池 UCC（符号上长下短），UCC 下端回公共线。红色电流箭头：IB 指向 B 流入，IC 向下流入 C，IE 向下流出 E；剖面内自 E 指向 C 的大橙色箭头、P 层内半透明双向箭头，N、P 区散布红点。无坐标轴、无波形刻度。图形说明：发射结正偏、集电结反偏条件下，IB 的微小变化引起 IC 成比例的大变化，即电流放大作用。版面文字：红色 Active mode（放大模式）；黄框 Characteristics:（特性）；蓝框 Emitter junction —Forward biased（发射结正偏）、Collector junction —Reverse biased（集电结反偏）；四条带序号的结论：① IB↑→IC↑↑（基极电流增大则集电极电流增大更多）；② IC = β IB（集电极电流等于电流放大系数 β 乘基极电流）；③ UCE = UCC − RC IC（管压降等于电源电压减去集电极电阻上的压降）；④ Active means amplification（放大区意味着放大作用）；其中黄色高亮结论框：0 < UCE < UCC。

**读图要点**：这页在放大模式的同一张偏置电路上给出定量特性，读图时盯住 IB、IC、IE 三个电流箭头方向与 0 < UCE < UCC 这个区间，把 IC = βIB 和 UCE = UCC − RC IC 对到集电极支路上的 RC。
