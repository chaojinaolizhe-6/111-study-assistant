图1：电路图（直流含源电路，待用电源等效变换求电流）；元件与标注：最左侧竖直支路为 10V 电压源（红色圆形电源符号，圆上方标 «+»、圆下方标 «−»），标注 10V；其右侧一条竖直支路串一只绿色矩形电阻，标注 6Ω；中段顶部为一对并联支路——上支路是 5A 电流源（红色圆形符号，其右侧有洋红色箭头指向右），下支路是一只绿色矩形电阻，标注 6Ω，这两条支路并联在同一对节点之间（导线从左侧上翘的一段与右侧下落的一段构成）；最右侧竖直支路串一只绿色矩形电阻，标注 4Ω，其上方有洋红色箭头与斜体标号 «I»，箭头指向下方，表示 I 的参考方向沿该 4Ω 由上向下；下部水平导线把 10V 电压源的 «−» 端、左侧 6Ω 的下端与右侧 4Ω 的下端连在一起，构成回路。图形说明的动作：用电源等效变换把 10V 与 6Ω 的串联组合与 5A 电流源合并，最终求出流过 4Ω 的电流 I。无波形、无坐标轴刻度。版面文字：上方栏头 «1.6 Practical source» 与 «Review+ Preview»，黄色高亮题面 «Find I by using source transformation.»，右上角校名「大连理工大学」，右下角页码 2。

**读图要点**：这页给出一张可用电源等效变换逐步化简的直流电路图，读图要盯住 10V 与 6Ω、5A 与 6Ω 各自落在哪两条并联支路上、以及 I 的参考方向沿 4Ω 向下。
