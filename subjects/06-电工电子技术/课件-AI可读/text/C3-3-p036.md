图1：表格（板书式汇总表，版面标题「(3) Summary」）。表头分两行：第一行左格为「Half wave rectifier」（半波整流器）与「Full wave rectifier」（全波整流器），第二行左格为「No capacitor」（无电容）与「With capacitor」（有电容），共四列；行标题为「Load Parameters」（负载参数）、「Diode Parameters」（二极管参数）。四列取值为：半波无电容 uO=0.45U2、iO=UO/RL、iD=iO、URm=√2U2；半波有电容 uO=U2、iO=UO/RL、iD=iO、URm=2√2U2；全波无电容 uO=0.9U2、iO=UO/RL、iD=½iO、URm=√2U2；全波有电容 uO=1.2U2、iO=UO/RL、iD=½iO、URm=√2U2。表中 uO 为输出直流电压、U2 为变压器副边电压有效值、iO 为负载电流、iD 为二极管电流、URm 为二极管承受的最高反向电压；带电容各列以蓝底黄字强调，表头以黄底红字强调（均为版面文字）。

图2：电路图（单相桥式整流＋电容滤波＋稳压管稳压电路，占据页面中下部主体）。左侧画变压器：原边绕组两端有引出圆点并标注 u1 与 ＋/－ 标记（交流输入电压及其参考极性），副边绕组标注 u2 与 ＋/－ 标记。副边两端接到由四只二极管组成的桥式整流电路：上臂为 D1、D2（旁边各画红色实心三角），下臂为 D4、D3，中间竖直支路接变压器副边，D1 与 D4 在左桥臂成一列、D2 与 D3 在右桥臂成一列，构成桥式拓扑（交流两端分别进两个桥臂中点，直流正负母线取自另两个桥臂中点）；D1 与 D3 的三角被涂成红色高亮、D2 与 D4 为黑色空心三角，表示图中这一瞬间 D1、D3 处于导通状态。直流上母线向右引出，串接一只绿色矩形元件（电阻）后分三路并联到同一下母线：第一路为电解电容 C（标注 C，带 ＋ 极板符号）与负载电阻 RL 并联；第二路为一只稳压二极管（齐纳二极管：三角加带折角的横杠符号，符号被涂成红/青/紫彩色）构成稳压支路；第三路为绿色矩形负载电阻，其两端标注 uO 与 ＋/－ 参考极性，即输出电压取自该支路。右侧画出红色与黑色表笔夹在负载电阻两端的手持数字万用表（屏幕读数 000，红色表笔接正端、黑色表笔接负端，夹头处有黄色「Top1」「Top1b」字样水印），示意测量输出电压 uO。全部引出线与母线均为黑色实线，无坐标轴与刻度。图表达的机制是：u2 经 D1–D4 桥式整流后由电容 C 充放电滤波削平脉动，再由稳压管支路稳住直流，最后送到负载 RL，输出 uO 由万用表读出。版面文字：顶部标题「8.6.1 zener voltage regulator」（齐纳/稳压二极管稳压器），右上角「大连理工大学 电气工程学院」水印，右下角页码 36。
