图1：电路图①（三支路并联 RLC 与其电流表读数）。版面文字标题为 Example，题面 If the current in each branch is 5A, find the total current.；左上角标圈码 ①。电路：最左干路串圆形电流表 A；其后导线分三条并联支路、右端汇合，左右各留开口引线；自上而下三条支路依次为绿色螺旋线圈（电感 L，串电流表 A1，标 5A）、红色双竖线（电容 C，串电流表 A2，其右侧标 5A）、绿色实心矩形（电阻 R，串电流表 A3，其下方标 5A）。连接关系：L、C、R 三条支路并联，与干路电流表 A 串联。

图2：电路图②（两条支路并联，圈码 ②）。左端干路串圆形电流表 A；导线分成上下两条并联支路后右端汇合，两侧各有开口引线；上部支路为绿色螺旋线圈（电感 L，串电流表 A1，标 5A），下部支路为红色双竖线（电容 C，串电流表 A2，其右侧标 5A）。即只有 L 与 C 两条支路并联。

图3：电路图③（两条支路并联，圈码 ③）。左端干路串圆形电流表 A；导线分成上下两条并联支路后汇合；上部支路为绿色实心矩形（电阻 R，串电流表 A1，标 5A），下部支路为红色双竖线（电容 C，串电流表 A2，其右侧标 5A）。即只有 R 与 C 两条支路并联。

图4：相量图（三组，位于页面下部，无坐标刻度与 ωt 轴）。每组以黑色十字轴为基准（向上、向下、向右三个箭头方向）：第1组（对应电路①）画一条竖直向下的黑色箭头，另在水平方向画一支绿色向右箭头，图下方标 5A；第2组（对应电路②）同样为竖直向下黑色箭头与绿色向右箭头，图下方标 0A；第3组（对应电路③）画一条竖直向上的浅蓝色箭头、一条水平向右的黑色箭头，以及一条由原点斜向右上方的红色合成箭头，图下方标 5√2A。三组图只给出方向关系与结果数值，未标元件名。右下角为页码 14（版面文字）。

**读图要点**：这页把同一问题拆成 RLC 全并联、L 与 C 并联、R 与 C 并联三种接法，用底部三组相量图给出总电流 5A、0A、5√2A，读图要盯住每次并联的是哪几条支路、以及相量图上各支路电流方向（正交则用勾股合成、反向则相消）。
