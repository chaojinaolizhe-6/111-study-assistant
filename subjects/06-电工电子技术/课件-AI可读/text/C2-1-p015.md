### 2.2.1 Phasor representation of sine wave

### Sine wave ↔ Rotating vector

（此位置版面为图表，见整页扫描图）

The vector rotates in an anticlockwise direction if we take the projection of this vector in Y-axis then we get the instantaneous value of this sinusoidal signal.

图1：波形/矢量对应示意图（正弦波 ↔ 旋转矢量）。图为一个带网格的直角坐标框：纵轴刻度自上而下标 +1、0、−1，横轴刻度自左向右标 0、½π、π、3/2π、2π（两条轴都没有写出轴名）；原点处画有一个半径等于 1 个单位的浅绿色圆，圆内横轴高度上有一段蓝色水平线段，自圆心沿横轴向左延伸到圆内左侧；图上没有元件符号，也没有 Tr、D/VD、RL、C、L、u₂、uO、β、IB、UCE 等标注，因此本页不涉及整流器、二极管或负载。图形说明的过程：一个长度等于幅值的矢量绕原点逆时针旋转，取它在纵轴（Y 轴）上的投影，投影值随横轴相位从 0 推进到 2π 而在 +1 与 −1 之间连续变化，即正弦量的瞬时值（旋转矢量与正弦波一一对应）。版面文字：顶部标题栏「2.2.1 Phasor representation of sine wave」，副标题「Sine wave ↔ Rotating vector」，图下说明句「The vector rotates in an anticlockwise direction if we take the projection of this vector in Y-axis then we get the instantaneous value of this sinusoidal signal.」；右下角页码 15 与「大连理工大学」水印。

**读图要点**：这页用一幅圆与纵轴投影的示意图说明正弦量可以看成匀速旋转的矢量：读图要盯住矢量在纵轴上的投影随横轴相位推进而作正弦变化，以及横轴 0→2π 的四个刻度对应一个完整周期。
