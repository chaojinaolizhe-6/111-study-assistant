§2 二极管为什么能把交流变成直流

整流的物理基础只有一条：二极管单向导电（Chapter Three-1 / 3.2）。

2.1 一条判据，两种写法

  • 真实器件：阳极电位高于阴极电位 0.7 V（硅管）→ 正偏导通；反之 反偏截止。判据就是算 VA − VK。
  • 理想模型（本讲义的整流分析用它，也是课件画波形用的口径）：导通 = 一根导线（压降 0），截止 = 断路（电流 0）。
为什么有了这条判据，整流就能算？因为整流电路的结构是固定的：交流源 + 二极管网络 + 负载。把一个周期拆成两个半周，每个半周里哪只二极管阳极电位高是唯一确定的 → 每一段都能画出一条确定的电流路径 → 负载上的电压就确定了。你不需要解方程，只需要「判导通 + 顺着路径走一遍」。

2.2 桥式的两条路径（课件 p19、p20 原文）

半周电流路径导通截止
正半周（u2 > 0）a → D1 → RL → D3 → bD1、D3D2、D4
负半周（u2 < 0）b → D2 → RL → D4 → aD2、D4D1、D3

关键结论：两个半周里流过 RL 的电流方向相同（都是从上到下）→ 输出电压方向始终不变 → 这就是「直流」；但大小仍随交流起伏 → 所以叫脉动直流。

§3 半波整流（课件 p14–p16、p24）

3.1 分半周看

  • 正半周（ωt = 0~π）：u2 > 0，二极管正偏导通 → 相当于短路 → uO = u2（课件 p15）。
  • 负半周（ωt = π~2π）：u2 < 0，二极管反偏截止 → 相当于断路 → uO = 0（课件 p16：这就是它叫「半波」的原因——只用了半个周期）。

3.2 四个量，逐个说清来历

① 输出直流电压 UO —— 0.45 是「平均值」，不是峰值也不是有效值

UO = 平均值 = (1/2π)·∫0π √2U2·sin(ωt) d(ωt) = √2U2/π = 0.45 U2（复算 0.4502）

为什么分母是 2π？因为整个周期长 2π，而函数只在 0~π 非零。「平均值 = 面积 ÷ 周期」，半波只贡献了半个鼓包的面积，所以系数只有全波（0.9）的一半。这是 0.45 与 0.9 关系的全部秘密。

② 负载电流 IO = UO/RL（欧姆定律，直流平均值之间的关系）。

③ 二极管平均电流 ID = IO：半波里只有这一只管子，负载电流全部从它身上过（课件 p24 表格原文）。

④ 最大反向电压 URm = √2U2：负半周二极管截止，此时副边电压的负峰值（−√2U2）整个压在二极管两端，所以它必须能承受 √2U2（课件 p24）。

3.3 它的优缺点

只要 1 只二极管，最简单；代价是只用了半个周期：输出平均值只有 0.45U2，脉动很大，变压器利用率低。所以工程上多数场合改用全波。

§4 桥式全波整流（课件 p17–p24）

全波有两条技术路线（课件 p17）：中心抽头式与桥式。桥式不需要中心抽头，用的是 4 只二极管。

中心抽头全波（p17）桥式全波（p18–p23）
二极管数24
变压器必须有中心抽头不需要
二极管最大反压2√2 U2（两半绕组叠加）√2 U2
适用—最常用

4.1 四个量

① UO = 0.9 U2。课件 p22 的原式：

UO = (1/π)·∫0π √2U2·sin(ωt) d(ωt) = (2√2/π)·U2 = 0.9 U2（复算 0.9003）

与半波唯一的差别在分母：全波每 π 就重复一次（一个周期两个鼓包），所以周期记成 π 而不是 2π → 面积一样、周期减半 → 平均值翻倍。0.9 = 2 × 0.45。

② IO = UO/RL（不变）。

③ ID = ½ IO：每只二极管只在半个周期导通，另一半由另一对承担 → 单管的平均电流是负载电流的一半（课件 p22 原文）。这是最常被漏掉的一个系数。

④ URm = √2 U2：桥式里每只管子关断时，承受的也是副边峰值——比中心抽头式的 2√2U2 小一半，这正是桥式的另一大优势（课件 p40/p41 复习页专门对比过）。

4.2 波形

输出是「全波脉动直流」：每个周期两个鼓包（|sin| 形状），每个鼓包底部都回到 0。

§5 电容滤波：为什么电压会「升高」（课件 p25–p34）

5.1 机理：电容的电压不能突变

课件 p27 的原话：滤波电路利用「电容两端电压（或电感中的电流）不能突变」的特性，把电容并联在负载两端，从而达到平滑输出电压波形的效果。

  • u2 上升时：二极管导通，电容被充电，电能存进电容（p28）。
  • u2 下降时：电容电压比电源高，二极管反偏截止，电容通过 RL 放电，把存的能量供给负载（p29）。
为什么加了电容，输出电压反而比 0.9U2 高？因为输出电压不再是「电源的瞬时值」，而是「电容上的电压」。电容只在电源比它高的那一小段时间里充电（导通角远小于 180°），一充就充到接近峰值 √2U2；电源掉下来以后二极管截止，电容慢慢放电，电压就停在峰值附近下不来。所以平均值被抬到接近峰值。

放电快慢由时间常数 τ = RLC 决定（课件 p30）→ C 越大、RL 越大（负载越轻），放电越慢，电压越高、纹波越小（课件 p30–p32 的结论原文）。

5.2 三个必须记住的极端与经验值

状态输出为什么
空载（RL → ∞，即负载断开）uO = √2 U2，一条水平线没有放电回路，电容充到峰值后就一直保持（课件 p31 原文：uL = uC = √2u2）
有载（桥式 + C）UO ≈ 1.2 U2一边充一边放，实际停在峰值与 0.9U2 之间的某个位置（课件 p33 给的经验值）
半波 + CUO = U2（≈1.0 U2）半波每周期只充一次电，放电时间更长 → 平均值比桥式低（课件 p33）
1.2 不是一条严格公式[教学归纳，非课件原文]：它是「典型负载」下的工程经验值。负载越重（RL 越小），放电越快，UO 越往 0.9U2 靠；负载越轻，越往 √2U2 靠。做题时按课件取 1.2，但心里要知道它是一个近似。

5.4 电容怎么选（课件 p33、p46）

容量：C ≥ (3~5)·T/(2RL) ＝ (1.5~2.5)/(RL·f)　　耐压：UCN ≥ √2 U2

这两个容量写法是同一个式子：把 T = 1/f 代进去，(3~5)/(2RLf) = (1.5~2.5)/(RLf)。它的物理含义是：让 RLC 至少是半个周期 T/2 的 3~5 倍，这样放电足够慢、纹波才够小。耐压取 √2U2，是因为电容上实际承受的最高电压就是副边峰值。
本讲最容易被扣分的一格：半波 + 电容时，二极管的反压是 2√2 U2，不是 √2U2（课件 p34、p37 的总表里专门列了这一格）。原因：电容上存着 +√2U2，而副边在负半周又摆到 −√2U2，两者叠加压在截止的二极管上 → 2√2U2。

5.5 什么时候不该用电容滤波

课件 p26：电容滤波适合输出电压较高、负载电流较小且变化不大的场合；课件 p48：输出电压较低、负载电流较大时通常改用电感滤波（或 π 型复式滤波，p25）。这不是记忆题，是「电容靠储能顶电流，顶不住大电流」的直接后果。

Q1　半波整流（无电容）

题面：RL = 100 Ω，u2 = 20 sin(ωt) V。求 UO、ID、URm。

① 判形态（写在最前面）：只有一只二极管、没有电容 → 半波整流 → 用 0.45 这一行。

② 先把峰值换成有效值（这一步最容易漏）：题面给的是 u2 = 20 sinωt，峰值 20 V，所以

U2 = 20/√2 = 14.14 V（有效值；四栏表里的 U2 一律指有效值）

③ 套公式

UO = 0.45 U2 = 0.45 × 14.14 = 6.36 ≈ 6.4 V
IO = UO/RL = 6.36/100 = 63.6 mA
ID = IO = 64 mA（半波：负载电流全部由它承担）
URm = √2 U2 = 20 V（正好等于题面给的峰值）

你 10-12 的手写错在哪（同一处根因）：你写了 UO = 14.14 V、ID = 0.141 A。这两个数其实都是 U2 自己（有效值电压、有效值电流 U2/RL），不是「整流后的直流量」。
根因不是算错，而是把「副边有效值」当成了「整流输出」——中间少了「套整流系数」这一步。修正动作只有一句：看到 U2 就提醒自己它是交流有效值，输出必须再乘系数（半波 0.45 / 桥式 0.9 / 带电容 1.2）。
✅ URm = 20 V 你写对了。

波形怎么写（题目问波形就要画出形状，不能只写数）：

  • uo1（第 1 问，有电容有负载）：近似平直的直流。每个半周期有一个很窄的充电尖峰把电容充满，其余时间电容通过 RL 缓慢放电 → 形成小锯齿纹波；全波整流后纹波周期是 T/2 = 10 ms（50 Hz → 100 Hz）。
  • uo2（第 3 问，空载）：从 0 迅速充到峰值 42.4 V，之后是一条水平线——不是锯齿，因为没有放电回路（这正是课件 p31 的结论）。

  • 第 4 问：D2 断 → 负半周没有通路（负半周本来靠 D2、D4）→ 只剩正半周 → 变成半波波形，鼓包之间隔一整个空档。
为什么第 3 问电压最高？因为「空载」= 断开的是负载，电容充满后无处放电，电压就冻在峰值。注意区分两个完全不同的状态：负载断开（电压最高 √2U2）与电容支路断开（电压回到无电容的 0.9U2）——第 3 问与第 2 问正好是这两种，也是最容易写反的一对。

§9 易错清单（含你自己踩过的）

  1. 把 U2 当输出：U2 是交流有效值，输出必须再乘系数（0.45 / 0.9 / 1.0 / 1.2）。← Q1 手写错在这里
  2. 不看「有没有电容」就先套 0.9：同一个桥式，有电容是 1.2、无电容是 0.9。
  3. 桥式的 ID 忘了除以 2：每只管子只干半个周期的活。
  4. 半波 + 电容时仍写 URm = √2U2：应为 2√2U2（p34/p37 总表）。
  5. 选型只看电流不看耐压：Q3 的 2CP11 就是这样被淘汰的。
  6. 把「负载断开」和「电容支路断开」弄反：前者电压最高，后者电压回落。
  7. 忘了电容耐压 UCN ≥ √2U2：容量算完就收笔。
  8. C 的公式记成两个式子：(3~5)T/(2RL) 与 (1.5~2.5)/(RLf) 是同一个。
  9. 题目不给 U2 就卡住：要用 UO/1.2 反推（Q3、E1 都是这样起手）。
  10. 用真实二极管的 0.7 V 去算整流输出：本课程的整流计算按理想管（0.7 V 只用于判断导通/截止）。[教学归纳，非课件原文]

§10 自检 5 题（做完再看答案）

  1. 半波整流、无电容，U2 = 10 V。求 UO、URm。
  2. 桥式整流、无电容，U2 = 30 V。求 UO；并说出 ID 与 IO 的关系。
  3. 桥式 + 电容，负载开路，U2 = 20 V。求 UO。
  4. 半波 + 电容，U2 = 12 V。求 UO 与 URm（注意这一格的 2 倍）。
  5. 设计题：桥式 + 电容，UO = 24 V，RL = 50 Ω，f = 50 Hz。求 U2、IO、ID、URm 与 C 的取值范围。

答案（先自己写，再对）

#答案
1UO = 0.45 × 10 = 4.5 V；URm = √2 × 10 = 14.1 V
2UO = 0.9 × 30 = 27 V；ID = ½ IO
3UO = √2 × 20 = 28.3 V（空载 = 峰值，水平线）

§11 一句话收尾

判形态 → 查四栏表 → 算要求值 → 比型号

判形态问三句：有没有电容？哪种整流？问哪个量？——四栏表里 0.45 / 1.0 / 0.9 / 1.2 就是全部的输出系数；ID 只在「半波 / 桥式」之间选 IO 或 ½IO；URm 只有「半波 + 电容」这一格是 2√2U2，其余都是 √2U2。选型永远比两个条件：电流（有电容要 2 倍）与耐压。
