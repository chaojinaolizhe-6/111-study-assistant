## 2. 每个模块"要会什么"

### 模块 A：一维保守运动（5-1 p5–p6）`[已读图核对]`

**要会的概念**
1. **能量积分**：`E = ½mẋ² + U(x)` 守恒 ⟹ 一阶方程 `ẋ = ±√( 2(E − U(x))/m )`。
2. **允许区**：`E ≥ U(x)`；不满足的地方粒子**永远到不了**。
3. **转向点（= 停止点）**：`E = U(x)` 的解 `x_A(E), x_B(E), …`；此处速度为零、随后反向。
4. **有限 vs 无限运动**：允许区是**有界区间** `[x_A, x_B]` ⟹ 有限（振荡）；是**射线** `[x_C, +∞)` ⟹ 无限。
5. 一维有限运动**必为振荡**（来回跑）；由时间可逆性，**周期 = 从 x_A 到 x_B 所花时间的 2 倍**。

**要会的式子**（课件原式）

```
ẋ = ±√( 2(E − U(x))/m )
E = U(x)                        → 解转向点
τ(E) = √(2m) ∫(x_A→x_B) dx/√(E − U(x))          ← 周期
t = ±√(m/2) ∫ dx/√(E − U(x)) + const            ← 运动规律 t = t(x)
```

**要会做的题**
给 `U(x)` → ①画草图 ②由初条件 `x₀, ẋ₀` 定 `E` ③求转向点 ④判有限/无限 ⑤（需要时）积分求 `x(t)` 或周期。

**自检点**
- `E = U_min` ⟹ 粒子静止在极小点；
- `E` 比 `U_min` 略大 ⟹ 小振动，周期 `→ 2π/ω`，`ω² = U″(x_min)/m`；
- 转向点处被积函数发散，但**周期通常有限**（该积分收敛）；`E → U_max⁻`（势垒顶）时周期 → ∞。

### 模块 B：一维例题与专题（5-1 p7–p14）

- **p10 例题（已读图）**：分段势能 `U₁ = 2(x+2)² − 8 (x<0)`、`U₂ = −(x−4)² + 16 (x>0)`，初条件 `x₀ = 0`、`ẋ₀ = −4` ⟹ `E_k(0) = ½(−4)² = 8`、`U(0) = 0` ⟹ `E = 8`；解 `E = U₁` 得 `x₁ = −2 − √8`、解 `E = U₂` 得 `x₂ = 4 − √8`；`U_max = 16 > E` ⟹ **有限运动**。这道题就是 H5.1 的同型模板。
- **p12 静止点**：`E = U` 且 `ẋ = 0` 恒成立的点（平衡点）；`U″ > 0` 稳定、`U″ < 0` 不稳定。`[仅文字层]`
- **p13 势能的空间分布**：不同 `U(x)` 形状对应不同运动类型（阱/垒/单调）。`[仅文字层]`
- **p14 例题 5.4 单摆周期（已读图）**：`E = ½ml²φ̇² + mgl(1 − cos φ) ≈ ½ml²φ̇² + ½mglφ²`（小角）⟹ `τ = 2π√(l/g)`；用到 `cos φ ≈ 1 − φ²/2` 与 `∫dx/√(1−x²) = arcsin x`。

### 模块 C：两体问题 → 有心力（5-2 p2–p9）`[p9 已读图]`

**要会的概念**
1. 两体问题可分离为**质心平动**+**相对运动**；相对运动用**约化质量** `μ = m₁m₂/(m₁+m₂)`。
2. 相对运动的拉格朗日量（平面极坐标）：`L = ½μ(ṙ² + r²φ̇²) − U(r)`。
3. `φ` 是循环坐标 ⟹ **角动量守恒** `L = μr²φ̇ = const`（＝开普勒第二定律：面积速度恒定）。
4. **有效势能**：把离心项并入势能，问题变成**一维**问题：
   `U_eff(r) = U(r) + L²/(2μr²)`（第二项＝**离心能**）
   `E = ½μṙ² + U_eff(r)`

**要会的式子**（课件 p9 原式）

```
ṙ = ±√( (2/μ)(E − U_eff(r)) ) = ±√( (2/μ)(E − U(r)) − L²/(μ²r²) )
t = ±∫ dr [ (2/μ)(E − U(r)) − L²/(μ²r²) ]^(−1/2) + const
φ = ±∫ dr (L/r²) [ 2μ(E − U(r)) − L²/r² ]^(−1/2) + const
dφ = (L/(μr²)) dt
```

### 模块 D：允许区与运动类型（5-2 p10–p12）`[p11 已读图]`

- 判据与一维**完全一样**：`E ≥ U_eff(r)`；转向点 `E = U_eff(r)`。
- ⚠ **关键差别**：转向点处 `ṙ = 0`，但 `φ̇ = L/(μr²) ≠ 0` —— **不是停住点**（课件原话 "NOT the stopping points"）。粒子只是"不再靠近/远离"，仍在绕转。
- **单解 `r_min`** ⟹ 无界运动（从无穷远来、回无穷远去）；
  **双解 `r_min, r_max`** ⟹ 有限运动，轨迹夹在**环（annulus）**内 —— 但**轨道不一定闭合**；闭合条件 `Δφ = 2π m/n`（n 为整数）。`[已读图]`
- **能否落向中心**：取决于 `U_eff` 在 `r → 0` 处的行为与有没有离心势垒（H5.2 就要讨论这个）。

### 模块 E：轨道方程与开普勒问题（5-2 p13–p19）`[p20 已读图]`

- 由 `φ` 的积分得**轨道方程** `r(φ)`；对 `U = −α/r`（引力/库仑）化为**圆锥曲线**：
  `r = p/(1 + e cos φ)`，`p = L²/(μα)`；`e < 1` 椭圆、`e = 1` 抛物线、`e > 1` 双曲线。
- **开普勒三定律**（椭圆轨道）：①椭圆、太阳在焦点 ②面积速度恒定 ③`T² ∝ a³`。
- **Laplace–Runge–Lenz 矢量** `A = p × L − μα r̂` 是开普勒问题的**额外运动积分** ⟹ 轨道闭合、近日点不进动（p20 的 Task #5 就是证明 `dA/dt = 0`）。

### 模块 F：散射（5-2 p24–p26）

- 无穷远渐近线、**碰撞参数**、**偏转角** χ 与能量/碰撞参数的关系；与有心力轨道同一套积分。
