§2 一维保守运动：整套机器都在这一节（5-1 p3–p6）

2.1 什么时候能量守恒（前提，不是口号）

课件 5-1 p4 的两个前提：① 拉格朗日量不显含时间（∂L/∂t = 0）；② 坐标变换关系不显含时间（约束稳定）。两条都满足时，广义能量 E = Σ(∂L/∂q̇_i)·q̇_i − L 守恒；在稳定约束下它就是普通的机械能 E = T + U。

（Topic 4 已经专门练过这两条判据；tm.t4.energy-criteria 目标目前仍是「需支持」，用到时先回顾 Topic 4 的判据二。）

2.2 从能量守恒到一阶方程（这一步是本讲全部技术的源头）

E = ½mẋ² + U(x)　⟹　ẋ² = (2/m)(E − U(x))　⟹　ẋ = ±√( 2(E − U(x))/m )

为什么这一步这么重要？二阶的运动方程 mẍ = −U′(x) 一般解不出来；但能量守恒把它降成一阶方程，而且变量已经分离（左边只有 ẋ，右边只有 x）——直接积分就能得到 t(x)。这就是"守恒量 ⟹ 能积就积"的具体含义。
± 号的含义：同一能量下粒子有两个可能的运动方向；具体取哪个由初条件（如 ẋ₀ > 0）决定，并在转向点切换。

2.3 三个概念，一次讲清

概念定义要点
允许区E ≥ U(x) 的区段不满足的地方 ẋ² < 0，物理上粒子永远到不了——它是"经典禁区"，不需要任何动力学论证
转向点E = U(x) 的解 x_A, x_B, …此处动能恰为 0、速度为零，粒子随即反向。⚠ 它是"停下改方向"，不是平衡点
运动类型允许区是有界区间 [x_A, x_B] ⟹ 有限（振荡）；是射线 [x_C, +∞) ⟹ 无限一维有限运动必为来回振荡；由时间可逆性，周期＝单程时间的 2 倍

2.4 周期与运动规律（5-1 p11 原式）

τ(E) = 2∫(x_A→x_B) dx/√( 2(E − U)/m ) = √(2m)·∫(x_A→x_B) dx/√(E − U)　　← 有限运动周期

t = ±√(m/2)·∫(x₀→x) dx/√(E − U(x)) + const　　　　← 运动规律（变上限积分）

为什么是 2 倍？从 x_A 走到 x_B 用掉的时间，与从 x_B 回到 x_A 的时间相等（运动方程只含 ẋ²，时间反演对称）⟹ 一个完整来回 = 2 × 单程。
为什么积分在转向点发散、周期却有限？被积函数 1/√(E−U) 在端点处 → ∞，但它是可积的奇性（1/√ε 型，积分收敛）；只有在"势垒顶"那种 U 与 E 相切的情形，粒子趋近顶点所需时间才真正 → ∞。

2.5 三个必须记牢的自检点

  • E = U_min ⟹ 粒子静止在极小点（稳定平衡）；
  • E 比 U_min 略大 ⟹ 小振动，周期 → 2π/ω，其中 ω² = U″(x_min)/m；
  • E → U_max⁻（趋近势垒顶）⟹ 周期 → ∞。

§3 一维例题（5-1 p7–p14）：H5.1 的同型模板就在这里

3.1 课件 p10 例题：分段势能 + 初条件定 E（已读图核对）

题：U₁ = 2(x+2)² − 8（x < 0）、U₂ = −(x−4)² + 16（x > 0）；初条件 x₀ = 0、ẋ₀ = −4。

解法四步（这就是"给一个 U(x) 该怎么做"的标准流程）

  1. 由初条件定总能量：E_k(0) = ½·1·(−4)² = 8，U(0) = 0 ⟹ E = 8。（注意 U(0) 取 0 是因为两段在 x = 0 处都等于 0，连续。）
  2. 解转向点：左支 2(x+2)² − 8 = 8 ⟹ (x+2)² = 8 ⟹ x = −2 ± 2√2，取 x < 0 的那支 x₁ = −2 − 2√2 ≈ −4.83；右支 −(x−4)² + 16 = 8 ⟹ (x−4)² = 8 ⟹ x = 4 ± 2√2，取靠近原点的那支 x₂ = 4 − 2√2 ≈ 1.17。
  3. 看中间有没有过不去的坎：右支在 x = 4 处有极大 U_max = 16 > E = 8 ⟹ 粒子到不了那里。
  4. 下结论：允许区 [−4.83, 1.17] 有界 ⟹ 有限运动（振荡）。

⚠ 第 2 步会解出多余的根（4 + 2√2 ≈ 6.83 也在右支上），必须用"是否落在允许区内"筛掉——这是分段势能题最常见的失分点。

3.2 课件 p12–p13：静止点与势能的空间分布

  • 静止点（平衡点）：U′(x) = 0 且 ẋ = 0 恒成立的点。U″ > 0 ⟹ 稳定（极小）；U″ < 0 ⟹ 不稳定（极大）；U″ = 0 ⟹ 需看更高阶。
  • 势能的空间分布决定运动类型：阱（有界振荡）／垒（越过 or 被反射）／单调（单向或无界）。这就是"先看两端、再看驻点"的全部依据。

§4 从两体问题到有心力（5-2 p2–p9）

4.1 两步降维

  1. 两体 → 单体：用质心 R = (m₁r₁ + m₂r₂)/(m₁+m₂) 与相对位矢 r₁₂ = r₁ − r₂ 换掉 r₁, r₂。质心匀速直线运动（整体动量守恒），相对运动等效于一个质量为 μ = m₁m₂/(m₁+m₂) 的粒子在同一个 U(r) 中运动。
  2. 三维 → 二维：中心力只沿 r 方向 ⟹ 力矩为零 ⟹ 角动量守恒 ⟹ 运动始终在过力心的一个平面内（课件 p3 的"问题似乎是三维，仔细分析是二维"）。

第 1 步不是一句话，是一段可以写出来的代数。补在下面，因为「凭什么可以换成 μ」是这块最常卡住的地方。

4.2 把 μ 推出来：三步代数（课件 p3–p4 的 EXERCISE）

第 ① 步：换变量。由定义解出两个质点各自的位置（课件 p3 右栏原式）：

r₁ = R + (m₂/m_tot)·r₁₂　　r₂ = R − (m₁/m_tot)·r₁₂　　（m_tot ≡ m₁ + m₂）

第 ② 步：代入拉氏量。两体拉氏量（这里就藏着前提）：

L = ½m₁|ṙ₁|² + ½m₂|ṙ₂|² − U(r₁₂)

把 ① 求导后代进去，展开动能：

T = ½m_tot|Ṙ|² + ½μ|ṙ₁₂|² + (交叉项)，　μ = m₁m₂/(m₁+m₂)

交叉项为什么恰好消失？因为 ① 式里两个系数 m₂/m_tot 与 m₁/m_tot 不是随便挑的——它们正是让 m₁(m₂/m_tot) − m₂(m₁/m_tot) = 0 的那一组值。换句话说：μ 不是「定义出来的近似」，而是「交叉项归零」这个要求的唯一解。 换任何一个别的系数，动能里都会剩下一项 Ṙ·ṙ₁₂，两个自由度就缠在一起，降维立刻失效。

第 ③ 步：拆成两件互不相干的事（课件 p4 原式）：

L = m_tot|Ṙ|²/2　＋　[ μ|ṙ₁₂|²/2 − U(r₁₂) ]　=　L_R　＋　L_r₁₂

对 R 用拉格朗日方程：d/dt(∂L/∂Ṙ) − ∂L/∂R = 0　⟹　R̈ = 0　⟹　质心匀速直线运动

剩下的 L_r₁₂ 就是一个质量为 μ 的粒子、在同一个势 U 里的运动——所以「两体问题」被完整地换成了「单体问题」。

4.3 ⚠ 用约化质量的四个前提（这一格就是"看不懂前提"的正解）

前提要求什么违反会怎样
① 系统孤立
（无外力）		除了两体之间的相互作用，没有第三个东西施力：总动量守恒。R̈ = 0 不再成立，L_R 与 L_r₁₂ 通过 R 又耦合回来，"质心匀速"和"等效单体"两条同时失效。
例：日–地系统还要算银河系潮汐力时，两体约化不严格。
② 势只依赖相对距离
U = U(r₁₂)		相互作用是内力，且是有心力：只与 |r₁₂| 有关，与方向、与绝对位置都无关。若 U 还依赖绝对位置（外力势），L 里会出现 U(R, r₁₂)，两项不再分离；
若 U 依赖 r₁₂ 的方向，仍能分离出相对运动，但它不是中心力问题，没有角动量守恒，后面整套有效势都不适用。
③ 这是精确变换，不是近似只要 ①② 成立，任意质量比（哪怕 m₁ = m₂）都成立，没有小量近似。把它当成"近似"会引发一串假问题：例如误以为 m₁ ≫ m₂ 是使用 μ 的前提。它不是——它只是可以进一步把 μ 换成 m₂ 的条件。
④ 坐标要回收用 μ 解出来的是相对位矢 r₁₂ 的轨道，不是任一个质点的轨道。直接把 r₁₂(φ) 当"行星轨道"画，形状对、位置错：
r₁ = R + (m₂/m_tot)r₁₂，质点 1 的轨道要乘 m₂/m_tot；质点 2 乘 m₁/m_tot。两个都是与相对轨道同形状、同焦点（质心）、尺度不同的圆锥曲线。
「μ ≈ m₂」这个近似出现在哪里？——只在最后一步的数值代入，不在方法本身。
课件 p4 的原话：Note: in the limit m₁ ≫ m₂ → μ ≈ m₂，并注明 Valid for all planets in our solar system in comparison to the sun!
意思是：大质量中心 + 小质量绕行者时（太阳–行星、地球–卫星、原子核–电子），μ 与 m₂ 的差别小到可以忽略， 于是可以让小质量粒子的质量直接当 μ 用。
数量级感受：地球/太阳的质量比约 3×10⁻⁶，所以 μ ≈ m_地球 的误差也在 10⁻⁶ 量级；但双星系统里两颗星质量同量级，绝不能做这个替换——那时 μ = m/2（等质量时），差了一倍。

小结成一句话：「可以换成 μ」的前提是——孤立系统 ＋ 势只依赖相对距离；「可以写成 m₂」的前提才是——m₁ ≫ m₂。两件事不要并成一件。

4.4 三维 → 二维：为什么轨道一定在一个平面里

中心力沿 r̂ 方向 ⟹ 对力心的力矩为零 ⟹ dL/dt = r × f = 0 ⟹ L = μr×v 是常矢量。 而 L·r = 0 恒成立（叉乘的定义），所以 位矢永远垂直于这个固定的 L——位矢只能在一个过力心、以 L 为法向的平面里转。 这就是"问题看似三维、实则二维"的全部理由。它不是假设，是守恒量的推论。

4.5 角动量守恒 ⟺ 开普勒第二定律（5-2 p5–p7）

L = μr²φ̇ = const　（φ 是循环坐标 ⟹ p_φ = ∂L/∂φ̇ 守恒；也可由 dL/dt = r × f = 0 得到）

几何含义：极坐标下扇形面积 dA = ½r²dφ，所以

dA/dt = ½r²φ̇ = L/(2μ) = const

—— 这正是开普勒第二定律（面积速度相等）。课件 p7 用的就是开普勒《新天文学》里的原始表述： 「在相等时间内，太阳和运动着的行星的连线所扫过的面积都是相等的」，并注明 当 dt = 1 unit time 的读法。
反向也成立：第二定律成立 ⟺ 力是有心力。所以开普勒第二定律其实是"引力指向太阳"的实验证据。

4.6 有效势：把转动那一份动能搬进势能（5-2 p8–p9）

L = ½μ(ṙ² + r²φ̇²) − U(r)，　φ̇ = L/(μr²)

E = ½μṙ² + ½μr²φ̇² + U(r) = ½μṙ² + U(r) + L²/(2μr²)　⟹　U_eff(r) = U(r) + L²/(2μr²)

E = ½μṙ² + U_eff(r)　　← 形式上与一维问题一模一样

离心能的物理含义（课件 p9 原词 centrifugal energy）：L 固定时 r 越小，φ̇ = L/(μr²) 越大，转动动能 ½μr²φ̇² 也越大。粒子想靠近中心，就必须把径向动能"兑换"成转动动能——效果等同于撞上一堵排斥墙。它不是新加的力，也不是新的势能，只是把转动动能改写了一个形式。
记账规则（最容易犯的错）：写 U_eff 时，½μr²φ̇² 已经被吸收进 L²/(2μr²) 了；能量式里不能再单独写一遍，否则重复计算。

§6 有效势的三套标准形状（把「两端谁主导」讲透）

形状 1：U(r) = −α/r（开普勒／库仑）——势垒 + 势谷

U_eff(r) = −α/r + L²/(2μr²)

  • 两端：r → 0⁺ 时 +L²/(2μr²) → +∞（离心势垒，粒子永远到不了中心）；r → ∞ 时 −α/r → 0⁻。
  • 驻点：唯一 r₀ = L²/(μα)；U_eff(r₀) = −μα²/(2L²)；U_eff″(r₀) = α⁴μ³/L⁶ > 0 ⟹ 稳定圆轨道。
  • 允许的 E：E ≥ −μα²/(2L²)。分类：E = U_eff(r₀) ⟹ 重根 ⟹ 圆轨道；U_eff(r₀) < E < 0 ⟹ 两个根 ⟹ 有限（椭圆）；E ≥ 0 ⟹ 一个根 ⟹ 无限（抛物线/双曲线）。
  • 结论：只要 L ≠ 0，粒子永远到不了 r = 0。

sympy 复核 ✓：r₀ = L²/(μα)、U_eff(r₀) = −μα²/(2L²)、U_eff″(r₀) = α⁴μ³/L⁶。

形状 2：U(r) = −α/r + β/r² —— 两项吸引 &「竞争」 [教学归纳，非课件原文]

U_eff(r) = −α/r + β/r² + L²/(2μr²) = −α/r + C/r² ,　其中 C = β + L²/(2μ)

关键一句话：C 是"离心势垒"与"额外吸引项"合并之后的净系数。

情形r → 0⁺驻点结论

形状 3：课件 p24 Exercise 5.5（已读图核对）—— 官方版的"竞争"

题：U(r) = α/r − β/(2r²)（α > 0, β > 0），求粒子到力心的最小与最大距离。

U_eff(r) = α/r + (L² − μβ)/(2μr²)

  • 系数决定命运：L² − μβ > 0（即 L² > μβ）⟹ 离心项为正，r → 0⁺ 有势垒；L² < μβ ⟹ 系数为负，r → 0⁺ 时 U_eff → −∞（对应课件图上的陡降）。
  • 驻点：r₀ = (μβ − L²)/(μα)（L² < μβ 时它是极大＝势垒顶）；U_eff(r₀) = μα²/(2(μβ − L²))。
  • 转向点方程（课件原式）：E = U_eff ⟹ r² − (α/E)r − (L² − μβ)/(2μE) = 0 ⟹ r = (α/2E)(1 ± √(1 + 2(L²−μβ)E/(μα²)))，取合理的解。
  • 课件给的分类（0 < E < U_eff(r₀) 这一档）：出现两组解——{r_min = 0, r_max = (α/2E)(1 − √…)} 与 {r_min = (α/2E)(1 + √…), r_max = ∞}。
两组解是什么意思？势垒顶把允许区分成了两块：内区（粒子可以一直走到 r = 0，落向中心）和外区（粒子被挡在 r_min 之外，一路跑到无穷远）。同一道题里"落向中心"和"无界运动"可以同时都是答案——取决于初始在哪一侧。
数值例（α = μ = L = 1, β = 2 ⟹ L² = 1 < μβ = 2，已复核）：r₀ = 1，U_eff(r₀) = 0.5；0 < E < 0.5 就出现上面两块允许区。

⚠ 注意这道题与形状 2 的差别：这里 U 本身是排斥的（+α/r）加一个吸引的 −β/(2r²)；形状 2 是两项都吸引。结论的判法完全一样：把系数合并，看它是正还是负。

7.0 这一节要回答的三个问题

问题回答它的工具结论
轨道是什么形状？φ(r) 积分r = q/(1 + e cos φ)，圆锥曲线，力心在焦点 ⟹ 开普勒第一定律

注意顺序：第一定律是"积出来"的，第二定律是"守恒量"直接读的，第三定律是前两条一乘一除拼出来的。三条里只有第一条需要真正动手积分。

7.1 第一步：把 dt 消掉（得到只含 r 与 φ 的方程）

起点是 §4 已经建好的两个一阶方程：

① 角动量：dφ/dt = L/(μr²)　　② 径向能量：dr/dt = ±√( 2(E − U_eff(r))/μ )

为什么要"相除"？这两个方程各自都带 t，但右边只含 r。两式相除，dt 被约掉，就得到一条纯粹的几何关系——它描述轨道的形状，与"什么时候走到那里"无关。这就是"轨道方程"与"运动规律"的分工。

dφ/dr = [L/(μr²)] ÷ [±√(2(E−U_eff)/μ)]　⟹　dφ = ± (L/r²)·dr/√( 2μ(E − U_eff(r)) )

代入 U_eff = −α/r + L²/(2μr²)，把 r⁻² 挪进根号里整理（课件 p13 原式）：

φ = ∫ dr · (L/r²) · [ 2μ(E + α/r) − L²/r² ]−1/2 + const

其中 2μ(E + α/r) − L²/r² = (2μ/r²)·[ (E + α/r)r²/1 − L²/(2μ) ] 型；把 r² 乘进括号后是一个关于 1/r 的二次式。

7.2 第二步：为什么换元是 x = 1/r − μα/L²

把根号里的东西换成 u = 1/r 来看。利用 dr = −du/u²，并注意 (L/r²)dr = −L·du：

括号 = 2μE + 2μαu − L²u²　（一个关于 u 的开口向下的二次式）

对二次式配方：

2μE + 2μαu − L²u² = L²·[ ( μ²α²/L⁴ + 2μE/L² ) − ( u − μα/L² )² ]

括号里第一项正好是一个完全平方，记为 a₀²；第二项提醒我们令 x = u − μα/L² = 1/r − μα/L²。于是积分变成教科书里最标准的一条：

a₀ ≡ √( μ²α²/L⁴ + 2μE/L² )　　⟹　φ = ∫ −L du/(L√(a₀² − x²)) = ∫ −dx/√(a₀² − x²)

这个换元的"名字"叫"配方法"。看到根号里是 1/r 的二次式，就一定要想到配方；配方之后平移一下（把一次项吃掉），就只剩 √(a² − x²)。 课件 p13 右栏给的两条 Hint 就是这一步的备忘：∫dz/√(a²−z²) = arcsin(z/a) + C = −arccos(z/a) + C，以及 x = 1/r − μα/L²、a = √(μ²α²/L⁴ + 2μE/L²)。

7.3 第三步：积出来 —— 从 arccos 到圆锥曲线

用上面的标准积分（取 −arccos 那一支）：

φ = arccos( x/a₀ ) + const　⟹　φ = arccos( (1/r − μα/L²) / a₀ ) + const　（课件 p13 原式）

接下来是纯代数三步，也是课件 p14 右栏做的事：

① 定义两个记号（课件 p14 原式，q 在课件里写作 parameter / 2q 是 latus rectum 正焦弦）：

q ≡ L²/(μα)　　e ≡ √( 1 + 2EL²/(μα²) )

② 关键恒等式：a₀ = e/q。这是整段推导的枢纽，验算一下：

a₀·q = √(μ²α²/L⁴ + 2μE/L²) · L²/(μα) = √( 1 + 2EL²/(μα²) ) = e　✓

③ 把 ① ② 代回 7.2 的换元式（注意 μα/L² = 1/q）：

(1/r − μα/L²)/a₀ = (1/r − 1/q)/(e/q) = (q/r − 1)/e

于是 φ = arccos( (q/r − 1)/e )，两边取 cos 并移项：

q/r − 1 = e·cos φ　⟹　r = q/(1 + e·cos φ)　（课件 p14 原式）

这条式子的身份：equation of a conic section with one focus at the origin（课件 p14 原话）——以原点为焦点的圆锥曲线的极坐标方程。 q 叫半正焦弦（latus rectum 的一半，课件 p14 标注"正焦弦"），e 叫离心率（eccentricity）。

sympy 复核（_scratch/tm-kepler-check-20261015.py，B1/B2/B3 三项）：d/dr[arccos((1/r−μα/L²)/a₀)] 与课件被积函数逐点相等； a₀q = e；(1/r−μα/L²)/a₀ = (q/r−1)/e —— 三式全部成立。

7.4 两个"为什么"（课件 p13 的注释与 Hint）

（1）积分常数为什么可以直接取 0？课件在 + const 上画了红叉，批注 =0 by choosing the initial position。
理由：这个常数是近日点方向相对于极轴的夹角。极轴取在哪，是我们自己选的（= 选择 φ 的零点），不是物理量。 把极轴指向近日点，常数就是 0；换成别的方向，常数变，但轨道形状一个字都不变。所以这不是"丢掉一个常数"，而是"用坐标选择的自由把它消掉"。

（2）课件为什么提示"cosine function is an even function"？
因为 arccos 的值域只有 [0, π]，但 φ 显然要取到负值（粒子会转到另一侧）。
而 cos(−φ) = cos(φ)，所以由 (q/r − 1)/e = cos φ 反解时，±φ 给出同一个 r：
r(φ) = r(−φ) 它的物理含义是：轨道关于"近日点—远日点"这条轴（拱线）左右镜像对称；φ 的正负只区分粒子往哪一侧转（顺行 / 逆行），不改变轨迹形状。
这也正是椭圆（及一切圆锥曲线）都有一条对称轴的原因。

7.5 四个数把轨道锁死（椭圆的情形）

量表达式由谁决定几何意义
q 半正焦弦L²/(μα)只由 L 决定（也给 α、μ）过焦点垂直于长轴的弦的一半
e 离心率√(1 + 2EL²/(μα²))E 与 L 的组合形状：0 圆 → 1 抛物线 → 大于 1 双曲线
a 半长轴q/(1−e²) = α/(2|E|)只由 E 决定，与 L 无关椭圆中心到顶点

r_min 近日点q/(1+e) = a(1−e)—φ = 0 处
r_max 远日点q/(1−e) = a(1+e)—φ = π 处
一句话记住分工：能量 E 管"多大"（a），角动量 L 管"多扁"（e 与 q）。 这与 §5 的定性结论完全一致——那里我们说"E ≥ U_eff,min 才有运动"，这里给出了 U_eff,min = −μα²/(2L²) 对应 e = 0（圆）。 顺带：r_min, r_max 也可以直接由 U_eff(r) = E 解二次方程得到，两条路必须给出同一个答案——这是最好的自检。

一个可以手算的例子（α = μ = L = 1，E = −1/4）

U_eff,min = −μα²/(2L²) = −0.5　⟹　E = −0.25 大于它 ⟹ 椭圆 ✔

q = L²/(μα) = 1　　e = √(1 + 2(−0.25)) = √0.5 = 1/√2 ≈ 0.707

a = q/(1−e²) = 1/(1−0.5) = 2　　（核对：α/(2|E|) = 1/0.5 = 2 ✔）

b = a√(1−e²) = 2×0.7071 = √2 ≈ 1.414　（核对：L/√(2μ|E|) = 1/√0.5 = √2 ✔）

r_min = a(1−e) = 2 − √2 ≈ 0.586　　r_max = a(1+e) = 2 + √2 ≈ 3.414

四个数互相印证，全部对上。做任何开普勒题（包括 H5.2 那种"先定性再看形状"的题）都可以拿这几个关系自查。

7.7 开普勒第一定律（椭圆 + 焦点在力心）

第一定律：行星沿椭圆运动，太阳位于椭圆的一个焦点上。

力学证明（两句话）：

  1. 由 7.3 的积分，任何平方反比吸引场中的轨道都是 r = q/(1+e cos φ)；当 E < 0 时 e < 1，这条曲线就是椭圆。
  2. 方程的推导起点是"r 从力心量起"（极坐标原点＝力心），所以椭圆的焦点就落在力心上，而不是中心。

两体版本要说清的一点：真实的太阳–行星系统里"力心"其实是质心。 由 §4 的坐标回收关系 r₁ = R + (m₂/m_tot)r₁₂，太阳与行星各自都走一条以质心为焦点的椭圆， 半长轴分别是 a_太 = (m_行/m_tot)·a、a_行 = (m_太/m_tot)·a——同形状、同离心率、尺度按质量反比分配。 因为 m_行/m_太 ~ 10⁻⁶，质心几乎就在太阳中心，所以平时说"太阳在焦点上"完全够用。

7.8 开普勒第二定律（面积速度恒定）

dA/dt = ½r²φ̇ = L/(2μ) = const　（§4.5 已推出；这里看它的几何后果）

把 dt = (μr²/L)dφ 代进去，还能得到一条有用的等价形式（后面第三定律与例题都要用）：

dA = ½r²dφ = (L/(2μ))·dt　⟹　扫过的面积 ∝ 花掉的时间

它同时是"引力是有心力"的实验判据：若太阳对行星的力不是指向太阳，力矩不为零，L 就不守恒，面积速度会变。 开普勒是从第谷的观测数据里"看出"这一条的，牛顿反过来用它论证引力的方向。

7.9 开普勒第三定律（T² ∝ a³）　[教材补充]

⚠ 这一条课件 27 页里没有（已用文字层全文检索 "third law"/"Kepler" 确认无命中）。课件只到第一定律与第二定律。 下面按 Landau《Mechanics》§15 式 (15.8) 补上——因为"开普勒三定律"是一个整体，缺了它这条线不闭合。

第 ① 步：周期 = 总面积 ÷ 面积速度。

T = (椭圆面积) / (dA/dt) = πab / (L/(2μ)) = 2πμab/L

第 ② 步：把 a、b 换成 E 与 L（用 7.5 的表）：

a = α/(2|E|),　b = L/√(2μ|E|)

T = 2πμ·(α/(2|E|))·(L/√(2μ|E|))/L = 2πa^(3/2)·√(μ/α)　（因为 √(2|E|) = √(α/a)）

第 ③ 步：写成"定律"的样子：

T = 2π a^(3/2) √(μ/α)　⟺　T² = 4π² μ a³ / α　（等价写法：T = πα√(μ/(2|E|³))）

第 ④ 步：换成牛顿引力。取 α = Gm₁m₂、μ = m₁m₂/(m₁+m₂)：

T² = 4π² a³ / [ G(m₁ + m₂) ]

行星质量远小于太阳（m₂ ≪ m₁）时，分母 ≈ Gm₁，就回到中学课本里的 T² = 4π²a³/(GM_太阳)，也就是"T²/a³ 对所有行星是同一个常数"。

三个"顺带"很重要：
  1. 周期只依赖能量（T = πα√(μ/(2|E|³)) 里没有 L）。配合 a = α/(2|E|)，"只依赖 E"和"∝ a^(3/2)"是同一句话。
  2. 比例系数里带 μ（即带两体质量）——这正是"称太阳质量"的原理：测出某行星的 a 与 T，就能反解 G(m₁+m₂)。
  3. 第三定律只对 E < 0（椭圆）成立：E ≥ 0 时运动无限，根本没有周期可谈。

sympy 复核（D1–D5）：T = πab/(L/(2μ)) = 2πa^(3/2)√(μ/α)、T² = 4π²μa³/α、引力化 T² = 4π²a³/[G(m₁+m₂)] 三式全部成立。

数量级感受（顺便看"μ ≈ m₂"到底差多少）：地球轨道 a ≈ 1 AU、T = 1 年。 用 T² = 4π²a³/[G(M_☉+m_⊕)] 反解得到的是太阳与地球的质量之和； 因为 m_⊕/M_☉ ≈ 3×10⁻⁶，忽略地球质量带来的相对误差也只有 3×10⁻⁶ —— 这就是 §4.3 里"μ ≈ m₂ 只在最后代入时才用"的实例。

7.10 圆轨道的能量分配与位力定理（课件 p18 Task #3、p19 Task #4）

（a）圆轨道：T = −E，U = 2E（课件 p18 Task #3）

圆轨道上 r = r₀ = L²/(μα) 恒定，用径向力平衡（或 U_eff′(r₀) = 0）得到 μv²/r₀ = α/r₀²，即 μv² = α/r₀。于是：

T = ½μv² = α/(2r₀)，　U = −α/r₀ = −2T，　E = T + U = −T

⟹　T = −E，　U = 2E　（因为 E < 0，所以 T > 0 而 U = 2E < 0）

课件 p18 特意写了 "但人家没这类条件！" —— 意思是：这个漂亮的 T = −E 只在圆轨道上逐点成立，椭圆上不成立（椭圆上 T 与 U 都在变）。那椭圆怎么办？看下一格。

（b）位力定理：椭圆轨道上的"平均"版本（课件 p19 Task #4）

课件 p19 的推导骨架：

d/dt(r·p) = 2T + r·F　（把 r·p 求导并用 p = μv、牛顿方程）

对一个完整周期取平均，左边是 [r·p]/τ：因为椭圆轨道上 r 与 p 都是周期函数，一周期后回到原值，左边平均为零。于是：

2T̄ + r·F = 0　⟹　2T̄ = −r·F

对 U = −α/r（r 的 −1 次齐次函数），欧拉齐次定理给出 r·F = −U，所以 −r·F = Ū：

2T̄ = −Ū　⟹　配合 T̄ + Ū = E：　Ū = 2E，　T̄ = −E

课件 p19 把它写成一般形式 2T̄ = kŪ，并注明对 U = −α/r 有 k = −1；右边的方框还标注 "Here the average potential energy is calculated by using definition"， 并给出直接的积分验算：Ū = (1/τ)∫₀^τ U dt = −(2μα/(τL))∫₀^π dφ·r(φ)，代 r(φ) = q/(1+e cos φ) 积出来恰好是 2E。

为什么必须用"平均值"？因为 T 与 U 在椭圆上逐点变化（近处 U 很负、T 很大）。 但它们的时间平均满足一套干净的关系 T̄ = −E，形式与圆轨道完全一样。这不是巧合： 位力定理对"r 的 k 次齐次势"普遍成立，开普勒问题只是 k = −1 的特例。
读法建议：把圆轨道那条 T = −E 看成位力定理的"逐点成立"版本；椭圆上只能谈平均。这样两条就不冲突了。

7.11 Laplace–Runge–Lenz 矢量：为什么椭圆轨道会闭合（课件 p20 Task #5）

到 7.9 为止，我们已经能算出轨道。但还有一个"额外"的问题：§5 说过，一般有心力场里轨道并不闭合（玫瑰线，近日点会进动）； 为什么开普勒问题的椭圆一圈一圈严丝合缝地叠在一起、长轴方向一动不动？答案是存在一个额外的守恒量。

课件 p20 的定义

A = p × L − μα·r̂　（Task #5 原式写作 A = p × L − μαr/r，r̂ = r/r）

证明 dA/dt = 0（课件 p20 的三步）：

  1. 把 μ 提出来：A = μ( v × L − α r̂ )，且 L = μ(r × v) 守恒（L̇ = 0）。
  2. 求导并用双重叉乘公式 a × (b × c) = b(a·c) − c(a·b)：

    d/dt( v × L − α r̂ ) = μ[ r̂(v̇·v) − v(v̇·r̂) ] − (α/r)v + (α/r³)r(v·r̂)

    （课件 p20 中间那行原式就是把 d/dt(r/r) 展开成后两项。）
  3. 代入运动方程 v̇ = −αr/(μr³)，三项两两相消 ⟹ dA/dt = 0。∎

它的两个用处：

① 与 r 点乘：A·r = Ar·cos φ = L² − μαr　⟹　r = q/(1 + e cos φ)　—— 不用积分，又一次得到圆锥曲线！
② 大小：|A| = μα·e（课件 p20 原文 with magnitude |A| = eμα），方向沿拱线从焦点指向近日点。

为什么它保证了闭合？A 是一个固定方向的常矢量，而它总是指向近日点。 所以近日点方向在空间里不动 ⟹ 每转一圈都回到同一条拱线上 ⟹ 轨道闭合、不进动。 反过来，只要势离开严格的 −α/r（例如 H5.2 里的 −α/r − γ/r³），A 就不再守恒，近日点就会进动。 Landau §15 Problem 3 正是这条的反例练习：加 δU = β/r² 得 δφ = −2πβ/(αp)，加 δU = γ/r³ 得 δφ = −6πγ/(αp²)——这是水星近日点进动（广义相对论修正）的经典原型。
⚠ 三处写法不要混（这是最容易看晕的地方）
同一个矢量在不同书上差一个 μ 因子，甚至差一个符号，全都"对"，因为约定不同。对照如下：
出处势的写法矢量写法大小
课件 p20（Task #5）U = −α/r，α > 0（吸引）A = p × L − μαr̂，p = μvμα·e
课件 p15、Landau §15 (15.17)U = α/r，α 符号任意v × L + αr̂，用 v 而不是 pα·e
换算关系把 Landau 的 α 取成 −α_吸（吸引场），再把整体乘 μ，就得到课件 p20 的形式：
A_(p20) = μ · [ v × L − α_吸·r̂ ]，于是大小从 α_吸·e 变成 μ·α_吸·e。差的就是这一个 μ。
sympy 复核：F1（dA/dt = 0，三维符号验证）、F2（A·r = L² − μαr）、F3（A_(p20) = μ·A_Landau）、 F4（|A| = μαe）、F6–F8（数值：沿椭圆取 40 个点，A 恒定；|A| = μαe 精确成立）。

7.12 课件里另外两道 Task 的落笔（p16、p17）

Task #2（课件 p17）：由"到两焦点距离之和为常数"推椭圆方程

|PF₁| + |PF₂| = 2a　⟹　f₁ + f₂ = 2a　⟹　f₂ = 2a − f₁

f₁² = Y² + (l + X)²，　f₂² = Y² + (l − X)²　⟹（相减消去 Y²）　f₁² − f₂² = 4lX

又 f₁² − f₂² = (f₁+f₂)(f₁−f₂) = 2a(f₁−f₂)　⟹　f₁ = a + (l/a)X

代回 f₁² = Y² + (l+X)² 整理，得　X²/a² + Y²/b² = 1，　b² = a² − l²（l = 焦距的一半）

这就是"椭圆的标准方程"的来历；课件标注 a = semi-major axis（半长轴）、b = semi-minor axis（半短轴）。 它与 7.5 的极坐标形式是同一条曲线：把焦点放到原点做坐标平移，就得到 r = q/(1+e cos φ)。两种写法要能互相转换。

Task #1（课件 p16）：自由落体的时间，与传统弹道结果比较

两团质量 m、M 从相对静止（L = 0）开始，初距离 R+h，相碰到距离 R。此时 U_eff = U（无离心项），直接用 5-1 的能量积分：

ṙ = ±√( (2/μ)(E − U(r)) )，　E = U(R+h) = −GmM/(R+h)

(2/μ)(E − U(r)) = (2/μ)·GmM·( 1/r − 1/(R+h) ) = 2G(mM/μ)·( 1/r − 1/(R+h) )

t = ∫(R → R+h) dr / √( (2/μ)[U(R+h) − U(r)] )

课件进一步把 U(r) 在 r = R 附近线性化（U(r) ≈ U(R) + U′(R)(r−R)，即匀加速近似）来求得闭式的弹道时间，再与精确式比较——这是"有心力方法 vs 经典弹道方法"的对照练习。

注意右边标注的"条件"：α = GmM、E = U(R+h)、L = 0。L = 0 是关键——没有角动量就没有离心势垒，运动才是一维的。

7.13 课件 p25 Exercise 5.6：把 β/r² 并进离心项（一个漂亮的技巧）

题：U(r) = α/r + β/r²（α > 0, β > 0），求轨道。

思路：不要为多出来的 β/r² 重做一遍积分。U_eff 里 β/r² 和离心项 L²/(2μr²) 是同一幂次，先合并：

U_eff(r) = α/r + (β + L²/(2μ))/r² = α/r + L̃²/(2μr²)，　其中 L̃ ≡ √(L² + 2μβ)

于是它变成了另一道开普勒题，只是角动量换成了 L̃、势系数换成了 α̃ = −α（因为这里是排斥的 +α/r）。直接套 7.3 的公式：

(φ − ψ)·L̃/L = arccos( (1/r − μα̃/L̃²) / √( μα̃²/L̃⁴ + 2μE/L̃² ) )

这个技巧的一般形式：见到 U(r) 里有 1/r² 项，第一件事永远是把 它和离心项合并—— 合并后的净系数决定"还有没有离心势垒"（这正是 §6 形状 2 的 C = β + L²/(2μ)）， 而"再往后怎么积"则可以整段照抄开普勒的结果，只把 L 换成 L̃。先合并、再判类型、最后套模板——三步，一次都不用重积分。

§8 散射（5-2 p26，仅地图）

粒子从无穷远飞来、被中心场偏转、再飞向无穷远。用的是同一套积分（§7.1–7.3 的那两个），只是边界条件换成"两端都到无穷远"：

  • 渐近线（asymptotes）：r → ∞ 时轨道趋近的两条直线。对吸引场双曲线（E > 0，e > 1），渐近线条件是 1 + e cos φ = 0，给出两个渐近方向 φ₁, φ₂。
  • 碰撞参数（瞄准距离）：入射渐近线到力心的垂直距离，ρ = L/√(2μE)。
  • 偏转角（velocity deflection angle）：出射方向与入射方向之差。课件 p26 原式：Δφ = π − (φ₁ − φ₂) = π − 2·arccos(1/e)。
  • 课件 p26 还给出一般 U = α/r + β/r² 的双曲轨道写法：r(φ) = q̃/(ẽ·cos[γ(φ−ψ)] − 1)，其中 γ = √(1 + 2μβ/L²)——即 §7.13 那个 L̃ 技巧在散射场合的版本。
