## 已经建立的部分（不用重讲）

```
E = ½mẋ² + U(x)  ⟹  ẋ = ±√( 2(E − U)/m )  ⟹  t = ±√(m/2) ∫(x₀→x) dx/√(E − U)
```

## 待弄清的三点（学习者回去要看）

1. **变上限积分定义的是一个函数**，不保证有初等闭式、也不保证能反解 —— 什么时候"积分号能消失"？
2. **积分号消失 ＝ 找到原函数**：`∫f dθ = F(θ)` 的意思就是 `F′ = f`。三种情形分别消失成：
   - 不定积分 → `F(θ) + C`
   - **定**积分 `∫(a→b)` → `F(b) − F(a)`（一个**数**）
   - **变上限**积分 `∫(x₀→x)` → `F(x) − F(x₀)`（一个**函数**）
   ⚠ 运动规律里上限是变量，所以消失后得到的是**函数**，这才有后面的反解。
3. **本题恰好可积**（判据：换元后是"有理函数 × √二次式"）：
   - 配方：`E − U = (E + A) − A(e^(−αx) − 1)²`
   - 换元：`y = e^(−αx) − 1`（`dx = −dy/(α(y+1))`）→ 标准型 `∫dy/((y+1)√(a² − y²))`，`a² = 1 + E/A`
   - 再令 `y = a sinθ` → `∫dθ/(1 + a sinθ)`，标准结果（**已用数值积分核对** ✓ `_scratch/std-integral-check.py`）：
     - `|a| < 1`（即 **E < 0**）：`(2/√(1−a²))·arctan[ (tan(θ/2) + a)/√(1−a²) ]`
     - `|a| > 1`（即 **E > 0**）：`(1/√(a²−1))·ln| (a + sinθ − cosθ·√(a²−1))/(1 + a·sinθ) |`
   - ⟹ **E < 0 出 arctan（周期振荡）／E > 0 出 ln（单向）**：数学形式与运动形态一一对应。
