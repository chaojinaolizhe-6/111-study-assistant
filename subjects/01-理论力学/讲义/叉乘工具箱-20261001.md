# 叉乘（向量积）工具箱 —— 为 Topic 4 ④角动量推导补基础（2026-10-01）

> 用途：④角动量的推导只用得上下面 **三条**（B 反交换、C 分配律、D 混合积轮换），
> 但先把整套记住更省事。做题时照这张纸查即可。

## 0.「外积」这个名字：两门课指两个东西（别混）

| 名字 | 记法 | 结果是什么 | 在哪门课 |
|---|---|---|---|
| 数量积／点积（内积、标积） | `a · b` | **标量** | 高数·向量代数 |
| **向量积／叉积（矢积）** | `a × b` | **向量** | 高数·向量代数；力学天天用 |
| **外积／并矢（张量积）** | `a ⊗ b` 或 `a bᵀ` | **矩阵（3×3，秩 1）** | **线性代数** |
| （外代数的外积 `a ∧ b`） | — | 2-形式 | 高年级／微分几何 |

- 如果你记忆里的"外积"来自**力学/物理**课 → 那**就是叉乘**，你没记错；
- 如果来自**线性代数** → 那是 `a bᵀ`（并矢），**和叉乘不是一回事**。
- 所以：**你要找的计算法则在「高数·向量代数」那一章**（同济《高等数学》下册"向量代数与空间解析几何"；或《大学物理》力学第一章）。

## A. 定义与坐标算法

- **几何定义**：`a × b` 是一个**向量**，方向由**右手法则**（`a` 转向 `b`，拇指指向），大小为 `|a||b| sin θ`。
- **坐标算法**（行列式展开，最常用）：
  ```
  a × b = ( a_y b_z − a_z b_y ,  a_z b_x − a_x b_z ,  a_x b_y − a_y b_x )
  ```
  记忆：`| i  j  k ; a_x a_y a_z ; b_x b_y b_z |`
- **绕 z 轴（二维）的情形**：`(r × p)_z = x p_y − y p_x = m(xẏ − yẋ)`
  ← 这就是第三章那个 `L_z = Σ m(xẏ − yẋ)`（**你已经见过它**）。

## B. 反交换（★ 最常用）

```
a × b = − (b × a)        特别地：  a × a = 0
```
- 用途：④ 推导里 `pₐ ∥ vₐ` ⟹ `vₐ × pₐ = 0` —— **那一项会自己消失，靠的就是这条**。

## C. 分配律与数乘（★ 展开求和要用）

```
a × (b + c) = a × b + a × c        (λa) × b = λ (a × b)
```
- 用途：把 `Σ_a` 里的每一项拆开、把常数提出来。

## D. 混合积（标量三重积，★ 推导的关键工具）

```
a · (b × c)
```
- **几何意义**：以 `a, b, c` 为棱的**平行六面体体积**（带符号）。
- **轮换不变**（★ 这就是课件 p26 的恒等式）：
  ```
  a·(b × c) = b·(c × a) = c·(a × b)
  ```
- **换两个就变号**：`a·(b × c) = − a·(c × b)`
- 坐标算法：`det[ a ; b ; c ]`（三行行列式）
- ⚠ **常见错**：写成 `(a·b) × c` —— 混合积**必须先叉后点**；先点积就退化成"标量 × 向量"，没有意义。

## E. 二重叉积（BAC-CAB，课件 p26 的那个）

```
a × (b × c) = b (a · c) − c (a · b)
```
- ⚠ **叉乘不满足结合律**：`(a × b) × c ≠ a × (b × c)`
  （左边 = `b(a·c) − a(b·c)`，与右边**不同**）
- 口诀：**"中间往前提，其余做点积"**（BAC − CAB）。

## F. 和 ④ 推导的接口（只需这三条）

| 推导里的一步 | 用到哪条 |
|---|---|
| `δrₐ = δφ × rₐ`（转动位移的几何） | A（定义）＋ 右手法则 |
| `δL = Σ_a ṗₐ·(δφ × rₐ) + Σ_a pₐ·(δφ × vₐ)` | B（展开）＋ C（求和/数乘） |
| 把 `δφ` 提到 Σ 外面 | **D（混合积轮换）** |
| 第二项 `Σ_a vₐ × pₐ = 0` | **B（`a × a = 0`，因 `pₐ ∥ vₐ`）** |

## G. 三个小检查（做完就知道自己会不会了）

1. `(1, 2, 3) × (4, 5, 6) = ?`
2. `a × a = ?` 为什么？
3. 用 `a = (1,0,0)`、`b = (0,1,0)`、`c = (0,0,1)` 验证轮换：`a·(b × c) = b·(c × a) = ?`
4. （选做）用 BAC-CAB 展开 `a × (a × b)`

> 答案不给 —— 但**第 1 题算完可以自己验**：结果应与 `a` 和 `b` 都垂直（分别点乘 = 0）。

# 附录：为什么这些法则**必然成立**（证明链，2026-10-01 补）

> 学习者提问：「我会算，但从来没给过数学证明，我怎么知道它是对的、也无法理解它。」
> 下面每一条都是**可验证的证明**，不是"规定"。核心结论先说：
>
> **叉乘不是被"规定"出来的 —— 它被三条要求唯一确定。**

## 0. 出发：三条要求（这就是"公理"）

1. **双线性**：对 `a`、`b` 各自线性，即 `(λa+μa′)×b = λ(a×b)+μ(a′×b)`，对 `b` 同理；
2. **反交换**：`a × b = − b × a`（等价于 `a × a = 0`）；
3. **基向量的乘法表**（右手系、循环）：`e₁ × e₂ = e₃`，`e₂ × e₃ = e₁`，`e₃ × e₁ = e₂`，
   再由 2 得 `e₂ × e₁ = −e₃` 等等。

## 1. 「坐标公式」是**推出来的**（这一条最关键）

把 `a = a₁e₁ + a₂e₂ + a₃e₃`、`b = b₁e₁ + b₂e₂ + b₃e₃` 代入，用**双线性**展开 9 项；
其中 `eᵢ × eᵢ = 0`（由反交换），只剩 6 项：

```
a×b = a₁b₂(e₁×e₂) + a₁b₃(e₁×e₃) + a₂b₁(e₂×e₁)
      + a₂b₃(e₂×e₃) + a₃b₁(e₃×e₁) + a₃b₂(e₃×e₂)
```
代入第 3 条：`e₁×e₂ = e₃`、`e₁×e₃ = −e₂`、`e₂×e₁ = −e₃`、`e₂×e₃ = e₁`、`e₃×e₁ = e₂`、`e₃×e₂ = −e₁`：

```
a×b = e₁(a₂b₃ − a₃b₂) + e₂(a₃b₁ − a₁b₃) + e₃(a₁b₂ − a₂b₁)
```
**这就是那个行列式公式。** 所以它不是天上掉的 —— 它是"双线性 + 反交换 + 右手乘法表"的**唯一**结果
（也顺带证明了：满足这三条的乘法**只有这一个**）。

## 2. 「与两者都垂直」是**算出来的**

```
a · (a × b) = a₁(a₂b₃−a₃b₂) + a₂(a₃b₁−a₁b₃) + a₃(a₁b₂−a₂b₁)
              = a₁a₂b₃ − a₁a₃b₂ + a₂a₃b₁ − a₁a₂b₃ + a₁a₃b₂ − a₂a₃b₁
              = 0                      ← 六项两两相消
```
同理 `b · (a × b) = 0`。⟹ **垂直不是"规定"，是算出来的。**

## 3. 「大小 = 平行四边形面积」也是**算出来的**

用 **Lagrange 恒等式**（两边分量展开即得，属标准恒等式）：
```
|a × b|² = |a|²|b|² − (a · b)²
```
右边 `= |a|²|b|²(1 − cos²θ) = |a|²|b|² sin²θ` ⟹ **`|a × b| = |a||b| sin θ`** = 底 × 高 = 面积 ✓

## 4. 混合积 = 行列式 = 体积

```
a · (b × c) = a₁(b₂c₃−b₃c₂) + a₂(b₃c₁−b₁c₃) + a₃(b₁c₂−b₂c₁) = det[ a ; b ; c ]
```
而行列式的**几何意义**就是"以三行为棱的平行六面体（带符号）体积" ⟹ 混合积 = 体积 ✓

## 5. 「轮换不变、交换变号」来自行列式

- 交换两行 ⟹ 行列式**变号**（奇置换）；
- **循环**置换三行 = 两次交换（偶置换）⟹ **不变号**：
  `a·(b×c) = b·(c×a) = c·(a×b)` ✓
  ⟹ 这就是"为什么是**轮换**、不是随便交换"的原因。

## 6. 二重叉积（BAC-CAB）与"结合律为什么失效"

`a × (b × c) = b(a·c) − c(a·b)`
- **证明思路**：两边对 `a,b,c` 都是线性的 ⟹ 只需在基向量上验证（取 `b = eᵢ`、`c = eⱼ` 的 9 种情形），再由线性性推广。
- **结合律失效的反例（一行）**：
  `(e₁ × e₁) × e₂ = 0`，而 `e₁ × (e₁ × e₂) = e₁ × e₃ = −e₂ ≠ 0` ✓

## 7. 更深的"为什么长这样"（选读，两条）

- **数学归属**：叉乘属于**线性代数／多重线性代数** —— 它是一个**反对称双线性映射** `R³ × R³ → R³`，
  等价于李代数 `so(3)`：`a × b = [a]_× b`，其中
  ```
  [a]_× = ⎡ 0   −a₃  a₂ ⎤
           ⎢ a₃   0  −a₁ ⎥        ← 反对称矩阵（这就是它在矩阵语言里的样子）
           ⎣ −a₂  a₁   0 ⎦
  ```
- **它为什么"又反交换又垂直于两者"**：叉乘本质上是**外积 `a ∧ b`（2-形式）在 3 维下的 Hodge 对偶**。
  这也解释了**为什么叉乘只在 3 维（和 7 维）存在**：只有 3 维能把"2-形式"对偶回一个向量。
  想看严谨体系：**外代数（Grassmann）／微分几何**；入门级可查 "cross product as Hodge dual"。

## 8. 两套定义是**等价**的（课本为什么"几何给意义、代数给计算"）

| 出发点 | 要证什么 |
|---|---|
| 几何定义（面积 + 右手） | 需先证**双线性**（用"面积在投影下的可加性"，较繁）→ 再得坐标公式 |
| 代数定义（坐标公式／三条要求） | 直接得坐标公式 → 再由 §2–§4 得**垂直性、面积、体积** |

两条路得到**同一个**运算 ⟹ 课本的做法（几何讲意义、代数给公式）不是偷懒，而是把证明放在了等价性的两边。
