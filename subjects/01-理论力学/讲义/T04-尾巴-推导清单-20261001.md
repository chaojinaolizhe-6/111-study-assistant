## ④ 角动量守恒（课件 **p25–p29**）—— 只推**一件事**

### 目标（一句话）
> 从「**转动不改变 L**（空间各向同性）」推出 **`dL/dt = 0`**。

### 手上有的五件工具（都在 p25–p26）[课件原文]
1. 一次**整体转动** `δφ`（方向 = 转轴 `n`，大小 = 转角）给所有质点**同一个**位移：
   `δrₐ = δφ × rₐ`，相应地 `δvₐ = δφ × vₐ`
2. 一般变分式：`δL = Σ_a (∂L/∂rₐ)·δrₐ + Σ_a (∂L/∂vₐ)·δvₐ`
3. 两条替换：`pₐ ≡ ∂L/∂vₐ`，且由拉格朗日方程 `∂L/∂rₐ = ṗₐ`
4. **混合积换位**：`a·(b × c) = b·(c × a)`（p26 的矢量恒等式）
5. 单质点 `pₐ ∥ vₐ` ⟹ `vₐ × pₐ = 0` ← **推导里有一项会自己消失，就是它**

### 推导路线（4 步，每步一行）
1. 把工具 1 代进工具 2：
   `δL = Σ_a ṗₐ·(δφ × rₐ) + Σ_a pₐ·(δφ × vₐ)`
2. 用工具 4 把 `δφ` 提到外面：
   第一项 → `δφ · Σ_a (rₐ × ṗₐ)`；第二项 → `δφ · Σ_a (vₐ × pₐ)`
3. 第二项 = **0**（工具 5）
4. 得 `δL = δφ · (d/dt Σ_a rₐ × pₐ)`；因**各向同性** `δL = 0` 对**任意** `δφ` 成立
   ⟹ 括号内恒为 0 ⟹ **`dL/dt = 0`**，其中 **`L ≡ Σ_a rₐ × pₐ`**

### "推完了"的标准
- 你能**不看**上面第 3、4 步自己写出它们；
- 能说清"**为什么 `δφ` 任意就能把括号判零**"（`δφ` 三个分量独立 ⟹ 括号三个分量都为 0）。

## ⑤ 力学相似（课件 **p30–p35**）—— 推**三件事**

### ① 时间标度（p30 的 `EXERCISE`）[课件原文]
`rₐ → α rₐ`、`t → βt` 代入后
```
L′ = (α²/β²)·T − α^λ·U
```
要求 `L′ = C·L`（常数倍 ⟹ 运动方程不变）⟹ 两个系数必须相等：`α²/β² = α^λ`
⟹ **`β = α^(1−λ/2)`** ← 你 2026-09-30 **已经推过**，这里只需复习一遍。

### ② 三个缩放比（p31）[课件原文]
用 `β` 各推一行：

| 量 | 目标式子 | 一行理由 |
|---|---|---|
| 速度 | `v′/v = α^(λ/2)` | `v = dr/dt` ⟹ `α/β` |
| 能量 | `E′/E = α^λ` | `E ∝ U`，而 `U` 是 λ 次齐次 |
| 角动量 | `\|L′\|/\|L\| = α^(1+λ/2)` | `\|r × p\| ∝ α · (m v)` |

### ③ Virial 定理（p34 的 `EXERCISE`）[课件原文]
- **先当已知用**：`2T = kŪ`（`k` 就是前面的 `λ`，符号换了）；联立 `T + Ū = E` ⟹
  **`Ū = 2E/(k+2)`、`T = kE/(k+2)`**（纯代数）
  代进去看两眼：`k = 2`（小振动）⟹ `T = Ū`；`k = −1`（引力）⟹ `E = −T`
- **（想推得更彻底就推这个）`2T = kŪ` 本身从哪来** [教学归纳]：
  对有界运动 `〈d/dt Σ_a rₐ·pₐ〉 = 0`；把导数展开
  `Σ_a (vₐ·pₐ + rₐ·ṗₐ) = 2T + Σ_a rₐ·Fₐ`；
  再用**欧拉齐次定理** `Σ_a rₐ·∂U/∂rₐ = kU` ⟹ 取时间平均得 `2T − kŪ = 0`。

### ④ 自检（p32 的三个例子）
| 系统 | λ | 代进 `β = α^(1−λ/2)` | 结论 |
|---|---|---|---|
| 弹簧 `kx²/2` | 2 | `β = 1` | 周期**与振幅无关** |
| 均匀重力 `mgz` | 1 | `β = α^(1/2)` | 落体时间 ∝ √高度 |
| 牛顿引力 `−α/r` | −1 | `β = α^(3/2)` | 两边平方 ⟹ **开普勒第三定律** `(t′/t)² = (l′/l)³` |
