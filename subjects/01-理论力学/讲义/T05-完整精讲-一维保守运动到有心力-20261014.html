§2 一维保守运动：整套机器都在这一节（5-1 p3–p6）

2.1 什么时候能量守恒（前提，不是口号）

课件 5-1 p4 的两个前提：① 拉格朗日量不显含时间（∂L/∂t = 0）；② 坐标变换关系不显含时间（约束稳定）。两条都满足时，广义能量 E = Σ(∂L/∂q̇_i)·q̇_i − L 守恒；在稳定约束下它就是普通的机械能 E = T + U。

（Topic 4 已经专门练过这两条判据；tm.t4.energy-criteria 目标目前仍是「需支持」，用到时先回顾 Topic 4 的判据二。）

2.2 从能量守恒到一阶方程（这一步是本讲全部技术的源头）

E = ½mẋ² + U(x)　⟹　ẋ² = (2/m)(E − U(x))　⟹　ẋ = ±√( 2(E − U(x))/m )

为什么这一步这么重要？二阶的运动方程 mẍ = −U′(x) 一般解不出来；但能量守恒把它降成一阶方程，而且变量已经分离（左边只有 ẋ，右边只有 x）——直接积分就能得到 t(x)。这就是"守恒量 ⟹ 能积就积"的具体含义。
± 号的含义：同一能量下粒子有两个可能的运动方向；具体取哪个由初条件（如 ẋ₀ > 0）决定，并在转向点切换。

2.3 三个概念，一次讲清

概念定义要点
允许区E ≥ U(x) 的区段不满足的地方 ẋ² < 0，物理上粒子永远到不了——它是"经典禁区"，不需要任何动力学论证
转向点E = U(x) 的解 x_A, x_B, …此处动能恰为 0、速度为零，粒子随即反向。⚠ 它是"停下改方向"，不是平衡点
运动类型允许区是有界区间 [x_A, x_B] ⟹ 有限（振荡）；是射线 [x_C, +∞) ⟹ 无限一维有限运动必为来回振荡；由时间可逆性，周期＝单程时间的 2 倍

2.4 周期与运动规律（5-1 p11 原式）

τ(E) = 2∫(x_A→x_B) dx/√( 2(E − U)/m ) = √(2m)·∫(x_A→x_B) dx/√(E − U)　　← 有限运动周期

t = ±√(m/2)·∫(x₀→x) dx/√(E − U(x)) + const　　　　← 运动规律（变上限积分）

为什么是 2 倍？从 x_A 走到 x_B 用掉的时间，与从 x_B 回到 x_A 的时间相等（运动方程只含 ẋ²，时间反演对称）⟹ 一个完整来回 = 2 × 单程。
为什么积分在转向点发散、周期却有限？被积函数 1/√(E−U) 在端点处 → ∞，但它是可积的奇性（1/√ε 型，积分收敛）；只有在"势垒顶"那种 U 与 E 相切的情形，粒子趋近顶点所需时间才真正 → ∞。

2.5 三个必须记牢的自检点

  • E = U_min ⟹ 粒子静止在极小点（稳定平衡）；
  • E 比 U_min 略大 ⟹ 小振动，周期 → 2π/ω，其中 ω² = U″(x_min)/m；
  • E → U_max⁻（趋近势垒顶）⟹ 周期 → ∞。

§3 一维例题（5-1 p7–p14）：H5.1 的同型模板就在这里

3.1 课件 p10 例题：分段势能 + 初条件定 E（已读图核对）

题：U₁ = 2(x+2)² − 8（x < 0）、U₂ = −(x−4)² + 16（x > 0）；初条件 x₀ = 0、ẋ₀ = −4。

解法四步（这就是"给一个 U(x) 该怎么做"的标准流程）

  1. 由初条件定总能量：E_k(0) = ½·1·(−4)² = 8，U(0) = 0 ⟹ E = 8。（注意 U(0) 取 0 是因为两段在 x = 0 处都等于 0，连续。）
  2. 解转向点：左支 2(x+2)² − 8 = 8 ⟹ (x+2)² = 8 ⟹ x = −2 ± 2√2，取 x < 0 的那支 x₁ = −2 − 2√2 ≈ −4.83；右支 −(x−4)² + 16 = 8 ⟹ (x−4)² = 8 ⟹ x = 4 ± 2√2，取靠近原点的那支 x₂ = 4 − 2√2 ≈ 1.17。
  3. 看中间有没有过不去的坎：右支在 x = 4 处有极大 U_max = 16 > E = 8 ⟹ 粒子到不了那里。
  4. 下结论：允许区 [−4.83, 1.17] 有界 ⟹ 有限运动（振荡）。

⚠ 第 2 步会解出多余的根（4 + 2√2 ≈ 6.83 也在右支上），必须用"是否落在允许区内"筛掉——这是分段势能题最常见的失分点。

3.2 课件 p12–p13：静止点与势能的空间分布

  • 静止点（平衡点）：U′(x) = 0 且 ẋ = 0 恒成立的点。U″ > 0 ⟹ 稳定（极小）；U″ < 0 ⟹ 不稳定（极大）；U″ = 0 ⟹ 需看更高阶。
  • 势能的空间分布决定运动类型：阱（有界振荡）／垒（越过 or 被反射）／单调（单向或无界）。这就是"先看两端、再看驻点"的全部依据。

3.3 课件 p14 例题：单摆周期（已读图核对）

E = ½ml²φ̇² + mgl(1 − cos φ)　⟹（小角：cos φ ≈ 1 − φ²/2）　E ≈ ½ml²φ̇² + ½mglφ²

与 ½kx² 对照得等效 k = mgl/l²·l… 直接读：ω² = (mgl)/(ml²) = g/l ⟹ τ = 2π√(l/g)。用到的两件事：小角近似 cos φ ≈ 1 − φ²/2，以及标准积分 ∫dx/√(1−x²) = arcsin x。

H5.1 的落笔路径（我们不给答案，只给顺序与自查点）

  1. 子任务 1 草图：算 U′(x) = 0 定驻点、算 U″ 定性质、算 x → ±∞ 两端走向、算与 x 轴的交点（零点）。两端与驻点都是"算出来的"，不许凭印象画。
  2. 子任务 2 允许的 E：写成区间形式 E ≥ U_min，再按 E = U_min / U_min < E < 0 / E ≥ 0 三类各说一句运动形态（静止？两个转向点？一个转向点？）。
  3. 子任务 3 转向点：令 U(x) = E 直接解不好解时，换元把指数吃掉（例如令 u = e^(−αx) > 0，方程就变成 u 的二次方程）；解出 u 后 x = −(1/α)ln u。务必回头筛掉 u ≤ 0 的根，并说明每个根对应哪一端。
  4. 子任务 4 运动规律：达标线是课件的原话——方程可 "be integrated in general form"，即写出 t = ±√(m/2)∫ dx/√(E−U) + const 并说明在哪个 E 区间成立；能给出闭式 x(t) 是加分项。闭式的技术（配方 + 换元 + 标准积分）已单独整理：subjects/01-理论力学/讲义/挂起-变上限积分与闭式求解-20261012.md。

§4 从两体问题到有心力（5-2 p2–p9）

4.1 两步降维

  1. 两体 → 单体：用质心 R = (m₁r₁ + m₂r₂)/(m₁+m₂) 与相对位矢 r₁₂ = r₁ − r₂ 换掉 r₁, r₂。质心匀速直线运动（整体动量守恒），相对运动等效于一个质量为 μ = m₁m₂/(m₁+m₂) 的粒子在同一个 U(r) 中运动。
  2. 三维 → 二维：中心力只沿 r 方向 ⟹ 力矩为零 ⟹ 角动量守恒 ⟹ 运动始终在过力心的一个平面内（课件 p3 的"问题似乎是三维，仔细分析是二维"）。

4.2 角动量守恒 ⟺ 开普勒第二定律（5-2 p5–p7）

L = μr²φ̇ = const　（φ 是循环坐标 ⟹ p_φ = ∂L/∂φ̇ 守恒）

中心力 f = f(r)r̂ 沿 r 方向 ⟹ 对力心的力矩 r × f = 0 ⟹ dL/dt = 0。
几何含义：单位时间扫过的面积 dA/dt = ½r²φ̇ = L/(2μ) = const —— 这正是开普勒第二定律（面积速度相等）。课件 p7 就是拿"行星与太阳连线在相等时间扫过相等面积"这句话来讲的。

4.3 有效势：把转动那一份动能搬进势能（5-2 p8–p9）

L = ½μ(ṙ² + r²φ̇²) − U(r)，　φ̇ = L/(μr²)

E = ½μṙ² + ½μr²φ̇² + U(r) = ½μṙ² + U(r) + L²/(2μr²)　⟹　U_eff(r) = U(r) + L²/(2μr²)

E = ½μṙ² + U_eff(r)　　← 形式上与一维问题一模一样

离心能的物理含义（课件 p9 原词 centrifugal energy）：L 固定时 r 越小，φ̇ = L/(μr²) 越大，转动动能 ½μr²φ̇² 也越大。粒子想靠近中心，就必须把径向动能"兑换"成转动动能——效果等同于撞上一堵排斥墙。它不是新加的力，也不是新的势能，只是把转动动能改写了一个形式。
记账规则（最容易犯的错）：写 U_eff 时，½μr²φ̇² 已经被吸收进 L²/(2μr²) 了；能量式里不能再单独写一遍，否则重复计算。

§5 允许区、转向点与运动类型（5-2 p10–p12）

问题判据结论
哪些 r 到得了？E ≥ U_eff(r)允许区；其余是经典禁区
转向点在哪？解 U_eff(r) = E⚠ 此处 ṙ = 0，但 φ̇ = L/(μr²) ≠ 0 —— 不是停住点（课件 p11 原话 "NOT the stopping points"），粒子仍在绕转
运动类型？一个根 r_min无界运动：从无穷远来、回无穷远去（`finite` 只在下界一侧）
两个根 r_min, r_max有界运动，轨迹夹在环（annulus）内；但轨道不一定闭合——只有 Δφ = 2π·(m/n)（有理分数）时才闭合（玫瑰线 rosette）
能不能掉进中心？看 r → 0⁺ 端是否被允许若 U_eff → −∞（势垒被吃掉）⟹ 可能落向中心，且是有限时间内到达（H5.2 要讨论的正是这一条）

课件 p11 还提到：U 是一般的（arbitrary），所以 m/n 没法预先说是多少——闭合是"特殊条件"，不是常态。

§6 有效势的三套标准形状（把「两端谁主导」讲透）

形状 1：U(r) = −α/r（开普勒／库仑）——势垒 + 势谷

U_eff(r) = −α/r + L²/(2μr²)

  • 两端：r → 0⁺ 时 +L²/(2μr²) → +∞（离心势垒，粒子永远到不了中心）；r → ∞ 时 −α/r → 0⁻。
  • 驻点：唯一 r₀ = L²/(μα)；U_eff(r₀) = −μα²/(2L²)；U_eff″(r₀) = α⁴μ³/L⁶ > 0 ⟹ 稳定圆轨道。
  • 允许的 E：E ≥ −μα²/(2L²)。分类：E = U_eff(r₀) ⟹ 重根 ⟹ 圆轨道；U_eff(r₀) < E < 0 ⟹ 两个根 ⟹ 有限（椭圆）；E ≥ 0 ⟹ 一个根 ⟹ 无限（抛物线/双曲线）。
  • 结论：只要 L ≠ 0，粒子永远到不了 r = 0。

sympy 复核 ✓：r₀ = L²/(μα)、U_eff(r₀) = −μα²/(2L²)、U_eff″(r₀) = α⁴μ³/L⁶。

形状 2：U(r) = −α/r + β/r² —— 两项吸引 &「竞争」 [教学归纳，非课件原文]

U_eff(r) = −α/r + β/r² + L²/(2μr²) = −α/r + C/r² ,　其中 C = β + L²/(2μ)

关键一句话：C 是"离心势垒"与"额外吸引项"合并之后的净系数。

情形r → 0⁺驻点结论
C > 0→ +∞（势垒还在）唯一 r_min = 2C/αU_eff(r_min) = −α²/(4C)，U_eff″ = α⁴/(8C³) > 0 ⟹ 稳定圆轨道；E ≥ −α²/(4C) 才有运动
C ≤ 0→ −∞（势垒被吃掉）无单调升到 0⁻ ⟹ 任何 E 都会落向中心

数值例（α = μ = L = 1，已复核）：β = +0.1 ⟹ C = 0.6，r_min = 1.2，U_eff(r_min) = −0.4167；β = −0.6 ⟹ C = −0.1 < 0 ⟹ 没有势垒。

形状 3：课件 p24 Exercise 5.5（已读图核对）—— 官方版的"竞争"

题：U(r) = α/r − β/(2r²)（α > 0, β > 0），求粒子到力心的最小与最大距离。

U_eff(r) = α/r + (L² − μβ)/(2μr²)

  • 系数决定命运：L² − μβ > 0（即 L² > μβ）⟹ 离心项为正，r → 0⁺ 有势垒；L² < μβ ⟹ 系数为负，r → 0⁺ 时 U_eff → −∞（对应课件图上的陡降）。
  • 驻点：r₀ = (μβ − L²)/(μα)（L² < μβ 时它是极大＝势垒顶）；U_eff(r₀) = μα²/(2(μβ − L²))。
  • 转向点方程（课件原式）：E = U_eff ⟹ r² − (α/E)r − (L² − μβ)/(2μE) = 0 ⟹ r = (α/2E)(1 ± √(1 + 2(L²−μβ)E/(μα²)))，取合理的解。
  • 课件给的分类（0 < E < U_eff(r₀) 这一档）：出现两组解——{r_min = 0, r_max = (α/2E)(1 − √…)} 与 {r_min = (α/2E)(1 + √…), r_max = ∞}。
两组解是什么意思？势垒顶把允许区分成了两块：内区（粒子可以一直走到 r = 0，落向中心）和外区（粒子被挡在 r_min 之外，一路跑到无穷远）。同一道题里"落向中心"和"无界运动"可以同时都是答案——取决于初始在哪一侧。
数值例（α = μ = L = 1, β = 2 ⟹ L² = 1 < μβ = 2，已复核）：r₀ = 1，U_eff(r₀) = 0.5；0 < E < 0.5 就出现上面两块允许区。

⚠ 注意这道题与形状 2 的差别：这里 U 本身是排斥的（+α/r）加一个吸引的 −β/(2r²)；形状 2 是两项都吸引。结论的判法完全一样：把系数合并，看它是正还是负。

§7 轨道方程与开普勒问题（5-2 p13–p19，本讲只给地图）

把 §0 的 φ 积分做出来，就得到轨道方程 r(φ)（不再含时间）。对 U = −α/r：

r = p/(1 + e·cos φ)，　p = L²/(μα)（半正焦弦 latus rectum），　e = √(1 + 2EL²/(μα²))（离心率）

离心率轨道能量
e = 0圆E = U_eff(r₀)
0 < e < 1椭圆U_min < E < 0
e = 1抛物线E = 0
e > 1双曲线E > 0

课件 p25 Exercise 5.6（已读图核对）：一个漂亮的技巧

题：U(r) = α/r + β/r²（α > 0, β > 0），求轨道。

φ = ∫ (L dr)/(r²√(2μ(E − U_eff(r))))，　把 β/r² 并进离心项：α̃ = −α，　L̃ = √(L² + 2μβ)

⟹ (φ − ψ)·L̃/L = arccos( (1/r − μα̃/L̃²) / √(μα̃²/L̃⁴ + 2μE/L̃²) )

这个技巧的意义：多出来的 β/r² 项不用单独处理——把它和离心项合并，问题就"变成"了另一道开普勒题，只是角动量换成了 L̃。这与形状 2 的 C = β + L²/(2μ) 是同一个思想：负幂次项先合并，再判类型。

开普勒三定律（椭圆轨道）：① 行星沿椭圆运动、太阳在一个焦点上；② 面积速度恒定（＝角动量守恒）；③ T² ∝ a³。

Laplace–Runge–Lenz 矢量：A = p × L − μα·r̂ 是开普勒问题额外的运动积分（dA/dt = 0，课件 p20 的 Task #5 就是证它）。正是这个额外守恒量让椭圆轨道闭合、近日点不进动——注意与 §5 的结论对照：一般有心力场里轨道不闭合，闭合是需要额外条件的。

§8 散射（5-2 p26，仅地图）

粒子从无穷远飞来、被中心场偏转、再飞向无穷远。用的是同一套积分：渐近线（asymptotes）、碰撞参数（瞄准距离）、偏转角（velocity deflection angle ＝ 出射方向与入射方向之差）。朗道第四章 §18–§20（含卢瑟福公式）是这一块的深读材料，本讲不展开。

§9 作业 H5.1 / H5.2 的落笔路径与自查

H5.2（中心场 U(r) = −α/r − γ/r³，α > 0, γ > 0）

  1. 写 U_eff：三项——−α/r、−γ/r³、+L²/(2μr²)。别漏、别重复算转动动能。
  2. 看 r → 0⁺：−γ/r³（三次）与 +L²/(2μr²)（二次）谁增长更快？（§6 的图给的正是这个判据）⟹ 决定草图左端朝 +∞ 还是 −∞，也就是还有没有离心势垒。
  3. 求驻点：U_eff′(r) = 0 通分后分子是 r 的二次式，系数含 α, γ, μ, L²；判别式的符号决定"两个驻点（势垒 + 势谷）"还是"没有驻点（单调）"——题目说的 "depending on the ratio of parameters" 指的就是这。
  4. 画草图 + 分类：照 §0 的五步第 4、5 步走；单独交代 r → 0 端（能不能落向中心）。

同型例题：§6 形状 2（合并系数 C 的正负）与形状 3（课件 Exercise 5.5 的两组解）。把这两道看懂，H5.2 就是同一套动作换一个势。
