## 0. 它到底解决什么问题

有心力问题是**二维**的：位置要用 `r` 和 `φ` 两个数描述，看起来要同时解两个运动方程。

但角动量守恒让 `φ` 变成了"附属变量"——它自己转它的，**不反过来影响 `r` 怎么走**。有效势就是把这个降维写成一个**一维能量守恒式**：把转动那一份动能挪进势能里，然后就可以完全套用 Topic 5-1 的一维套路（允许区、转向点、运动类型）。

## 1. 三行推导（整块知识的核心）

平面极坐标下的拉格朗日量（原式，学习指引模块 C）：

```
L = ½μ(ṙ² + r²dφ/dt²) − U(r)
```

`φ` 是循环坐标 ⟹ 角动量守恒（原式）：

```
L = μr²dφ/dt = const          ← 只有中心力才有这一条
```

解出 `dφ/dt = L/(μr²)`，代回能量表达式：

```
E = ½μṙ² + ½μr²dφ/dt² + U(r)
  = ½μṙ² + U(r) + L²/(2μr²)
```

定义**有效势能**（课件 p9 原式）：

```
U_eff(r) = U(r) + L²/(2μr²)          ← 第二项＝离心能
E = ½μṙ² + U_eff(r)                  ← 形式上与一维问题一模一样
```

**这一步的全部意义**：方程里再也没有 `dφ/dt`，只剩 `r`。于是 5-1 的整套机器（`E ≥ U(x)`、转向点、有限/无限运动）可以原样搬过来用。

## 2. 两项各是什么

| 项 | 名称 | 性质 |
|---|---|---|
| `U(r)` | 真实势能 | 由力场决定 |
| `L²/(2μr²)` | **离心能**（课件 p9 原词 centrifugal energy） | 由角动量守恒"生"出来的排斥项，`r → 0` 时 `→ +∞` |

`[教学归纳]` **离心项不是一个新加的力，也不是一个新的势能**——它是**把转动动能改写**的结果：`L` 固定时，`r` 越小则 `dφ/dt = L/(μr²)` 越大，转动动能 `½μr²dφ/dt² = L²/(2μr²)` 也越大。粒子要靠近中心，就得把径向动能"兑换"成转动动能，效果与撞上一堵排斥墙相同。

⚠ 由此带来一个**记账规则**：写 `U_eff` 时，`½μr²dφ/dt²` 那一项**已经被吸收进去了**，不能再在能量式里单独写一遍，否则重复计算。

## 3. 成立条件与边界（讲"为什么"必须带的部分）

1. **必须是中心力场**：`U = U(r)`，势不依赖角度。势依赖 `φ`（如带方向的场）就不成立。
2. **需要角动量守恒**：有外力矩时 `L ≠ const`，`L²/(2μr²)` 就不是常数项，整个化简失效。
3. **`L = 0` 时退化**：`U_eff = U(r)`，没有离心势垒 ⟹ 一切沿径向的运动都会直冲中心。
4. **它只描述 `r` 的运动**。`φ` 要另外积出来：`dφ = (L/(μr²))dt`。所以有效势能回答"离中心多远、怎么远近"，回答不了"转到哪个角度"。
5. **转向点 ≠ 停住点**（课件 p11 原话 "NOT the stopping points"）：在 `r` 的转向点处 `ṙ = 0`，但 `dφ/dt = L/(μr²) ≠ 0` —— 粒子**没有停**，它只是不再靠近/远离，仍在绕中心转。

## 4. 五步套路（拿到任何 `U(r)` 都这么走）

1. **写**：`U_eff(r) = U(r) + L²/(2μr²)`。
2. **看两端**：`r → 0⁺` 和 `r → ∞` 时**哪一项主导** ⟹ 草图左右两端的走向。（这一步就决定"有没有离心势垒"。）
3. **求驻点**：解 `U_eff′(r) = 0`，**按参数比分类讨论**（有几个实根）。
   - `U_eff″ > 0` ⟹ **极小** ⟹ 稳定圆轨道；
   - `U_eff″ < 0` ⟹ **极大** ⟹ 势垒顶 / 不稳定圆轨道。
4. **画草图**：把第 2 步的两端和第 3 步的驻点拼起来。
5. **读运动**：允许区 `E ≥ U_eff(r)` ⟹ 解 `U_eff(r) = E` 得转向点 ⟹ 分类：
   - 重根 ⟹ **圆轨道**（`r` 恒定）；
   - 两个根 ⟹ **环内有限运动**（有界，但不一定闭合）；
   - 一个根 ⟹ **无界运动**（从无穷远来、回无穷远去）；
   - 另外单独看 `r → 0` 那一端**允不允许**（允许 ⟹ 可能**落向中心**）。

## 5. 示范例 1（课件主线）：`U(r) = −α/r`（开普勒／库仑）

```
U_eff(r) = −α/r + L²/(2μr²)
```

- 两端：`r → 0⁺` 时 `+L²/(2μr²) → +∞`（**离心势垒**挡住中心）；`r → ∞` 时 `−α/r → 0⁻`。
- 驻点：`α/r² − L²/(μr³) = 0` ⟹ **唯一驻点 `r₀ = L²/(μα)`**。
- 极小值 **`U_eff(r₀) = −μα²/(2L²)`**；且 **`U_eff″(r₀) = α⁴μ³/L⁶ > 0`** ⟹ **稳定圆轨道**。
- 允许的 `E`：**`E ≥ −μα²/(2L²)`**（比这更低则 `ṙ² < 0`，无解）。
- 转向点分类：
  - `E = U_eff(r₀)` ⟹ 重根 ⟹ 圆轨道；
  - `U_eff(r₀) < E < 0` ⟹ 两个根 ⟹ **有限运动**（夹在 `r_min, r_max` 的环内；椭圆轨道）；
  - `E ≥ 0` ⟹ 一个根 ⟹ **无限运动**（抛物线/双曲线）。
- 结论：只要 `L ≠ 0`，离心势垒使粒子**永远到不了 `r = 0`**。

> 以上式子已用 sympy 复核（`_scratch/tm-effpot-check-20261014.py`）：`r₀ = L²/(μα)`、`U_eff(r₀) = −μα²/(2L²)`、`U_eff″(r₀) = α⁴μ³/L⁶` ✓

## 6. 示范例 2：`U(r) = −α/r + β/r²` —— "竞争"这件事讲透

这是 H5.2 的**孪生结构**（多一项对 `r` 的负幂次吸引项），但换了函数、换了参数，不是同一道题。

```
U_eff(r) = −α/r + β/r² + L²/(2μr²) = −α/r + C/r² ,   其中 C = β + L²/(2μ)
```

**关键就一句话**：`C` 是"离心势垒"和"额外吸引项"**合并之后**的净系数。

| 情形 | `r → 0⁺` 行为 | 驻点 | 结论 |
|---|---|---|---|
| **`C > 0`**（即 `β > −L²/(2μ)`） | `→ +∞`（势垒还在） | 唯一 `r_min = 2C/α` | `U_eff(r_min) = −α²/(4C)`，`U_eff″ = α⁴/(8C³) > 0` ⟹ 稳定圆轨道；`E ≥ −α²/(4C)` 才允许运动 |
| **`C ≤ 0`**（即 `β ≤ −L²/(2μ)`） | `→ −∞`（**势垒被吃掉**） | 无 | `U_eff` 从 `−∞` 单调升到 `0⁻` ⟹ **任何 `E` 都会落向中心** |

数值例子（`α = 1`、`μ = 1`、`L = 1`，已复核）：
- `β = +0.1` ⟹ `C = 0.6 > 0`，`r_min = 1.2`，`U_eff(r_min) = −5/12 ≈ −0.417`；
- `β = −0.6` ⟹ `C = −0.1 < 0`，**没有势垒**，无论初条件如何都落向中心。

`[教学归纳]` 这两行的用途：以后见到"势里多了一项吸引性的负幂次项"，**第一件事就是把离心项和它合并**，看合并后的系数是正还是负——正的就是"还有势垒"，负的就是"势垒没了"。判据始终是**两端谁主导**加上**驻点方程有没有实根**。

## 7. 课件 p9 的两个积分式（原式）

```
ṙ = ±√( (2/μ)(E − U_eff(r)) ) = ±√( (2/μ)(E − U(r)) − L²/(μ²r²) )

t = ±∫ dr [ (2/μ)(E − U(r)) − L²/(μ²r²) ]^(−1/2) + const        ← 运动规律 t(r)

φ = ±∫ dr (L/r²) [ 2μ(E − U(r)) − L²/r² ]^(−1/2) + const        ← 轨道方程 φ(r)

dφ = (L/(μr²)) dt
```

`[教学归纳]` 两个积分式**只差一个 `μ²` 因子**：`t` 式的方括号 = `(1/μ²) ×`（`φ` 式方括号）。因为
`dφ = (L/(μr²))dt`，把 `dt = dr/ṙ` 代进去就能从 `t` 式推出 `φ` 式。**定性分析（草图、允许区、转向点）根本不需要这两个积分**——它们是"要定量求 `t(r)`、`r(φ)` 时"才用的。

## 8. 落到 H5.2 时怎么起手（只给起手式，不给答案）

题意：`U(r) = −α/r − γ/r³`（`α > 0`、`γ > 0`），要草图、允许的 `E`、转向点与运动类型。

1. 先写 `U_eff(r)`，认清这里有**三项**：`−α/r`、`−γ/r³`、`+L²/(2μr²)`。
2. 只看 `r → 0⁺`：`−γ/r³`（三次）和 `+L²/(2μr²)`（二次）**谁增长更快**？—— 这一步决定草图左端朝 `+∞` 还是 `−∞`，也就决定了"还有没有离心势垒"。
3. 求驻点：`U_eff′(r) = 0` 通分后，分子是 `r` 的**二次式**（系数里含 `α`、`γ`、`μ`、`L²`）；它的**判别式**决定"两个驻点（势垒＋势阱）"还是"没有驻点（单调）"。题目说的 "depending on the ratio of parameters"，指的就是这个判别式的符号。
4. 然后照第 4 节的第 4、5 步做分类。
