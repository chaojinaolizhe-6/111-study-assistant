## 2. 选材原则（2026-10-04）

优先复用已有资料，按当前练习给一个材料或短片段。有文本方便复盘，没有原文也可听大意。范文可作学习材料，同题模仿照实记受助；不禁止打开其他题的范文，不把一般方法学习自动算成新题曝光。错因从实际证据与必要的局部确认判断，不能只凭diff生成四类占比。

### 关于剑桥真题的版权立场（不绕弯）

剑桥真题集是**在售商业出版物**，完整电子版没有合法免费来源。导师**不去找盗版**，理由不是道德表演，是三条实际后果：
① 盗版 PDF 常是**扫描件**（导师读不到文字层，等于废纸）；② 听力音频来路不明，**你要靠它的原文做逐词 diff**，错一处全盘错；③ 让学习证据建立在不稳定来源上，与这个项目「可核验」的立身之本冲突。

**但这不是缺口**——本次下载的官方免费材料已经覆盖了剑桥真题的**大部分训练功能**：

| 剑桥真题能给的 | 已下载材料的对应情况（2026-10-03 更新，含学习者补充） |
|---|---|
| 写作题面 + 范文 | ✅ **3 道 Task 2 ＋ 3 道 Task 1 题面**；✅ 官方范文（4 份答卷 + Band 分 + 考官点评）范文可作示例学习，正式检查避免本题答案 |
| 听力音频 + 原文 | ✅ **8 个官方 MP3（学习者补）＋ 对应题面／原文／答案（页码已映射）** |
| 阅读文章 + 题目 | ✅ **46 页含文章片段、题目与答案（学习者补）** |
| 题型广度 | ✅ 听力八种题型 ＋ 阅读多种题型（**按题型切片**，非整套） |
| **完整、未做过的计时套题** | ❌ 完整且可靠的未见套题需要单独确认——官方样题是片段，**不能拼起来当整套换算分数** |

## 7. 兴趣输入与材料复用（2026-10-04）

TED、讲座、播客是学习者已选择的输入。可先听、读字幕、重听、跟读、精读同一份内容，不强制分成永久互斥的用途。看过原文后听写仍能训练，只不能证明未见材料的一遍听力。用户不用维护两栏清单，不需逐次汇报；选正式检查时助手另取未曝光片段。精读按 `讲义/精读协议-20261004.md` 默认一个短片段，不要求整篇60–75分钟。
