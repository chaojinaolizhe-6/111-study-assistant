## 0. 什么是孤立奇点（课件 p48 原文要点）

- **孤立奇点**：f 在 z₀ **不可导**，而在 z₀ 的**任意小邻域内除 z₀ 点外处处可导**。
- **非孤立奇点**：z₀ 的任意小邻域内**总能找到别的不可导点**。
- 课件给的例子 `[复现]`：
  - `1/(z(1−z))` 在 `z = 0`：半径 < 1 的圆内没有别的奇点 → **孤立**；
  - `1/sin(1/z)` 在 `z = 0`：奇点在 `z = 1/(nπ)`，n 足够大就靠近 0 → **非孤立**。

## 1. 分类的**定义**（课件 p49 原文要点）

函数在**去掉 z₀ 的环形区域**内可展成洛朗级数 `f(z) = Σ_{n=−∞}^{∞} aₙ (z − z₀)ⁿ`。按**负幂部分**分三类：

| 洛朗级数里的负幂项 | 名称 | 备注 |
|---|---|---|
| **没有**负幂项 | **可去奇点** | 补 `f(z₀) = a₀` 后解析 |
| **有限个**（最高为 `a₋ₘ/(z−z₀)^m`，`a₋ₘ ≠ 0`） | **m 阶极点** | `lim f = ∞` |
| **无穷个** | **本性奇点** | **没有阶数** |

## 2. 三种判据（课件分页给出的两条路）

### 可去奇点（课件 p50–p51）
1. **定义法**：洛朗展开**无负幂项**；
2. **极限法**：`lim_{z→z₀} f(z)` **存在且为有限值**（等价：f 在去心邻域**有界**）。
- 课件自己的例子 `[复现]`：`f(z) = sin z / z` 在 `z = 0` 处"发散"（分母为 0），但
  `sin z / z = 1 − z²/3! + z⁴/5! − …` **无负幂项**，且 `lim = 1` ⟹ **可去奇点**。
- ⚠ **这正是 2026-09-30 诊断里判错的第一个函数**（当时答"一个负幂项"）——**课件 p50–51 就有它**。

### 极点（课件 p52–p53）
1. **定义法**：洛朗展开有**有限个**负幂项，最高为 `(z−z₀)^(−m)` ⟹ **m 阶极点**；
2. **课件方法 2 `[复现]`**：找最小的 m 使 `h(z) = (z − z₀)^m f(z)` 在 z₀ **解析且 `h(z₀) ≠ 0`** ⟹ m 阶极点（口语：**乘到不再有奇性**为止）。
- 课件例题 1（p53）`[复现]`：`f(z) = 1/sin z` 的奇点 `z = nπ` ——
  **因为 `sin z` 的一阶导数 `cos z` 在 zₙ 处不为零**，所以 zₙ 是**一阶极点**。
  → 读这句的关键：**分母零点是一阶 ⟹ 极点就是一阶**。

### 本性奇点（课件 p54–p55）
1. **定义法**：洛朗展开**有无穷多个负幂项**；课件例子 `e^(1/z)`（p54）；
2. **极限法**：`lim_{z→z₀} f(z)` **不存在**（既不趋于 ∞，也不趋于任何有限值）。
- ⚠ 本性 **没有阶数**：说"无穷阶极点"是错的。

## 3. `[教学归纳]` 不展开整个函数的实操：三步定案

1. **先看有没有"本身在 z₀ 不解析"的因子**（`e^(1/z)`、`cos(1/z)`、`sin(1/z)` …）
   → 有 ⟹ **本性奇点**，结束。
2. 否则，把**分子、分母各自展开到首个非零项**：分子最低次 `z^k`、分母最低次 `z^n`。
3. 比较：
   - `k ≥ n` → 极限有限（0 或有限非零）⟹ **可去**（＝课件 p51 极限法）；
   - `k < n` ⟹ **n − k 阶极点**（＝课件 p53 方法 2）。
   - 即 **极点阶数 = 分母零点阶数 − 分子零点阶数**。
4. **分母/分子是乘积时**：各因子的零点阶数**分别求出后相加**。

> 与课件的关系：**分类定义与三条判据都是课件原文**；"数最低次项 / 相除看指数差"是**我的整理口径**，
> 它只是把课件的两条路（定义法 + 极限法）写成可执行的三步，**结论完全一致**。

## 4. `[教学归纳]` 最常错的三处（2026-09-30 实测踩过）

1. **把"看得见的最低次"当成最低次** —— 凡"函数 − 它的低次项"，**减法会消掉低次项**，必须展开到**不抵消**为止：
   - `z − sin z = z³/3! − z⁵/5! + …` ⟹ **3 阶零点**
   - `ln(1+z) − z = −z²/2 + z³/3 − …` ⟹ **2 阶零点**
   - `e^z − 1 − z = z²/2! + z³/3! + …` ⟹ **2 阶零点**
2. **把"负幂项的个数"当成阶数** —— 阶数看**最低次幂**：
   `sin z/z³ = z⁻² − 1/3! + …` → 负幂项**1 个**、阶数**2**；`1/z³ + 1/z` → 个数 2、阶数 3。
3. **术语**：本性 ≠ 极点，本性**无阶数**；"可去"仍是孤立奇点（只是补一个值就解析）。

## 7. 2026-10-03 补充：**负幂的"深度"由谁决定**（学习者当天自己提出的问题）

> 起因：延迟变式 `attempt-39` 第 3 项 `1/(z(e^z − 1))` 被判成本性奇点；学习者追问"为什么它不是本性"，
> 随后自己说出了正确的观察：**「分母括号里面就只有一个 z，其它都能直接带入 0」**。
> 本节把这条观察写成可复用的规则。

### 7.1 规则（`[教学归纳]`，结论与课件 p49/p52 一致）

**负幂项有多少个、最深到几次，只由分母在 z₀ 的「最低次项」决定；分母的更高次项只贡献非负幂。**

写法：`D(z) = N(z)/D(z)` 前先把分母写成

`D(z) = c·(z − z₀)ⁿ·(1 + 高阶项)`，其中 `c ≠ 0`，`n` ＝ 分母零点阶数

关键是**括号在 z₀ 处等于 1 ≠ 0**，所以它的倒数在 z₀ **解析**，只有非负幂：

`1/(1 + 高阶) = 1 − 高阶 + 高阶² − …`

两边幂次都是 `≥ 0`。于是

`f = (1/c)(z − z₀)^(−n)·[非负幂级数]` ⟹ **负幂最多到 `z^(−n)`，到 n 就停。**

- 分母**有**有限阶零点 ⟹ 负幂有限 ⟹ **极点**（阶数 = n − 分子零点阶数 k）。
- 「无穷多负幂」（**本性**）来自**另一种结构**：`e^(1/z)`、`sin(1/z)` 这类**本身在 z₀ 不解析**的因子。它们不是"分母零点阶数太大"，而是**根本没有有限的 n**：对任意 m，`z^m f` 在 z₀ 仍不解析。
  → 这就是第 3 节「三步定案」第 1 步要**先扫一遍有没有不解析因子**的原因。

### 7.2 两个"无穷"不要混（`attempt-39` 的错因机制）

- **分母是无穷级数** ＝ 泰勒展开有**无穷多项**（幂次 `≥ 0`）。
- **负幂有无穷多项** ＝ 洛朗展开的主要部分不终止。
- 这两件事**无关**。`e^z − 1` 的级数有无穷多项，但它只给分母一个**二阶零点**；除下去负幂只有 2 个。
- 判据不是"分母有几项"，而是"分母**最低次项**是几次"。

### 7.3 实例：`f(z) = 1/(z(e^z − 1))`（中心 0）

```
e^z − 1 = z(1 + z/2 + z²/6 + z³/24 + …)
z(e^z − 1) = z²(1 + z/2 + z²/6 + …)          ← 分母二阶零点，n = 2
f = (1/z²)·1/(1 + u),  u = z/2 + z²/6 + …
1/(1 + u) = 1 − z/2 + z²/12 + …               ← 解析部分，只有非负幂
⟹ f = 1/z² − 1/(2z) + 1/12 − z²/720 + …      ← 负幂只有 2 项 ⟹ 二阶极点
```

**数值核对（2026-10-03 实算，可作为"是否真收敛"的自检）**

| 检查 | 结果 |
|---|---|
| 真值 `f(0.1) = 1/(0.1(e^0.1 − 1))` | `95.08331945` |
| 只用两项负幂的级数 `100 − 5 + 1/12 − 0.01²/720` | `95.08331944` |
| `z²f` 在 `z = 0.1 / 0.01 / 0.001` | `0.9508 / 0.99500 / 0.99950` → 趋向 **1**（有限非零）|

**对照 `e^(1/z)`**（本性）：`1 + 1/z + 1/(2!z²) + …` 负幂永不终止；乘 `z^5` 在 `z = 0.01` 处仍约 `2.7×10³³`，乘 `z^50` 在 `z = 0.001` 处仍约 `10^284`。**幂律追不上指数** ⟹ 无有限阶。

### 7.4 快速判阶的实操（与第 3 节一致）

1. 先扫**不解析因子**（`e^(1/z)`、`sin(1/z)`、`cos(1/z)`…）→ 有 ⟹ 本性，结束。
2. 没有 → 把**分母**展开到首个非零项，读出零点阶数 `n`；分子同理读 `k`（分子为常数则 `k = 0`）。
3. `k ≥ n` ⟹ 可去；`k < n` ⟹ **`n − k` 阶极点**。
4. 复核：`lim_{z→z₀} (z − z₀)^(n−k) f(z)` 应**有限且非零**。
