## 类型 1：有理三角积分 ∫₀^{2π} R(cos θ, sin θ) dθ（p32–p42）

**换元**：`z = e^(iθ)`，θ 从 0 到 2π 时 z 沿**单位圆 |z| = 1 逆时针一整圈**。

| 量 | 换成 z |
|---|---|
| dθ | `dz/(iz)` |
| cos θ | `(z + z⁻¹)/2` |
| sin θ | `(z − z⁻¹)/(2i)` |

代入后**必定**得到单位圆上的有理函数积分：

 ∫₀^{2π} R(cos θ, sin θ) dθ = ∮_{|z|=1} f(z) dz， f(z) = (1/(iz))·R( (z+z⁻¹)/2, (z−z⁻¹)/(2i) )

**步骤**：换元 → 通分整理成 P(z)/Q(z) → 找**单位圆内**的极点并判阶数 → 算留数 → `2πi Σ`。
（⚠ 单位圆**外**的极点全部不管。）

**作业 第 2 组（p62，4 题）**

1. ∫₀^{2π} dθ/(2 + cos θ)
2. ∫₀^{2π} dθ/(1 + ε cos θ)²，0 < ε < 1
3. ∫₀^{2π} dθ/(1 + sin²θ)
4. ∫₀^{2π} dθ/(1 + cos²θ)

## 类型 2：有理函数的无穷积分（p43–p52）

**围道**：实轴从 −R 到 R ＋ 上半平面半圆弧 C_R，合成闭合围道 C。

**成立条件**（缺一不可）：

1. f(z) 在**实轴上无奇点**；
2. f(z) 在**上半平面**除有限个极点外解析；
3. |z| → ∞ 时 **z·f(z) → 0**（保证半圆弧上的积分趋于 0）—— 实操判据：**分母次数 ≥ 分子次数 + 2**。

**公式**：

 ∫_{−∞}^{∞} f(x) dx = 2πi Σ_{上半平面极点} Res f(z)

**∫₀^∞ 怎么办**：若 f 是**偶函数**，则 ∫₀^∞ f dx = ½∫_{−∞}^∞ f dx。
（⚠ 只在偶函数时能这么折半，一般函数不行。）

**作业 第 3 组（p62，3 题）**

1. ∫_{−∞}^{∞} x² dx/((x² + 1)(x² + 4))
2. ∫₀^{∞} x² dx/(x⁴ + a⁴)，a > 0
3. ∫_{−∞}^{∞} x² dx/(x² + a²)²，a > 0

## 类型 3：含三角函数的无穷积分（约当引理）（p53–p61）

∫_{−∞}^{∞} f(x) cos(mx) dx 或 ∫_{−∞}^{∞} f(x) sin(mx) dx，其中 **m > 0**。

**做法**：换成复指数 `e^(imx)`，解出后**取实部或虚部**。

 ∫_{−∞}^{∞} f(x) e^(imx) dx = 2πi Σ_{上半平面极点} Res [ f(z) e^(imz) ]

**约当引理**（保证半圆弧 C_R 上的积分趋于 0）：
`m > 0` 时，若在**上半平面**（含实轴附近）`|f(z)| → 0`（一致），则 ∫_{C_R} f(z) e^(imz) dz → 0。

> **[教学归纳，非课件原文]** 约当引理比类型 2 的条件**宽**：`z f(z) → 0` 不够、甚至不必要时它也可能成立，因为 `e^(imz)` 在上半平面自带指数衰减（z = iy 时 |e^(imz)| = e^(−my)）。所以像 `sin x / x` 这类（分母只高一次）也能处理。
> 【来源与数学】上面这句是归纳，用来解释「为什么类型 3 的条件比类型 2 松」；做题时以课件 p53–p61 的**原始条件**和老师的写法为准，不要用这句话替代条件陈述。

**结果取哪一部分**：

| 原积分 | 取的部位 |
|---|---|
| ∫ f(x) cos(mx) dx | **实部** |
| ∫ f(x) sin(mx) dx | **虚部** |

**⚠ 若被积函数含 z 乘在三角函数前**（如 `x sin x/(x²+1)`、`x sin(mx)/(x²+a²)²`），仍写 `f(z) e^(imz)`，这里的 f(z) = `z/(z²+1)`、`z/(z²+a²)²`，最后**取虚部**。

**必然是实数**：实积分的结果虚部必须消干净。

**作业 第 4 组（p78，3 题）**

2. ∫_{−∞}^{∞} x sin x/(x² + 1) dx
3. ∫_{−∞}^{∞} x sin(mx)/(x² + a²)² dx，m > 0，a > 0

## 自查清单（誊写前逐题过一遍）

1. **极点位置对不对**：类型 1 只数单位圆**内**；类型 2、3 只数**上半平面**（Im z > 0）。
2. **实轴上有奇点没有**：类型 2、3 要求实轴无奇点，否则公式不成立。
3. **分子次数够不够**：类型 2 要分母比分子高 **≥ 2** 次。
4. **结果必须是实数**：类型 1 应为正实数；类型 2、3 虚部必须为 0。
5. **2πi 有没有漏**：留数 ≠ 积分值。
6. **类型 3 取对部位**：cos → 实部，sin → 虚部。

## 三类模板题（导师带做用；答案已复核）

### 类型 1 模板 = 第 2 组第 1 题

 ∫₀^{2π} dθ/(2 + cos θ)

令 z = e^(iθ)：

 2 + cos θ = 2 + (z + z⁻¹)/2 = (z² + 4z + 1)/(2z)
 dθ = dz/(iz)

 ⟹ f(z) = 1 / [ (iz) · (z²+4z+1)/(2z) ] = 2 / [ i (z² + 4z + 1) ]

 z² + 4z + 1 = 0 ⟹ z = −2 ± √3。**单位圆内只有 z = −2 + √3 ≈ −0.268**。

 Res = lim_{z→z₀} (z−z₀)·2/[i(z−z₀)(z−z₁)] = 2/[i(z₀ − z₁)] = 2/[i(2√3)] = 1/(i√3) = −i/√3

 **∫₀^{2π} dθ/(2 + cos θ) = 2πi · (−i/√3) = 2π/√3 ≈ 3.6276**

独立复核：tan(θ/2) = t 代换得 ∫₀^∞ 2dt/(t²+3) = (2/√3)·(π/2) = **2π/√3** ✓

### 类型 2 模板 = 第 3 组第 1 题

 ∫_{−∞}^{∞} x² dx/((x²+1)(x²+4))

上半平面极点：z = i（一阶）、z = 2i（一阶）。（实轴无奇点；分母 4 次、分子 2 次，差 2 ✓）

 Res(i) = i²/[(i+i)(i²+4)] = −1/[2i·3] = −1/(6i) = i/6
 Res(2i) = (2i)²/[(2i)²+1)(2i+2i)] = −4/[(−3)(4i)] = 1/(3i) = −i/3

 Σ = i/6 − i/3 = −i/6

 **∫_{−∞}^{∞} = 2πi · (−i/6) = π/3 ≈ 1.0472**

### 类型 3 模板 = 第 4 组第 1 题

 ∫_{−∞}^{∞} cos(mx) dx/((x²+1)(x²+4))，m > 0

取 f(z) = 1/((z²+1)(z²+4))，上半平面极点 z = i、z = 2i。

 Res[ f(z)e^(imz), i ] = e^(−m)/[(i+i)(i²+4)] = e^(−m)/(6i) = −i e^(−m)/6
 Res[ f(z)e^(imz), 2i ] = e^(−2m)/[((2i)²+1)(2i+2i)] = e^(−2m)/[(−3)(4i)] = i e^(−2m)/12

 Σ = −i e^(−m)/6 + i e^(−2m)/12

 2πi Σ = 2πi · i( e^(−2m)/12 − e^(−m)/6 ) = 2π( e^(−m)/6 − e^(−2m)/12 ) = **π( 2e^(−m) − e^(−2m) )/6**

**∫_{−∞}^{∞} cos(mx)/((x²+1)(x²+4)) dx = π(2e^(−m) − e^(−2m))/6**

自检：m → 0 时 → π(2−1)/6 = **π/6**，与类型 2 那道在 m = 0 的退化情形一致 ✓

## 第 1 组（p28）完整过程与答案（2026-10-09 逐步工具复核）

> ⚠ **重要更正**：Q4 的答案是 **2πi sin 2**，**不是** 2π sin 2。
> 2026-10-08 本文件「复核记录」表里写的 `2π sin 2` **是错的**（已在下表更正）。
> 原因：这是**复围道积分**，被积函数 `e^(2z)` 不是实值函数在实轴上的限制，结果**允许是复数**。
> 「结果必须是实数」这条自检只适用于**第 2、3、4 组那类实积分**，不适用于第 1 组。

### Q1  ∮_C dz/((z²+1)²(z−1))，C: |z−1| = 2

**① 围道**：圆心 1、半径 2（过 z = −1 与 z = 3）。
**② 极点**：z = 1（一阶）、z = i（二阶）、z = −i（二阶），**三个都在 C 内**。

**③ 留数**

 z = 1（规则 I）：Res = 1/(1²+1)² = **1/4**

 z = i（二阶 → 规则 III，m = 2）：先把 (z−i)² 约掉

 g(z) = (z−i)²f(z) = 1/[(z+i)²(z−1)]
 g′(z) = −2(z+i)⁻³(z−1)⁻¹ − (z+i)⁻²(z−1)⁻²

 代入 z = i，先备三个数：**(2i)³ = 8i³ = −8i**、**(2i)² = 4i² = −4**、**i − 1 = −1 + i**

 第一项 = −2 / [ (−8i)(−1+i) ] = −2 / (8i − 8i²) = −2/(8 + 8i) = −1/(4 + 4i)
 　　　　= −(4 − 4i)/((4+4i)(4−4i)) = −(4 − 4i)/32 = **−1/8 + i/8**

 第二项 = −1 / [ (−4)(−1+i)² ]，而 (−1+i)² = 1 − 2i + i² = **−2i**
 　　　　= −1 / [ (−4)(−2i) ] = −1/(8i) = **i/8**

 **Res(i) = (−1/8 + i/8) + i/8 = −1/8 + i/4**

 z = −i（同法）：**Res(−i) = −1/8 − i/4**

**④ 收尾**

 Σ Res = 1/4 + (−1/8 + i/4) + (−1/8 − i/4) = **1/4 − 1/4 + 0·i = 0**

 **∮_C dz/((z²+1)²(z−1)) = 2πi × 0 = 0**

> 关键结构：**两个二阶极点的虚部互相抵消**（+i/4 与 −i/4），**实部各 −1/8、合起来 −1/4**，
> 正好把 z = 1 的 +1/4 抵光 ⟹ 0。

### Q2  ∮_{|z|=1} cos z / z³ dz

 z = 0 是**三阶**极点（分母三阶零点；分子 cos 0 = 1 ≠ 0）；分子不是多项式 ⟹ 规则 I/II/III 都不好用，
 用**洛朗展开**：

 cos z = 1 − z²/2! + z⁴/4! − …
 cos z/z³ = z⁻³ − ½ z⁻¹ + (1/24) z − …

 Res = **−1/2**（读 z⁻¹ 的系数）

 **∮ = 2πi × (−1/2) = −πi**

### Q3  ∮_{|z|=1} 1/(z sin z) dz

 z = 0 是**二阶**极点（分母 z·sin z 在 0 为二阶零点；分子 1 ≠ 0）。
 **快捷路**：f(−z) = 1/((−z)sin(−z)) = 1/(z sin z) = f(z)，**偶函数** ⟹ 洛朗展开只含偶次幂
 ⟹ **z⁻¹ 项不存在** ⟹ Res = **0** ⟹ **∮ = 0**
 （硬用规则 III 亦得 0：Res = lim_{z→0} d/dz[z/sin z] = 0。）

### Q4  ∮_{|z|=2} e^(2z)/(z²+1) dz

 z² + 1 = (z−i)(z+i) ⟹ 极点 **z = ±i，都一阶**，都在 |z| = 2 内。
 规则 II（P(z) = e^(2z)、Q(z) = z² + 1、Q′(z) = 2z、P(±i) = e^(±2i) ≠ 0）：

 Res(i) = e^(2i)/(2i) = **−i e^(2i)/2**
 Res(−i) = e^(−2i)/(−2i) = **i e^(−2i)/2**

 Σ Res = −i e^(2i)/2 + i e^(−2i)/2 = −i( e^(2i) − e^(−2i) )/2
 　　　= −i( 2i sin 2 )/2 = **sin 2**（实数！）

 **∮ = 2πi × sin 2 = 2πi sin 2 ≈ 5.7133i**

> ⚠ 这一题结果**是纯虚数**，这是**正常的** —— 它是复围道积分，不是实积分。
> 「实积分的结果必须是实数」那条自检**不适用于第 1 组**。

## 第 4 组（p78）完整过程与答案（2026-10-09 工具复核）

### 4(1)  ∫_{−∞}^{∞} cos(mx)/((x²+1)(x²+4)) dx，m > 0

 f(z) = 1/((z²+1)(z²+4))，上半平面极点 z = i、z = 2i（都一阶）。
 规则 II，Q(z) = (z²+1)(z²+4) = z⁴+5z²+4 ⟹ **Q′(z) = 4z³ + 10z**

 Res(i) = e^(−m)/(4i³+10i) = e^(−m)/(−4i+10i) = e^(−m)/(6i) = **−i e^(−m)/6**
 Res(2i) = e^(−2m)/(4(2i)³+10(2i)) = e^(−2m)/(−32i+20i) = e^(−2m)/(−12i) = **i e^(−2m)/12**

 Σ Res = i( e^(−2m)/12 − e^(−m)/6 )
 2πi Σ = 2π( e^(−m)/6 − e^(−2m)/12 )

 **∫ = π(2e^(−m) − e^(−2m))/6**（已取实部；结果本身是实数）

 自检：m → 0 时 → π/6，与第 3 组第 1 题（m = 0 退化）一致 ✓

### 4(2)  ∫_{−∞}^{∞} x sin x/(x²+1) dx

 A(z) = z e^(iz)、B(z) = z²+1 ⟹ B′(z) = 2z；上半平面极点 **z = i**（一阶），A(i) = i e^(−1) ≠ 0。
 规则 II：Res = i e^(−1)/(2i) = **1/(2e)** = e^(−1)/2

 2πi · Res = **π i/e**

 取**虚部**（原题是 sin）：**∫ = π/e ≈ 1.1557**

 ⚠ **易错点**：`e^(imz)` 里的 z₀ **直接代入**（z₀ = i ⟹ e^(i·i) = e^(−1)），**不要写 e^(2imz₀)**。

### 4(3)  ∫_{−∞}^{∞} x sin(mx)/(x²+a²)² dx，m > 0，a > 0

 A(z) = z e^(imz)、B(z) = (z²+a²)²；上半平面极点 **z = ai**（**二阶**）。
 二阶 ⟹ **规则 III**，m = 2，导 1 次（1/1! = 1）。先把 (z−ai)² 约掉：

 g(z) = (z−ai)² f(z) = z e^(imz)/(z+ai)²
 g′(z) = **im·z e^(imz)/(z+ai)²** + e^(imz) · d/dz[ z (z+ai)⁻² ]

 第二项的导数（乘积法则）：d/dz[ z (z+ai)⁻² ] = (z+ai)⁻² − 2z(z+ai)⁻³ = **(ai − z)/(z+ai)³**

 **代入 z = ai**（(2ai)² = −4a²，(2ai)³ = −8ia³）：

 第一项 = im·(ai)/(2ai)²·e^(−am) = im·ai/(−4a²)·e^(−am) = (i²m a)/(−4a²)·e^(−am) = **m e^(−am)/(4a)**
 第二项 = e^(−am)·(ai − ai)/(2ai)³ = **0**

 **Res(ai) = m e^(−am)/(4a)**

 I′ = 2πi · Res = **π m e^(−am)/(2a) · i**
 取**虚部** ⟹ **∫ = π m e^(−am)/(2a)**

 数值自检（a = 2、m = 3）：π·3·e^(−6)/4 = **0.00584042**（与直接数值积分一致）
