## C05-01 分词、嵌入与序列

目标：解释文本如何变成 token ID、向量与批量序列。

教材定位：[Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1)：Tokenizer 相关章节；[动手学深度学习，第二版](https://zh.d2l.ai/)：8.2 文本预处理。

前置参考：C04-10。已有能力证据可以替代重复学习，不机械按完成次数拦截。

动手任务：对中英文短句观察分词，做一个小词表嵌入查表，并记录形状与特殊 token。

验收依据：

- 不把字数等同 token 数。
- 嵌入形状可解释。
- 理解截断与上下文限制。

变式核验：对同一句话换分词器，说明长度和词表 ID 为什么不可直接互换。

自评关联：AD04。目标标识：`ai-tech.c05-01`。

## C05-02 自注意力与因果遮罩

目标：用小矩阵解释查询、键、值及可见范围。

教材定位：[动手学深度学习，第二版](https://zh.d2l.ai/)：10.3 注意力评分；10.6 自注意力。

前置参考：C05-01。已有能力证据可以替代重复学习，不机械按完成次数拦截。

动手任务：对三个 token 的小矩阵计算注意力权重，加入因果遮罩后比较。

验收依据：

- 维度与权重归一化可核对。
- 解释为何未来 token 必须被遮挡。
- 能追踪一次值向量加权。

变式核验：改变一个 token 的键或遮罩位置，预测哪些输出可能变化。

自评关联：LA03, AD04。目标标识：`ai-tech.c05-02`。

## C05-03 多头、位置与 Transformer 块

目标：解释注意力之外的主要组件及其形状关系。

教材定位：[动手学深度学习，第二版](https://zh.d2l.ai/)：10.5—10.7；[Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1)：Transformer 模型概览。

前置参考：C05-02。已有能力证据可以替代重复学习，不机械按完成次数拦截。

动手任务：画出一个简化 Transformer 块，标出位置表示、残差、归一化、前馈层与多头拼接。

验收依据：

- 能解释每块解决的问题。
- 维度与残差相容。
- 区分编码器、解码器的可见信息。

变式核验：去掉位置信息或因果遮罩，解释不同任务下的后果。

## C05-04 预训练目标、生成与解码

目标：区分训练时目标和逐步生成过程。

## C05-06 SFT、参数高效微调与 RAG 的边界

目标：判断训练调整行为、检索提供资料与提示约束的不同作用。

教材定位：[Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1)：微调与数据准备相关章节；[动手学深度学习，第二版](https://zh.d2l.ai/)：13.2 迁移学习。

## C05-07 大模型任务评估与失败分析

目标：把主观感觉转成固定任务集、规则和人工核验。

教材定位：[Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1)：任务与模型使用主题；[RAG Evaluation](https://huggingface.co/learn/cookbook/en/rag_evaluation)：检索与生成分开评估的思路。

前置参考：C05-06。已有能力证据可以替代重复学习，不机械按完成次数拦截。

动手任务：设计一组正常、边界与无资料答案的问题，比较两个提示或配置，检查格式与事实分别如何判。

验收依据：

- 测试问题与修改记录可复用。
- 不只用模型自评充当正确性证据。
- 说明输出随机性和样例规模限制。

变式核验：加入一个原提示容易误答的新问题，解释如何防止只针对原测试集改提示。

## C05-08 语言模型原理项目

目标：将结构、目标和评估串成可检查的小实验。

教材定位：[Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1)：按选定模型和任务回查；[动手学深度学习，第二版](https://zh.d2l.ai/)：10.7 Transformer。

- 不要求训练实用大模型。

变式核验：更换序列规律或文档条件，指出需要重新训练还是仅改变检索 / 输入。
