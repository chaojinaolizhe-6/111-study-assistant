# AI 技术学习课程包：交给现有 DeepSeek 学习助手

这套课程根据用户已提供的自评定制：先补编程与开发实作，再做数据项目、机器学习、深度学习与大模型；应用和量化为支线，数学统计按需补。共 9 门课程、74 个学习单元，每个单元都设计了来源定位、目标、任务、验收和变式。一个单元不等于一天。

## 现在如何开始

在现有 DSH / Harness 学习助手中，复制发送 [交接给DeepSeek.txt](交接给DeepSeek.txt) 的内容。它会从 C00-01 开始，之后按真实进度续学。本包无需安装新 skill；原助手必须实际拥有读取本目录的权限，读不到时应明确报告。

本次已准备可交接课程包，未代 DeepSeek 授课、未操作原助手界面、未写入其能力账本或修改原 skill。原助手已有 12-AI学习，偏向使用方法与认知讨论；本包技术标识 AI-TECH，交接时保留区分。

## 主材料

Python 官方中文教程；Wes McKinney 的 Python for Data Analysis 第三版；Inria / scikit-learn MOOC；ISLP 及作者配套课程；动手学深度学习第二版与课程；PyTorch 官方教程；Hugging Face LLM Course。统计用 OpenIntro，数学用 MML 按需查；应用用 DeepSeek 官方接口说明及检索评估材料；时间序列支线用 FPP3。

来源链接已按本次核验范围登记，不声称全书通读或视频全部看过；没有把教材正文、付费课程或受限教师答案复制进包。英文材料由 DeepSeek 用中文解释必要内容。旧教材与新 API 差异在实际执行时核查，不强制安装某套过时依赖。

## 尚未固定的条件

每周投入时间、近期具体项目和电脑详细配置尚未提供，所以不排固定总周数。首项目采用原创合成表格；后续按兴趣换任务。每次只确认影响当前执行的条件，不让完整访谈阻止开课。允许资料和 AI，记录帮助、理解、验证与修改情况，不用总分判断起点。
