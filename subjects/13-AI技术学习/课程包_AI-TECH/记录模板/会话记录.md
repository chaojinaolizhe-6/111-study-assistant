# 会话记录模板（空白，不是学习事实）

- 实际日期、时区：
- 单元 / 目标 ID：
- 本次实际目标：
- 实际读取的教材或资料：
- 学习者提交的代码、推导或作品位置：
- 学习者亲自完成的关键动作：
- 查阅资料 / AI 生成 / 提示 / 原题曝光情况：
- 实际运行、手算或反例核对：
- 换条件后的表现：
- 已会且可跳过的动作：
- 仍需补或待验证的动作：
- 当前有效步骤、失败尝试和卡点：
- 下次第一个动作：
- 原助手真实记录的事件 / 产物引用：
- 保存及收尾是否成功：

正式能力状态沿用原助手账本。不要因为模板存在就创建虚构事件；不知道的帮助史保留未知，不填成无帮助。
