## 0. 一句话主线

> **真实球面不能完善成像 → 把光束限制在光轴附近（傍轴）→ 严格关系式里的 sin²(φ/2) 项被消掉 → 得到只含 s, s′, r, n, n′ 的物像公式 → 用它推出焦距、放大率、透镜公式。**

**课件自己的说法（p14 页内标题层级）**：
`Exact Spherical Refraction → Nonlinearity → Non-stigmatic Point Objects Fail to Form Perfect Images → Paraxial Linearization → Gaussian Optics`

## 1. 「近似」在课件里出现三次 —— 分清它们（★ 上次没学明白的根因）

| # | 名称 | 位置 | 内容 | 作用 |
|---|---|---|---|---|
| **A** | **严格成像条件**（不是近似） | **p11–p13** | 令关系式**两项同时为 0**，解出 `s′/s = ±n/n′` 的两组**共轭点** | 只对**两对特殊点**成立，不是通用公式 |
| **B** | **★ 傍轴近似 Paraxial Approximation** | **p14（两张）、p15** | 小视场＋小孔径；`sin θ ≈ θ`、`cos θ ≈ 1`、`tan θ ≈ θ`；条件写作 `h² ≪ s², s′², r²` 与 `u², u′², φ² ≪ 1` | **唯一的主近似**——所有后续公式都建立在它之上 |
| **C** | **薄透镜近似 Thin Lens Approximation** | **p22–p23** | `d → 0`，两顶点与光心 O 重合；`−s₂ ≈ s₁′`、`s ≈ s₁`、`s′ ≈ s₂′` | 把**两个球面**合成**一个薄透镜**（在 B 之上再叠加） |

> `[教学归纳]` **B 是「前提」，C 是「简化模型」，A 是「例外情形」。** 做题时看到 `n/s + n′/s′ = (n′−n)/r` 或 `1/s + 1/s′ = 1/f`，就已经在用 B 了。

### 第 1 部分：§1.5-1 单球面折射的精确关系（p5–p13）

| 页 | 内容 |
|---|---|
| **p5** | 球面折射比平面折射复杂在哪：平面只依赖折射率（`n sin i = n′ sin i′`）；**球面还依赖曲率半径 r**。定义 C（曲率中心）、A（顶点）、光轴 |
| **p6** | **共轴球面系统定义**：所有球面的曲率中心在同一直线上（光轴）。**三条性质**：① 每个球面有曲率中心与半径；② **除特殊点外，球面不成完善像**（红框）；③ 参与成像的**边缘光线只限于光轴附近**（paraxial approximation）——页内中文标注「**参与成像的光线只能是光轴附近的细光束（傍轴光线）**」 |
| **p7** | **基本关系**：Snell `n sin i = n′ sin i′`；角关系 `i − u = i′ + u′ = φ`；**正弦定理** `p/sin φ = (s+r)/sin i = r/sin u`、`p′/sin φ = (s′−r)/sin i′ = r/sin u′`；**余弦定理** `p² = (s+r)² + r² − 2r(s+r)cos φ`、`p′² = (s′−r)² + r² + 2r(s′−r)cos φ` |
| **p8** | 用余弦定理配方：**p² = s² + 4r(s+r)sin²(φ/2)**、**p′² = s′² − 4r(s′−r)sin²(φ/2)**（两个红框） |
| **p9** | 正弦定理两式相除：`p/p′ = (s+r)n / (s′−r)n′`；再平方：`p²/[(s+r)n]² = p′²/[(s′−r)n′]²` |
| **p10** | **代入化简得主关系式**：<br>`s²/[(s+r)n]² − s′²/[(s′−r)n′]² = −4r sin²(φ/2)·[ 1/((s′−r)n′²) + 1/((s+r)n²) ]`<br>★ 页面提示（红框）：**右边含 sin²(φ/2) ⟹ 像距 s′ 依赖角度 φ ⟹ 球面不能完善成像** |
| **p11** | **严格成像条件**：要 s′ 与 φ 无关，必须**两式同时成立**：`s²/[(s+r)n]² − s′²/[(s′−r)n′]² = 0` 且 `1/((s′−r)n′²) + 1/((s+r)n²) = 0`；由此得 `(s′−r)n′² = −(s+r)n²` 与 **`s′/s = ±n/n′`** |
| **p12** | 分两种情况解：**＋情况**：`s′ = (n/n′)s`、`s = ((n′−n)/n)r`、`s′ = ((n′−n)/n′)r`；**−情况**：`s′ = −(n/n′)s`、`s = −((n′+n)/n)r`、`s′ = ((n′+n)/n′)r` |
| **p13** | **共轭点的物理位置与意义**（★ 这就是 p2 结构图里的 Cardinal Points）：<br>正情况：`s = ρ − r`、`s′ = r − ρ′`，其中 `ρ = (n′/n)r`、`ρ′ = (n/n′)r`<br>负情况：`s = −(ρ + r)`、`s′ = ρ′ + r`<br>★ **Conjugate Points**：两对特殊共轭点，放在这两点时**球面严格成像、无像差** |

### 第 2 部分：§1.5-2 傍轴近似与物像公式（p14–p16）★ 本课核心

| 页 | 内容 |
|---|---|
| **p14a** | **从折射定律到近似成像——傍轴近似**（三栏结构）：<br>**1. 问题**：严格球面折射 `n sin i = n′ sin i′` 是**非线性**的，不同高度光线入射角不同 ⟹ 非定点成像，一束光不汇聚于一点；轴上→球差，轴外→彗差、像散等<br>**2. 桥梁：傍轴近似**：限制在光轴附近 —— **小视场**（物高 y 小）＋**小孔径**（光束窄、光线与光轴夹角 u 小）；近似 `sin θ ≈ θ`、`cos θ ≈ 1`、`tan θ ≈ θ` ⟹ **非线性关系线性化到一阶**；★ **轴上点只需小孔径；轴外点需小视场＋小孔径两者**<br>**3. 解法：高斯光学**：近轴细光束 → 近似点对点共轭成像；建立统一的理想成像模型（物像距、焦点焦距、放大率）；超出傍轴范围 → 高阶项显著 → 出现像差（球差、彗差、像散、畸变） |
| **p14b** | **近似成像的要求——傍轴条件**：回到 p10 的主关系式 ⟹ **光束限制在傍轴区域**；<br>**长度写法：`h² ≪ s², s′², r²`**；**角度写法：`u², u′², φ² ≪ 1`**；<br>此时 `sin²(φ/2) ≈ (φ/2)² → 0` ⟹ `s²/[(s+r)n]² = s′²/[(s′−r)n′]²` ⟹ **物像公式 `n/s + n′/s′ = (n′−n)/r`** |
| **p15** | **单球面折射的轴上物像距公式**：由 `s²/[(s+r)n]² = s′²/[(s′−r)n′]²` 开方整理得<br>★ **`n/s + n′/s′ = (n′−n)/r`**（红框）<br>**必须区分**：折射定律 ≠ 球面成像关系（页内黄底标注） |

### 第 5 部分：§1.6 透镜（p22–p29）

| 页 | 内容 |
|---|---|
| **p22** | **§1.6 透镜与成像规律**：透镜 ＝ **两个折射球面**组成的光学系统；**薄透镜近似 `d → 0`**，两顶点与光心 O 重合；此时 `−s₂ ≈ s₁′`、`s ≈ s₁`、`s′ ≈ s₂′`。**单球面公式 `f/s + f′/s′ = 1`**。符号约定：物在 A 左（实物）`s > 0`、右（虚物）`s < 0`；像在 A 右（实像）`s′ > 0`、左（虚像）`s′ < 0` |
| **p23** | **薄透镜方程的推导**：两个球面各写 `f₁/s₁ + f₁′/s₁′ = 1`、`f₂/s₂ + f₂′/s₂′ = 1`；用 `−s₂ = s₁′`、`s = s₁`、`s′ = s₂′` **消去中间量 s₂、s₁′** ⟹ **`f₁f₂/s + f₁′f₂′/s′ = f₁′ + f₂′`**；**薄透镜焦距公式**：`s′ → ∞` 时 `s = f`、`s → ∞` 时 `s′ = f′` ⟹ **`f = f₁f₂/(f₁′+f₂′)`、`f′ = f₁′f₂′/(f₁′+f₂′)`**；**薄透镜物像距公式 `f/s + f′/s′ = 1`** |
| **p24** | **磨镜者公式（Lensmaker's Formula）**：单球面焦距 `f₁ = n r₁/(n_L−n)`、`f₁′ = n_L r₁/(n_L−n)`、`f₂ = n_L r₂/(n′−n_L)`、`f₂′ = n′ r₂/(n′−n_L)`；代入得 `f = n / [ (n_L−n)/r₁ + (n′−n_L)/r₂ ]`、`f′ = n′ / [ … ]`；★ **空气中 `n = n′ ≈ 1`：`f = f′ = 1 / [ (n_L−1)(1/r₁ − 1/r₂) ]`** |
| **p25** | **凸透镜与凹透镜**：**凸（会聚）f, f′ > 0**；**凹（发散）f, f′ < 0**；`n_L > 1` 时由磨镜者公式，凸透镜 `1/r₁ > 1/r₂`、凹透镜 `1/r₁ < 1/r₂`；**五种凸透镜**（双凸/平凸/正弯月/负弯月/平凸）与**五种凹透镜**的 r₁、r₂ 符号表 |
| **p26** | **薄透镜方程的高斯形式**：`f/s + f′/s′ = 1`，`f = f′` 时 ⟹ ★ **`1/s + 1/s′ = 1/f`**；配 **Gaussian Lens Equation Diagram**：f = a > 0 与 f = −a < 0 两种情形下，s–s′ 平面上 Virtual／Real 四区域的分布（图要会读） |
| **p27** | **牛顿公式**：从焦点 F、F′ 量起，物距 x、像距 x′；**符号约定**：Q 在 F 左 `x > 0`、右 `x < 0`；Q′ 在 F′ 右 `x′ > 0`、左 `x′ < 0`；`s = x + f`、`s′ = x′ + f′` 代入 `f/s + f′/s′ = 1` ⟹ ★ **`x x′ = f f′`** |
| **p28** | **薄透镜的横向放大率**：`V = y₂/y₁ = (y₁′/y₁)(y₂/y₁′) = V₁V₂`；单球面 `V₁ = −s₁′n/(s₁n_L)`、`V₂ = −s₂′n_L/(s₂n′)` ⟹ ★ **`V = −s′n/(sn′)`**；再用 `f′/f = n′/n` ⟹ **`V = −s′f/(sf′)`**；用 `xx′ = ff′` ⟹ ★ **`V = −f/x = −x′/f′`** |
| **p29** | **密接薄透镜组合**：两透镜贴合 `−s₂ ≡ s₁′` ⟹ `1/s₁ + 1/s₂′ = 1/f₁ + 1/f₂`；令 `s₂′ → ∞, s₁ = f` ⟹ ★ **`1/f = 1/f₁ + 1/f₂`**；**光焦度 `P = 1/f`**，单位 **屈光度 diopter (D)**；★ **`P = P₁ + P₂`** |
