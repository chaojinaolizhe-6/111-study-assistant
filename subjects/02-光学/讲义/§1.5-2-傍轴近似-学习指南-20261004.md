## 0. 这一节到底在解决什么（先记住这句话）

**球面本身不能完善成像**；把它**限制在光轴附近的细光束**（傍轴），才能得到一个**只依赖 s、r、n、n′ 的像距公式**。

所以这一节的主线只有一个：**为什么必须傍轴 → 傍轴下物像公式长什么样 → 怎么用它算题**。

## 3. 必须留下的五个式子（附"哪来的／干什么用"）

1. **严格关系**（p10，只作理解，不用背）
   `s²/((s+r)n)² − s′²/((s′−r)n′)² = −4r·sin²(φ/2)·[ 1/((s′−r)n′²) + 1/((s+r)n²) ]`
   → 右边不为 0 ⟹ 像距随光线角度变 ⟹ **不能完善成像**
2. **傍轴条件**（p14/p15）
   长度写法 `h² << s², s′², r²`；角度写法 `u², u′², φ² << 1`；小角近似 `sin θ ≈ θ`、`cos θ ≈ 1`、`tan θ ≈ θ`
3. **近轴物像公式**（p15/p16）
   `n/s + n′/s′ = (n′−n)/r` ← **这一节的核心**
4. **焦距**（p17；由上式令 `s → ∞` 与 `s′ → ∞`）
   `f′ = n′r/(n′−n)`，`f = nr/(n′−n)`，且 **`f′/n′ = f/n`**（两焦距之比 = 两侧折射率之比）
5. **横向放大率**（p21）
   `V = −s′n/(sn′)`（折射）；`V = −s′/s`（反射）；`V > 0` 正立、`V < 0` 倒立
   （反射特例：`1/s + 1/s′ = −2/r`，`f = f′ = −r/2`，p18）

## 4. 三个最容易踩的坑

1. **符号约定有两套，别混用。**
   课件用「**图上距离取正**」：`n/s + n′/s′ = (n′−n)/r`（s、s′、r 都按图上方向量）；
   教材里另有一套**符号化写法** `n′/s′ − n/s = (n′−n)/r`（此时实物 `s < 0`）。
   → **在一道题里只用一套**；你现在按课件那套最省事。
   课件自带的符号说明：`y`（或 `y′`）在光轴上方为正、下方为负（p21）；反射里 `Q′` 在顶点左侧（实像）`s′ > 0`、右侧（虚像）`s′ < 0`（p18）。
2. **"傍轴"不是偷懒的近似**，而是**唯一能把"像距随光线角度变"那一项消掉**的办法——消掉它，才有"一个物点对应一个像点"。
3. **"球面不成像" ≠ "球面不能成像"**：严格意义下除齐明点外不成完善像；**傍轴下近似成点像**。这两句不矛盾，考试常在这里出判断。

## 5.1 补充：「傍轴」本身怎么考（2026-10-08 加）

> 起因：学习者问「这和傍轴近似有什么关系吗」——**问得对**。每当你写出 `n/s + n′/s′ = …`，
> 就已经在用傍轴近似了：**那个式子是傍轴的产物，不是普遍事实**。

真正在考"傍轴"的题型有四类：

| 类型 | 典型问法 |
|---|---|
| **① 数量级判断** | 给定 `h`（光线在球面上的高度）、`r`、`s`，判断这束光算不算傍轴：看 `h² << r²`、`h² << s²` 是否成立 |
| **② 误差估计** | 用 `sin θ ≈ θ`、`cos θ ≈ 1` 的误差说明"傍轴范围有多宽" |
| **③ 反问题** | 要求成像误差不超过某百分比，求允许的最大 `φ`（或最大 `h`） |
| **④ 概念辨析** | "球面不能成像"与"球面能成像"为什么不矛盾？（齐明点 + 傍轴近似） |

**小角近似的误差表**（`φ = h/r`）：

| `h/r` | `φ` | `sin φ ≈ φ` 的相对误差 | `cos φ ≈ 1` 的误差 |
|---|---|---|---|
| 0.05 | 0.05 rad ≈ 2.9° | 0.04% | 0.12% |
| 0.10 | 0.10 rad ≈ 5.7° | 0.17% | 0.50% |
| 0.30 | 0.30 rad ≈ 17.2° | **1.5%** | **4.5%** |

> 读法：`h/r ≲ 0.1` 时误差千分之几，傍轴很好用；到 `h/r ≈ 0.3`（约 17°）误差已到百分之几，像差开始看得出来。
> **"傍轴"不是开关，而是"误差可接受的范围"。**
