## 抄写时的三个提醒（不用抄，是给你看的）

1. **两份「ста́рый」**：第 1 组「旧」和第 2 组「老」都是 `ста́рый` —— 一个词两个意思，**照抄两遍**即可。
2. **重音**：`молодо́й`、`большо́й`、`родно́й` 的重音在**词尾**（-о́й），和 `но́вый`（重音在词干）不同 —— 抄的时候把重音标上，以后变格靠它判断。
3. **同一页的词尾提示可以顺手记**：
   - 硬词干：`но́вый / ста́рый / краси́вый / интере́сный / у́мный / глу́пый / солёный / вку́сный / холо́дный / дли́нный / тру́дный / иностра́нный / некраси́вый` → **-ый**
   - к 结尾（写 и 不写 ы）：`высо́кий / ни́зкий / ма́ленький / лёгкий / сла́дкий / го́рький / ску́чный(ч)` → 复数是 **-ие**
   - ж/ш/ч/щ 结尾：`горя́чий(ч)` → 中性 **-ее**、复数 **-ие**
   - 重音在词尾：`молодо́й / большо́й / родно́й` → **-о́й**

## 抄完的自检（三个词，说四种形式）

1. `но́вый` → но́вая / но́вое / но́вые？
2. `сла́дкий` → 复数是什么？（提示：к 后面写 и）
3. `большо́й` → 阴性是什么？（提示：重音在词尾那一族）
