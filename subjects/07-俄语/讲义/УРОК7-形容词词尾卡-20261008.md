## 1. 一条总规律

形容词**跟着名词变**：名词是 阳／阴／中／复数，形容词就换成对应的词尾。
语序固定是 **形容词 + 名词**：но́вый телефо́н（不是 *телефо́н но́вый）。
判断顺序：**① 先定名词的性/数 → ② 再选词尾**。

## 2. 词尾表（核心，背这一张）

| 词干类型 | 阳性 он како́й? | 阴性 она́ кака́я? | 中性 оно́ како́е? | 复数 они́ каки́е? | 例（课件词） |
|---|---|---|---|---|---|
| 硬词干（末尾硬辅音，重音**不在**词尾） | -ый | -ая | -ое | -ые | кори́чневый → кори́чневая, кори́чневое, кори́чневые（p39 模型） |
| 词干末尾 **г／к／х** | -ий | -ая | -ое | -ие | лёгкий → лёгкая, лёгкое, лёгкие |
| 词干末尾 **ж／ш／ч／щ** | -ий | -ая | **-ее** | -ие | све́жий → све́жая, све́жее, све́жие（p42） |
| 软词干 **-ний** | -ий | **-яя** | **-ее** | -ие | после́дний → после́дняя, после́днее, после́дние（p40） |
| **重音在词尾** | **-о́й** | **-а́я** | **-о́е** | **-ы́е** | дорого́й → дорога́я, дорого́е, дороги́е（p41） |

`[教学归纳]` 三句话：

1. 多数形容词走 **-ый / -ая / -ое / -ые**。
2. 词干末尾是 **г, к, х, ж, ш, ч, щ**，或软辅音 **-ний** → 阳性写 **-ий**；**ж/ш/ч/щ** 与软词干的中性、复数写 **-ее / -ие**。
3. **重音落在词尾**时，四个形式是 **-о́й / -а́я / -о́е / -ы́е**（听起来和写法都跟第一行不同，是一整族）。

⚠ **拼写规则（课件 p41–p42）**：**г, к, х, ж, ш, ч, щ 后面永远写 и，不写 ы** → 是 ру́сский、хоро́ший，不是 *ру́сскый、*хоро́шый。（课件 p41／p42 的标注写成「-ий\-о́й」：这两类词干上**重音落到词尾**时就换成第 5 行的 **-о́й 族**——большо́й、чужо́й、дорого́й。）

## 4. 练习 3（写）怎么做

课件 p39 题面：Соста́вьте возмо́жные словосочета́ния.（组成可行的搭配）
模型：кори́чневый шарф / кори́чневая су́мка / кори́чневое пальто́ / кори́чневые боти́нки。

`[教学归纳]` 做法：**每个颜色写 4 个搭配 ＝ 阳 1 ＋ 阴 1 ＋ 中 1 ＋ 复数 1**，9 个颜色共 **36 个**。

- 名词可沿用模型的 шарф / су́мка / пальто́ / боти́нки，也可换成你会写的词（性和数对得上就行）。
- 写完三条自检：① 名词的性/数判对了吗？② 词尾跟它一致吗？③ 有没有哪个颜色的重音落在词尾上、该走第 5 行那一族？

## 5. 练习 7（写）怎么做

课件 p44 题面：Отве́тьте на вопро́сы（для отве́та испо́льзуйте слова́ спра́ва）。（用**右边**给的两个词回答）
模型：– Како́й э́то дом? – Э́то большо́й но́вый дом.

`[教学归纳]` 两条要点：

1. **问句里的 Какой / Какая / Какое / Какие 就是提示**——它已经告诉你名词的性/数，形容词直接选同族词尾：
   Какой → -ый/-ий/-о́й｜Какая → -ая/-яя/-а́я｜Какое → -ое/-ее/-о́е｜Какие → -ые/-ие/-ы́е。
2. 照模型，每个回答用**右边给出的两个**形容词：Это ＋ 形容词 ＋ 形容词 ＋ 名词。同一栏的词不够两两不重复时**可以重复用**（一栏里 5 个名词、4–5 个形容词，本来就不够 10 个）。

四个坑：

- **метро́** 是不变格外来词、中性 → 问句写的是 Како́е э́то метро́?，跟着问句走。
- **кни́ги / друзья́ / журна́лы / откры́тки / лю́ди** 都是**复数** → Какие ＋ -ые/-ие。（лю́ди 是 челове́к 的复数，又是不规则形式。）
- **де́вушка / библиоте́ка / маши́на / статья́ / страна́** 阴性 → Какая ＋ -ая/-яя。
- 形容词要**挑得合适**：阳性栏只给了 красивый / новый / русский / большой / интересный 五个，别把别栏的词搬过来。
