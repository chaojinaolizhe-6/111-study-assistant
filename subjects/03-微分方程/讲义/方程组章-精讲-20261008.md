## 一、为什么会有"方程组"这一章

现实里的问题几乎都是**多个未知函数互相耦合**的（多个质点、多个回路、多个物种…），写出来就是

`y₁′ = f₁(x, y₁, …, yₙ)`，…，`yₙ′ = fₙ(x, y₁, …, yₙ)`，记成向量形式 **`Y′ = F(x, Y)`**。

两个关键认识（L13 的动机）：

1. **高阶方程可以降成方程组**：令 `y₁ = y, y₂ = y′, …, yₙ = y⁽ⁿ⁻¹⁾`，则 n 阶方程 `y⁽ⁿ⁾ = f(x, y, y′, …, y⁽ⁿ⁻¹⁾)` 等价于
   `y₁′ = y₂, y₂′ = y₃, …, yₙ′ = f(x, y₁, …, yₙ)`。
   → **所以"方程组"不是新东西，它是把高阶方程统一处理的语言**。（L13 p26–29 例 6/7；作业 H 就是把 `y‴ = y″ − x²(y′)²` 化过去，注意那是个**非线性**系统。）
2. **解有几何意义**：把 `(y₁, …, yₙ)` 看成 n 维空间的点，解 `Y(x)` 就是一条**曲线**（相空间里的轨迹）。初值 `Y(x₀) = Y₀` 决定从哪个点出发。

> 和你们已经学过的内容对接：L9–L11 的"n 阶常系数线性方程"其实就是**一个特殊的方程组**（取 `A` 为伴随矩阵）。两边特征方程是**同一个**：`det(A − λE) = 0` ↔ `p(λ) = 0`。所以这一章不是推翻前面，而是**把前面装进矩阵的语言**。

## 二、线性系统的解结构（L13 §2）

线性系统：**`Y′ = A(x)Y + F(x)`**；`F ≡ 0` 时叫**齐次**。

### 定理 2.1（存在唯一性）与一个容易忽略的推论

`a_kj(x)`、`f_k(x)` 在 `[a,b]` 上连续 ⟹ 对任意 `x₀ ∈ [a,b]`、任意初值 `Y₀`，初值问题在 `[a,b]` 上有**唯一解**。

> **Remark（很重要）**：**线性系统没有奇解**。
> 一阶非线性方程（比如 `y′ = 2√y`）会有"通解之外多出来的奇解"，而线性系统**不会**——你在 L2–L6 见过的"奇解"麻烦，在方程组这一章不会再出现。这条解释了为什么线性系统"好办"。

### 定理 2.2（通解结构）：`Y = Z(x) + Ỹ(x)`

- `Z(x)`：对应**齐次**系统 `Y′ = AY` 的通解；
- `Ỹ(x)`：非齐次的**任意一个**特解。

**为什么**（一句话证明）：若 `Y₁, Y₂` 都是非齐次解，则 `(Y₁ − Y₂)′ = A(Y₁ − Y₂)` ⟹ 差是齐次解；反之任何"齐次解 + 特解"都满足方程。
→ 这和二阶线性方程 `y = y_h + y_p` 是**同一个结构**，一字不差。

### Wronskian 与基本解组（L13 p20–p23）

n 个向量解 `Y₁, …, Yₙ` 排成矩阵取行列式，就是 **Wronskian `W(Y₁,…,Yₙ)(x)`**：

- **定理 2.3**：`Y₁, …, Yₙ` 线性无关 ⟺ **存在**某点 `x₀` 使 `W(x₀) ≠ 0`。
- **定义（基本解组 FSS）**：齐次系统的 n 个**线性无关**解。
- **定理 2.4**：解的线性组合仍是解（齐次系统是线性的）。

**用法**：齐次通解 = `c₁Y₁ + … + cₙYₙ`（`Y₁…Yₙ` 是基本解组）。

> 直觉：单个函数时"两个函数线性无关"看它们的 Wronskian；向量函数一模一样，只是行列式从 2×2 变成 n×n。**Wronskian 就是"这组解有没有真正撑满 n 维"的体检表。**

## 三、常系数齐次系统的解法主线（`Y′ = AY`）

### 3.1 `Y = Ve^(λx)` 是怎么想到的

单个方程时我们试 `y = e^(λx)`（L9 的老套路）。这里同样试：

`Y = Ve^(λx)` 代入 `Y′ = AY` ⟹ `λVe^(λx) = AVe^(λx)` ⟹ **`AV = λV`**。

因为 `e^(λx) ≠ 0`，所以：

> **`Y = Ve^(λx)` 是解 ⟺ `λ` 是 `A` 的特征值、`V` 是对应特征向量**（且 `V ≠ 0`）。

### 3.2 特征值怎么求

`AV = λV ⟺ (A − λE)V = 0`。这是关于 `V` 的**齐次代数方程组**：

- 只有零解 `V = 0` → 不行（我们要非零特征向量）；
- 有非零解 ⟺ **`det(A − λE) = 0`** ← **特征方程**。

展开后 `det(A − λE) = (λ − λ₁)^m₁ (λ − λ₂)^m₂ … (λ − λ_k)^m_k`，`m₁ + … + m_k = n`。

- **`m_j` = 代数重数**（这个根在特征多项式里出现几次）；
- **`g_j` = 几何重数** = 对应 `λ_j` 的**线性无关特征向量个数** = `n − rank(A − λ_jE)`；
- 永远 **`1 ≤ g_j ≤ m_j`**。

> `g = n − rank` 不是背的：`(A − λE)V = 0` 的解空间就是这个矩阵的**零空间**，维数 = `n − rank`（秩–零化度定理）。

### 3.3 三种情形与各自的做法（L14–16）

| 情形 | 条件 | 基本解怎么写 |
|---|---|---|
| **Case 1** 相异实根 | `λ₁, …, λₙ` 互不相同 | `Y_j = V_j e^(λ_j x)`，n 个直接凑成基本解组 |
| **Case 2** 复根 | `λ = α ± iβ`（实矩阵的复根必**共轭成对**，p21） | 取 `V₁e^(λ₁x)` 的**实部与虚部**，得两个实值解：`U = Re(...)`、`W = Im(...)` |
| **Case 3a** 重根但 `g = m` | 重数 `m` 的根也凑得齐 `m` 个线性无关特征向量 | 和 Case 1 一样写：`(c₁V₁ + … + c_mV_m)e^(λx)` |
| **Case 3b** 重根且 `g < m` | 特征向量不够 | 需要**广义特征向量**，解里会出现 `t e^(λt)`（下面 §四） |

**Case 2 为什么要取实部虚部**：`A` 是**实矩阵**，若 `Y = U + iW` 是复值解，则 `Y′ = AY` 取实部、虚部各自成立 ⟹ `U`、`W` 都是实解。取一次就得到两个（避免复数解）。

**Case 3a 在例 5 里的样子**（见 §五）。

## 四、`g < m`（Case 3b）：为什么会出现 `t e^(λt)`

这一节**不在你手上的 PDF 里**（缺的后 24 张），但它是这章最容易翻车的地方，先给你讲透。

**最小例子**：`A = [[1, 1], [0, 1]]`。

- 特征多项式 `(λ − 1)²` ⟹ `λ = 1`，代数重数 `m = 2`；
- `A − E = [[0, 1], [0, 0]]`，`rank = 1` ⟹ **`g = 2 − 1 = 1`** ⟹ **`g < m`**，只有 1 个特征向量：`V₁ = (1, 0)ᵀ`。
- 于是只有 `Y₁ = V₁e^t` 这一个解，**凑不满 2 维**。补第二个解的办法：设 `Y₂ = (V₁t + V₂)e^t`，代入 `Y′ = AY`：

  `Y₂′ = V₁e^t + (V₁t + V₂)e^t`，`AY₂ = (AV₁)t e^t + AV₂ e^t = (λV₁)t e^t + AV₂ e^t`

  两边比较 `t e^t` 项自动成立；比较 `e^t` 项得 `V₁ + V₂ = AV₂` ⟹ **`(A − λE)V₂ = V₁`**。

  → 解出 `V₂`（叫**广义特征向量**），就得到第二个解 `Y₂ = (V₁t + V₂)e^(λt)`。

**通解**：`Y = c₁V₁e^(λt) + c₂(V₁t + V₂)e^(λt)`。

> **和二阶方程的重根对上**：方程 `y″ − 2y′ + y = 0` 重根 `λ = 1` 时，解里有 `x e^x`；
> 系统里对应的就是这里的 **`t e^(λt)`**——同一个现象，换了身衣服。
> ⚠ 反过来要注意：**标量 n 阶方程的重根一般对应 `g < m`**（伴随矩阵通常"缺"特征向量），所以方程那边天生就有 `x^j e^(λx)` 项；而在**系统**里，只有碰上 `g = m` 的特例（比如可对角化的矩阵）才能省掉广义特征向量。

## 五、老师例 5 的完整演算（L14–16 p33–36，今天讲到这里）

**题目**：解 `Y′ = AY`，`A = [[4, −1, −1], [1, 2, −1], [1, −1, 2]]`。

**第 1 步 特征方程**

`det(A − λE) = 0`：`λ³ − 8λ² + 21λ − 18 = 0`，即 `(λ − 2)(λ − 3)² = 0`
⟹ `λ₁ = 2`（`m₁ = 1`，简单根）、`λ₂ = 3`（`m₂ = 2`，二重根）。
（自检：`tr A = 8 = 2+3+3` ✓；`det A = 18 = 2·3·3` ✓）

**第 2 步 `λ₁ = 2` 的特征向量**

`A − 2E = [[2, −1, −1], [1, 0, −1], [1, −1, 0]]`。由第 2 行 `v₁ = v₃`、第 3 行 `v₂ = v₁` ⟹ **`V₁ = (1, 1, 1)ᵀ`**。

**第 3 步 `λ₂ = 3` 的特征向量（关键）**

`A − 3E = [[1, −1, −1], [1, −1, −1], [1, −1, −1]]`（三行相同）⟹ `rank = 1` ⟹ **`g₂ = n − rank = 3 − 1 = 2`**。
方程只有一条 `v₁ − v₂ − v₃ = 0`，取两组独立解：**`V₂ = (1, 1, 0)ᵀ`、`V₃ = (1, 0, 1)ᵀ`**。

> ✅ **`g₂ = 2 = m₂`** —— 这就是标题里 **`g = m`** 的含义：重数是 2，独立特征向量也正好 2 个，**不需要广义特征向量**，直接照 Case 1 写。

**第 4 步 通解**（p36）

`Y(x) = c₁V₁e^(2x) + c₂V₂e^(3x) + c₃V₃e^(3x)`

分量形式：

`y₁ = c₁e^(2x) + c₂e^(3x) + c₃e^(3x)`
`y₂ = c₁e^(2x) + c₂e^(3x)`
`y₃ = c₁e^(2x) + c₃e^(3x)`

**第 5 步 若给初值（"初值问题"）**：代入 `Y(0) = (y₁⁰, y₂⁰, y₃⁰)ᵀ`，就得到关于 `c₁, c₂, c₃` 的 **3×3 线性方程组**：

`c₁ + c₂ + c₃ = y₁⁰`；`c₁ + c₂ = y₂⁰`；`c₁ + c₃ = y₃⁰`

解出常数代回通解即可。（老师课上如果给了具体初值，就是这一句在算。）

## 六、这一章的"地图"（一句话版）

| 你看到什么 | 你做什么 |
|---|---|
| 高阶方程 | 令 `y₁=y, y₂=y′, …` 化成 `Y′ = AY + F` |
| 齐次 `Y′ = AY` | 求 `det(A − λE) = 0` 的根，再对每个 λ 解 `(A − λE)V = 0` |
| 根互不相同 | `V e^(λx)` 直接写 |
| 有复根 | 取实部、虚部，得两个实值解 |
| 重根且 `g = m` | 照简单根写（例 5） |
| 重根且 `g < m` | 补广义特征向量 `(A − λE)V₂ = V₁`，解里出现 `t e^(λt)` |
| 非齐次 | 齐次通解 + 一个特解（定理 2.2） |
| 要定常数 | 代 `Y(x₀) = Y₀`，解线性方程组 |
