## 1. 结构：为什么设 y = y_p·v 之后 v 会消失

设

<div class="formula">y = y_p(x)·v(x)</div>

求导：

<div class="formula">y′ = y_p′·v + y_p·v′</div>
<div class="formula">y″ = y_p″·v + 2y_p′·v′ + y_p·v″</div>

代进 `L[y] = y″ + a₁(x)y′ + a₂(x)y`：

<div class="formula">L[y] = y_p·v″ + (2y_p′ + a₁y_p)·v′ + v·(y_p″ + a₁y_p′ + a₂y_p)</div>

最后一个括号是 `L[y_p]`。y_p 是解，所以它是 0，于是

<div class="formula">L[y] = y_p·[ v″ + (2y_p′/y_p + a₁)·v′ ]</div>

在 `y_p ≠ 0` 的区间上，要求 L[y] = 0 就等价于

<div class="formula">v″ + (2y_p′/y_p + a₁)·v′ = 0</div>

**这就是"降阶"的全部机制**：方程里已经没有 v 本身，只含 v′，所以对 z = v′ 来说它是一阶线性齐次方程。`[教学归纳]` 注意 v 项消失不是巧合，也不是"试出来的"——因为 L 是线性算子，`L[y_p v]` 展开后 v 的系数就是 `L[y_p]`，而它恒为零。对 n 阶方程同理，课件 (18) 就是这个替换：

<div class="formula">y(x) = y_p(x)·∫ z(x) dx</div>

## 2. 路线一：降阶（课件的做法）

由 §1，令 z = v′：

<div class="formula">z′ + (2y_p′/y_p + a₁)·z = 0</div>

这是一阶线性齐次方程，解出来（积分因子或分离变量都行）：

<div class="formula">z = C·exp(−∫a₁ dx) / y_p²</div>

因为 `−∫(2y_p′/y_p + a₁)dx = −2ln|y_p| − ∫a₁dx`，指数上正好除出 `y_p²`。

再积一次分：

<div class="formula">v = C₂ + C₁·∫ exp(−∫a₁ dx)/y_p² dx</div>
<div class="formula">y = C₁·y_p + C₂·y_p·∫ exp(−∫a₁ dx)/y_p² dx</div>

这就是通解。课件在例 1、例 2 里没有写这一步的通用公式，而是每题现场分离变量（因为 `2y_p′/y_p + a₁` 恰好很简单）；写成上面这个样子，就是"公式版"。

## 3. 路线二：Abel 公式一步到位

先把方程化成**标准形**（首项系数为 1）：

<div class="formula">y″ + a₁(x)y′ + a₂(x)y = 0</div>

两个解的朗斯基行列式定义为

<div class="formula">W = y_p·y₂′ − y_p′·y₂</div>

Abel 定理（课件 L8 p50；俄文教材里这条也叫刘维尔–奥斯特罗格拉茨基公式）说：

<div class="formula">W(x) = W(x₀)·exp(−∫(x₀→x) a₁(t) dt)</div>

把 W 除以 `y_p²`，左边正好凑成商的导数：

<div class="formula">(y₂/y_p)′ = (y_py₂′ − y_p′y₂)/y_p² = W/y_p²</div>

代进 Abel 公式再积分：

<div class="formula">y₂ = y_p·W(x₀)·∫ exp(−∫a₁ dx)/y_p² dx + C·y_p</div>

`C·y_p` 是齐次解，并进通解的 C₁ 即可。取 `W(x₀) = 1`（只差常数，见 §4），得到

<div class="formula">y₂ = y_p·∫ exp(−∫a₁ dx)/y_p² dx</div>
<div class="formula">y = C₁·y_p + C₂·y_p·∫ exp(−∫a₁ dx)/y_p² dx</div>

**这个方法的特点**：只看 `a₁(x)` 和 `y_p(x)`，`a₂(x)` 完全不出现 —— 因为 Abel 公式里只有 a₁。这就是"甚至不用看 y 前面的系数"的原因。

## 4. 两条路线是同一个积分

对比一下：

- 路线一解出的 `z = C·exp(−∫a₁)/y_p²`；
- 路线二直接用的被积函数 `W/y_p² = W(x₀)·exp(−∫a₁)/y_p²`。

两者只差常数 `W(x₀)`，而这个常数积分一次以后变成 `C·y_p`，被通解的 C₁ 吸收。所以：

> **Abel 法不是另一个方法，它只是把路线一里"解 z 的一阶方程"那一步，换成了一个现成的公式。**

`[教学归纳]` 两条路线各自适合什么场合：路线一要算 y″、要整理代数，但每一步都能看见；路线二一步到位，但要求你先信任 Abel 定理、并且记得先把方程化标准形。考场上推荐路线二（快、不容易在代数上翻车），检查时用路线一（把 y₂ 代回原方程）。

## 5. 例 1（课件 L7 p31–p33）：一个三阶变系数方程

方程是

<div class="formula">x³y″ + (x−1)y′ − y = 0</div>

已知特解 `y_p = x−1`。先验证：`y_p′ = 1`、`y_p″ = 0`，代入得 `0 + (x−1) − (x−1) = 0` ✓。

**路线一（课件）。** 设 `y = (x−1)∫z dx`，则

<div class="formula">y′ = ∫z dx + (x−1)z,　y″ = 2z + (x−1)z′</div>

代回原方程，两个 `∫z dx` 项正好抵消：

<div class="formula">x³(x−1)z′ + [2x³ + (x−1)²]·z = 0</div>

分离变量：

<div class="formula">z′/z = −[ 2/(x−1) + (x−1)/x³ ]</div>

积分（`∫(x−1)/x³ dx = −1/x + 1/(2x²)`）：

<div class="formula">z = C·exp(1/x − 1/(2x²)) / (x−1)²</div>

**路线二（Abel）。** 先化标准形（整体除以 x³）：

<div class="formula">y″ + [(x−1)/x³]·y′ − (1/x³)·y = 0　⟹　a₁ = (x−1)/x³</div>

<div class="formula">∫a₁ dx = ∫(1/x² − 1/x³)dx = −1/x + 1/(2x²)</div>
<div class="formula">W = exp(1/x − 1/(2x²))</div>
<div class="formula">z = W/y_p² = exp(1/x − 1/(2x²))/(x−1)²</div>

一步就得到课件那串分离变量的结果，中间那一步 `x³(x−1)z′ + [2x³+(x−1)²]z = 0` 都不用写。

通解（`x ≠ 0, 1`）：

<div class="formula">y = (x−1)·[ C₁ + C₂·∫ exp(1/x − 1/(2x²))/(x−1)² dx ]</div>

`[教学归纳]` 这个积分也不是初等函数。课件到 p33 就停在这里，是正常的（题目只要求"降阶并解出降阶后的一阶方程"，没有要求把最后那个积分积出来）。

## 6. 例 2（课件 L7 p33–p36）：你问的这道二阶方程

方程是

<div class="formula">y″ + xy′ − (x+1)y = 0</div>

已知特解 `y_p = e^x`。先验证：`y_p′ = y_p″ = e^x`，代入得

<div class="formula">e^x + x·e^x − (x+1)·e^x = 0　✓</div>

### 6.1 路线一（课件的做法）

设 `y = e^x·v`，则

<div class="formula">y′ = e^x(v′ + v),　y″ = e^x(v″ + 2v′ + v)</div>

代入原方程并约掉 `e^x`：

<div class="formula">(v″ + 2v′ + v) + x(v′ + v) − (x+1)v = 0</div>

含 v 的项两两抵消（`v + xv − xv − v = 0`），只剩

<div class="formula">v″ + (x+2)v′ = 0</div>

令 z = v′：

<div class="formula">z′ + (x+2)z = 0　⟹　z = C₄·exp(−x²/2 − 2x)</div>

再积分一次：

<div class="formula">v = C₅ + C₄·∫ exp(−x²/2 − 2x)dx</div>
<div class="formula">y = e^x·[ C₅ + C₄·∫ exp(−x²/2 − 2x)dx ]</div>

这就是课件 p36 的答案。

### 6.2 路线二（Abel，三行）

`a₁ = x`，所以

<div class="formula">W = exp(−∫x dx) = exp(−x²/2)</div>
<div class="formula">y₂ = y_p·∫ W/y_p² dx = e^x·∫ exp(−x²/2)/e^(2x) dx = e^x·∫ exp(−x²/2 − 2x) dx</div>
<div class="formula">y = e^x·[ C₁ + C₂·∫ exp(−x²/2 − 2x)dx ]</div>

和 §6.1 一字不差。

### 6.3 那个积分到底是什么

配平方：

<div class="formula">−x²/2 − 2x = −(x+2)²/2 + 2</div>

所以

<div class="formula">∫ exp(−x²/2 − 2x)dx = e²·√(π/2)·erf((x+2)/√2) + C</div>

其中 `erf` 是误差函数（不是初等函数）。这解释了为什么课件、以及任何标准答案都把它留在积分号里 —— 不是偷懒，是这个积分积不出来。考试写到 §6.1 或 §6.2 那一步就是完整答案。

### 6.4 顺手验一下 W

由 §6.2 的 y₂ = e^x∫u dx（记 u = exp(−x²/2 − 2x)）：

<div class="formula">W(e^x, y₂) = e^x·(e^x∫u + e^xu) − e^x·(e^x∫u) = e^(2x)·u = exp(−x²/2)　✓</div>

这也说明"取 W(x₀)=1"没有丢东西：算出来的 W 就是 exp(−x²/2)。

## 7. 例 3（课件 L8 p51–p53）：Abel 求第二解的标准演示

题目：

<div class="formula">2xy″ − (x+4)y′ + (1+4/x)y = 0,　x ≠ 0</div>

已知 `y₁ = x` 是解。化标准形（除以 2x）：

<div class="formula">y″ − [(x+4)/(2x)]·y′ + [1/(2x) + 2/x²]·y = 0　⟹　a₁ = −(x+4)/(2x)</div>

<div class="formula">∫a₁ dx = −x/2 − 2ln|x|　⟹　W ∝ exp(x/2)·x²</div>

（`exp(−∫a₁) = exp(x/2 + 2ln|x|) = x²·exp(x/2)`，只差常数倍。）

<div class="formula">y₂/y₁ = ∫ W/y₁² dx = ∫ x²exp(x/2)/x² dx = ∫exp(x/2)dx = 2exp(x/2)</div>

<div class="formula">y₂ = 2x·exp(x/2) ∝ x·exp(x/2)</div>

通解 `y = C₁x + C₂x·exp(x/2)`，与课件 p53 的答案一致。

这个例子值得记：W 里会自动出现 `x²`，和 `y₁² = x²` 正好约掉，积分立刻变成 `∫exp(x/2)dx`。**很多题设计成"W 与 y_p² 大量约分"**，所以看到复杂系数不要慌，先算 W/y_p² 再化简。

## 8. 公式卡与四步用法

| 步骤 | 做什么 | 注意 |
|---|---|---|
| 1 | 化成标准形 `y″ + a₁y′ + a₂y = 0` | 首项系数必须是 1；这一步错了全错 |
| 2 | 确认 `y_p` 真的是解（代一下，30 秒） | 题目给了也要验，防止抄错题 |
| 3 | 算 `W = exp(−∫a₁ dx)` | 只差常数，取 1；能化简先化简 |
| 4 | `y₂ = y_p∫W/y_p² dx`，写通解 `y = C₁y_p + C₂y₂` | 积分算不出来就保留积分形式 |

**收尾检查**：直接算 `W(y_p, y₂)`，看它是否等于第 3 步取的 `W`（差常数也算对）。这一条能抓住绝大多数符号错误。

## 9. 六条易错点

1. **没化标准形**。例 1 的 `a₁` 是 `(x−1)/x³`，不是 `x−1`；例 3 的是 `−(x+4)/(2x)`，不是 `−(x+4)`。用 Abel 之前先除首项系数。
2. **W 只差常数倍**。例 3 真实的 `W(x, xe^{x/2}) = (x²/2)·exp(x/2)`，而 `exp(−∫a₁) = x²exp(x/2)`，差 1/2；`y₂` 只差常数倍，不影响通解。别以为算出 1/2 就错了。
3. **y_p 的零点要挖掉**。例 1 的 `y_p = x−1` 在 x = 1 处为零，公式在那里失效；例 3 还要挖掉 x = 0（系数奇点）。通解只在 `y_p ≠ 0` 且系数连续的区间上成立。
4. **非初等积分不是错**。例 2 的 `∫exp(−x²/2 − 2x)dx` 就是积不出来的；课件也停在积分形式。
5. **只降一阶**。n 阶方程用 `y = y_p∫z dx` 得到的是 n−1 阶，不是一阶（课件 (17)(18) 的原话是 reduced by unity）。二阶才恰好降成一阶。
6. **别和参数变易法混**。两处都有 W、都有 `exp(−∫a₁)`，但位置相反：求**齐次**第二解时 W 在**分子**（`y₂ = y_p∫W/y_p²`）；求**非齐次**特解时 W 在**分母**（`C₁′ = −y₂f/W`）。记成"求通解 W 上，求特解 W 下"。

## 10. 自检（先做，答案在文后）

1. `x²y″ − 2xy′ + 2y = 0`（x > 0），已知 `y₁ = x`，求 `y₂` 与通解。
2. `y″ + (1/x)y′ − (1/x²)y = 0`（x > 0），已知 `y₁ = x`，求通解。
3. 若方程是 `y″ + q(x)y = 0`（没有 y′ 项），Abel 公式告诉你 W 是什么？由此说明两个解的 W 与 x 无关。
4. 用例 2 的 `y₂ = e^x∫exp(−x²/2 − 2x)dx`，直接算 `W(e^x, y₂)`，验证它等于 `exp(−x²/2)`。
5. **作业对照（本讲义不给答案）**：`xy″ + 2y′ − xy = 0`，`y_p = exp(x)/x`（L7 p46 作业 III）。第一步先化标准形（两边除以 x）、读出 `a₁`，然后按 §8 的四步自己做。

## 自检答案

**1.** 化标准形：`a₁ = −2/x`，`W = exp(∫2/x dx) = x²`。

<div class="formula">y₂ = x·∫ x²/x² dx = x·∫1 dx = x²</div>
<div class="formula">y = C₁x + C₂x²</div>

（这是 Cauchy–Euler 型的老朋友，答案对得上。）

**2.** `a₁ = 1/x`，`W = exp(−ln x) = 1/x`。

<div class="formula">y₂ = x·∫ (1/x)/x² dx = x·∫ x^(−3)dx = x·(−1/(2x²)) = −1/(2x)</div>

常数 −1/2 并进 C₂，所以

<div class="formula">y = C₁x + C₂/x</div>

**3.** `a₁ = 0`，所以 `W = W(x₀)·exp(0) = W(x₀)` 是常数。两个解线性无关 ⟺ 这个常数不为 0。物理上这就是 `y″ + q(x)y = 0` 型方程的"朗斯基守恒"。

**4.** 记 `u = exp(−x²/2 − 2x)`，`y₂ = e^x∫u dx`，则 `y₂′ = e^x∫u dx + u`：

<div class="formula">W = e^x·y₂′ − e^x·y₂ = e^x·u = e^(2x)·exp(−x²/2 − 2x) = exp(−x²/2)　✓</div>

**5.** 答案不在这里：作业需要你自己走完 §8 的四步。只提醒一句 —— `y_p = exp(x)/x` 带一个 1/x，算 `W/y_p²` 时先把 `y_p²` 写开（它等于 `exp(2x)/x²`），看看 x 的幂能不能约掉。

## 12. 本讲三句话

1. 已知一个解 `y_p`，设 `y = y_p·v`，含 v 的项必然消失（因为 `L[y_p] = 0`），方程降成只含 `v′` 的一阶方程。
2. 那条一阶方程的解恒等于 `W/y_p²`，而 `W = exp(−∫a₁)`，所以 `y₂ = y_p·∫W/y_p² dx` —— 记住 `a₂` 从头到尾不出现。
3. 先化标准形再读 `a₁`；W 差常数不要紧；积分积不出来就保留积分形式。这三条能解释本讲 90% 的"我算得对不对"。
