## 四、参考答案（先做完再看）

### 课件原题

**A1（①）x²y″ − 2xy′ + 2y = x²**
- 指标方程：r(r−1) − 2r + 2 = r² − 3r + 2 = (r−1)(r−2) = 0 ⟹ r₁ = 1，r₂ = 2。
- 齐次通解：y_h = c₁x + c₂x²。
- 特解：试 y_p = Ax² 代入左边得 **0**（因为 x² 本来就在齐次解里）→ 共振，改设 y_p = Ax²ln x，代入得左边 = A x²，故 A = 1：y_p = x²ln x。
- 通解：**y = c₁x + c₂x² + x²ln x**（x < 0 时写 x²ln|x|）。与 L11 p52 的结论一致。

**A2（②）x²y″ + xy′ − y = 2x**
- 指标方程：r(r−1) + r − 1 = r² − 1 = 0 ⟹ r = ±1。
- y_h = c₁x + c₂/x；特解 y_p = (ln x − 1)x（试 y_p = Ax ln x 得 A = 1）。
- 通解：**y = (ln x + c₁)x + c₂/x**。x < 0 时 **y = (ln|x| + c)x + C/x**。

**A3（③）x²y″ + 5xy′ + 4y = 0**
- 指标方程：r(r−1) + 5r + 4 = r² + 4r + 4 = (r+2)² = 0 ⟹ r = −2（二重）。
- 通解：**y = (c₁ + c₂ln x)/x²**。

### 补充练习册

| 题 | 答案 |
|----|------|
| 1 | 指标 (r+1)(r+2) = 0 ⟹ **y = c₁/x + c₂/x²** |
| 2 | 指标 (r−2)² = 0 ⟹ **y = (c₁ + c₂ln x)x²**（重根必带 ln x） |
| 3 | 指标 r² + 2r + 2 = 0 ⟹ r = −1 ± i ⟹ **y = x⁻¹(c₁cos ln x + c₂sin ln x)** |
| 4 | 指标 (r+1)³ = 0 ⟹ **y = (c₁ + c₂ln x + c₃ln²x)/x** |
| 5 | 指标 (r−1)⁴ = 0 ⟹ **y = (c₁ + c₂ln x + c₃ln²x + c₄ln³x)x** |
| 6 | 齐次 (r+1)² ⟹ y_h = (c₁ + c₂ln x)/x；y_p = 1 ⟹ **y = (c₁ + c₂ln x)/x + 1** |
| 7 | 同上齐次；y_p = (2/9)x² ⟹ **y = (c₁ + c₂ln x)/x + (2/9)x²** |
| 8 | 齐次 (r−1)(r−2) ⟹ y_h = c₁x + c₂x²；y_p = (1/2)x³ ⟹ **y = c₁x + c₂x² + x³/2** |
| 9 | 同上齐次；y_p = (1/6)x⁴ ⟹ **y = c₁x + c₂x² + x⁴/6** |
| 10 | 指标 (r−3)(r−4) = 0 ⟹ **y = c₁x³ + c₂x⁴**；变成 = 1 时 y_p = 1/12 |
| 11 | 换元后为 d²y/dt² + 4dy/dt + 4y = e^{3t}；y_h = (c₁ + c₂t)e^{−2t}，y_p = e^{3t}/25；回代得 **y = (c₁ + c₂ln x)/x² + x³/25** |
| 12 | 指标 (r−2)²(r+2)² = 0 ⟹ **y = (c₁ + c₂ln x)x² + (c₃ + c₄ln x)/x²** |

> 第 11 题的换元检查：x²y″ = D(D−1)y、xy′ = Dy（D = d/dt），所以 x²y″ + 5xy′ + 4y = (D² − D)y + 5Dy + 4y = D²y + 4Dy + 4y；右端 x³ = e^{3t}。

## 五、方法要点（三句话版）

1. **试幂函数法**：设 y = xʳ 代入，得**指标方程** a₀r(r−1)…(r−n+1) + a₁r(r−1)…(r−n+2) + … + aₙ = 0。
   - 相异实根 r₁, r₂ → x^r₁, x^r₂；
   - **重根 r（m 重）→ xʳ, xʳln x, …, xʳln^{m−1}x**；
   - 共轭复根 α ± iβ（m 重）→ x^α cos(β ln x), x^α sin(β ln x)（重根再乘 ln x 的幂）。
2. **换元法**：x = eᵗ（x > 0）⟹ t = ln x，且
   xy′ = dy/dt，x²y″ = d²y/dt² − dy/dt，x³y‴ = d³y/dt³ − 3d²y/dt² + 2dy/dt，xᵏy⁽ᵏ⁾ = D(D−1)…(D−k+1)y。
   化成常系数方程后按老办法解；**右端 f(x) 必须一起换成 f(eᵗ)**，最后用 t = ln x 回代。
   （x < 0 用 x = −eᵗ，t = ln(−x)；练习 ①②③ 的结果都可并写成 ln|x|。）
3. **三条容易丢分的边界**：
   - 重根漏掉 ln x（或漏掉 ln²x、ln³x）；
   - 复根忘了乘回 x^α；
   - x = 0 是最高阶系数退化的点，通解只在 x > 0 或 x < 0 的半轴上成立，**不能延拓到 0**。
