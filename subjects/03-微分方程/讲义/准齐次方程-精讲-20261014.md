## 1. 定义（课件 L3 p8 原文要点）

一阶 DE `y' = f(x, y)` 称为**准齐次**，若存在实数 α、β，使得在缩放 `x ↦ k^α x`、`y ↦ k^β y` 下

```
f(k^α x, k^β y) = k^(β−α) · f(x, y)          （对一切 k > 0）
```

解法：引入新未知函数 **u = y / x^(β/α)**。
两个关键观察（课件原话）：**α = β 时得到的是经典齐次方程**；α ≠ β 才是真正的准齐次。

## 2. 权重记账法（操作核心）

给 x 记权重 a、y 记权重 b（都由 `y' = dy/dx` 推出，不是自由参数）：

| 对象 | 权重 |
|---|---|
| `x^m y^n` | `m·a + n·b` |
| **`y' = dy/dx`** | **`b − a`** |
| `x^m / y^n` | `m·a − n·b` |
| 纯常数项 | `0` |

**归一化固定 a = 1**（不要再去设 y' 的权重），设 b 为未知量 → 逐项写权重 → **令所有项权重相等** → 解出 b。
若这些等式互相矛盾（各项无法同次）⟹ **该方程不是准齐次**，改用别的方法（线性 / Bernoulli / 恰当…）。
求得 b 后换元 **`y = x^b u`**（因 b = β/α）。

## 3. 为什么换元后一定可分离（可解性证明，关键一行）

设 c = β/α，u = y/x^c。在定义式中取 `k = x^(−1/α)`（把 x 缩放到 1）：

```
f(x, y) = x^((β−α)/α) · f(1, y·x^(−β/α)) = x^(c−1) · F(u),   F(u) := f(1, u)
```

代入 `y = x^c u`（左边 `y' = c x^(c−1)u + x^c u'`）得

```
c x^(c−1) u + x^c u' = x^(c−1) F(u)  ⟹  x u' = F(u) − c u  ⟹  du/(F(u) − c u) = dx/x
```

**加权不变性 ⟹ f 只通过 u 依赖 (x, y) ⟹ 换元后是可分离方程。** 这就是本方法的全部原理。

## 4. 五步流程

1. 写成 `y' = f(x, y)`；
2. **权重记账**（a = 1，解 b）；解不出 ⟹ 不是准齐次；
3. 换元 `y = x^b u`，`y' = b x^(b−1) u + x^b u'`；
4. 代入 → 约去公因子 `x^(b−1)` → 得 `x u' = F(u) − b u` → 分离、积分；
5. 代回 `u = y/x^b`；**丢解检查**（分离时除掉的因子：u = 0？F(u) = b u？）＋ 注明定义域（x ≠ 0）。

## 5. 课件例题（L3 p9–p17）：`y' = y/x + x/y²`，x ≠ 0，y ≠ 0

1. **先试经典齐次**（x→kx、y→ky）：`y/x` 不变，但 `x/y² → k^(−1)·x/y²` ⟹ 两项缩放不同 ⟹ **不是经典齐次**。
2. **记账**：y' → b−1；y/x → b−1；x/y² → 1−2b ⟹ `b − 1 = 1 − 2b` ⟹ **b = 2/3**（课件取 α = 3、β = 2，比值同为 2/3）。
3. **换元** `y = x^(2/3) u` ⟹ `y' = (2/3)x^(−1/3)u + x^(2/3)u'`。
4. **代入并乘 x^(1/3)**：`(2/3)u + x u' = u + u^(−2)` ⟹ `x u' = u/3 + u^(−2) = u^(−2)(u³/3 + 1)`。
5. **分离积分**：`u²/(u³/3 + 1) du = dx/x`；令 `v = u³/3 + 1, dv = u²du` ⟹ `ln|v| = ln|x| + C` ⟹ `u³/3 + 1 = Cx`。
6. **代回**：`u = y/x^(2/3)` ⟹ `y³ = 3x²(Cx − 1)` ⟹ **`y = ∛(3x²(Cx − 1))`，C ∈ ℝ**。
7. **丢解检查（课件示范）**：除掉了 `u²`（u = 0 ⟹ y = 0，被题设 y ≠ 0 排除）与 `u³/3 + 1`（u³ = −3 ⟹ y = −∛3·x^(2/3)）；代回验证它是解，且**正好对应 C = 0** ⟹ **不是奇解**，已含在通解中，故通解允许 C = 0。

## 6. 对照：定位卷 A2（`y' = y/x + x³/y`）

记账：y' → b−1；y/x → b−1；**x³/y → 3 − b** ⟹ `b − 1 = 3 − b` ⟹ **b = 2** ⟹ `y = x²u`。
代入：`2xu + x²u' = xu + x/u` ⟹ `u' = (1 − u²)/(x u)` ⟹ 分离 `u du/(1−u²) = dx/x` ⟹ `(1 − u²)x² = C` ⟹ **`y² = x⁴ + Cx²`**（sympy 复核代入 = 0）。
> ⚠ **两题差别只在第二项**：`x/y²` 的权重是 `1 − 2b`，`x³/y` 是 `3 − b` ⟹ 换元指数 b 完全不同（2/3 vs 2）。**必须每次重新记账，不能套模板。**

## 7. 边界与陷阱

1. **换元只依赖比值 β/α**：α、β 的具体取法不唯一（3:2 与 1:2/3 等价）。
2. **y' 的权重是 b − a，不可设**（归一化请固定 a = 1）。
3. **各项无法同次 ⟹ 不是准齐次**：如 `y' = x + y`（权重 1、b、b−1 无法同时相等）——它是**线性**方程，用 `μ = e^(−x)`。
4. **能用 Bernoulli / 线性更快解决时不必上准齐次**（例：`y' = y/x + x³/y` 也可看成 Bernoulli，n = −1，令 v = y²）。
5. **定义域**：换元含 `x^b` ⟹ x ≠ 0；分离时除掉的因子要单独查（可能给出 C = 0 的特殊解，也可能给奇解）。
6. **α = β 退化为经典齐次**（u = y/x），不必另设权重。

## 8. 复测题（下次用，不出现在讲解里）

- 判权重类（H0）：`y' = y/x + x²/y³` → 期望 b = 3/4（`b − 1 = 2 − 3b`），换元 `y = x^(3/4)u`。
- 完整解类（H0、未见）：`y' = y/x + x²/y³` 或 `y' = 2y/x + x/y²` 全解 + 丢解检查。
- 负权重类：`y' = y/x + x³y`（b − 1 = 3 + b 无解 ⟹ 非准齐次，应识别出来并改道）。
