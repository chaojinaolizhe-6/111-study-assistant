0. 这个方法在流程里站哪一格

先统一名字：这个方法有两个常用中文名（参数变易法、常数变易法），课件里叫 method of variation of parameters (Lagrange method)，三个说法指同一件事。

线性非齐次方程的结构定理（课件 L8 p16 的 Theorem 4）只有一句话：

y = c₁y₁ + c₂y₂ + y_p

前两块把齐次方程的全部解写全，最后一块 y_p 负责吸收右端 f(x) 带来的"外力"。所以解一个非齐次方程永远是两步：先解齐次拿到基本解组（FSS），再找一个特解。第一步是特征方程或降阶的活；第二步有两条路：

右端 f(x) 长什么样 首选方法 代价
多项式、指数、正弦余弦，以及它们的乘积 待定系数法 只对常系数方程有效；撞上齐次解要乘 x^s
tan x、sec x、1/x、ln x、exp(x)/x 这类 参数变易法 必须先有 y₁、y₂；要做两次积分
变系数方程（如 2xy″ − … = 4x²） 参数变易法 齐次解往往要另想办法（降阶或 Abel 公式）

为什么 tan x 不能对待定系数法。 待定系数法要 f 落在"多项式 × 指数 × 正余弦"张成的有限维空间里，而且这个空间对求导必须封闭（求完导还在空间内）。tan x 求一次导是 sec²x = 1 + tan²x，再求导又冒出 sec²x·tan x …，导数序列永远不回到有限个这类基本函数，空间不封闭，所以设不出有限的待定系数。这不是"方法不好"，而是它的适用范围本来就只到那个有限维空间。

一句话记住：参数变易法不是"又一种猜法"，它把"猜特解"换成了"解一个 n 元一次方程组 + n 次积分"的机械流程，代价是积分可能很难算。

1. 先看一阶：常数为什么可以"变易"

一阶线性方程

y′ + p(x)y = f(x)

齐次通解是

y_h = C·exp(−∫p(x) dx)

课件 L4 p18 用的就是这个方法（那里直接写了 "the method of variation of parameters due to Lagrange"）。现在把常数 C 换成函数 C(x)：

y = C(x)·exp(−∫p(x) dx)

求导：

y′ = C′·exp(−∫p) − C·p·exp(−∫p)

代回原方程，含 C 的两项正好抵消（这正说明 exp(−∫p) 是齐次解），只剩

C′·exp(−∫p) = f　⟹　C′ = f·exp(∫p)

积分即得一阶线性方程的通解公式

y = exp(−∫p) · [ ∫ f·exp(∫p) dx + C ]

[教学归纳] 注意这里为什么一定能解出来：一个未知函数 C(x)，正好一个方程。到了二阶，未知函数变成两个，方程还是一个 —— 多出来的那个自由度，就是下一节要用的东西。

2. 二阶：两个未知函数、一个方程，多出的自由度怎么用

设特解取成

y_p = C₁(x)y₁(x) + C₂(x)y₂(x)

（记号约定：带 (x) 的 C₁、C₂ 是待求的函数，与小写 c₁、c₂ 这两个任意常数不同。你图里把函数写成 C₁(x)，与此处一致。）

两个未知函数、一个方程 L[y] = f，还差一个条件。这个条件自己加，目标是让 y_p′ 看起来跟"常数情形"一模一样，这样二阶导里的 C′ 只出现在需要它的地方。于是规定

C₁′y₁ + C₂′y₂ = 0　（附加条件）

在此条件下求导：

y_p′ = C₁y₁′ + C₂y₂′
y_p″ = C₁′y₁′ + C₂′y₂′ + C₁y₁″ + C₂y₂″

代进 y″ + a₁(x)y′ + a₂(x)y = f：

(C₁′y₁′ + C₂′y₂′) + C₁(y₁″ + a₁y₁′ + a₂y₁) + C₂(y₂″ + a₁y₂′ + a₂y₂) = f

后两个括号为零（y₁、y₂ 解齐次方程），于是只剩

C₁′y₁′ + C₂′y₂′ = f　（第二个方程）

两条合起来就是课件 (13) 式的二元一次方程组：

C₁′y₁ + C₂′y₂ = 0
C₁′y₁′ + C₂′y₂′ = f

系数行列式正好是朗斯基行列式

W = y₁y₂′ − y₁′y₂ ≠ 0

所以 C₁′、C₂′ 有唯一解。

[教学归纳] 一个值得想清楚的问题：附加条件为什么可以随便加？ 设你改加 C₁′y₁ + C₂′y₂ = g(x)（g 是任意函数），再算一遍会发现第二个方程变成 C₁′y₁′ + C₂′y₂′ = f − g′，方程组照样可解，得到的 y_p 照样满足原方程。取 g = 0 只是让 y_p′ 的表达式最短、最好算，所以那条 0 是约定，不是定理。

3. 快速算法：三条公式，外加一条自检

用克拉默法则解上面的方程组（课件 p19–p20）：

C₁′(x) = −y₂(x)·f(x) / W(x)
C₂′(x) = y₁(x)·f(x) / W(x)

积分（积分常数取 0，理由见 §10 第 4 条）：

C₁(x) = −∫ y₂(t)f(t)/W(t) dt,　C₂(x) = ∫ y₁(t)f(t)/W(t) dt

记忆法：求 C₁′ 时分子用另一个解 y₂ 并带负号；求 C₂′ 时分子用 y₁ 并带正号。别死背符号，用两条式子当场验：

C₁′y₁ + C₂′y₂ = (−y₂y₁ + y₁y₂)·f/W = 0　✓
C₁′y₁′ + C₂′y₂′ = (−y₂y₁′ + y₁y₂′)·f/W = W·f/W = f　✓

几何读法（想一遍就忘不掉）：把每个解看成一个向量 (y_k, y_k′)。两条方程说的是

C₁′·(y₁, y₁′) + C₂′·(y₂, y₂′) = (0, f)

也就是把向量 (0, f) 按基 {(y₁, y₁′), (y₂, y₂′)} 分解。W 正是这两个向量张成的平行四边形的有向面积，所以它出现在分母上；W = 0 就是两个向量共线、基退化，解不出来。

W 为什么真的不会等于 0。 课件 Theorem 2（p9）给的是：若 n 个函数线性相关，则 W ≡ 0；反之若某点 W ≠ 0，则它们线性无关。对线性方程的解来说，"线性无关"与"W 处处不为 0"是同一件事 —— 因为 Abel 公式（§9）保证 W 要么恒为零、要么处处非零。

4. 例 1（你发的这题）：y″ + y = tan x

4.1 齐次与 W

y″ + y = 0 的基本解组取

y₁ = cos x,　y₂ = sin x
W = cos x·cos x − (−sin x)·sin x = cos²x + sin²x = 1

默认 cos x ≠ 0，即 x ≠ π/2 + kπ。

4.2 列方程组：设特解为

y_p = C₁(x)cos x + C₂(x)sin x

注意 y₁′ = −sin x、y₂′ = cos x，按 §2 的两条式子写：

C₁′cos x + C₂′sin x = 0
−C₁′sin x + C₂′cos x = tan x

这正是你图里的那个方程组。

4.3 解出 C₁′、C₂′

套 §3 的快速算法（W = 1）：

C₁′ = −y₂f/W = −sin x·tan x = −sin²x/cos x = (cos²x − 1)/cos x = cos x − sec x
C₂′ = y₁f/W = cos x·tan x = sin x

把 −sin²x/cos x 化成 cos x − sec x 是本题唯一的技巧；不化也能积，但要绕一点。

4.4 积分

C₁ = ∫(cos x − sec x) dx = sin x − ln|sec x + tan x| + c₃
C₂ = ∫sin x dx = −cos x + c₄

用到的公式是 ∫sec x dx = ln|sec x + tan x|。记不住可以现推：sec x = cos x/cos²x，令 u = sin x，就化成了 ∫du/(1 − u²)。

4.5 组装：交叉项会自己抵消

取 c₃ = c₄ = 0：

y_p = (sin x − ln|sec x + tan x|)·cos x − cos x·sin x = −cos x·ln|sec x + tan x|

两个 sin x·cos x 正好抵消。不要在半路把某一项当成"多余的"先扔掉，让它自己消。

通解：

y = c₁cos x + c₂sin x − cos x·ln|sec x + tan x|

定义区间：x ∈ (−π/2 + kπ, π/2 + kπ)，k ∈ ℤ。tan x 在这里断掉，ln|sec x + tan x| 也在同一批点断掉。

4.6 同一题的另一种写法（课件 p21–p25）

课件把基本解组取成相反的顺序：y₁ = sin x、y₂ = cos x。这时

W(sin x, cos x) = −1
c₁′ = −cos x·tan x/(−1) = sin x,　c₂′ = sin x·tan x/(−1) = cos x − sec x

积分后

c₁ = −cos x,　c₂ = sin x − ½ln((1 + sin x)/(1 − sin x))
y_p = −cos x·sin x + [sin x − ½ln((1 + sin x)/(1 − sin x))]·cos x
y_p = −½cos x·ln((1 + sin x)/(1 − sin x))

和 §4.5 的结果差一个系数、换了一个对数写法，其实是同一个函数，因为

½ln((1 + sin x)/(1 − sin x)) = ln|sec x + tan x|

验证一句话：把 (1 + sin x)/(1 − sin x) 上下同乘 (1 + sin x)，得 (1 + sin x)²/cos²x，开方就是 (1 + sin x)/|cos x| = |sec x + tan x|。

[教学归纳] 两种写法都对。要点只有一条：y₁、y₂ 的顺序、W 的行列式顺序、公式分子用哪个解，这三处必须同源。只要同源，结果一定相同 —— 互换 y₁、y₂ 会让 W 变号、C₁′ 与 C₂′ 互换，y_p 不变。

5. 例 2（课件 p26–p30）：变系数、首项系数不是 1

题目：

2xy″ − (x + 4)y′ + (1 + 4/x)y = 4x²,　x ≠ 0

5.1 第一件事：化标准形

公式要的是 y″ + a₁y′ + a₂y = f 的形状，所以先整体除以 2x：

y″ − [(x + 4)/(2x)]·y′ + [1/(2x) + 2/x²]·y = 2x

右端是 2x，不是 4x²。 这是本题最容易丢分的一步：把 4x² 直接代进公式，算出的 y_p 满足的是另一个方程，代回原式立刻露馅（左边会等于 4x² 而不是 2x）。

5.2 齐次与 W

课件在附加材料里用 Abel 公式从 y₁ = x 求出 y₂ = x·exp(x/2)（§9 再说怎么求）。于是

y₂′ = (1 + x/2)·exp(x/2)
W = x·(1 + x/2)exp(x/2) − 1·x·exp(x/2) = (x²/2)·exp(x/2)

在 x > 0（或 x < 0）的区间上 W ≠ 0，可以放心用。

5.3 解方程组

方程组是

C₁′·x + C₂′·x·exp(x/2) = 0
C₁′·1 + C₂′·(1 + x/2)exp(x/2) = 2x

套公式更省事：

C₁′ = −x·exp(x/2)·2x / [(x²/2)exp(x/2)] = −4
C₂′ = x·2x / [(x²/2)exp(x/2)] = 4exp(−x/2)

5.4 积分与通解

C₁ = −4x,　C₂ = −8exp(−x/2)
y_p = −4x·x + (−8exp(−x/2))·x·exp(x/2) = −4x² − 8x

通解

y = c₁x + c₂x·exp(x/2) − 4x² − 8x = c₅x − 4x² + c₂x·exp(x/2)

（c₁x 与 −8x 合并成一个新常数 c₅，课件就是这么写的。）

这个例子的意义：方程变系数、W 也不是常数，方法照样能用；代价是齐次解得另想办法，这里用的是 Abel 公式。

6. 例 3（课件 L9 p25–p31）：三阶，n 个未知函数

题目：

y‴ − 6y″ + 11y′ − 6y = 6x

特征方程 λ³ − 6λ² + 11λ − 6 = (λ − 1)(λ − 2)(λ − 3) = 0，基本解组 exp(x)、exp(2x)、exp(3x)。

6.1 三个条件怎么来

设

y_p = C₁(x)exp(x) + C₂(x)exp(2x) + C₃(x)exp(3x)

三个未知函数、一个方程，所以要加两条附加条件。做法是每求一次导，就用一条条件把带 C′ 的那一坨压成 0：

C₁′exp(x) + C₂′exp(2x) + C₃′exp(3x) = 0
C₁′exp(x) + 2C₂′exp(2x) + 3C₃′exp(3x) = 0
C₁′exp(x) + 4C₂′exp(2x) + 9C₃′exp(3x) = 6x

前两条是附加条件；第三条是把 y_p、y_p′、y_p″、y_p‴ 代进原方程后剩下的式子（所有含 C₁、C₂、C₃ 的项都因齐次方程而消失）。

6.2 解三元方程组：换元比克拉默快

令

u = C₁′exp(x),　v = C₂′exp(2x),　w = C₃′exp(3x)

方程组变成系数全是整数的形式：

u + v + w = 0
u + 2v + 3w = 0
u + 4v + 9w = 6x

第二式减第一式得 v = −2w；第三式减第二式得 2v + 6w = 6x；代入得 w = 3x。于是

u = 3x,　v = −6x,　w = 3x
C₁′ = 3x·exp(−x),　C₂′ = −6x·exp(−2x),　C₃′ = 3x·exp(−3x)

6.3 积分（三次分部积分）

C₁ = −3(x + 1)exp(−x),　C₂ = (3x + 3/2)exp(−2x),　C₃ = −(x + 1/3)exp(−3x)

回代：

y_p = −3(x + 1) + (3x + 3/2) − (x + 1/3) = −x − 11/6

通解

y = c₁exp(x) + c₂exp(2x) + c₃exp(3x) − x − 11/6

6.4 顺带订正课件的一处算术

课件 p29 把系数矩阵的行列式算成 W = 14exp(6x)。按第一行展开，三个二阶行列式要交替加减：

W = exp(6x)·[(2·9 − 3·4) − (1·9 − 3·1) + (1·4 − 2·1)] = exp(6x)·(6 − 6 + 2) = 2exp(6x)

差在把三个余子式直接相加了（6 + 6 + 2 = 14）。这个错不影响该页的答案：课件随后没有除以 W，而是把方程组换成 u、v、w 直接解，特解 −x − 11/6 代回原方程是对的。但如果你用 W 走克拉默法则，分母必须是 2exp(6x)。

[教学归纳] 三阶以上别硬套二阶的两个公式。做法只有一条：列 n 条方程（前 n − 1 条把 C′ 项压成 0，最后一条代回原方程），再解这个 n 元一次方程组。

7. 补充例（课件 L9 p20–p24）：常系数 + 右端 exp(x)/x

题目：

y″ − 2y′ + y = exp(x)/x,　x ≠ 0

特征根 λ = 1 是二重根，基本解组 exp(x)、x·exp(x)，且

W(exp(x), x·exp(x)) = exp(2x)

设 y_p = C₁(x)exp(x) + C₂(x)·x·exp(x)。两条方程是

C₁′exp(x) + C₂′x·exp(x) = 0
C₁′exp(x) + C₂′(1 + x)exp(x) = exp(x)/x

两边同时除以 exp(x)（这一步让方程变得极简，是这道题的关键），得

C₁′ + C₂′x = 0
C₁′ + C₂′(1 + x) = 1/x

相减得 C₂′ = 1/x，回代得 C₁′ = −1。积分：

C₁ = −x,　C₂ = ln|x|
y_p = −x·exp(x) + x·ln|x|·exp(x) = x·exp(x)·(ln|x| − 1)

通解

y = c₁exp(x) + c₂x·exp(x) + x·exp(x)·ln|x|

这道题展示了两个细节：重根时 W 不是常数（这里是 exp(2x)），以及右端带 1/x 时答案里出现 ln|x|、区间要挖掉 x = 0。

8. 升到 n 阶：矩阵写法与"影响函数"

8.1 矩阵写法

把 n 个解按列排成矩阵，第 k 列是 y_k 及其各阶导数：

Y(x)：第 k 列 = (y_k, y_k′, …, y_k^(n−1))ᵀ

则附加条件与方程可以合并成一条

Y(x)·(C₁′, C₂′, …, Cₙ′)ᵀ = (0, 0, …, 0, f(x))ᵀ

因为 Y 可逆（它的行列式就是 n 阶朗斯基行列式，不为 0），

(C₁′, …, Cₙ′)ᵀ = Y⁻¹·(0, …, 0, f)ᵀ

积分再回代：

y_p = Σ_k C_k(x)·y_k(x)

n = 2 时它就退化成 §3 的两条公式。考试写三阶题时，用 §6 的"列方程 + 换元"通常比矩阵求逆快。

8.2 定积分形式与影响函数

[教学归纳] 这一小节把课件的 (14) 式改写成"一个核 + 一次积分"的样子，考试不要求背，但看懂它有助于理解整件事。

如果把 C_k 写成从 x₀ 到 x 的定积分（课件 (14) 式），再代回 y_p = C₁y₁ + C₂y₂，可以合并成一条：

y_p(x) = ∫(x₀→x) K(x, t)·f(t) dt,　K(x, t) = [y₁(t)y₂(x) − y₁(x)y₂(t)] / W(t)

K 叫影响函数（格林函数的一维版本）。它有两个好性质：

  • 在 t = x 处 K = 0，所以 y_p(x₀) = 0；对 x 求导时，边界项（取 t = x）等于 [y₁y₂′ − y₁′y₂]/W = 1，正好补出 f。合起来就是：这个 y_p 满足零初值 y_p(x₀) = y_p′(x₀) = 0。

  • 对 y″ + y = tan x，取 y₁ = cos、y₂ = sin、W = 1，得 K = sin(x − t)，于是

y_p(x) = ∫(0→x) sin(x − t)·tan t dt

它和 §4.5 的 −cos x·ln|sec x + tan x| 只差一个齐次解 sin x：§4.5 那个在 x = 0 处值为 0、导数为 −1，这个在 x = 0 处值与导数都是 0。两者都是合法特解。数值抽查：x = 1 时两边都等于 0.178957…（已用数值积分核对）。

9. 朗斯基行列式与 Abel 公式：两个配套工具

W 的三重身份：① 方程组的系数行列式；② 保证 C′ 唯一（W ≠ 0）；③ 通解公式的分母。

Abel 公式（课件 p50，附加材料）对 n 阶标准形 y^(n) + a₁y^(n−1) + … + aₙy = f 成立：

W(x) = W(x₀)·exp(−∫(x₀→x) a₁(t) dt)

用处有两个：

  1. 验算：算完 W 用它核对一遍，尤其 W 是长式子时；

  2. 已知一个解求第二个解：由 W = y₁y₂′ − y₁′y₂ 解出

(y₂/y₁)′ = W/y₁²

积分即得 y₂。课件 p51–p53 就是这样从 y₁ = x 得到 y₂ = x·exp(x/2) 的。

[教学归纳] Abel 公式顺手解释了一件事：W 要么恒为零、要么处处不为零（指数因子永不为零），所以"两个解线性无关"这件事在区间上不会变来变去。

10. 六条易错点

  1. 首项系数没归一化。公式里的 f 是 y″ + a₁y′ + a₂y = f 的 f。方程写成 2xy″ − … = 4x² 时，f = 2x，不是 4x²（例 2）。

  2. y₁、y₂ 的顺序与 W 不一致。C₁′ 配的是"另一个"解，而 W 按你写的顺序展开。三处必须同源，否则整体符号会翻。

  3. 分子用错解。C₁′ 的分子是 y₂，C₂′ 的分子是 y₁。写反了代回第一条式子就不为零。

  4. 积分常数。只求一个特解，取 0 最省事；若保留常数，A·y₁ + B·y₂ 本来就是齐次解，会与通解里的 c₁、c₂ 重复，必须合并（例 2 的 c₁x − 8x 合并成 c₅x 就是这种情况）。

  5. 定义区间。W = 0 的点、f 不连续的点都要挖掉。tan x 的题答案是 x ≠ π/2 + kπ，不是全体实数；exp(x)/x 的题要挖掉 x = 0。

  6. 二阶公式套三阶。C₁′ = −y₂f/W 只对 n = 2 成立；三阶要列三条方程（例 3）。

再加一条心态提醒 [教学归纳]：算出来的 y_p 里如果混着齐次解的成分（比如多出一个 sin x），不必惊慌 —— 它要么来自没取 0 的积分常数，要么是交叉项没消干净；代回原方程验一次就知道对不对。

11. 四步流程与三个检查

四步流程

步骤 动作 检查点
1 解齐次方程，写出 y₁、y₂ 两个解线性无关吗？W 算得出来吗？
2 算 W（能化简先化简） 与 Abel 公式对得上吗？
3 解 C₁′、C₂′（克拉默或换元） 代回两条方程都对吗？
4 积分、回代、合并常数、写区间 代回原方程等于 f 吗？

三个检查（考场 30 秒能做完）

  1. 把 y_p 代回原方程，左边是否等于 f(x)；

  2. 通解里独立常数的个数是否等于方程的阶数；

  3. 若题目给了初值，代进去看是否自洽。

12. 自检（先做，答案在后）

  1. 求 y″ + y = sec x 的通解。

  2. 求 y″ − y = exp(x) 的通解。做完想一下：这题用待定系数法会怎样？两种方法结果一致吗？

  3. 已知 x²y″ − 2xy′ + 2y = x³（x > 0）的齐次基本解组是 x 与 x²，求通解。

  4. 求 y‴ − y′ = 1 的通解（基本解组 1、exp(x)、exp(−x)）。

  5. 概念题：为什么 y″ + y = tan x 不能对待定系数法？若改取 y₁ = sin x、y₂ = cos x，C₁′、C₂′ 分别是多少？

自检答案

1. y₁ = cos x、y₂ = sin x、W = 1、f = sec x：

C₁′ = −sin x·sec x = −tan x,　C₂′ = cos x·sec x = 1
C₁ = ln|cos x|,　C₂ = x
y = c₁cos x + c₂sin x + x·sin x + cos x·ln|cos x|

2. y₁ = exp(x)、y₂ = exp(−x)、W = −2、f = exp(x)：

C₁′ = −exp(−x)·exp(x)/(−2) = 1/2,　C₂′ = exp(x)·exp(x)/(−2) = −exp(2x)/2
C₁ = x/2,　C₂ = −exp(2x)/4
y_p = (x/2)exp(x) − (1/4)exp(x)

−(1/4)exp(x) 本身是齐次解，可并进 c₁，所以最简特解取 y_p = (x/2)exp(x)。待定系数法在这里会遇到"共振"（右端 exp(x) 本身就是齐次解），必须设 x·A·exp(x)，算出来同样是 (x/2)exp(x)，两种方法一致。

3. y₁ = x、y₂ = x²、W = x²；先把方程除以 x² 得 f = x：

C₁′ = −x²·x/x² = −x,　C₂′ = x·x/x² = 1
C₁ = −x²/2,　C₂ = x
y_p = −x³/2 + x³ = x³/2,　y = c₁x + c₂x² + x³/2

4. y₁ = 1、y₂ = exp(x)、y₃ = exp(−x)，W = 2，f = 1：

C₁′ = −1,　C₂′ = exp(−x)/2,　C₃′ = exp(x)/2
y_p = −x + 1/2 − 1/2 = −x,　y = c₁ + c₂exp(x) + c₃exp(−x) − x

5. tan x 的导数序列 tan x、sec²x、2sec²x·tan x、… 永远回不到"多项式 × 指数 × 正余弦"张成的有限维空间里，待定系数法要求的那组有限个试探解不存在，所以设不出来。换序后 W = −1，

C₁′ = −cos x·tan x/(−1) = sin x,　C₂′ = sin x·tan x/(−1) = cos x − sec x

与 §4.6 的课件写法完全一致。
