## 四、参考答案（先做完再看）

### 课件原题

**A1 y = xp² − 2p³**（φ = p²，ψ = −2p³，p ≠ 0, 1）
- 求导：p = p² + (2px − 6p²)p′ ⟹ **p(1 − p) = (2px − 6p²)·dp/dx**。
- 取倒数：**dx/dp + 2x/(p−1) = 6p/(p−1)**（线性方程）。
- 积分因子 (p−1)²：d/dp[x(p−1)²] = 6p(p−1)，积分得 x(p−1)² = 2p³ − 3p² + C，即
  **x = C/(1−p)² + 2p + 1**；
- 参数形式通解：**x = C/(1−p)² + 2p + 1，y = xp² − 2p³ = Cp²/(1−p)² + p²**（与你截图完全一致）。
- p = 1 时 p(1−p) 与 (2px − 6p²) 同时退化，参数族在 p = 1 处失效，需单独代入检验有无直线解；p = 0 时 y′ = 0 ⟹ y = 常数，代入得 **y ≡ 0** 是解。

**A2 xy′² − y′ − y = 0**（φ = p²，ψ = −p，p ≠ 0, 1）
- p(1 − p) = (2px − 1)dp/dx ⟹ **dx/dp + 2x/(p−1) = 1/(p(p−1))**。
- **x = (p − ln p + C)/(p−1)²**，y = xp² − p（课件 p16 写作 (p − ln\|p\| + C)/(p−1)²）。
- 奇解：**p = 0 ⟹ y ≡ 0**；**p = 1 ⟹ y = x − 1**。

**A3 y′sin y′ + cos y′ − y = 0**（φ ≡ 0，ψ = p sin p + cos p）
- p = ψ′(p)·p′ ⟹ p = p cos p·p′，p ≠ 0 时 **dx/dp = cos p**。
- **x = sin p + C，y = p sin p + cos p**。

**A4 y = xp² + p − p³，y(0) = 0**（φ = p²，ψ = p − p³，p ≠ 0, 1）
- p(1 − p) = (2px + 1 − 3p²)dp/dx ⟹ **dx/dp + 2x/(p−1) = (3p² − 1)/(p(p−1))**。
- 积分因子 (1−p)²：**x = (ln\|p\| − p − 3p²/2 + p³ + C)/(1−p)²**，y = xp² + p − p³。
- 被除掉的两支：**p = 0 ⟹ y ≡ 0**、**p = 1 ⟹ y = x**，两者都过 (0, 0)。
- 参数族里过原点的是 **C = 3/2**（用 p = −1、x = 0 定出），即第三个解。

| 题 | 答案 |

## 五、方法要点（对应你截图里那张卡）

1. **识别**：先整理成 **y = φ(p)x + ψ(p)**（p = y′）。若系数 A(p) 可能为 0，先看 A(p) = 0 时是否有直线解或不可能条件。
2. **求导得线性方程**：p = φ(p) + [φ′(p)x + ψ′(p)]·dx/dp，两边除以 (p − φ(p))：
   **dx/dp + A(p)x = B(p)，其中 A(p) = −φ′(p)/(p − φ(p))，B(p) = ψ′(p)/(p − φ(p))**。
   （截图里写的是同一件事：dx/dp − [φ′/(p−φ)]x = ψ′/(p−φ)。**注意 A 的分子是 φ′，不是 1**。）
3. **解线性方程**：积分因子 μ = exp(∫A dp)。多数题里 μ 会化简成 1/(p−1)² 或 (1−p)² 这类；
   第 3 题（A(p) = 2/(p−1)）会得到 x = (C − 2p + 2ln p)/(1−p)² 这种带 ln 的形式，属于正常。
4. **还原**：y = φ(p)x(p) + ψ(p)，通解保留参数形式即可（一般不必消去 p）。
5. **补讨论**：① 所有被除掉的 p 值（p − φ(p) = 0、除以 p 或 p−1 处）逐个代回原方程，得奇解或排除；
   ② 检查 dx/dp ≠ 0 的局部与分母零点；③ 需要时再消参。
6. **一个顺手自检**：把候选参数解代回 **(p − φ)·x′ = φ′·x + ψ′**，成立即对。
   ⚠ 别用「dy/dp = p·dx/dp 对任意 C 成立」当判据：C 是方程定出的常数，不是自由参数，那样验会得出错误结论（我核验时就踩过这个坑）。
   ⚠ 另一个坑：把线性方程写成 dx/dp − φ′x/(p−φ) = ψ′/(p−φ) 之后，**别再用 (p−φ) 去乘回去比对**——φ′ 项会被重复计入，看起来像"不一致"，其实是把方程改了。

## 六、与 Cauchy–Euler 的关系

两者都靠"先识别类型"，但工具完全不同：
- **Cauchy–Euler**：**高阶线性**方程，用 x = eᵗ 化成常系数（另有试幂函数 y = xʳ 的指标方程）；
- **Lagrange / Clairaut**：**一阶、对 y′ 解不出**，用 p = y′ **参数化**，把一个非线性问题降成"关于 x 的一阶线性方程"。

两者放在一起复习时的共同动作：**看清未知函数是谁**——Cauchy–Euler 里换成 t 后未知函数仍是 y(t)；Lagrange 里未知函数换成了 x(p)。
