🎯 你的 8 大核心易错缺口与针对性修正清单

结合近期练习（含 I-2、Riccati/准齐次、Clairaut 等）的错因锚定

  1. 缺口 1【线性分式方程平移 vs 平行】：形如 $(2x-4y+6)dx + (x+y-3)dy = 0$，必须先算行列式 $\Delta = a_1 b_2 - a_2 b_1$。若 $\Delta \neq 0$，解交点 $(h,k)$ 平移消常数；若 $\Delta = 0$，直接整体换元 $z = a_1 x + b_1 y$，切忌硬解交点。
  2. 缺口 2【准齐次方程 vs Riccati 方程识别与变形】：如 $x^2 y' + xy + x^2 y^2 = 4$，两边除以 $x^2$ 是标准 Riccati 方程；同时赋值 $\deg(x)=1, \deg(y)=-1$ 时各项幂次相等（均为 $0$），故也是准齐次方程！令 $u = xy$（即 $y = u/x$），注意导数代换 $y' = \frac{x u' - u}{x^2}$，代入即化为可分离变量方程 $x u' + u^2 = 4$。
  3. 缺口 3【非恰当方程积分因子符号与分母】：求单变量积分因子时，务必分清：对 $x$ 仅依赖看 $\frac{M_y - N_x}{N} = \varphi(x)$（分母是 $N$！）；对 $y$ 仅依赖看 $\frac{N_x - M_y}{M} = \psi(y)$（分母是 $M$ 且分子反号！）。
  4. 缺口 4【Clairaut / Lagrange 求导后因式分解漏解】：如对 $y = xy' + \dots$ 求导化简出 $p'(x - p^2) = 0$ 时，严禁直接约去 $p'$ 或提公因式出错！必须分两支：① $p' = 0 \Rightarrow p = C$ 代回原方程得通解族；② $x - p^2 = 0$ 消去 $p$ 得包络奇解（Singular Solution）。
  5. 缺口 5【分离变量与同除丢奇解】：在分离变量除掉 $g(y)$ 或 Bernoulli 同除 $y^n$ 时，未单独检验 $g(y_0)=0$ 是否为常数解/奇解。
  6. 缺口 6【待定系数法共振重数 $k$ 漏判】：当非齐次项为 $e^{\lambda x}[P_m(x)\cos\omega x + Q_n(x)\sin\omega x]$ 时，要看 $\alpha = \lambda + i\omega$ 作为特征根的重数 $k$（而非实部 $\lambda$ 单独的重数），特解必须乘 $x^k$，且阶数取 $N = \max(m, n)$。
  7. 缺口 7【Euler 方程令 $x = e^t$ 后的二阶导替换错误】：记住算子公式 $x^2 y'' = D(D-1)y = \frac{d^2y}{dt^2} - \frac{dy}{dt}$，千万不要把 $x^2 y''$ 直接当成 $\frac{d^2y}{dt^2}$！
  8. 缺口 8【IVP 初值问题收尾时机】：必须在总通解 $y = y_h + y_p$ 全部拼装完毕后再代入初值 $y(x_0), y'(x_0)$ 定 $C_1, C_2$，绝对不能在只求出齐次解 $y_h$ 时就代初值！
Lecture 1

基本概念、几何意义（方向场）与可分离变量方程

1.1 基本概念与等倾线 (Isoclines)

  • 阶数 (Order)：方程中出现的未知函数最高阶导数的阶数。
  • 通解 vs 特解 vs 奇解：含 $n$ 个独立任意常数 $C_1,\dots,C_n$ 的解为通解；固定常数后的解为特解；不包含在通解中（无论常数取何值或极限都得不到）、且每一点都与通解族某曲线相切的解称为奇解（包络线）。
  • 方向场与等倾线：对于 $y' = f(x,y)$，令 $f(x,y) = k$（常数）得到的曲线族称为等倾线，积分曲线在穿过等倾线时切线斜率均为 $k$。平衡点（驻点）满足 $f(x,y)=0$。

1.2 可分离变量方程 (Separable Equations)

标准形式： $\frac{dy}{dx} = f(x)g(y)$ 或 $M_1(x)N_1(y)dx + M_2(x)N_2(y)dy = 0$

🔧 标准解题方法论 (SOP)
  1. Step 1先找常数零点解：令分母即将除过去的因式 $g(y) = 0$，解出根 $y = y_0$。直接检验 $y \equiv y_0$ 是否满足原方程。
  2. Step 2分离变量并积分：假设 $g(y) \neq 0$，写成 $\int \frac{1}{g(y)}dy = \int f(x)dx + C$。
  3. Step 3合并与吸收常数：若出现 $\ln|y| = H(x) + C$，化为 $y = \pm e^C e^{H(x)} = \tilde{C} e^{H(x)}$。检查当 $\tilde{C}=0$ 时是否能找回 Step 1 的常数解 $y=0$；若找不回，必须在最终答案旁显式并上 $y = y_0$。
Lecture 2

一阶线性微分方程与常数变易法

2.1 一阶线性方程标准形式与积分因子

标准形式： $$\frac{dy}{dx} + P(x)y = Q(x)$$

🔧 标准解题方法论 (SOP)
  1. Step 1化一：把 $y'$ 前面的系数除到右边和 $P(x)$ 上（注意讨论除数是否为 0 的点）。
  2. Step 2求积分因子：计算 $\mu(x) = \exp\left(\int P(x)dx\right)$（此处不定积分不加常数 $C$，且通常省去绝对值）。
  3. Step 3左端缩并全导数：两边同乘 $\mu(x)$，左端必精确缩并为 $\frac{d}{dx}\big[\mu(x)y\big] = \mu(x)Q(x)$。
  4. Step 4积分得通解：$$y(x) = \frac{1}{\mu(x)} \left( \int \mu(x)Q(x)dx + C \right)$$
💡 破局技巧：x 与 y 角色互换法
当方程对 $y$ 极其非线性（例如含 $e^y, \sin y, y^3$），但观察发现 $x$ 只出现了一次幂时，立刻把方程改写为关于 $x(y)$ 的一阶线性方程： $$\frac{dx}{dy} + P(y)x = Q(y)$$ 用完全相同的公式对 $y$ 求积分因子 $\mu(y) = e^{\int P(y)dy}$，秒杀原题！
Lecture 3

齐次方程、可化为齐次（线性分式）与准齐次方程

3.1 标准齐次方程 (Homogeneous ODE)

判别特征： $M(x,y)dx + N(x,y)dy = 0$ 中 $M, N$ 是同次齐次函数（即 $M(tx,ty) = t^k M(x,y)$），或者能改写为 $y' = \varphi\left(\frac{y}{x}\right)$。

🔧 标准解题方法论 (SOP)
  1. 令 $u = \frac{y}{x}$，即 $y = ux$。
  2. 核心导数代换： $\frac{dy}{dx} = u + x\frac{du}{dx}$（微分形式：$dy = u\,dx + x\,du$）。
  3. 代入原方程化为可分离变量方程：$x\frac{du}{dx} = \varphi(u) - u \implies \int \frac{du}{\varphi(u)-u} = \int \frac{dx}{x} = \ln|x| + C$。
  4. 防漏解检查：若存在常数 $u_0$ 使 $\varphi(u_0) - u_0 = 0$，则直线 $y = u_0 x$ 是需要单独检验的解！回代 $u = y/x$ 完成求解。

3.2 可化为齐次的方程（线性分式方程 —— 你的练习 I-2 题型）

标准形式： $$\frac{dy}{dx} = f\left(\frac{a_1 x + b_1 y + c_1}{a_2 x + b_2 y + c_2}\right) \quad \text{或} \quad (a_1 x + b_1 y + c_1)dx + (a_2 x + b_2 y + c_2)dy = 0$$

🔧 双分支解题方法论 (SOP)

先计算系数行列式 $\Delta = \begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} = a_1 b_2 - a_2 b_1$：

  • 情形 A：$\Delta \neq 0$（两直线相交，如 $(2x-4y+6)dx + (x+y-3)dy = 0$）
    1. 联立线性方程组 $\begin{cases} a_1 h + b_1 k + c_1 = 0 \\ a_2 h + b_2 k + c_2 = 0 \end{cases}$ 解出交点 $(h, k)$（上例中 $(h,k)=(1,2)$）。
    2. 作平移变换 $\begin{cases} x = X + h \\ y = Y + k \end{cases}$，此时 $dx = dX, dy = dY$，常数项自动清零！
    3. 方程化为关于 $(X,Y)$ 的标准齐次方程 $(a_1 X + b_1 Y)dX + (a_2 X + b_2 Y)dY = 0$，再令 $Y = uX$ 求解，最后将 $X = x-h, Y = y-k$ 代回。
  • 情形 B：$\Delta = 0$（两直线平行，成比例 $\frac{a_1}{a_2} = \frac{b_1}{b_2}$）
    1. 无需平移（也无交点），直接令公共线性组合 $z = a_1 x + b_1 y$。
    2. 求导得 $\frac{dz}{dx} = a_1 + b_1 \frac{dy}{dx}$，代入原方程直接变成关于 $(x, z)$ 的可分离变量方程！

3.3 准齐次方程 (Quasi-Homogeneous / Isobaric Equations)

判别特征（物理量纲/标度不变性法）：赋权 $\deg(x) = 1, \deg(y) = \alpha$，则微分权数满足 $\deg(dx) = 1, \deg(dy) = \alpha, \deg(y') = \alpha - 1$。如果存在实数 $\alpha$ 使得方程中每一项的总权数完全相等，则为准齐次方程。

🔧 经典实例复盘：$x^2 y' + xy + x^2 y^2 = 4$
  • 权数检验：令 $\deg(x)=1, \deg(y)=\alpha$。四项的权数分别为： $$\deg(x^2 y') = 2 + (\alpha - 1) = \alpha + 1, \quad \deg(xy) = 1 + \alpha, \quad \deg(x^2 y^2) = 2 + 2\alpha, \quad \deg(4) = 0$$ 令 $\alpha + 1 = 2 + 2\alpha = 0 \implies \alpha = -1$！各项权数全为 $0$，完美匹配准齐次！
  • 标准换元：因为 $\deg(y) = -1$，说明 $x^1 y^1$ 是无量纲不变量（权数为 $1 + (-1) = 0$）。故直接令： $$u = xy \implies y = \frac{u}{x}, \quad y' = \frac{x u' - u}{x^2}$$
  • 化简求解：代入原方程： $$x^2 \left(\frac{x u' - u}{x^2}\right) + u + u^2 = 4 \implies x u' - u + u + u^2 = 4 \implies x \frac{du}{dx} = 4 - u^2$$ 瞬间退化为可分离变量方程！部分分式积分得 $\frac{1}{4}\ln\left|\frac{2+u}{2-u}\right| = \ln|x| + C$（并检查 $u = \pm 2 \Rightarrow y = \pm \frac{2}{x}$）。
Lecture 4

Bernoulli 方程与 Riccati 方程

4.1 Bernoulli 方程

标准形式： $$\frac{dy}{dx} + P(x)y = Q(x)y^n \quad (n \neq 0, 1)$$

🔧 标准解题方法论 (SOP)
  1. Step 1若 $n > 0$，先写下显然解 $y \equiv 0$。
  2. Step 2两边同除以 $y^n$：$$y^{-n}\frac{dy}{dx} + P(x)y^{1-n} = Q(x)$$
  3. Step 3令新变量 $z = y^{1-n}$，求导得 $\frac{dz}{dx} = (1-n)y^{-n}\frac{dy}{dx}$。
  4. Step 4代入化为关于 $z$ 的一阶线性方程： $$\frac{dz}{dx} + (1-n)P(x)z = (1-n)Q(x)$$ 用一阶线性公式解出 $z(x)$，再回代 $y^{1-n} = z(x)$。

4.2 Riccati 方程 (黎卡提方程)

标准形式： $$\frac{dy}{dx} = P(x)y^2 + Q(x)y + R(x) \quad (P(x) \not\equiv 0)$$

与准齐次的区别：Riccati 方程要求关于未知函数 $y$ 是严格的二次多项式（含 $y^2, y^1, y^0$），对 $x$ 的系数形式不限；而准齐次方程要求对 $(x, y)$ 满足幂次标度对称。有些方程（如 $y' = -\frac{1}{x}y - y^2 + \frac{4}{x^2}$）既是 Riccati 方程，又是准齐次方程！

🔧 标准解题方法论 (SOP)
  1. Step 1寻找一个特解 $y_1(x)$：题目通常会直接给出，或通过观察系数之和（如 $P+Q+R=0 \Rightarrow y_1=1$）、幂函数试探 $y_1 = c x^m$ 找到一个特解（例如 $x^2y'+xy+x^2y^2=4$ 可试出 $y_1 = \frac{2}{x}$）。
  2. Step 2平移换元（推荐直接化线性）：令 $$y(x) = y_1(x) + \frac{1}{z(x)} \implies y' = y_1' - \frac{z'}{z^2}$$ （或者先令 $y = y_1 + u$ 化为 Bernoulli 方程 $u' - (2P y_1 + Q)u = P u^2$，再令 $z = u^{-1}$）。
  3. Step 3求解关于 $z(x)$ 的一阶线性方程： $$z' + \big[2P(x)y_1(x) + Q(x)\big]z = -P(x)$$ 解出 $z(x)$ 后代回 $y = y_1 + \frac{1}{z}$。
Lecture 5

恰当方程与非恰当方程的积分因子 (Integrating Factors)

5.1 恰当微分方程 (Exact Equations)

判别充要条件：在单连通区域上，$M(x,y)dx + N(x,y)dy = 0$ 是恰当方程 $\iff$ $$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$

🔧 势函数 $\Phi(x,y) = C$ 求解三法
  • 方法 1（偏积分 + 对 y 求导待定法 —— 最稳健）： $$\Phi(x,y) = \int M(x,y)dx + \varphi(y)$$ 然后对 $y$ 求偏导令 $\frac{\partial \Phi}{\partial y} = N(x,y)$，求出 $\varphi'(y)$（此时所有含 $x$ 的项必完全抵消，若没抵消说明前面算错！），积分得 $\varphi(y)$，通解为 $\Phi(x,y) = C$。
  • 方法 2（分组凑全微分法 —— 最快）：熟记五大黄金微分组合： $$\begin{aligned} x\,dy + y\,dx &= d(xy), & \frac{x\,dy - y\,dx}{x^2} &= d\left(\frac{y}{x}\right), & \frac{y\,dx - x\,dy}{y^2} &= d\left(\frac{x}{y}\right) \\ \frac{x\,dx + y\,dy}{x^2+y^2} &= \frac{1}{2}d\ln(x^2+y^2), & \frac{x\,dy - y\,dx}{x^2+y^2} &= d\left(\arctan\frac{y}{x}\right) \end{aligned}$$
  • 方法 3（折线积分公式）： $\Phi(x,y) = \int_{x_0}^x M(t, y)dt + \int_{y_0}^y N(x_0, s)ds = C$。

5.2 非恰当方程：如何系统寻找积分因子 $\mu(x,y)$？

当 $\frac{\partial M}{\partial y} \neq \frac{\partial N}{\partial x}$ 时，先算差值 $\Delta = \frac{\partial M}{\partial y} - \frac{\partial N}{\partial x}$：

试探方向 判别准则（看比值是否消去另一变量） 积分因子公式 $\mu$
仅依赖 $x$：$\mu = \mu(x)$ $\frac{1}{N}\left(\frac{\partial M}{\partial y} - \frac{\partial N}{\partial x}\right) = \varphi(x)$（仅含 $x$） $\mu(x) = \exp\left(\int \varphi(x)dx\right)$
仅依赖 $y$：$\mu = \mu(y)$ $\frac{1}{M}\left(\frac{\partial N}{\partial x} - \frac{\partial M}{\partial y}\right) = \psi(y)$（仅含 $y$，注意分子反号或加负号） $\mu(y) = \exp\left(\int \psi(y)dy\right)$
齐次方程型 $M, N$ 同次齐次，且 $xM + yN \neq 0$ $\mu(x,y) = \frac{1}{xM(x,y) + yN(x,y)}$
形如 $yf(xy)dx + xg(xy)dy = 0$ 系数括号内仅含乘积 $xy$，且 $f(xy) \neq g(xy)$ $\mu(x,y) = \frac{1}{xM - yN} = \frac{1}{xy[f(xy) - g(xy)]}$
幂乘积试探 $\mu = x^\alpha y^\beta$ 多项式型 $M, N$，前几种均失效时 乘上 $x^\alpha y^\beta$ 后令 $\frac{\partial(\mu M)}{\partial y} \equiv \frac{\partial(\mu N)}{\partial x}$ 比较系数解出 $\alpha, \beta$
Lecture 6

一阶隐式方程：可解出 $y/x$、Lagrange 与 Clairaut 方程

6.1 统一引入参数 $p = \frac{dy}{dx}$ 的微分关系

在一阶隐式方程 $F(x, y, y') = 0$ 中，永远令 $p = y'$，并利用基本全微分恒等式： $$dy = p\,dx$$

  • 可解出 $y$ 型 $y = f(x, p)$：两边对 $x$ 求导得 $p = \frac{\partial f}{\partial x} + \frac{\partial f}{\partial p}\frac{dp}{dx}$，化为关于 $(x, p)$ 的一阶方程。
  • 可解出 $x$ 型 $x = f(y, p)$：两边对 $y$ 求导得 $\frac{1}{p} = \frac{\partial f}{\partial y} + \frac{\partial f}{\partial p}\frac{dp}{dy}$，化为关于 $(y, p)$ 的一阶方程。

6.2 Clairaut 方程 (克莱罗方程) —— 必考通解与包络奇解

标准形式： $$y = x y' + \psi(y') \quad \text{即} \quad y = xp + \psi(p)$$

🔧 标准解题方法论 (SOP)
  1. Step 1两边对 $x$ 求导： $$p = p + x p' + \psi'(p)p' \implies p'\big[x + \psi'(p)\big] = 0$$
  2. Step 2分支一（通解族 —— 直线族）：令 $p' = 0 \implies p = C$，直接把 $y' = C$ 代回原方程（无需任何积分！）得通解： $$y = Cx + \psi(C)$$
  3. Step 3分支二（奇解 —— 包络线）：令 $x + \psi'(p) = 0$，得到参数形式奇解： $$\begin{cases} x = -\psi'(p) \\ y = -p\psi'(p) + \psi(p) \end{cases}$$ 若能从中消去参数 $p$，即得显式奇解（如在 $p'(x - p^2) = 0$ 中，由 $x = p^2$ 消去 $p$）。
🚨 你的历史错题警示：提公因式切勿漏项或错配！
当你在对隐式方程求导整理出 $x p' - p^2 p' = 0$ 时，提取公因式 $p'$ 得到的是 $p'(x - p^2) = 0$，务必逐项核对，绝对不能直接把 $p'$ 约掉，否则会直接丢掉通解或丢掉奇解！

6.3 Lagrange 方程 (拉格朗日方程)

标准形式： $y = x\varphi(p) + \psi(p)$ （当 $\varphi(p) \equiv p$ 时即退化为 Clairaut 方程）。

解法：对 $x$ 求导得 $p = \varphi(p) + [x\varphi'(p) + \psi'(p)]\frac{dp}{dx}$。先讨论满足 $\varphi(p_0) = p_0$ 的常数根（给出直线解 $y = x\varphi(p_0) + \psi(p_0)$）；再当 $\varphi(p) \neq p$ 时，颠倒变量视为 $x$ 关于 $p$ 的一阶线性微分方程： $$\frac{dx}{dp} - \frac{\varphi'(p)}{p - \varphi(p)}x = \frac{\psi'(p)}{p - \varphi(p)}$$

Lecture 7

初值问题解的存在唯一性定理 (Picard) 与奇解判别

7.1 Peano 存在定理与 Picard-Lindelöf 存在唯一性定理

定理名称 条件要求（矩形邻域 $R: |x-x_0|\le a, |y-y_0|\le b$） 结论
Peano 存在定理 $f(x,y)$ 在 $R$ 上连续 初值问题 $y'=f(x,y), y(x_0)=y_0$ 在 $|x-x_0|\le h$ 上至少存在一个解（不一定唯一）
Picard 存在唯一性定理 $f(x,y)$ 在 $R$ 上连续，且对 $y$ 满足 Lipschitz 条件（在考题中通常检验偏导数 $\frac{\partial f}{\partial y}$ 连续有界） 在局部区间 $|x-x_0|\le h$ 上存在唯一解，其中 $h = \min\left(a, \frac{b}{M}\right), M = \max_R |f(x,y)|$

7.2 奇解的两种求法：$p$-判别法 vs $c$-判别法

  • 从微分方程直接找（$p$-判别曲线）：联立 $\begin{cases} F(x, y, p) = 0 \\ \frac{\partial F}{\partial p}(x, y, p) = 0 \end{cases}$ 消去 $p$ 得到 $p$-判别曲线，再代回原方程验证它是否真的是解（因为 $p$-判别曲线还可能包含尖点轨迹或重点轨迹）。
  • 从通解族找包络（$c$-判别曲线）：联立 $\begin{cases} \Phi(x, y, C) = 0 \\ \frac{\partial \Phi}{\partial C}(x, y, C) = 0 \end{cases}$ 消去参数 $C$。
Lecture 8

高阶可降阶方程 & 高阶线性微分方程通解结构

8.1 三类可降阶的高阶非线性方程

🔧 三大降阶模板（必背代换）
  1. 直接积分型 $y^{(n)} = f(x)$：连续对 $x$ 积分 $n$ 次，每积分一次加一个常数。
  2. 不显含未知函数 $y$ 型 $F(x, y', y'') = 0$： $$令 \ p = y' \implies y'' = \frac{dp}{dx} = p'$$ 化为关于 $(x, p)$ 的一阶方程。
  3. 不显含自变量 $x$ 型（自治方程）$F(y, y', y'') = 0$： $$令 \ p = y' \implies y'' = \frac{dp}{dx} = \frac{dp}{dy}\frac{dy}{dx} = p\frac{dp}{dy}$$ 化为关于 $(y, p)$ 的一阶方程！【易错警报】千万不能写成 $y'' = \frac{dp}{dy}$，且若两边消去因子 $p$，务必检验 $p=0 \Rightarrow y \equiv C$ 是否为解！

8.2 高阶线性方程的叠加原理与解空间结构

  • 齐次线性方程 $L[y] = y^{(n)} + a_1(x)y^{(n-1)} + \dots + a_n(x)y = 0$：所有解构成一个 $n$ 维线性空间，若 $y_1, \dots, y_n$ 线性无关（基本解组），则通解为 $y_h = C_1 y_1 + \dots + C_n y_n$。
  • 非齐次线性方程 $L[y] = f(x)$：通解 = 对应齐次通解 + 非齐次一个特解，即 $y = y_h + y_p$。
  • 解的差性质（考题常考）：若 $Y_1, Y_2$ 是非齐次方程 $L[y]=f(x)$ 的两个解，则 $Y_1 - Y_2$ 必是对应齐次方程 $L[y]=0$ 的解！
Lecture 9

函数组线性无关、Wronskian 行列式与 Liouville 公式

9.1 Wronskian 行列式 (朗斯基行列式)

对于 $n$ 个函数 $y_1(x), \dots, y_n(x)$，定义： $$W(x) = W[y_1, \dots, y_n](x) = \begin{vmatrix} y_1 & y_2 & \cdots & y_n \\ y_1' & y_2' & \cdots & y_n' \\ \vdots & \vdots & \ddots & \vdots \\ y_1^{(n-1)} & y_2^{(n-1)} & \cdots & y_n^{(n-1)} \end{vmatrix}$$

  • 重要定理：若 $y_1, \dots, y_n$ 是齐次线性方程 $L[y]=0$（系数连续）在区间 $I$ 上的解，则 $W(x)$ 在 $I$ 上要么处处不为零（此时线性无关），要么恒等于零（此时线性相关），绝无可能只在某些点为零而在另一些点不为零！

9.2 Abel-Liouville 公式 (刘维尔公式)

对于标准形式（最高阶导数系数化为 1）的 $n$ 阶齐次线性方程 $y^{(n)} + a_1(x)y^{(n-1)} + \dots + a_n(x)y = 0$，其任意 $n$ 个解的 Wronskian 行列式满足： $$W(x) = W(x_0) \exp\left( -\int_{x_0}^x a_1(t)\,dt \right)$$ 对于二阶方程 $y'' + P(x)y' + Q(x)y = 0$，即： $$W(x) = y_1 y_2' - y_1' y_2 = C \cdot e^{-\int P(x)dx}$$

Lecture 10

已知一解降阶法 (Reduction of Order) & 常系数齐次特征根法

10.1 二阶变系数方程已知一个非零齐次解 $y_1(x)$ 求第二线性无关解 $y_2(x)$

方程： $y'' + P(x)y' + Q(x)y = 0$（注意：必须先把 $y''$ 系数化为 1！）

🔧 两种等价秒杀法
  • 方法 A（Liouville 公式直接代公式 —— 最快）： $$y_2(x) = y_1(x) \int \frac{e^{-\int P(x)dx}}{y_1^2(x)}\,dx$$
  • 方法 B（代换法 $y = y_1(x) u(x)$ —— 最通用，也适用于非齐次方程）： 将 $y = y_1 u$ 代入原方程，所有不含 $u'$ 的项必自动抵消为 0，化为关于 $v = u'$ 的一阶线性方程： $$y_1 u'' + (2y_1' + P y_1)u' = 0$$

10.2 常系数齐次线性方程：特征根分类全表

对 $y^{(n)} + a_1 y^{(n-1)} + \dots + a_n y = 0$，写特征多项式 $P(\lambda) = \lambda^n + a_1 \lambda^{n-1} + \dots + a_n = 0$：

特征根 $\lambda$ 的类型 重数 对应的实值线性无关基本解
单实根 $\lambda = r$ $1$ $e^{rx}$
$k$ 重实根 $\lambda = r$ $k$ $e^{rx}, \; x e^{rx}, \; x^2 e^{rx}, \; \dots, \; x^{k-1}e^{rx}$
一对单共轭复根 $\lambda = \alpha \pm i\beta$ $1$ $e^{\alpha x}\cos(\beta x), \; e^{\alpha x}\sin(\beta x)$
$k$ 重共轭复根 $\lambda = \alpha \pm i\beta$ $k$ $x^j e^{\alpha x}\cos(\beta x), \; x^j e^{\alpha x}\sin(\beta x) \quad (j = 0, 1, \dots, k-1)$
Lecture 11

常系数非齐次线性方程：待定系数法（共振重数）与微分算子法

11.1 待定系数法 (Method of Undetermined Coefficients)

针对非齐次项 $f(x)$ 的两种标准结构，先提取特征参数，对比特征多项式 $P(\lambda) = 0$ 的根：

非齐次项 $f(x)$ 的形式 判别复数 $\gamma$ 特解 $y_p(x)$ 的标准设法（其中 $k$ 为 $\gamma$ 作为特征根的重数，不是根则 $k=0$）
I 型： $e^{\lambda x} P_m(x)$ $\gamma = \lambda$ $$y_p(x) = x^k Q_m(x) e^{\lambda x}$$（$Q_m$ 为含全部 0 到 $m$ 次项的完整待定多项式）
II 型： $e^{\lambda x}\big[P_m(x)\cos\omega x + R_n(x)\sin\omega x\big]$ $\gamma = \lambda + i\omega$ $$y_p(x) = x^k e^{\lambda x}\big[A_N(x)\cos\omega x + B_N(x)\sin\omega x\big]$$其中 $N = \max(m, n)$，即便原题只含 $\cos$ 或只含 $\sin$，$y_p$ 也必须同时设出 $\cos$ 和 $\sin$ 两项！
⚡ 微分算子逆算子秒杀法（避免解大型线性方程组）
记 $D = \frac{d}{dx}$，方程写为 $P(D)y = f(x)$，特解 $y_p = \frac{1}{P(D)}f(x)$：
  • 移位定理（最核心）： $\frac{1}{P(D)}\big[e^{\lambda x} V(x)\big] = e^{\lambda x} \frac{1}{P(D + \lambda)} V(x)$。
  • 指数输入 ($P(\lambda)\neq 0$)： $\frac{1}{P(D)} e^{\lambda x} = \frac{1}{P(\lambda)} e^{\lambda x}$；若 $P(D) = (D-\lambda)^k Q(D)$ 且 $Q(\lambda)\neq 0$，则 $\frac{1}{P(D)}e^{\lambda x} = \frac{x^k}{k! Q(\lambda)} e^{\lambda x}$！
  • 正余弦输入：把 $D^2$ 替换为 $-\omega^2$，即 $\frac{1}{\Phi(D^2)}\cos(\omega x) = \frac{1}{\Phi(-\omega^2)}\cos(\omega x)$（分母不为 0 时）。
Lecture 12

高阶常数变易法 (Variation of Parameters) 与 Euler-Cauchy 方程

12.1 二阶常数变易法（适用于含 $\sec x, \tan x, \ln x, e^x/x$ 等非待定系数题型）

对于已将最高阶系数化为 1 的方程 $y'' + P(x)y' + Q(x)y = f(x)$，设齐次基本解组为 $y_1(x), y_2(x)$：

🔧 标准解题方法论 (SOP)
  1. 设特解为 $y_p(x) = C_1(x)y_1(x) + C_2(x)y_2(x)$。
  2. 列线性方程组： $$\begin{cases} C_1'(x)y_1(x) + C_2'(x)y_2(x) = 0 \\ C_1'(x)y_1'(x) + C_2'(x)y_2'(x) = f(x) \end{cases}$$
  3. 由 Cramer 法则直接写出公式（其中 $W(x) = y_1 y_2' - y_1' y_2$）： $$C_1'(x) = -\frac{y_2(x)f(x)}{W(x)}, \qquad C_2'(x) = \frac{y_1(x)f(x)}{W(x)}$$
  4. 积分得特解： $$y_p(x) = -y_1(x)\int \frac{y_2(x)f(x)}{W(x)}dx + y_2(x)\int \frac{y_1(x)f(x)}{W(x)}dx$$

12.2 Euler-Cauchy 方程 (欧拉方程)

标准形式： $x^n y^{(n)} + a_1 x^{n-1} y^{(n-1)} + \dots + a_{n-1} x y' + a_n y = f(x) \quad (x > 0)$

🔧 两种标准解法
  • 方法 1：指数换元法（推荐非齐次 Euler 方程） 令 $x = e^t$（即 $t = \ln x$，若 $x<0$ 则令 $x = -e^t$），记微分算子 $\vartheta = \frac{d}{dt} = x\frac{d}{dx}$，则： $$\begin{aligned} x y' &= \vartheta y = \frac{dy}{dt} \\ x^2 y'' &= \vartheta(\vartheta - 1)y = \frac{d^2y}{dt^2} - \frac{dy}{dt} \\ x^3 y''' &= \vartheta(\vartheta - 1)(\vartheta - 2)y = \frac{d^3y}{dt^3} - 3\frac{d^2y}{dt^2} + 2\frac{dy}{dt} \end{aligned}$$ 代入后原方程直接变成关于 $t$ 的常系数线性微分方程！解出 $y(t)$ 后将 $t = \ln|x|$ 代回。
  • 方法 2：幂函数试探法（推荐齐次 Euler 方程） 令 $y = x^r$，代入齐次欧拉方程得指标方程（特征方程）： $$r(r-1)\cdots(r-n+1) + a_1 r(r-1)\cdots(r-n+2) + \dots + a_n = 0$$
    • 单实根 $r$：对应解 $x^r$
    • $k$ 重实根 $r$：对应解 $x^r, \; x^r \ln|x|, \; x^r (\ln|x|)^2, \dots, x^r (\ln|x|)^{k-1}$
    • 共轭复根 $r = \alpha \pm i\beta$：对应解 $x^\alpha \cos(\beta \ln|x|), \; x^\alpha \sin(\beta \ln|x|)$
