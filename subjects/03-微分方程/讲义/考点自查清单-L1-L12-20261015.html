漏掉的考点课件出处漏了什么具体是什么
乘积分因子后可能失解 / 增解L4 p12、p14、p15失解：µ = (1−y)^(−2) 隐含 y ≠ 1，丢掉奇解 y ≡ 1；增解：乘 µ = y 解出 y(xy+1) = C，多出 y ≡ 0，须剔除 C = 0 支。讲义只讲了「分离变量除掉 g(y)」这一种丢解，没讲「乘 µ」这一大类。
伪解（spurious）与判伪法L5 p35–p36 ／ L2 p12、p34由 y′ = x+C 直接积分会得到含两个任意常数的式子，多出的 C₁ 是伪解，须代回原方程定出 C₁ = C²；一阶方程的通解只能含一个任意常数。另 L2 有两处「解出 y 后按初值剔除 ± 支」。讲义两处都没有。

解的定义域 / 存在区间 / 有限时间爆破L2 p19–p21 ／ L1 p27最大存在区间 x ∈ (0, 1+e^(−a))；x→0⁺ 时 y→0 但 0 不在定义域内；有限时间爆破 T(a) = 1+e^(−a)；L1 的 y′ = y², y(0) = 1 只在 x < 1 有解。讲义全文没有「定义域 / 存在区间」讨论（这也是 x = 0 奇点那条的同一族）
存在唯一性定理的课件版条件与两个反例L1 p24–p27课件版是 n 阶：f ∈ C(D) 且各 ∂f/∂yᵢ ∈ C(D)，解在 |x−x₀| < h（h 充分小）上唯一；两个反例：y′ = 3y^(2/3) 在 y₀ = 0 有无穷多解（含拼接解与「唯一性区域 x ≤ x₀」），y′ = y², y(0) = 1 只在 x < 1 有解。讲义给的是 Peano / Picard-Lindelöf 另一版（条件与 h = min(a, b/M) 不同），反例没有
