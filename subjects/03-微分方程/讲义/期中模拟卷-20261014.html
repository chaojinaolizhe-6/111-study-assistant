二、 逐题完整详解、评分标准与易错提醒

第一部分：快速识别与判别题（共 12 分）

I-1（3 分）

  • 题目：x y′ = y + √(x² + y²)　(x > 0)
  • 参考答案：
  • (a) 方程类型：一阶齐次微分方程（Homogeneous first-order DE）。因为当 x > 0 时，两边同除以 x 可化为 y′ = y/x + √(1 + (y/x)²)。
  • (b) 第一步关键换元：令 u = y/x（即 y = u x），求导代换 y′ = u + x u′（化为可分离变量方程 x u′ = √(1 + u²)）。
  • 评分标准：写对「齐次方程」得 1.5 分；写对换元 u = y/x 及 y′ = u + x u′ 得 1.5 分。
  • 易错提醒：别把 √(x² + y²) 误判为准齐次而去设不等权重的 α ≠ β；x² 与 y² 同在根号下相加，本身就锁死了权重比 β/α = 1。

I-2（3 分）

  • 题目：(2x − 4y + 6) dx + (x + y − 3) dy = 0
  • 参考答案：
  • (a) 方程类型：可化为齐次的一阶微分方程（Equation reducible to homogeneous form）。
  • (b) 第一步关键换元：联立线性方程组 2h − 4k + 6 = 0 与 h + k − 3 = 0，解得交点 (h, k) = (1, 2)。令平移变换 x = X + 1, y = Y + 2（则 dx = dX, dy = dY），原方程化为齐次方程 (2X − 4Y) dX + (X + Y) dY = 0。
  • 评分标准：写对「可化为齐次方程」得 1 分；列出交点方程组并解出 (1, 2) 得 1 分；写出平移变换 x = X + 1, y = Y + 2 得 1 分。
  • 易错提醒：先看两直线系数行列式 Δ = 2×1 − (−4)×1 = 6 ≠ 0，交点唯一存在，可以平移。若行列式为 0（两行系数成比例，两直线平行、无交点），则不能平移，此时改用整体换元 z = a₂x + b₂y（取其中一行的线性式，例如 z = x − 2y 这种），方程即化为可分离变量方程——注意不是笼统地令 z = x + y。

I-3（3 分）

  • 题目：x = y y′ + (y′)²
  • 参考答案：
  • (a) 方程类型：关于 x 可解的一阶隐式微分方程（Solvable for x），同时也是关于 x(y) 的 Lagrange 型方程。
  • (b) 第一步关键换元：令 p = y′ = dy/dx（p ≠ 0），则原方程为 x = y p + p²。两边对 y 求导（利用 dx/dy = 1/p），得： 1/p = p + (y + 2p)(dp/dy)，即 dy/dp + [p / (p² − 1)] y = −2p² / (p² − 1)（关于 y(p) 的一阶线性微分方程）。
  • 评分标准：写对「关于 x 可解（或 Lagrange 型）」得 1.5 分；写出令 p = y′ 并利用 dx/dy = 1/p 对 y 求导的关系式得 1.5 分。
  • 易错提醒：方程左边是 x 而不是 y，千万别当成 Clairaut 方程对 x 求导！左边是 x 时，标准动作是对 y 求导并用 dx/dy = 1/p。

I-4（3 分）

  • 题目：x³ y‴ − 3x² y″ + 6x y′ − 6y = 0　(x > 0)
  • 参考答案：
  • (a) 方程类型：三阶 Cauchy–Euler 方程（欧拉方程 / 等维线性方程）。
  • (b) 第一步关键换元：令 x = e^t（即 t = ln x），或直接试幂函数解 y = x^r，代入得指标方程（特征方程）： r(r − 1)(r − 2) − 3r(r − 1) + 6r − 6 = 0 ⟹ (r − 1)(r − 2)(r − 3) = 0。
  • 评分标准：写对「Cauchy–Euler 方程」得 1.5 分；写出换元 x = e^t 或试解 y = x^r 及其指标方程得 1.5 分。
  • 易错提醒：试 y = x^r 时，三阶导数带来的是 r(r − 1)(r − 2)，不是 r³！

第二部分：一阶微分方程求解（共 53 分）

第 1 题（8 分｜可分离变量 ＋ 常数解检查 ＋ 对数去绝对值收尾）

  • 题目：(y² − 4) cos x dx + 2y sin x dy = 0
  • 完整详解：
  • 分离变量前先查除数为零的常数解：
    要将方程两边同除以 (y² − 4) sin x，需先令 (y² − 4) sin x = 0：
    • 若 y² − 4 = 0 ⟹ y = 2 或 y = −2，此时 dy = 0，代入原方程得 0 + 0 = 0 恒成立，故 y = 2 与 y = −2 是常数解；
    • 若 sin x = 0 ⟹ x = kπ (k ∈ ℤ)，此时 dx = 0，代入原方程得 0 + 0 = 0 恒成立，故 x = kπ (k ∈ ℤ) 也是常数解。
  • 分离变量与积分（当 y ≠ ±2 且 sin x ≠ 0 时）：
    (cos x / sin x) dx + [2y / (y² − 4)] dy = 0
    两边积分：
    ∫ (1 / sin x) d(sin x) + ∫ [1 / (y² − 4)] d(y² − 4) = C₁
    ln|sin x| + ln|y² − 4| = C₁
  • 合并对数并吸收正负号：
    ln|(y² − 4) sin x| = C₁ ⟹ |(y² − 4) sin x| = e^(C₁) ⟹ (y² − 4) sin x = ±e^(C₁)。
  • 统一收尾：
    令任意实常数 C ∈ ℝ（允许 C = 0）：当 C = 0 时，(y² − 4) sin x = 0 恰好完整包含了 y = ±2 与 x = kπ 全部常数解。
    最终隐式通解：(y² − 4) sin x = C（其中 C 为任意实常数）。
  • 评分标准：
  • 分离变量前（或收尾时）明确检验 y = ±2 与 x = kπ 常数解（2 分）；
  • 正确分离变量并完成两边对数积分（3 分）；
  • 正确保留积分常数并化简出隐式解 (y² − 4) sin x = C（3 分）。
  • 易错提醒（针对你的历史记录）：
  • 你在定位卷 A1 曾漏写积分常数 C、漏检除式为零的常数解；在攻关卷第 2 题曾因嫌去绝对值麻烦而停笔。记住：两边都是 ln|⋯| 时，先合并成一个 ln|A·B| = C₁，再直接写成 A·B = C（用 C = 0 顺手收编常数解）是最干净的一步到位写法！

第 2 题（10 分｜Bernoulli 方程 ＋ 奇次三角积分 ∫cos³x dx ＋ 初值收尾）

  • 题目：y′ + (tan x) y = −y² cos²x,　y(0) = 1　(−π/2 < x < π/2)
  • 完整详解：
  • 识别类型与换元：
    右端含 y²（n = 2），属于 Bernoulli 方程。因初值 y(0) = 1 ≠ 0，在解的邻域内 y ≠ 0。
    两边同除以 y²：y^(−2) y′ + (tan x) y^(−1) = −cos²x。
    令 v = y^(1−2) = y^(−1) = 1/y，则 v′ = −y^(−2) y′。代入得关于 v(x) 的一阶线性微分方程：
    −v′ + (tan x) v = −cos²x ⟹ v′ − (tan x) v = cos²x。
  • 求积分因子：
    p(x) = −tan x，积分因子为：
    μ(x) = exp(∫ −tan x dx) = exp(ln cos x) = cos x（因 −π/2 < x < π/2，cos x > 0）。
  • 化为全导数并计算 ∫cos³x dx：
    方程两边同乘 cos x：
    cos x · v′ − (sin x) v = cos³x ⟹ d/dx (v cos x) = cos³x。
    两边对 x 积分（拆奇次幂 cos³x dx = (1 − sin²x) d(sin x)）：
    v cos x = ∫ cos³x dx = ∫ (1 − sin²x) d(sin x) = sin x − (sin³x)/3 + C。
  • 代入初值条件 y(0) = 1：
    由 y(0) = 1 得 v(0) = 1 / y(0) = 1。代入 x = 0：
    1 · cos 0 = sin 0 − 0 + C ⟹ C = 1。
    故 v cos x = 1 + sin x − (sin³x)/3 ⟹ v = [3 + 3 sin x − sin³x] / (3 cos x)。
  • 回代 y = 1/v：
    最终特解：y(x) = cos x / [1 + sin x − (sin³x)/3]（或写作 y(x) = 3 cos x / (3 + 3 sin x − sin³x)，定义域 −π/2 < x < π/2）。
  • 评分标准：
  • 识别出 Bernoulli 方程并正确设 v = 1/y 化为线性方程 v′ − (tan x)v = cos²x（3 分）；
  • 求出积分因子 μ(x) = cos x（2 分）；
  • 正确拆项算出 ∫cos³x dx = sin x − (sin³x)/3 + C（3 分）；
  • 代入初值算出 C = 1 并回代出 y(x)（2 分）。
  • 易错提醒：
  • v = 1/y 求导有负号 v′ = −y′/y²，代回时别漏变号（如果写成 v′ + (tan x)v，积分因子就会变成 sec x，右边变成 cos x 而算错）；
  • 积完 v 之后必须既代初值又倒数回代 y = 1/v，千万别把 v(x) 当作最终答案交卷！

第 3 题（10 分｜纯准齐次方程：加权次数求尺度 ＋ 换元分离 ＋ 特殊解检验）

  • 题目：x³ y′ = 2x² y + y² − x⁴　(x > 0)
  • 完整详解：
  • 识别类型与求权重比 λ = β/α：
    方程同时含 y¹、y² 与不含 y 的 −x⁴，既不是可分离变量、也不是线性或 Bernoulli 方程。检验准齐次（Quasi-Homogeneous）权重：
    设 x 的权重为 α，y 的权重为 β，则导数 y′ = dy/dx 的权重为 β − α。
    逐项写出方程各项的权重：
    • 左端 x³ y′：权重为 3α + (β − α) = 2α + β；
    • 右端第一项 2x² y：权重为 2α + β；
    • 右端第二项 y²：权重为 2β；
    • 右端第三项 −x⁴：权重为 4α。
      令各项权重相等：2α + β = 2β = 4α ⟹ β = 2α ⟹ λ = β/α = 2。
  • 做准齐次标准换元 y = x² u：
    令 y = x² u（即 u = y / x²），对 x 求导得 y′ = 2x u + x² u′。
    代入原方程：
    x³ (2x u + x² u′) = 2x² (x² u) + (x² u)² − x⁴
    2x⁴ u + x⁵ u′ = 2x⁴ u + x⁴ u² − x⁴
    两边消去 2x⁴ u，再同除以 x⁴（因 x > 0），x 的幂次整行约去，化为可分离变量方程：
    x u′ = u² − 1。
  • 检查常数解并分离变量积分：
    • 先看 u² − 1 = 0 ⟹ u = 1 或 u = −1，对应原方程的两个特解 y = x² 与 y = −x²。
    • 当 u ≠ ±1 时，分离变量：
      [1 / (u² − 1)] du = (1/x) dx ⟹ ½ ∫ [1/(u − 1) − 1/(u + 1)] du = ∫ (1/x) dx
      ½ ln|(u − 1)/(u + 1)| = ln x + C₁
  • 消去分数系数并回代 u = y/x²：
    两边同乘 2：ln|(u − 1)/(u + 1)| = 2 ln x + 2C₁ = ln(x²) + C₂
    去对数并用任意常数 C ∈ ℝ 吸收正负号：
    (u − 1)/(u + 1) = C x²
    将 u = y/x² 代回，分子分母同乘 x²：
    (y − x²) / (y + x²) = C x²（或显式解出 y = x² (1 + C x²) / (1 − C x²)）。
    • 检查特殊解：当 C = 0 时得 y = x²（已包含）；而 y = −x²（对应 u = −1，使分母 y + x² = 0）需单独补列（或把任意常数放到分子分母写作 y − x² = C x² (y + x²) 并补 y = −x²）。
  • 评分标准：
  • 正确列出各项权重并算出 λ = β/α = 2（3 分）；
  • 正确写出换元 y = x² u 与 y′ = 2xu + x² u′ 并化简至 x u′ = u² − 1（3 分）；
  • 正确完成部分分式积分、消掉 ½ 并回代 u = y/x²（3 分）；
  • 讨论 u = ±1（指出特解 y = ±x²）（1 分）。
  • 易错提醒：
  • 你在今晚攻关卷第 1 题曾把准齐次代换误写反；永远记住：既然 y 的权重是 x 的 λ 倍，那么 y 就与 x^λ 同量纲，所以必然是 y = x^λ u（验算标准：代进去后 x 必须能整行约光，若约不光立刻回头查 λ）！

第 4 题（9 分｜非恰当方程 ＋ 单变量积分因子 μ(y) ＋ 恰当方程求解）

  • 题目：(2x y³ + y) dx + (x² y² − x) dy = 0　(y ≠ 0)
  • 完整详解：
  • 检验是否恰当：
    记 M(x, y) = 2x y³ + y，N(x, y) = x² y² − x。
    计算交叉偏导数：
    ∂M/∂y = 6x y² + 1，∂N/∂x = 2x y² − 1。
    因 ∂M/∂y ≠ ∂N/∂x，原方程不是恰当微分方程。
  • 寻找单变量积分因子：
    计算差商：
    (∂N/∂x − ∂M/∂y) / M = (2x y² − 1 − 6x y² − 1) / (2x y³ + y) = −2(2x y² + 1) / [y(2x y² + 1)] = −2 / y。
    该商仅依赖于 y！故存在关于 y 的积分因子：
    μ(y) = exp(∫ (−2/y) dy) = exp(−2 ln|y|) = 1 / y²。
  • 同乘积分因子并求势函数（原函数）：
    原方程两边同乘 1/y²（y ≠ 0），化为恰当方程：
    (2x y + 1/y) dx + (x² − x/y²) dy = 0。
    求势函数 F(x, y)：
    F(x, y) = ∫ (2x y + 1/y) dx + φ(y) = x² y + x/y + φ(y)。
    对 y 求偏导并与新 N 比较：
    ∂F/∂y = x² − x/y² + φ′(y) = x² − x/y² ⟹ φ′(y) = 0 ⟹ φ(y) = 0。
  • 写出通解：
    隐式通解：x² y + x/y = C（或同乘 y 写作 x² y² + x = C y, y ≠ 0）。
  • 评分标准：
  • 算出 ∂M/∂y 与 ∂N/∂x 并判别非恰当（2 分）；
  • 算出 (∂N/∂x − ∂M/∂y)/M = −2/y 并求出积分因子 μ(y) = 1/y²（4 分）；
  • 求出势函数并写出隐式通解 x² y + x/y = C（3 分）。
  • 易错提醒：
  • 找 μ(y) 时，公式分子符号是 (∂N/∂x − ∂M/∂y) / M（或者记：乘上 μ(y) 后要求 ∂(μM)/∂y = ∂(μN)/∂x ⟹ M μ′ + μ M_y = μ N_x ⟹ μ′/μ = (N_x − M_y)/M，花 5 秒现推绝不会背反符号！）。

第 5 题（9 分｜Riccati 方程：观察法找幂函数特解 ＋ 化一阶线性求解）

  • 题目：x² y′ + x y + x² y² = 4　(x > 0)
  • 完整详解：
  • 化为标准形式并识别类型：
    两边同除以 x²（x > 0）：
    y′ + (1/x) y + y² = 4 / x²。
    这是 Riccati 方程，需先用观察法找出一个特解 y₁(x)。
  • 观察法试幂函数特解 y₁ = c x^n：
    观察各项幂次：当 n = −1（即 y₁ = c / x）时，y₁′ = −c / x²，(1/x)y₁ = c / x²，y₁² = c² / x²，全部与右端 4 / x² 同为 x^(−2) 次！
    将 y₁ = c / x 代入方程：
    −c/x² + c/x² + c²/x² = 4/x² ⟹ c² = 4 ⟹ c = ±2。
    取特解 y₁ = 2 / x。
  • 做 Riccati 标准换元 y = 2/x + 1/v：
    令 y = 2/x + 1/v，则 y′ = −2/x² − v′/v²。代入标准形式：
    (−2/x² − v′/v²) + (1/x)(2/x + 1/v) + (4/x² + 4/(xv) + 1/v²) = 4/x²
    整理消去 4/x² 与 ±2/x²：
    −v′/v² + 5/(x v) + 1/v² = 0
    两边同乘 −v²，得到关于 v(x) 的一阶线性微分方程：
    v′ − (5/x) v = 1。
  • 求解一阶线性方程并回代：
    积分因子 μ(x) = exp(∫ (−5/x) dx) = x^(−5)。
    两边同乘 x^(−5)：
    d/dx (x^(−5) v) = x^(−5) ⟹ x^(−5) v = −1/(4x⁴) + C ⟹ v = C x⁵ − x/4。
    代回 y = 2/x + 1/v：
    通解：y(x) = 2/x + 1 / (C x⁵ − x/4)（其中 C 为任意常数；当 C = 0 时即得另一特解 y = −2/x）。
    丢解检查（必补一句）：换元 y = y₁ + 1/v 把基准特解本身排除在外（它对应 v → ∞，任何有限常数 C 都取不到）。因此完整解集 ＝ 上式含 C 的一族 ＋ 特解 y = 2/x（y = −2/x 已含在 C = 0 里）。
  • 评分标准：
  • 化标准形并通过幂次平衡试出特解 y₁ = 2/x（或 −2/x）（3 分）；
  • 设 y = y₁ + 1/v 正确化简出一阶线性方程 v′ − (5/x)v = 1（3 分）；
  • 解出 v 并代回写出最终通解（3 分）。
  • 易错提醒：
  • 展开 (2/x + 1/v)² 时，交叉项是 2 · (2/x) · (1/v) = 4/(xv)，再加上一次项 (1/x)y 贡献的 1/(xv)，合起来是 5/(xv)，千万别漏加一次项里的 1/(xv)！（刚才程序符号验算专门校验了这一步。）

第 6 题（7 分｜Clairaut 方程：通解直线族 ＋ 奇解包络线）

  • 题目：y = x y′ − (y′)³ / 3　(x ≥ 0)
  • 完整详解：
  • 识别类型并引入参数 p = y′：
    方程形如 y = x y′ + φ(y′)，其中 φ(p) = −p³/3，属于 Clairaut 方程。
    令 p = y′ = dy/dx，原方程写为：
    y = x p − p³ / 3。
  • 两边对 x 求导并因式分解：
    对 x 求导（注意左边 dy/dx = p，右边对 x p 用乘积法则）：
    p = p + x p′ − p² p′
    两边消去 p 并提取 p′：
    p′ (x − p²) = 0。
  • 分两支求解：
    • 第一支（通解直线族）：令 p′ = 0 ⟹ p = C（C 为任意常数）。
      将 p = C 直接代回原方程，得通解：
      y = C x − C³ / 3（C ∈ ℝ）。
    • 第二支（奇解包络线）：令 x − p² = 0 ⟹ x = p²。
      将 x = p² 代入 y = x p − p³/3，得奇解的参数形式：
      x = p², y = p³ − p³/3 = (2/3) p³。
      消去参数 p（由 p = ±√x, x ≥ 0）：
      奇解：y = ±(2/3) x^(3/2)（或写作等价的隐式平方形式 9 y² = 4 x³，x ≥ 0）。
  • 评分标准：
  • 令 p = y′ 并对 x 求导得出 p′(x − p²) = 0（2 分）；
  • 由 p = C 写出通解 y = Cx − C³/3（2 分）；
  • 由 x = p² 消去参数 p 求出奇解 y = ±(2/3) x^(3/2) 或 9y² = 4x³（3 分）。
  • 易错提醒（对应今晚攻关卷第 4 题）：
  • 通解千万别写成 y = C₁ x + C₂！一阶微分方程的通解只能有 1 个独立任意常数 C，因为 p = C 是直接代回原方程 y = xp − p³/3，截距必须锁死为 −C³/3。

第 7 题（9 分｜高阶降阶法：不显含 x 的二阶方程 ＋ 初值问题）

  • 题目：y y″ − 2(y′)² = 0,　y(0) = 1,　y′(0) = 1　(y > 0)
  • 完整详解（提供两种等价解法，考场任选一种即可满分）：
  • 方法一（标准降阶法：令 p = y′, y″ = p dp/dy）：
    1. 因方程不显含自变量 x，令 y′ = p(y)，则 y″ = (dp/dy)(dy/dx) = p (dp/dy)。
    2. 代入原方程：y p (dp/dy) − 2p² = 0。
    3. 因 p(0) = y′(0) = 1 ≠ 0，在初值邻域内 p ≠ 0，同除以 y p 并分离变量：
      (1/p) dp = (2/y) dy ⟹ ln|p| = 2 ln y + C₁ ⟹ p = C₁ y²。
    4. 先代入初值 x = 0 时 y(0) = 1, p(0) = y′(0) = 1：
      1 = C₁ · 1² ⟹ C₁ = 1。
      故一阶方程为 y′ = dy/dx = y²。
    5. 再次分离变量积分：
      y^(−2) dy = dx ⟹ −1/y = x + C₂。
      代入 y(0) = 1 得 −1 = 0 + C₂ ⟹ C₂ = −1。
      解得 −1/y = x − 1 ⟹ 最终特解：y(x) = 1 / (1 − x)（定义域 x < 1）。
  • 方法二（凑商导数秒杀法）：
    1. 原方程两边同除以 y³（y > 0）：
      [y y″ − 2(y′)²] / y³ = 0 ⟹ d/dx (y′ / y²) = 0（或写成 (1/y)″ = 0！因为 (1/y)′ = −y′/y²，(1/y)″ = −(y″ y² − 2y(y′)²)/y⁴ = 0）。
    2. 直接积分：y′ / y² = C₁，以下同方法一第 4、5 步，立得 y(x) = 1 / (1 − x)。
  • 评分标准：
  • 正确写出 y″ = p dp/dy 换元（或除以 y³ 凑出 (y′/y²)′ = 0）（3 分）；
  • 第一次积分并结合初值求出 y′ = y²（3 分）；
  • 第二次积分并求出特解 y(x) = 1/(1 − x)（3 分）。
  • 易错提醒：
  • 如果用方法一，千万别把 y″ 写成 dp/dx（那样又回到含 x 和 y 三个变量的僵局），必须是 y″ = p · dp/dy！而且第一次积完 p = C₁ y² 后立刻代初值算 C₁，能省掉带着字母常数做第二次积分的麻烦。

第 8 题（8 分｜四阶常系数齐次：零根 ＋ 三重实根解组完整性）

  • 题目：y⁽⁴⁾ − 6y‴ + 12y″ − 8y′ = 0
  • 完整详解：
  • 写出特征方程：
    p(λ) = λ⁴ − 6λ³ + 12λ² − 8λ = 0。
  • 因式分解求全部特征根与重数：
    提取公因式 λ，括号内恰好是 (λ − 2)³ 的完全立方展开：
    λ (λ³ − 6λ² + 12λ − 8) = λ (λ − 2)³ = 0。
    故特征根为：
    • λ₁ = 0（单实根，m₁ = 1），贡献 1 个解：e^(0x) = 1；
    • λ₂ = λ₃ = λ₄ = 2（三重实根，m₂ = 3），贡献 3 个线性无关解：e^(2x), x e^(2x), x² e^(2x)。
  • 个数自检与写出通解：
    基本解组共 1 + 3 = 4 个线性无关解，等于方程阶数 n = 4 ✓。
    通解：y(x) = C₁ + (C₂ + C₃ x + C₄ x²) e^(2x)（其中 C₁, C₂, C₃, C₄ 为任意常数）。
  • 评分标准：
  • 写出特征方程并正确分解为 λ(λ − 2)³ = 0（3 分）；
  • 写出 λ = 0 对应的常数项 C₁（1 分）；
  • 完整写出三重根 λ = 2 的三项 (C₂ + C₃ x + C₄ x²) e^(2x)（4 分；若漏掉 x² e^(2x) 扣 3 分）。
  • 易错提醒（对应你的缺口 1）：
  • 看到三重根 m = 3，幂次 x^j 从 j = 0 到 m − 1 = 2，必须一路写到 x² e^(2x)！写完通解后务必手指点一下 C₁, C₂, C₃, C₄ 四个独立项是不是真的两两线性无关。

第 9 题（10 分｜常系数非齐次：二重特征根共振 s = 2 ＋ 初值收尾）

  • 题目：y″ − 2y′ + y = 2 + 6 e^x,　y(0) = 1,　y′(0) = 0
  • 完整详解：
  • 求对应齐次方程的通解：
    特征方程：λ² − 2λ + 1 = (λ − 1)² = 0 ⟹ λ = 1 为二重特征根（重数 m = 2）。
    齐次通解：y_h(x) = (C₁ + C₂ x) e^x。
  • 按叠加原理分拆右端并设定特解形式（关键：判断共振重数 s）：
    右端 f(x) = f₁(x) + f₂(x)，其中：
    • 第一部分 f₁(x) = 2 = 2 e^(0x)：指数 α₁ = 0 不是特征根（s₁ = 0），设 y_{p1} = A。代入 y″ − 2y′ + y = 2 立得 A = 2。
    • 第二部分 f₂(x) = 6 e^x：指数 α₂ = 1 恰好是特征方程的二重根（s₂ = 2）！
      为什么必须乘 x²？ 因为 e^x 和 x e^x 都已经是齐次解（代入左边都会变成 0），所以特解必须乘 x²，设为：
      y_{p2} = B x² e^x。
  • 代入求待定系数 B：
    对 y_{p2} = B x² e^x 求导：
    y_{p2}′ = B (x² + 2x) e^x，
    y_{p2}″ = B (x² + 4x + 2) e^x。
    代入 y″ − 2y′ + y = 6 e^x：
    B [(x² + 4x + 2) − 2(x² + 2x) + x²] e^x = 2B e^x = 6 e^x ⟹ B = 3。
    故 y_{p2} = 3 x² e^x，非齐次方程通解为：
    y(x) = 2 + (C₁ + C₂ x + 3x²) e^x。
  • 代入初值条件 y(0) = 1, y′(0) = 0：
    • 代入 y(0) = 1：2 + C₁ · 1 = 1 ⟹ C₁ = −1。
    • 求导 y′(x) = (C₂ + 6x) e^x + (C₁ + C₂ x + 3x²) e^x。
      代入 x = 0, C₁ = −1, y′(0) = 0：
      C₂ + C₁ = 0 ⟹ C₂ = −C₁ = 1。
      最终初值问题特解：y(x) = 2 + (3x² + x − 1) e^x。
  • 评分标准：
  • 求对齐次通解 y_h = (C₁ + C₂ x) e^x（2 分）；
  • 求出 y_{p1} = 2（1 分）；
  • 准确判断二重共振 s = 2、设出 y_{p2} = B x² e^x 并解出 B = 3（4 分）；
  • 在合并后的完整通解上代入两个初值解出 C₁ = −1, C₂ = 1（3 分）。
  • 易错提醒（对应你的缺口 5）：
  • 千万别一看到共振就条件反射只乘一个 x！乘 x^s 的幂次 s 等于 α 在特征方程里的重数：单根重合乘 x，二重根重合必须乘 x²！
  • 初值条件 y(0)=1, y′(0)=0 必须在加上特解 y_p 之后的完整通解上代入，绝不能只代进齐次解 y_h 里算 C₁, C₂！

第 10 题（8 分｜常系数非齐次：共轭复根 ＋ 三角函数待定系数法）

  • 题目：y″ + 2y′ + 5y = 10 cos x
  • 完整详解：
  • 求齐次通解：
    特征方程：λ² + 2λ + 5 = (λ + 1)² + 4 = 0 ⟹ λ = −1 ± 2i（共轭复根 α = −1, β = 2）。
    齐次通解：y_h(x) = e^(−x) (C₁ cos 2x + C₂ sin 2x)。
  • 设定非齐次特解 y_p：
    右端 f(x) = 10 cos x 对应特征数 ±i，不是特征方程的根（s = 0）。
    设特解为正余弦完整组合：
    y_p(x) = A cos x + B sin x。
  • 求导代入求 A, B：
    y_p′ = −A sin x + B cos x，y_p″ = −A cos x − B sin x。
    代入原方程：
    (−A cos x − B sin x) + 2(−A sin x + B cos x) + 5(A cos x + B sin x) = 10 cos x
    合并同类项：
    (4A + 2B) cos x + (−2A + 4B) sin x = 10 cos x。
    比较系数得线性方程组：
    4A + 2B = 10 且 −2A + 4B = 0 ⟹ A = 2B ⟹ 10B = 10 ⟹ B = 1, A = 2。
    故 y_p(x) = 2 cos x + sin x。
  • 写出通解：
    通解：y(x) = e^(−x) (C₁ cos 2x + C₂ sin 2x) + 2 cos x + sin x。
  • 评分标准：
  • 解出特征根 −1 ± 2i 并写出齐次通解 e^(−x)(C₁ cos 2x + C₂ sin 2x)（3 分）；
  • 设出 y_p = A cos x + B sin x（2 分）；
  • 正确解出 A = 2, B = 1 并写出完整通解（3 分）。
  • 易错提醒：
  • 右端哪怕只有 cos x 没有 sin x，因为方程里有一阶导数 2y′，求导后会产生 sin x，所以设 y_p 时必须把 A cos x + B sin x 成对写全，绝不能只设 A cos x！

附加部分：常系数线性方程组与矩阵指数（选做，共 20 分）

附加题 B1（10 分｜Lecture 14–15 常系数齐次线性系统初值问题）

  • 题目：Y′ = [[1, 2], [2, 1]] Y，Y(0) = [3, −1]^T
  • 完整详解：
  • 求特征值：det(A − λI) = (1 − λ)² − 4 = λ² − 2λ − 3 = (λ − 3)(λ + 1) = 0 ⟹ λ₁ = 3, λ₂ = −1。
  • 求特征向量：
    • 对 λ₁ = 3：[[-2, 2], [2, -2]] v₁ = 0 ⟹ v₁ = [1, 1]^T；
    • 对 λ₂ = −1：[[2, 2], [2, 2]] v₂ = 0 ⟹ v₂ = [1, −1]^T。
  • 写出通解并代初值：
    Y(x) = C₁ e^(3x) [1, 1]^T + C₂ e^(−x) [1, −1]^T。
    代入 x = 0：C₁ + C₂ = 3, C₁ − C₂ = −1 ⟹ C₁ = 1, C₂ = 2。
    最终特解：y₁(x) = e^(3x) + 2e^(−x)，y₂(x) = e^(3x) − 2e^(−x)。

附加题 B2（10 分｜Lecture 16–17 矩阵指数 Cayley–Hamilton 法）

  • 题目：求 A = [[0, 1], [−1, 2]] 的矩阵指数 e^(Ax) 及 Y′ = A Y 的通解。
  • 完整详解：
  • 特征多项式：p(λ) = det(A − λI) = λ(λ − 2) + 1 = (λ − 1)² = 0 ⟹ λ = 1（二重特征根）。
  • 用 Cayley–Hamilton 定理展开 e^(Ax)：
    对 2 阶矩阵，余式为 1 次多项式：e^(λx) = q(λ)(λ − 1)² + α₀(x) + α₁(x)(λ − 1)（或设为 β₀(x) + β₁(x)λ）。
    将二重根 λ = 1 代入原式及对 λ 的一阶导数式：
    • 代入 λ = 1：e^x = α₀(x)；
    • 对 λ 求导后代入 λ = 1：x e^x = α₁(x)。
      故由 Cayley–Hamilton 定理：
      e^(Ax) = e^x I + x e^x (A − I) = e^x ([[1, 0], [0, 1]] + x [[-1, 1], [-1, 1]]) = e^x [[1 − x, x], [−x, 1 + x]]。
  • 写出方程组通解：
    Y(x) = e^(Ax) C = e^x [C₁(1 − x) + C₂ x, −C₁ x + C₂(1 + x)]^T。
