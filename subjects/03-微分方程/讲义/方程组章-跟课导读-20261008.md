## 一、L13：Systems of ODEs（Chapter 5，W.Y., DLUT）

**本讲提纲（p2 原文）**：`1 Introduction to Systems of Differential Equations　2 Linear Systems　3 Transformation　4 Homogeneous Linear System with Constant Coefficients　5 Homework`

| 小节 | 页 | 要点 |
|---|---|---|
| §1 系统与初值问题 | p7–p10 | 解 `Y(x)` 在相空间里是一条**解曲线**（看作运动质点的轨迹）；**方程 + 初值 = 初值问题（IVP）**。例 1：`dy₁/dx = y₂`、`dy₂/dx = −y₁`（圆型运动）；例 2：`dy₁/dx = 2√y₁`、`dy₂/dx = y₁` |
| §2 线性系统 | p13–p17 | 一般形 `Y′ = A(x)Y + F(x)`；**`F ≡ 0` 叫齐次**，否则非齐次。例 3 是 3×3 齐次系统。<br>**定理 2.1（存在唯一性）**：`a_kj, f_k` 在 `[a,b]` 上连续 ⟹ 初值问题有唯一解；**Remark 2.1：线性系统没有奇解**（对比一阶非线性方程会有奇解）。<br>**定理 2.2（通解结构）**：非齐次通解 `Y = Z(x) + Ỹ(x)`（齐次通解 + 一个特解）——和二阶线性方程的结构完全同构 |
| §3 变换 | p26–p31 | **高阶方程 → 一阶方程组**：令 `y₁ = y, y₂ = y′, …, yₙ = y⁽ⁿ⁻¹⁾`；初值 `y(t₀)=c₀,…,y⁽ⁿ⁻¹⁾(t₀)=c_{n−1}` 变成**向量初值**。例 6 是一般 n 阶线性方程；例 7 是二阶方程（带 `t⁴` 项，得到**非齐次**线性系统） |
| §4 常系数齐次线性系统 | p32–p36 | `y′_k = Σⱼ a_kj y_j`，即 `Y′ = AY`；**关键事实**：`Y(x) = V e^(λx)` 是解 ⟺ `λ` 是特征值、`V` 是对应特征向量；`(A − λE)V = 0`；特征多项式 `det(A − λE) = (λ−λ₁)^m₁ …`，`m₁+…+m_k = n`，**`m_j` ＝代数重数** |
| §5 作业 | p37 | **HW**：把 `y‴ = y″ − x²(y′)²` 化为等价的一阶方程组（**原文提示：它不是线性系统**）→ 对应 `learning/tasks/ode-sys-hw-01.md` |

> 顺带记住：**线性系统的解组理论**（Wronskian、基本解组）在 L13 就讲完了：
> p20–21 **Wronskian** `W(Y₁,…,Yₙ)(x)`；**定理 2.3**：解组线性无关 ⟺ 存在 `x₀` 使 `W(x₀) ≠ 0`；
> p22 **定义：基本解组（FSS）**；**定理 2.4**：解的线性组合仍是解。
> p23 例 5 用 `dy₁/dx = y₂, dy₂/dx = −y₁` 验证 `W = 1 ≠ 0`，通解 `c₁(cos x, −sin x) + c₂(sin x, cos x)`。

## 二、L14–16：常系数齐次线性系统（**今天讲到这里**）

**本讲提纲（p2 原文）**：`1 Eigenvalues and Eigenvectors　2 Homogeneous Linear Systems with Constant Coefficients：Case 1. Distinct Real Eigenvalues／Case 2. Distinct Real and Complex Eigenvalues／Case 3. Repeated Eigenvalues`

| 块 | 页 | 要点 |
|---|---|---|
| 基础复习 | p4–p8 | 重申 `Y = V e^(λx)`、`(A−λE)V = 0`、特征多项式。**p7 定义了两个重数**：<br>**`m_j` ＝代数重数**（`(λ−λ_j)^m_j` 的指数）；**`g_j` ＝几何重数**（线性无关特征向量个数），且 **`1 ≤ g_j ≤ m_j`**。<br>若 `λ` 的重数 `k > 1`，它的线性无关特征向量/广义特征向量个数在 `1` 到 `k` 之间 |
| **Case 1** 相异实特征值 | p9–p15 | 特征方程 → 逐个求特征向量 → 基本解组 `V_j e^(λ_j x)`。例 1 是 3×3 |
| **Case 2** 复特征值（成对） | p16–p29 | `λ = α ± iβ` 必**共轭成对**（p21 Remark）；由 `V₁e^(λ₁x)` 取**实部/虚部**得两个实值解 `U = Re(...)`、`V = Im(...)`。<br>例 2：2×2，`(λ+1/2)² + 1 = 0` → `λ = −1/2 ± i`，验证 `W[U,V] = e^(−x) ≠ 0`；<br>例 3：3×3（含复根）；例 4：4×4，`λ⁴ + 5λ² + 4 = (λ²+1)(λ²+4)` → `λ = ±i, ±2i`，得四个实值解 |
| **Case 3** 重特征值 | p30– | 大标题，今天正讲这一块 |

### 今天她在讲的那一节：**Case 3a：重根但 `g = m`**

**p31 原文标题**：`Case 3a. Repeated Eigenvalues g=m (n linearly independent eigenvectors)`
- **`g₁ = n − rank(A − λ₁E)`**（p31 定义 2.2：几何重数）
- **定理 2.3**：若 `g₁ = m₁`，则存在 **`m₁` 个线性无关的特征向量** `V₁,…,V_{m₁}` 对应 `λ₁`

**p32 给的做法（Case 3a 的通解）**：
`Y(x) = (c₁V₁ + … + c_{m₁}V_{m₁})e^(λ₁x) + Σ_{k>m₁} c_k V_k e^(λ_k x)`

**p33–p36 例 5（就是 `g = m` 的样子）**：

`A = [[4, −1, −1], [1, 2, −1], [1, −1, 2]]`

- `λ₁ = 2`，`m₁ = 1`（简单根）→ `V₁ = (1, 1, 1)ᵀ`
- `λ₂ = 3`，`m₂ = 2`（二重根）→ 解 `(A − 3E)V = 0` 得 `v₁ = v₂ + v₃` ⟹ 取两组独立解
  **`V₂ = (1, 1, 0)ᵀ`，`V₃ = (1, 0, 1)ᵀ`** ⟹ 线性无关特征向量**正好 2 个 ＝ 重数 2** ⟹ **`g = m`**，不需要广义特征向量
- 通解（p36）：
  `Y(x) = c₁V₁e^(2x) + c₂V₂e^(3x) + c₃V₃e^(3x)`
  分量式：`y₁ = c₁e^(2x) + c₂e^(3x) + c₃e^(3x)`；`y₂ = c₁e^(2x) + c₂e^(3x)`；`y₃ = c₁e^(2x) + c₃e^(3x)`

> **一句话**：`g = m` ＝ 重根也凑得齐 `m` 个线性无关特征向量 → 直接写 `e^(λx)V` 型基本解组；
> 需要**广义特征向量**的是 `g < m`（下一小节 Case 3b），那才是这一章最容易翻车的地方。

**接下来大概会是什么**（预测，不是事实）：给定 `Y(0)` 定常数 `c₁,c₂,c₃`（所谓"初值问题"），然后 **Case 3b（`g < m`）**，再往后可能进非齐次系统/相图。
