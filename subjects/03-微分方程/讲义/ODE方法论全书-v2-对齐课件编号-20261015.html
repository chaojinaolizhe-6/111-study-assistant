1.1 基本定义（课件 p9–p16）

  • 阶数 (Order)：方程中出现的未知函数最高阶导数的阶数（y′ 是一阶、y″ 是二阶）。
  • 线性 / 非线性：方程关于 y, y′, y″, … 是一次的（系数只含 x）才是线性；出现 y², yy′, sin y, e^y 等就是非线性。
  • 通解：含 n 个独立任意常数 C₁, …, Cₙ 的解（n ＝方程阶数）。
  • 特解：把常数固定后得到的解；它的图形叫积分曲线。
  • 奇解 (singular solution)：不包含在通解中（无论常数取何值、取极限都得不到）的解；几何上是通解族的包络线。
  • 平衡解：导数处处为 0 的解（例如 y′ = y² − 9 = (y+3)(y−3) 有 y ≡ 3、y ≡ −3 两个平衡解）。
  • 显式解 / 隐式解 / 参数解三种写法都合法；用积分表示出来的通解叫「在求积式中求解 (solved in quadratures)」。
一句话记住通解与奇解的分工：通解 ＝ 一族曲线（含 n 个常数）；奇解 ＝ 这族的包络，要另外用「求导 + 因式分解」或「p-判别 / c-判别」去捞。

1.2 一阶 DE 的两种标准形式（课件 p21）

正规形：dy/dx = f(x, y)　　　微分形式：M(x, y)dx + N(x, y)dy = 0

两者可互化。例：dy/dx = (x² − y²)/(x² + y²) ⟺ (x² + y²)dy + (y² − x²)dx = 0。

⚠ 在微分形式里，哪个变量当因变量其实可以自选（课件原话：unless the contrary is specifically stated）。这正是「x 与 y 角色互换法」的依据（见板块 4）。

1.3 Euler 方法（数值解）v2 新增

课件 p22–p23 独立一节，上一版完全没有。解析解求不出来时，用切线一步步推进。

y₁ = y₀ + Δx · f(x₀, y₀)　⟹　y_{n+1} = y_n + Δx · f(x_n, y_n)

几何意义：以 (x₀, y₀) 为起点，沿该点切线斜率 f(x₀, y₀) 走一小步 Δx 到 (x₁, y₁)；再以新点为起点重新取切线，逐段折线逼近积分曲线。Δx 足够小时数值解收敛到精确解。

考法：给 y′ = f(x, y)、y(x₀) = y₀、步长 h，要求算前两三步。别把「步长 h」和「迭代次数」搞反；每一步都要写全代入过程（老师明确要求写全计算，见附录 C）。

1.4 存在唯一性定理与两个反例v2 新增

定理（课件原文条件）：考虑 n 阶初值问题
y⁽ⁿ⁾ = f(x, y, y′, …, y⁽ⁿ⁻¹⁾)，y(x₀) = y₀, y′(x₀) = y₁, …, y⁽ⁿ⁻¹⁾(x₀) = y_{n−1}。
设 D 是 ℝ^(n+1) 中的区域，(x₀, y₀, …, y_{n−1}) ∈ D，且 f ∈ C(D)、每个 ∂f/∂yᵢ ∈ C(D)（i = 1, …, n）。
则在某个区间 |x − x₀| < h（h 充分小）上存在唯一解。（课件未给证明。）

推论式提醒：定理只保证局部唯一性——解可能跑出这个小邻域，甚至根本活不到你想要的区间。h 的显式估计 h = min(a, b/M) 是教材版写法，课件没有给；答题时按课件的条件叙述更稳。

反例 1：条件不满足 ⟹ 唯一性被破坏（课件 p25–p26）

y′ = 3y^(2/3), y(x₀) = y₀。右端 f = 3y^(2/3) 在 ℝ² 上连续，通解 y = (x + C)³，且 y ≡ 0 是奇解。

  • 算 ∂f/∂y = 2y^(−1/3)：只在 y ≠ 0 时连续。
  • 若 y₀ ≠ 0：取 C = −x₀ + y₀^(1/3) 得唯一解 y = (x − x₀ + y₀^(1/3))³。
  • 若 y₀ = 0：y = (x − x₀)³ 与 y ≡ 0 都是解；还能把两段拼起来（左段 (x − x₀)³、中段 0、右段 (x − x̄)³，x̄ > x₀ 任意）⟹ 无穷多个解。
  • 课件还问了一句：若把初值改成 y(x₁) = y₁，唯一性区域是哪里？答：x ≤ x₀。

反例 2：解可能只在一个很小的区间上存在（课件 p27）

y′ = y², y(0) = 1：所有条件都满足，解是 y = (1 − x)^(−1)，只对 x < 1 存在（x → 1⁻ 时 y → +∞）。

这两个反例与板块 2 的「有限时间爆破」是同一件事的两面：「存在唯一」永远只在局部成立。考试里若问「解在哪一段上有效」，一定要写出这个区间的推导，不要只写通解就完事。

2.1 可分离变量方程（课件 p3–p12）

判别特征：X₁(x)Y₁(y) + X₂(x)Y₂(y)y′ = 0，即 M₁(x)N₁(y)dx + M₂(x)N₂(y)dy = 0。分离条件是 Y₁(y) ≠ 0 且 X₂(x) ≠ 0。

标准动作（五步）
  1. 把方程整理成 f(x)dx = g(y)dy；
  2. 两边积分，立刻写 + C；
  3. 合并对数：ln|A| = ln|B| + C ⟹ A = ±e^C·B（把 ±e^C 记成新常数）⟹ 得到隐式解（不必强行解出 y）；
  4. 丢解检查：凡是被除掉的因子取零，代回原方程看是否恒成立；
  5. 有初值就代入定 C。

4.1 积分因子（课件 p3–p15）

定义：若存在非零函数 µ(x, y)，使 µM dx + µN dy = 0 成为恰当方程，则称 µ 为积分因子。充要条件是

(µM)_y = (µN)_x
母方程与一般理论v2 新增（课件 p3–p5，上一版零覆盖）
把上式展开，得到 µ 必须满足的一阶偏微分方程：
N·µ_x − M·µ_y = µ·(M_y − N_x)
这个方程一般解不出来，但我们只需要一个非零特解就够了。课件的办法是先指定 µ 依赖哪个组合：设 µ = µ(ω)，其中 ω = ω(x, y) 是已知函数（例如 ω = x、ω = y、ω = x² + y²、ω = xy）。由链式法则 µ_x = µ′·ω_x、µ_y = µ′·ω_y，母方程变成可分离的：
(N·ω_x − M·ω_y)·dµ/dω = µ·(M_y − N_x)
于是定义判别式
E(x, y) = (M_y − N_x) / (N·ω_x − M·ω_y)
判别链：若 E 只显式依赖 ω（记作 E = ψ(ω)），则可分离方程 dµ/dω = ψ(ω)·µ 直接解出
µ(ω) = exp( ∫ψ(ω)dω )
若 E 里仍混着 x、y，说明这个 ω 选得不对，换一个再试。——「没有求积分因子的通法」，只有试错（课件原话：trial and error）。

两个最常用的特例（取 ω = x 与 ω = y）

试探方向判别准则（看商是否只含一个变量）积分因子
只依赖 ' + M('x') + '：µ = µ(x)(M_y − N_x)/N = φ(x)（只含 x，分母是 N！）µ(x) = exp( ∫φ(x)dx )
只依赖 ' + M('y') + '：µ = µ(y)(N_x − M_y)/M = ψ(y)（只含 y，分母是 M 且分子反号！）µ(y) = exp( ∫ψ(y)dy )
指定 ' + M('ω = x² + y²') + '算 E = (M_y − N_x)/(2xN − 2yM)，若只含 x² + y² 则可求µ = exp(∫ψ(ω)dω)，例：µ = 1/(x² + y²)
指定 ' + M('ω = xy') + '用于 yf(xy)dx + xg(xy)dy = 0 型，此时 µ = 1/(xM − yN)µ = 1/[xy·(f(xy) − g(xy))]

表里后两行是上一版自己补的实用配方（课件 L4 只给了 µ(x)、µ(y) 两个定理），保留作为攻题工具；但要知道课件没讲，答题时先用课件方法。

标准动作（四步）

  3. 缩并成全导数：两边乘 µ，左端必精确缩并为 d/dx[µ(x)·y] = µ(x)·q(x)；

5.1 Bernoulli 方程（课件 p3–p21）

y′ + p(x)·y = q(x)·yⁿ　（n ≠ 0, 1）

判别特征：右端是 y 的 n 次幂。n = 0 或 1 时它就是线性方程，别硬套 Bernoulli。

标准动作（四步）
  1. 若 n > 0，先写下显然解 y ≡ 0（n < 0 时 y = 0 不是解，因为 yⁿ 无定义）；
  2. 两边同除 yⁿ：y^(−n)·y′ + p(x)·y^(1−n) = q(x)；
  3. 令新变量 z = y^(1−n)，则 z′ = (1−n)·y^(−n)·y′；
  4. 代入得关于 z 的一阶线性方程：z′ + (1−n)p(x)·z = (1−n)q(x)，用线性公式解出 z，再回代 y^(1−n) = z(x)。

例 ② 的过程中除了 x²、也除了 y。检查：y = 0 满足原方程，而且它由 C = 0 就能得到 ⟹ 是解、但不是奇解。
⟹ 凡除以过含未知函数的因子，都要写一句「除以了什么、丢掉什么、代回验证如何」——这是采分点。

5.2 Riccati 方程（课件 p22–p27）

y′ = q₀(x) + q₁(x)·y + q₂(x)·y²　（q₀ ≢ 0, q₂ ≢ 0）
  • 关于 y 是严格的二次多项式（含 y², y¹, y⁰ 三项），对 x 的系数形式不限。
  • q₀ ≡ 0 或 q₂ ≡ 0 时退化为 Bernoulli 或一阶线性。
  • 一般不能用积分求解（这是它的本质特征）——但只要你能「看出」一个特解 y_p，就能化成线性。所以题目一定给得出特解。
标准动作（三步）
  1. 找特解：题目直接给，或观察系数之和（如 P + Q + R = 0 ⟹ y₁ = 1）、试单项式 y₁ = c·x^m（也试常数 c、c/x^m）；
  2. 平移换元：令 y = y_p + 1/w（等价两步：先 y = y_p + u 化为 Bernoulli u′ − (2Py_p + Q)u = P·u²，再令 w = u^(−1)）；
  3. 解线性方程：w′ + [2q₂(x)·y_p(x) + q₁(x)]·w = −q₂(x)，解出 w 后代回 y = y_p + 1/w。

别忘了 y_p 本身也是解（常常还是奇解）。

课件例题特解结果
① y′ = 1 + x² − 2xy + y²（p24–p25）y_p = xy = x + 1/(C − x)，且 y = x 是奇解
② y′ = (2cos²x − sin²x + y²)/(2cos x)（p25–p27）y_p = sin x；此处 q₁ ≡ 0，积分因子可直接算 µ = 1/cos xy = sin x + 1/( C·cos x − sin x/2 )，y = sin x 是奇解

REMARK（课件 p24）：Riccati 方程的矩阵版本出现在最优控制理论中；它「一般不可积」这一事实，正是微分方程定性理论发展的动因之一。

5.3 一阶方程关于 y′ 未解出：关于 y 可解型（课件 p28–p36）

y = φ(x, y′)　⟹　令 p = y′，写成 y = φ(x, p)

核心恒等式：dy = p·dx。两边对 x 求导（注意 p 也是 x 的函数）：

p = ∂φ/∂x + (∂φ/∂p)·(dp/dx)

这是一个关于 (x, p) 的一阶方程。解出后有三种表达形式：

  • 显式：p = p(x, C) ⟹ y = φ(x, p(x, C))；
  • 反函数式：x = x(p, C) ⟹ 参数式 y = φ(x(p,C), p), x = x(p,C)；
  • 隐式参数式：ψ(x, p, C) = 0 与 y = φ(x, p) 联立。
特例：y = φ(y′)（不显含 x）v2 新增（课件 p30）
此时 p = φ′(p)·p′，即 dx = φ′(p)dp / p，可直接分离：
x = ∫ φ′(p)/p dp + C　　参数式：y = φ(p),　x = ∫φ′(p)/p dp + C

另有一条注记：p = 0 时常数解 y = φ(0) 也要写（见板块 12 复习例）。

两道课件例题

例 1（p31–p32）：2y′³ + y′² − y = 0 ⟹ 写成 y = 2p³ + p²，对 x 求导得 p = (6p² + 2p)p′ ⟹ dx = (6p + 2)dp ⟹ x = 3p² + 2p + C，参数式 x = 3p² + 2p + C, y = 2p³ + p²。除 p 丢掉的 y ≡ 0 是奇解，要补。

例 2（p33–p34）：y′² − x·y′ − y + x²/2 = 0 ⟹ y = p² − xp + x²/2，对 x 求导整理得 (2p − x)(p′ − 1) = 0：

  • 支 1 p′ = 1 ⟹ p = x + C ⟹ 通解 y = x²/2 + Cx + C²；
  • 支 2 2p − x = 0 ⟹ p = x/2 ⟹ 奇解 y = x²/4。
⚠「小心」：直接积分会引入伪解v2 新增（课件 p35–p36）
同一道题，如果你偷懒先由 p′ = 1 得 y′ = x + C 再积分，会得到
y = x²/2 + Cx + C₁　——两个任意常数，而一阶方程的通解只能有一个。
消除办法：把含 C₁ 的式子代回原方程，此处定出 C₁ = C²，伪解就被剔除。
课件还解释了伪解的来源：y = p² − xp + x²/2 + C₃ 求导后也得到同一个方程，但 (19) 与 (18) 不是等价变形。
奇解那一支同理：y = x²/4 + C₂ 中只有 C₂ = 0 才真是解。

6.1 Clairaut 方程（课件 p3–p10）

y = x·y′ + φ(y′)　即　y = xp + φ(p)
标准动作（三步，必考通解 + 奇解）
  1. 两边对 x 求导（p 是 x 的函数）：p = p + x·p′ + φ′(p)·p′ ⟹ p′·[ x + φ′(p) ] = 0；
  2. 支 1（通解族 = 直线族）：令 p′ = 0 ⟹ p = C，直接把 y′ = C 代回原方程（不用积分！）得 y = Cx + φ(C)；
  3. 支 2（奇解 = 包络线）：令 x + φ′(p) = 0，与 y = xp + φ(p) 联立，写成参数式 x = −φ′(p), y = −pφ′(p) + φ(p)；能消去 p 就消。

为什么奇解一定不在通解里：它是直线族的包络——任何有限 C 的取值都得不到它，取极限也得不到。

例题 1（p5–p6）：y = xy′ + e^(y′)

  • 通解：y = Cx + e^C；
  • 奇解：x = −e^p, y = e^p(1 − p)，消去 p（p = ln(−x)）得 y = −x·[1 − ln(−x)]。

例题 2（p7–p10）：y = xy′ + (y′)³ − 3y′, y(0) = 0　—— 初值问题有三个解

  • 通解：y = Cx + C³ − 3C；
  • 奇解：x = 3(1 − p²), y = −2p³ ⟹ y = ±2(1 − x/3)^(3/2)；
  • 代初值：y(0) = 0 ⟹ C³ − 3C = 0 ⟹ C = 0, ±√3 ⟹ 三条过原点的直线 y = 0、y = ±√3·x；
  • 奇解要不要算？奇解在 x = 0 处给 y = ±2 ≠ 0，不通过初值点 ⟹ 它不算这个 Cauchy 问题的解。
⚠ 初值问题可以有多解v2 新增：Clairaut 的 Cauchy 问题常常有多个解（这里 3 个）。判断某个候选解算不算，标准是它是否通过初值点。上一版没有这一节。

6.2 Lagrange 方程（课件 p11–p23）

一般式（课件 p11）：A(y′)·y + B(y′)·x + C(y′) = 0，要求 A(y′) ≠ 0。除以 A 后可写成
y = x·φ(p) + ψ(p)　（p = y′）

与 Clairaut 的关系：当 φ(p) ≡ p 时，它就退化成 Clairaut 方程。所以 Lagrange 是 Clairaut 的推广，Clairaut 是 Lagrange 的特例。

标准动作（四步）
  1. 两边对 x 求导：p = φ(p) + [x·φ′(p) + ψ′(p)]·dp/dx，整理成 [φ(p) − p] + [x·φ′(p) + ψ′(p)]·dp/dx = 0；
  2. 先讨论 φ(pᵢ) = pᵢ 的常数根：给出直线解 y = x·pᵢ + ψ(pᵢ)；
  3. 再讨论 φ(p) ≠ p：把 x 看成 p 的函数，颠倒变量得一阶线性方程 dx/dp − [φ′(p)/(p − φ(p))]·x = ψ′(p)/(p − φ(p))；
  4. 写出参数式通解：x = α(p)·C + β(p)，代回 y = φ(p)·[α(p)C + β(p)] + ψ(p)。

补充（课件 p12）：若 φ(p) 是常数（且不等于 p），则 (9) 式变成可分离方程，走可分离那条路。

例题 1（p14–p16）：x·y′² − y′ − y = 0　—— 两个例外参数

  • 整理成 y = xp² − p，即 φ(p) = p²、ψ(p) = −p；
  • 对 x 求导得 dx/dp + 2x/(p − 1) = 1/[p(p − 1)]，积分因子 µ = (p − 1)²；
  • 参数式通解 x = (p − ln|p| + C)/(p − 1)²（配合 y = xp² − p）。
⚠ 被除掉的 p 与 p − 1 要单独讨论v2 新增：
· p = 0 ⟹ y′ = 0 ⟹ 奇解 y ≡ 0；
· p = 1 ⟹ y′ = 1，代回原方程得 y = x − 1，验证 x·1² − 1 − (x − 1) = 0 ✓ ⟹ 奇解 y = x − 1。

例题 2（p17–p23）：y = x(y′)² + y′ − (y′)³, y(0) = 0　—— Cauchy 问题恰有三个解

  • 化为 dx/dp − [2/(1 − p)]·x = (1 − 3p²)/[p(1 − p)]，µ = (1 − p)²；
  • 参数式通解含 (ln|p| − p − 3p²/2 + p³ + C)/(1 − p)²；
  • 单独讨论被除掉的 p = 0 与 p = 1：分别给出奇解 y ≡ 0 与 y = x；
  • 三个解：y ≡ 0、y = x，以及参数解中取 p = −1, C = 3/2 的那一支（三条曲线的斜率分别是 0、1、−1）。

⚠ 老师课上把这道题的三个解单独列出来了——「Cauchy 问题多解」在 Lagrange 里比在 Clairaut 里更常见，因为例外参数 p 值往往正好给出过初值点的直线。

6.3 关于 x 解出的一阶方程（课件 p24–p33）

x = φ(y, y′)　⟹　令 p(y) = y′　（注意：p 看成 y 的函数！）

与 5.3 的关键区别：5.3 里 p 是 x 的函数，这里 p 是 y 的函数，所以求导对象也换成 y。

两边对 y 求导（用 dy/dx = p ⟹ dx/dy = 1/p）：

1/p = ∂φ/∂y + (∂φ/∂p)·(dp/dy)　⟹　p′(y) = (1 − p·φ_y)/(p·φ_p)

同样有三种结果形式：p = p(y, C)；或 y = y(p, C)；或隐式参数式 ψ(y, p, C) = 0。

特例：x = φ(y′)（不显含 y）v2 新增（课件 p26）
此时 dp/dy = 1/[p·φ′(p)]，即 dy = p·φ′(p)dp，直接分离：
x = φ(p),　y = ∫ p·φ′(p) dp + C　（参数式）

两道课件例题

例 1（p27–p31）：y′³ − y − x = 0。既可当「关于 x 可解」做，也可当「关于 y 可解」做，两条路都通；通解含 3p²/2 − 3p + 3ln|p + 1| ∓ C。关键：p = −1 是 dx/dp 的奇点（除过 p + 1）——此时给出奇解 y = −x − 1。课件原话：the parametric solution fails when p + 1 = 0。

例 2（p32–p33）：x·y′² − 2y′ − x = 0，解得 x = 2p/(p² − 1)、y = −ln|p² − 1| + 2/(p² − 1) + C。

⚠ p² = 1 时方程无解v2 新增：代 p = 1 得 x − 2 − x = −2 ≠ 0；代 p = −1 得 x + 2 − x = 2 ≠ 0，两支都不成立 ⟹ 原方程在 p² = 1 处没有解。这不是「漏了一个解」，而是「这两支本来就不存在」——写一句结论即可。

7.1 第 ① 型：最简形式（课件 p3–p7）

y⁽ⁿ⁾ = f(x)　⟹　y⁽ⁿ⁻¹⁾ = ∫f dx + c₁，逐次积分 n 次

带初值的写法（课件 p4–p5）：用 y⁽ⁿ⁻¹⁾(x₀) = y_{n−1} 等条件，在 [x₀, x] 上逐次定积分：

7.2 第 ② 型：不显含 x（课件 p8–p17）

7.4 第 ④ 型：高阶齐次方程（z = y′/y）v2 新增

核心换元：z(x) = y′(x)/y(x)，则
y′ = y·z；y″ = y·(z² + z′)；y‴ = y·(z³ + 3z·z′ + z″)；…；y⁽ⁿ⁾ = y·gₙ(z, z′, …, z⁽ⁿ⁻¹⁾)
代入后利用齐次性（取 k = y）把 yᵐ 整个提出来约掉：
F(x, 1, z, z² + z′, z³ + 3zz′ + z″, …) = 0　⟹　阶数降 1

7.5 第 ⑤ 型：广义齐次方程的降阶（课件 p25–p36）v2 新增

定义（课件 p25）：若存在常数 α, m，使

F(kx, kᵅy₀, k^(α−1)y₁, …, k^(α−n)yₙ) = kᵐ·F(x, y₀, y₁, …, yₙ)

则称 F 是广义齐次的。处理顺序：先判断是不是广义齐次（比较 k 的幂次解出 α），再作换元

x = e^u,　y = v(u)·e^(αu)

7.6 线性方程的降阶（课件 p30–p36）

对变系数线性方程，若已知一个非平凡特解 y_p，可令

y(x) = y_p(x) · ∫ z(x) dx

8.3 二阶参数变易法（课件 p17–p25）

动机：常系数齐次通解不能用来解非齐次；于是把常数「变易」成函数。设 y_p = c₁(x)y₁ + c₂(x)y₂。

人为附加条件（不是推导出来的，是为了简化 y_p′ 而主动设的）：c₁′y₁ + c₂′y₂ = 0。

标准动作
  1. 解方程组 c₁′y₁ + c₂′y₂ = 0；c₁′y₁′ + c₂′y₂′ = f(x)；
  2. 由 Cramer 法则直接写出（W = y₁y₂′ − y₁′y₂）：c₁′(x) = −y₂(x)f(x)/W(x)，c₂′(x) = y₁(x)f(x)/W(x)；
  3. 积分得特解 y_p = −y₁∫[y₂f/W]dx + y₂∫[y₁f/W]dx。

也可写成定积分形式 c₁ = −∫(x₀→x)[y₂f/W]dt、c₂ = ∫(x₀→x)[y₁f/W]dt。什么时候用它：右端含 sec x, tan x, ln x, e^x/x 等不属于待定系数法能处理的形状时。

8.4 n 阶参数变易法（课件 p26–p30）v2 新增

上一版的 12.1 标题写着「高阶常数变易法」，正文却只有 2×2 的方程组。完整的 n 阶版本是：

设 y_p = c₁(x)y₁ + … + cₙ(x)yₙ，加 n − 1 个人为条件：

c₁′y₁ + c₂′y₂ + … + cₙ′yₙ = 0 c₁′y₁′ + c₂′y₂′ + … + cₙ′yₙ′ = 0 … c₁′y₁⁽ⁿ⁻²⁾ + … + cₙ′yₙ⁽ⁿ⁻²⁾ = 0 c₁′y₁⁽ⁿ⁻¹⁾ + … + cₙ′yₙ⁽ⁿ⁻¹⁾ = f(x)

前 n − 1 个条件都是为了消掉 y_p 的低阶导数项；方程组的系数行列式正是 n × n 的 Wronskian W，由 Cramer 法则得 cᵢ′ = Wᵢ/W（Wᵢ 是把 W 第 i 列换成 (0, …, 0, f)ᵀ）。

8.5 附加材料：Abel–Liouville 公式与「由一解求第二解」（课件 p50–p53）

标准形式 y⁽ⁿ⁾ + a₁(x)y⁽ⁿ⁻¹⁾ + … + aₙ(x)y = 0 的任意 n 个解满足

W(x) = W(x₀)·exp( −∫(x₀→x) a₁(t) dt )

二阶情形就是最常见的那条：y″ + P(x)y′ + Q(x)y = 0 ⟹ W = y₁y₂′ − y₁′y₂ = C·e^(−∫P dx)。

推导思路（课件 p50）：把 W 求导，用方程把 yᵢ″ 替换掉，得到 W′ + a₁W = 0，解出来就是上式。

由一解求第二解（课件 p51–p53）
由 W = y₁²·(y₂/y₁)′ 得 (y₂/y₁)′ = W / y₁²，两边积分：
y₂ = y₁ · ∫ [ e^(−∫P dx) / y₁² ] dx

例：2xy″ − (x + 4)y′ + (1 + 4/x)y = 0，已知 y₁ = x，求得 W = c₂x²e^(x/2) ⟹ y₂ = x·e^(x/2)。

THEOREM 3（有理根定理，课件含证明）
设整系数多项式 P(x) = a₀xⁿ + a₁x⁽ⁿ⁻¹⁾ + … + a_{n−1}x + aₙ，若 x₀ = p/q 是它的有理根（p/q 为既约分数），则

操作流程（四步）
  1. 列出候选根 ±p/q：p 取常数项 aₙ 的全体因数，q 取首项系数 a₀ 的全体因数；

  3. 找到一个根 λ₁ 后，用综合除法除以 (λ − λ₁)，把次数降 1；
  4. 对降次后的多项式重复上述步骤，直到降到二次，用求根公式收尾。

规则：若右端是几项之和 f = f₁ + f₂ + … + f_k，则分别解 L[y] = f₁、L[y] = f₂、…，各得特解 y_{p1}, y_{p2}, …, y_{pk}，于是
y_p = y_{p1} + y_{p2} + … + y_{pk}
是原方程的一个特解。

为什么成立（课件两次给了证明）：L 是线性的，L[y_{p1} + … + y_{pk}] = L[y_{p1}] + … + L[y_{pk}] = f₁ + … + f_k。

叠加原理例题 5（课件 p22–p25）：y″ + 3y′ − 4y = e^(−4x) + x·e^(−x)

  • 特征根：λ² + 3λ − 4 = 0 ⟹ λ = 1, −4；
  • 第一项 f₁ = e^(−4x)：α = −4 是单根 ⟹ s = 1，设 y_{p1} = Ax·e^(−4x)，代入得 −5A = 1 ⟹ A = −1/5；
  • 第二项 f₂ = x·e^(−x)：α = −1 不是根 ⟹ s = 0，设 y_{p2} = (Bx + C)e^(−x)，代入得 −6B = 1, B − 6C = 0 ⟹ B = −1/6, C = −1/36；
  • 合并：y_p = −(1/5)x·e^(−4x) − (x/6 + 1/36)e^(−x)。
叠加原理例题 8（课件 p31–p35）：y⁽⁴⁾ + y″ = 12x + 4x·e^x + 2cos x
右端不属于情形 III 的标准形状，所以拆成三个方程：
① y⁽⁴⁾ + y″ = 12x　　：0 是二重根 ⟹ y_{p1} = x²(Cx + D) = Cx³ + Dx² ② y⁽⁴⁾ + y″ = 4x·e^x　：α = 1 不是根 ⟹ y_{p2} = (Ex + F)e^x ③ y⁽⁴⁾ + y″ = 2cos x　：α + iβ = i 是一重根 ⟹ y_{p3} = x(H·sin x + G·cos x) ⟹ y_p = y_{p1} + y_{p2} + y_{p3}

同一道题两法对照（课件 p9–p15）

课件对 y‴ − y″ = 2x 用了两种方法各做一遍：Method 1 参数变易法（y_p = c₁(x) + c₂(x)x + c₃(x)e^x，三方程消元，n 阶流程见 8.4）；Method 2 待定系数法（因 λ = 0 是二重根，设 y_p = x²(Ax + B)）。

A.2 n 次方根定理（课件 THEOREM 3）

定义：若 uⁿ = z，称 u 是 z 的 n 次方根，记 u = z^(1/n) 或 u = ⁿ√z。

定理：设 z ∈ ℂ, z ≠ 0，z = r(cos ϕ + i·sin ϕ)，则 z 恰有 n 个互不相同的 n 次方根：
u = z^(1/n) = r^(1/n)·[ cos( (ϕ + 2πk)/n ) + i·sin( (ϕ + 2πk)/n ) ]，　k = 0, 1, …, n − 1

几何意义：这 n 个根是复平面上以原点为心、半径 r^(1/n) 的正 n 边形的顶点，相邻两个相差 2π/n。

A.3 标准动作（四步）

  1. 把特征方程整理成 λⁿ = c 或 (λⁿ = c)ᵏ = 0 的形状（c 是实数或已知复数）；
  2. 把 c 写成三角形式：求 r = |c| 与 ϕ = arg c；
  3. 套公式列出 n 个根（k = 0, 1, …, n−1）；
  4. 按板块 10.1 的表逐根产出解，并数个数：解的总数必须等于 n。

B.2 Newton 冷却定律（课件 L1 p31）

dT/dt = −k·(T − A)　（k > 0，A 是环境温度）
  • T > A ⟹ dT/dt < 0，物体降温；T < A ⟹ dT/dt > 0，物体升温。
  • 带初值 T(0) = T₀ 的显式解：T(t) = A + (T₀ − A)·e^(−kt)，且 T(t) → A（t → ∞）。
  • 验证：dT/dt = −k(T₀ − A)e^(−kt) = −k(T − A) ✓

B.3 人口增长（课件 L2 p22–p23）

设 P(t) 是人口数，β(t)、δ(t) 分别是出生率与死亡率（连续函数）。短时间 Δt 内：

ΔP ≈ (β − δ)·P·Δt　⟹（Δt → 0）　dP/dt = (β(t) − δ(t))·P(t)

分离变量积分得

P(t) = P₀ · exp( ∫(0→t) ( β(τ) − δ(τ) ) dτ )，　t ≥ 0

β, δ 为常数时就是常见的指数增长/衰减模型。

B.4 飞机航迹（课件 L3 p3–p7）

完整推导与结论见板块 3.1。要点回顾：k = w/v₀，最终 y(x) = (a/2)[(x/a)^(1−k) − (x/a)^(1+k)]；k < 1 才到得了原点。
