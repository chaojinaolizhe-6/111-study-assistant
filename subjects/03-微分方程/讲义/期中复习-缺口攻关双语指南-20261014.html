缺口 1｜常系数齐次：m 重根（含复根重根）的解组 　m-fold roots

知识点：特征方程 p(λ) = 0 的根按重数产出基本解，解的总个数必须等于方程阶数 n。

特征根它贡献的解
实单根 λe^(λx)
实 m 重根 λe^(λx), x e^(λx), x² e^(λx), …, x^(m−1) e^(λx)　（共 m 个）
复单根 α ± iβe^(αx)cos βx, e^(αx)sin βx
复 m 重根 α ± iβe^(αx)x^j cos βx, e^(αx)x^j sin βx，j = 0…m−1　（共 2m 个）

方法（五步）：① 写特征方程；② 因式分解求全部根与重数（有理根定理 + 综合除法）；③ 按上表逐根产出解，重根必须一路给到 x^(m−1)；④ 数个数：解的总数 = n（这一步是自检，专治"重根少给 x 的幂"）；⑤ 通解 = 这些解的线性组合。

Method (EN) — Write the characteristic equation, factor it completely and record every root with its multiplicity. Each real root λ of multiplicity m contributes e^(λx), x e^(λx), …, x^(m−1)e^(λx); each complex pair α ± iβ of multiplicity m contributes e^(αx)x^j cos βx and e^(αx)x^j sin βx for j = 0…m−1. Check by counting: the number of independent solutions must equal n.
例题　y''' + 9y'' + 27y' + 27y = 0
（＝定位卷 A5；你的特征方程写对了，但解的第三项疑似漏了 x²）
解答
① p(λ) = λ³ + 9λ² + 27λ + 27 = 0　② 分解：(λ + 3)³ = 0 ⟹ λ = −3 是三重根（m = 3）
③ 三重根贡献三个解：e^(−3x)、x e^(−3x)、x² e^(−3x)　④ 自检：3 个解 = 3 阶 ✓
⑤ 通解 y = (C₁ + C₂x + C₃x²) e^(−3x)
⚠ 常见错法：写成 C₁e^(−3x) + C₂xe^(−3x) + C₃xe^(−3x) —— 后两项重复，实际只有 2 个独立解，解空间少一维。
缺口 2｜可分离方程的收尾：积分常数、隐式解、丢解检查

知识点：分离变量后两边各自积分，常数 C 在积分时就产生；对数结果要合并成"乘积 = 常数"的形式；分离时若除以了可能为零的因子，必须回头检查丢掉的常数解。

方法（五步）：① 把方程写成 f(x)dx = g(y)dy；② 两边积分，立即写 +C；③ 合并对数：ln|A| = ln|B| + C ⟹ A = ±e^C·B（把 ±e^C 记成新常数 C）⟹ 得到 隐式解（不必强行解出 y）；④ 丢解检查：凡是被除掉的因子取零，代回原方程看是否恒成立；⑤ 有初值就代入定 C。

Method (EN) — Separate, integrate and keep the constant of integration. Combine logarithms into a product equal to a constant and rename e^C as a new constant; an implicit answer is acceptable. If you divided by a factor that can vanish, test that factor separately — it may give extra (singular) solutions. Apply the initial condition to fix C.
例题　(e^v + 1) cos u du + e^v (sin u + 1) dv = 0
（＝定位卷 A1：你分离与积分全对，卡在"要化成什么样"）
解答
① 分离：(e^v + 1)cos u du = −e^v(sin u + 1) dv ⟹ cos u/(sin u + 1) du = −e^v/(e^v + 1) dv
② 积分（补上 C）：ln|sin u + 1| = −ln|e^v + 1| + C
③ 合并对数：ln[(sin u + 1)(e^v + 1)] = C ⟹ (sin u + 1)(e^v + 1) = C（隐式通解）
④ 丢解检查：第 ① 步除以了 (sin u + 1) ⟹ 令 sin u + 1 = 0，即 u = −π/2 + 2kπ；代回原式左边两项同为 0，恒成立 ⟹ 它也是解（常数解），要单独写出。
（严格说：若允许常数 C = 0，这条常数解已被 (sin u + 1)(e^v + 1) = C 覆盖；但按采分点，"除以了什么、丢了什么"显式写出来最稳妥，保持现有写法。）
⑤（若有初值）代入定 C。
缺口 3｜一阶线性的收尾：通解公式的乘除方向 ＋ 三角积分（∫cos²θ / ∫cos³θ）

知识点：一阶线性方程解到最后会遇到两种"小麻烦"：① 通解公式里 μ 是乘还是除、积分号里要不要再乘 μ（这正是定位卷 B1 踩的坑）；② 收尾那个三角积分走哪条路线。

① 先把公式链锁死（三行，不许背错）

r' + P(θ)·r = Q(θ)　⟹　μ(θ) = e^(∫P dθ)　⟹　两边乘 μ：(μ r)' = μ Q　⟹　r = (1/μ)·( ∫ μ·Q dθ + C )

★ 两个最容易错的地方：(a) 括号外是 1/μ，不是 μ；(b) 积分号里必须乘上 μ —— 因为凑出来的导数是 (μr)'，右端就是 μQ，不是 Q。

② 三角积分的三条路线

形状标准动作例
偶次幂（cos²、sin²、cos⁴…）倍角降幂：cos²θ = (1 + cos2θ)/2，sin²θ = (1 − cos2θ)/2∫cos²θ dθ = θ/2 + sin2θ/4
奇次幂（cos³、sin³…）拆一个因子给微分：cos³θ = cosθ(1 − sin²θ)，配 d(sinθ)∫cos³θ dθ = sinθ − sin³θ/3
含 tan / secsec²θ = d(tanθ)、tan²θ = sec²θ − 1∫tanθ dθ = ln|secθ|
Method (EN) — Lock the linear formula first: μ = e^(∫P dθ); multiply through to get (μ r)' = μ Q; then r = (1/μ)(∫ μ Q dθ + C) — note the 1/μ outside and the μQ inside. For the trigonometric integral that remains: even powers → double-angle reduction; odd powers → split off one factor and use cos² = 1 − sin² so that the rest fits d(sin θ).
例题（＝定位卷 B1）　cos θ dr + (r sin θ − cos⁴θ) dθ = 0
⚠ 前一版指南在这一步把公式用反了（括号外写了 μ，且积分号里漏乘 μ），导致结果错误；本版已修正并逐行验算。
解答
① 化成标准形（两边同除 cos θ dθ）：r' + tanθ·r = cos³θ（P = tanθ，Q = cos³θ）
② 积分因子：μ = e^(∫tanθ dθ) = e^(ln|secθ|) = 1/cosθ
③ 两边乘 μ：(r/cosθ)' = (1/cosθ)·cos³θ = cos²θ　← 右端是 μQ；注意这里已经变成 偶次幂
④ 积分（走偶次幂路线）：r/cosθ = ∫cos²θ dθ + C = ∫(1 + cos2θ)/2 dθ + C = θ/2 + sin2θ/4 + C
⑤ 通解 r = cosθ·( θ/2 + sin2θ/4 + C )
验算（代回原式）：r' + tanθ·r = cosθ·(1/2 + cos2θ/2) = cosθ·cos²θ = cos³θ ✓　（sympy：dsolve 给出 (4C₁ + 2θ + sin2θ)cosθ/4，即同一结果）
附：奇次幂小练（另一条路线，考试同样会考）
∫cos³θ dθ = ∫cosθ(1 − sin²θ) dθ = ∫(1 − sin²θ) d(sinθ) = sinθ − sin³θ/3 + C
判别口诀：幂次为偶 → 降幂；幂次为奇 → 拆一个配微分。B1 收尾出现的是 cos²θ（偶），所以走降幂路线；若收尾是 cos³θ，则走拆因子路线。
缺口 4｜Riccati 方程：用"观察法"找特解

知识点：Riccati 形如 y' = P(x) + Q(x)y + R(x)y²。它不能直接积，但只要你能"看出"一个特解 y₁，令 y = y₁ + 1/v 就能化成线性方程。（所以题目一定给得出特解——通常是单项式。）

方法（五步）：① 整理成标准形 y' = P + Qy + Ry²；② 试单项式特解 y₁ = c xⁿ（也试常数 c、c/xⁿ）；把 y₁ 代进去，比较各项 x 的幂次，解出 n 与 c；③ 令 y = y₁ + 1/v；④ 代入后得到线性方程 v' + (Q + 2R y₁)v = −R（记住这个式子，比每次重推快）；⑤ 解线性方程得 v，代回 y = y₁ + 1/v。

Method (EN) — Put the equation in the standard form y' = P + Qy + Ry². Look for a particular solution by inspection, trying y₁ = c xⁿ (or c, or c/xⁿ); match powers of x to find n and c. Then set y = y₁ + 1/v, which turns the equation into the linear ODE v' + (Q + 2R y₁)v = −R. Solve for v and substitute back.
例题　x³y' + 2x²y + 2x⁴y² = 18　(x ≠ 0)
（＝定位卷 A4：你写"找不到特解，也用不上洛卡蒂"）
解答
① 除以 x³：y' + (2/x)y + 2x y² = 18/x³（P = 18/x³，Q = −2/x，R = −2x）
② 观察法：右端是常数 18，前两项是一次的 y —— 试 y₁ = c/x²（让 x³y'、2x²y 都变成常数项）：
　　y₁' = −2c/x³ ⟹ x³(−2c/x³) + 2x²(c/x²) + 2x⁴(c²/x⁴) = −2c + 2c + 2c² = 2c² = 18 ⟹ c = ±3 ⟹ 取 y₁ = 3/x²
③ 令 y = 3/x² + 1/v；④ 代入公式：Q + 2Ry₁ = −2/x + 2(−2x)(3/x²) = −2/x − 12/x = −14/x，−R = 2x
　　⟹ v' − (14/x)v = 2x（一阶线性）
⑤ 积分因子 μ = x^(−14)：v = C x^14 − x²/6 ⟹ y = 3/x² + 1/(C x^14 − x²/6)
自检：把 y₁ = 3/x² 单独代回原式：−6 + 6 + 18 = 18 ✓
缺口 5｜待定系数法 + 共振（为什么乘 x^s）+ 初值收尾

知识点：常系数非齐次 a y'' + b y' + c y = f(x)，按 f(x) 的形状设 y_p；若设出来的形式已经是齐次解（即 f 的"指数"撞上特征根），必须乘 x^s，s ＝ 该特征根的重数（撞一次乘 x，撞两次乘 x²）。

f(x) 的形状设 y_ps 的取法
P_m(x)（m 次多项式）x^s·Q_m(x)s = 0 的重数（0 是不是特征根）
P_m(x) e^(αx)x^s·Q_m(x) e^(αx)s = α 作为特征根的重数
e^(αx)(A cos βx + B sin βx)x^s e^(αx)(C cos βx + D sin βx)s = (α ± iβ) 作为特征根的重数
f = f₁ + f₂（和）y_p = y_p1 + y_p2（叠加，分别设）逐个判断
Method (EN) — Guess y_p from the shape of f. If the guess duplicates a solution of the homogeneous equation, multiply it by x^s, where s is the multiplicity of the corresponding characteristic root. For a sum f₁ + f₂, find a particular solution for each part and add them. Finally apply the initial conditions to the general solution to get the constants.
例题　y'' + 4y = 12x + 8cos 2x，　y(0) = 0，　y'(0) = 5
（＝定位卷 B4：你会拆解，但"为什么这样设"不清；系数疑似写成 −2；初值没代）
解答
① 齐次：λ² + 4 = 0 ⟹ λ = ±2i ⟹ y_h = C₁cos2x + C₂sin2x
② f₁ = 12x（多项式）：0 不是特征根（特征根是 ±2i）⟹ s = 0 ⟹ 设 y_p1 = Ax + B ⟹ 代入：4Ax + 4B = 12x ⟹ A = 3，B = 0 ⟹ y_p1 = 3x
③ f₂ = 8cos2x：这里的 α ± iβ = ±2i 正是特征根（单根）⟹ s = 1 ⟹ 设 y_p2 = x(C cos2x + D sin2x)
　　⟹ 代入左端：−4C sin2x + 4D cos2x = 8cos2x ⟹ C = 0，D = 2 ⟹ y_p2 = 2x sin 2x
　　★ 为什么必须乘 x：不乘的话 y_p = C cos2x + D sin2x 本身就是齐次解，代入左端恒为 0，永远凑不出 8cos2x。乘 x 之后多出的那一项恰好补上右端。
④ 通解：y = C₁cos2x + C₂sin2x + 3x + 2x sin2x
⑤ 代初值：y(0) = C₁ = 0；y' = −2C₁sin2x + 2C₂cos2x + 3 + 2sin2x + 4x cos2x ⟹ y'(0) = 2C₂ + 3 = 5 ⟹ C₂ = 1
⑥ y = sin2x + 2x sin2x + 3x = (1 + 2x) sin 2x + 3x
自检：y'' + 4y = (−4sin2x + 8cos2x − 8x sin2x) + (4sin2x + 8x sin2x + 12x) = 8cos2x + 12x ✓
缺口 6｜准齐次（广义齐次）方程：识别与换元

知识点：普通齐次要求"分子分母同次"（令 u = y/x）；准齐次是"加权同次"——给 x 记权重 a、y 记权重 b，若所有项在变换 x → k^a x、y → k^b y 下乘同一个因子，则令 u = y / x^(b/a)（即 y = x^(b/a)·u）可化为可分离。

★ 关键关系（先记住这一条，方法就不会乱）：y' = dy/dx 的权重恒等于 b − a（分子一次、分母一次）。
所以不要把"y' 的权重"当成自由参数去设；归一化请固定 a = 1（x 的权重），于是 y' 自动是 b − 1，全方程只剩 b 一个未知数。

方法（四步）：① 固定 a = 1（x 的权重），设 y 的权重为 b；则 y' 的权重自动 = b − 1；② 逐项写权重：项 x^m y^n 的权重 = m + n·b，含 y' 的项按 y' → b − 1 计；令所有项权重相等 → 解出 b；③ 令 y = x^b·u（例：b = 2 → y = x²u）；④ 代入后方程变成可分离 → 分离积分 → 代回 u = y/x^b。

Method (EN) — Fix the weight of x as a = 1 and let the weight of y be b. Then y' = dy/dx automatically has weight b − 1 (do not treat it as a free parameter). Write the weight of every term — a term x^m y^n has weight m + n·b, and any y' counts as b − 1 — and set them all equal; this gives one equation for b. Then substitute y = x^b u; the equation becomes separable. Integrate and substitute u back.
例题　y' = y/x + x³/y　(x ≠ 0, y ≠ 0)
（＝定位卷 A2：你写"不会"——关键就是认出它不是普通齐次）
解答
① 归一化：固定 x 权重 a = 1，设 y 权重 b ⟹ y' 的权重自动 = b − 1
② 逐项写权重：y' → b − 1；　y/x → b − 1（自动与 y' 同次 ✓）；　x³/y → 3 − b
　　令各项同次：b − 1 = 3 − b ⟹ 2b = 4 ⟹ b = 2（即 y ~ x²）
③ 令 y = x² u ⟹ y' = 2xu + x²u' ⟹ 代入：2xu + x²u' = xu + x/u
　　⟹ x²u' = −xu + x/u ⟹ u' = (1 − u²)/(x u)（可分离）
④ 分离：u du/(1 − u²) = dx/x ⟹ −½ ln|1 − u²| = ln|x| + C ⟹ (1 − u²)x² = C
　⑤ 代回 u = y/x²：x² − y²/x² = C ⟹ y² = x⁴ − Cx²（等价写法 y² = x⁴ + Cx²）
另一条路（也通）：看成 Bernoulli y' − (1/x)y = x³y^(−1)（n = −1），令 v = y² 化线性，结果一致（sympy 复核：代入 = 0 ✓）。
缺口 7｜不含 x 的高阶降阶 + "凑导数"识别

知识点：高阶方程若缺变量，可降阶；非线性方程常常要先除以一个因子把左边凑成某个函数的导数，再换元。

缺什么 / 看到什么换元或凑法
缺 x（不含 x）令 p = y'，则 y'' = p·dp/dy（把 y 当自变量）
缺 y直接令 z = y'（或 z = y^(k)）降一阶
出现 y y'' − y'²除以 y² ⟹ (y'/y)' = (y y'' − y'²)/y²；令 z = y'/y 或 z = ln y
出现 y''/y'（不含 x）除以 y' ⟹ (ln|y'|)'；或用 p dp/dy 形式
Method (EN) — If x is missing, set p = y' and use y'' = p·dp/dy. If y is missing, set z = y'. When you see combinations such as y y'' − y'², divide by a suitable factor to create a derivative — e.g. (y'/y)' = (y y'' − y'²)/y² — and then set z = y'/y or z = ln y.
例题　y y'' − y'² = y² ln y　(y > 0, y' > 0)
（＝定位卷 B3：设 w = y'、y'' = w·w' 都对，随后卡住）
解答
① 两边除以 y²：(y y'' − y'²)/y² = ln y ⟹ (y'/y)' = ln y（左边正好是 (y'/y) 的导数）
② 令 z = ln y ⟹ z' = y'/y，z'' = (y'/y)' ⟹ 方程变成 z'' = z
③ 常系数齐次：λ² − 1 = 0 ⟹ λ = ±1 ⟹ z = C₁e^(x) + C₂e^(−x)
④ 回代：y = e^z = exp(C₁ e^(x) + C₂ e^(−x))（自动满足 y > 0 ✓）
缺口 8｜Clairaut 方程与奇解（别忘了第二支）

知识点：Clairaut 方程形如 y = x p + φ(p)（p = y'）。对 x 求导后必然分成两支：一支给通解（直线族），另一支给奇解（直线族的包络）。奇解是最常被漏掉的部分。

方法（五步）：① 令 p = y'，写成 y = xp + φ(p)；② 两边对 x 求导（注意 p 是 x 的函数）：p = p + (x + φ'(p))p'；③ 移项因式分解：(x + φ'(p))·p' = 0；④ 支 1：p' = 0 ⟹ p = C ⟹ 通解 y = Cx + φ(C)；⑤ 支 2：x + φ'(p) = 0 与 y = xp + φ(p) 联立、消去 p ⟹ 奇解。有初值时要判断它落在哪一支上。

Method (EN) — Write the equation as y = xp + φ(p) with p = y' and differentiate with respect to x. This factors as (x + φ'(p))·p' = 0. The branch p' = 0 gives the general solution y = Cx + φ(C); the branch x + φ'(p) = 0, combined with the original equation, gives the singular solution (the envelope). Do not omit it.
例题　y = x y' − y'²　（＝定位卷 B2）
解答
① 令 p = y' ⟹ y = xp − p²（φ(p) = −p²）
② 对 x 求导：p = p + x p' − 2p p' ⟹ (x − 2p) p' = 0
③ 支 1：p' = 0 ⟹ p = C ⟹ 通解 y = Cx − C²（直线族）
④ 支 2：x − 2p = 0 ⟹ p = x/2 ⟹ y = x(x/2) − (x/2)² = x²/4（奇解，是直线族的包络）
自检：y = x²/4 时 y' = x/2 = p ✓，xy' − y'² = x²/2 − x²/4 = x²/4 = y ✓
