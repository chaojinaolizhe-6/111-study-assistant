## 0. 为什么 ODE 会显得"零散、靠记忆"

`[教学归纳]` 因为 ODE 没有"一个通吃公式"——它是一套**按方程形状分流**的算法库：
拿到方程先问「**它长什么形状**」，形状决定走哪条路；路本身都只有 2–3 步，**能现推**，不必背结论。

全章其实只在做三件事：

1. **分离变量**（把 x 和 y 分到两边，直接积分）；
2. **化成线性**（换元把非线性变成 `y' + p(x)y = q(x)`，因为线性有通用解公式）；
3. **降阶**（高阶 → 低阶，直到能积分）。

真正需要"记结论"的只有**线性方程那一半**：常系数齐次的特征根三情形、非齐次的待定系数法。其余都是变形。

## 1. 总表：识别特征 → 标准动作 → 自检

### A. 一阶（L1–L6）

| 识别特征（看到这个形状） | 标准动作 | 收尾自检 |
|---|---|---|
| `y' = f(x)g(y)`，或能写成 `X₁(x)Y₁(y)dx + X₂(x)Y₂(y)dy = 0` | 分离变量，两边各自积分 | 有没有漏掉 `g(y) = 0` 给出的**常数解** |
| `y' = g(y/x)`（分子分母同次） | 令 `u = y/x`（即 `y = ux`）→ 化成可分离 | 最后**代回** `u = y/x`，别留 u |
| `y' = (a₁x + b₁y + c₁)/(a₂x + b₂y + c₂)`，常数项不全为 0 | 解线性方程组找出平移量，把原点移到交点 → 化为齐次 | 两行系数**成比例**时退化，不能直接平移 |
| 准齐次（Generalised Homogeneous）`y' = f(x, y)`：存在 `α, β` 使 `x → k^α x`、`y → k^β y` 时 `f` 只差因子 `k^(β−α)` | 逐项看缩放幂次，令各幂次相等解出 `β/α`；再令 `u = y / x^(β/α)` | `α = β` 时它**就是**普通齐次；本质上是"加权齐次" |
| `M dx + N dy = 0` 且 `∂M/∂y = ∂N/∂x` | **恰当方程**：求 `F` 使 `F_x = M`、`F_y = N`，解 `F(x,y) = C` | 先验交叉偏导**是否真的相等** |
| 同上，但交叉偏导**不相等**；且 `(M_y − N_x)/N` 只含 x，或 `(N_x − M_y)/M` 只含 y | 求**积分因子** `μ`，乘上去变恰当 | 那个商**只依赖一个变量**公式才成立；否则要试别的 μ 形式 |
| 能整理成 `y' + p(x)y = q(x)` | **一阶线性**：`μ = exp(∫p dx)`，`y = (1/μ)(∫μq dx + C)` | `y'` 的系数先化成 1，再取 `p(x)` |
| `y' + p(x)y = q(x)yⁿ`（`n ≠ 0, 1`） | **Bernoulli**：两边除 `yⁿ`，令 `v = y^(1−n)` → 变成线性 | `n = 0` 或 `1` 时它就是线性，别套 Bernoulli |
| `y' = P(x) + Q(x)y + R(x)y²` | **Riccati**：题目会给一个特解 `y₁`，令 `y = y₁ + 1/v` → 变线性 | 没有特解就做不下去（这是它的特征） |
| `y = x y' + φ(y')` | **Clairaut**：令 `p = y'` 后对 x 求导 → 通解 `y = Cx + φ(C)` | **通解之外常另有奇解**（参数式），别漏 |
| `y = x φ(y') + ψ(y')` | **Lagrange**：令 `p = y'`，对 x 求导 → 得 `x` 关于 `p` 的一阶线性 | `φ(p) = p` 的情形要单独讨论 |
| 关于 `y` 可解：`y = f(x, y')` | 令 `p = y'`，对 x 求导 → 降成一阶 | — |
| 关于 `x` 可解：`x = f(y, y')` | 令 `p = y'`，用 `dx = dy/p` 换自变量 | — |
| 一阶数值：只要近似值 | **Euler 方法** `y_{n+1} = y_n + h·f(x_n, y_n)` | 步长 h 与迭代次数别搞反 |

### B. 高阶与线性（L7–L11）

| 识别特征 | 标准动作 | 收尾自检 |
|---|---|---|
| 高阶，但**不含 y**（或只含更高阶的 y⁽ᵏ⁾） | **降阶**：令 `p = y⁽ᵏ⁾` 当新未知函数 | 降阶后阶数、常数个数与初始条件数目对得上吗 |
| 高阶，**不含 x** | 令 `p = y'`，且 `y'' = p·dp/dy` | 别忘了 `dp/dy` 那个链式因子 |
| `y⁽ⁿ⁾ = f(x)` 最简形式 | 连积 n 次 | n 个积分常数 |
| 齐次／广义齐次高阶 | 按缩放次数换元降阶 | 与一阶的齐次别混 |
| `a₀(x)y⁽ⁿ⁾ + … + aₙ(x)y = 0`（变系数线性齐次） | 解的结构：通解 = 基本解组的线性组合；用 Wronski 判线性无关 | 系数连续性/`a₀ ≠ 0` 的条件 |
| 同上的**非齐次**，右端不合适定系数 | **参数变易法**：`y_p = Σ cᵢ(x)yᵢ`，解 Wronski 方程组再积分 | 常数别与齐次解的 C 重复计 |
| **常系数**线性齐次 `y⁽ⁿ⁾ + a₁y⁽ⁿ⁻¹⁾ + … + aₙy = 0` | 写**特征方程** `p(λ) = 0`：<br>· 单实根 `λ` → `e^(λx)`<br>· m 重实根 → `x^j e^(λx)`，`j = 0…m−1`<br>· 复根 `α ± iβ` → `e^(αx)(cos βx, sin βx)` | 重根要乘 `x^j`；复根别丢 `e^(αx)` |
| `xⁿy⁽ⁿ⁾ + … `（x 的幂次与导数阶数**配对**） | **Cauchy–Euler**：令 `x = e^t`（或试 `y = x^λ`）→ 化常系数 | 每项 `x` 的幂与导数阶数是否真配对 |
| 常系数非齐次，右端 `f(x)` 形如 `P(x)e^(αx)`、`e^(αx)(A cos βx + B sin βx)` | **待定系数法**：先解齐次，按 `f` 的形状设特解 | 与齐次解**重合**时要乘 `x^s`（共振） |
| 非齐次，`f(x)` 不属上面那些形状 | 回到**参数变易法** | 同上 |

## 2. 复习时的三个自检问题（每块都问一遍）

1. **看到这个形状，我第一步做什么？** —— 说不出 ⟹ 这一块要回去看。
2. **这个方法的适用条件是什么？**（例如积分因子要求那个商只依赖一个变量；待定系数要求右端形状合适）
3. **做完之后有什么必须补的？**（漏掉的常数解、奇解、重根乘 `x^s`、代回换元）

> `[教学归纳]` 一个现实建议：这 8 块里，**考试主干是 2、4、7、8**（可分离/齐次类、一阶线性类、常系数齐次、非齐次）。
