## 0. 这一节到底在回答什么问题

解一个初值问题，你平时做的是两件事：**找一个解**、**确认它符合初值**。但这里还有第三件事，平时被跳过了：

> 凭什么说「这个解就是唯一的那个」？会不会还有别的解？

存在唯一性定理回答的就是这个问题。它不给你算法的公式，而给一个**资格判定**：

> 在什么条件下，我可以放心地说「解存在、且只有一个」？

`[教学归纳]` 这门课的解方程算法之所以能放心写「通解 + 初值定常数」，前提就是这类定理；一旦条件被破坏，就会出现「同一个初值对应无穷多个解」的现象（下面的课件例 1 就是）。

## 1. 定理的完整陈述（课件 p24 原文）

**课件原文：**

> THEOREM. (Existence and uniqueness theorem) Consider the initial value problem
> `y⁽ⁿ⁾(x) = f(x, y(x), y′(x), …, y⁽ⁿ⁻¹⁾(x))`, (16)
> `y(x₀) = y₀, y′(x₀) = y₁, …, y⁽ⁿ⁻¹⁾(x₀) = y_{n−1}`. (17)
> Let D be a domain in ℝⁿ⁺¹, `(x₀, y₀, …, y_{n−1}) ∈ D`, `f(x, y₁, y₂, …, yₙ) ∈ C(D)` and `∂f/∂y_i ∈ C(D)` for `i = 1, …, n`. Then there exists a unique solution of (16), (17), **defined on some interval |x − x₀| < h, where h is sufficiently small**. The proof of this theorem is omitted.

**逐条拆开看**：

| 条件 | 意思 | 破坏了会怎样 |
|---|---|---|
| `D` 是 ℝⁿ⁺¹ 中的区域 | 讨论范围是一个开连通域 | 初值落在边界上时无从谈起 |
| 初值点 `(x₀, y₀, …, y_{n−1}) ∈ D` | 初值必须在区域内 | 初值不在 D 内 → 定理不适用 |
| `f` 在 `D` 上连续 | 右端不过分野蛮 | 有间断点 → 连存在性都可能没有 |
| `∂f/∂y_i` 在 `D` 上连续 | 比"连续"更紧：对 y 的变化率有界 | 这正是**唯一性**的那一条 |

**结论只保证局部**：存在某个 `h > 0`，在 `|x − x₀| < h` 上有唯一解。定理**不说** `h` 等于多少，也**不说**解能延拓多远。

两个常见误读：

- ✗「解在整个定义域上存在」——不保证（见 §4 例 2）；
- ✗「f 连续就够了」——不够，还要 `∂f/∂y_i` 连续（见 §3 例 1）。

## 2. 考场上怎么检查（实用判据）

`[教学归纳]` 定理里的「`∂f/∂y_i` 连续」是为了保证 f 对 y 满足 **Lipschitz 条件**；Lipschitz 才是唯一性的真正来源。课堂上不考证明，只考**检查**，所以把它变成三步：

1. 写出 `f(x, y)`（高阶方程先化成一阶方程组，或直接看右端含 `y, y′, …` 的表达式）；
2. 找 `∂f/∂y` 的**表达式**；
3. 看 `∂f/∂y` 在**初值点附近**是否连续。连续 ⟹ 定理适用（局部存在唯一）；不连续 ⟹ **定理无法保证**，此时既可能多解、也可能仍然唯一，必须单独讨论。

**典型破坏点**（记住这几类，考场基本就够）：

- `y^α`（`0 < α < 1`，如 `y^(2/3)`、`√y`、`y^(1/3)`）在 `y = 0` 处：导数 `∝ y^(α−1)` 发散；
- `ln y` 在 `y → 0⁺`；
- `1/y`、`1/(y − c)` 在 `y = c`；
- `tan y` 在 `y = π/2 + kπ`。

## 3. 例 1：唯一的判据被破坏会怎样（课件 p25–p26）

**题目**：`y′(x) = 3y^(2/3)(x)`，`y(x₀) = y₀`。（课件 (18) 式）

**第一步，检查条件。** 右端 `f(x, y) = 3y^(2/3)` 在 `D = ℝ²` 上连续——**但也仅止于连续**。求偏导：

  ∂f/∂y = 2y^(−1/3)

这个式子只在 `y ≠ 0` 时连续；`y = 0` 处发散。所以定理**分两种情况**说话：

**情形 A：`y₀ ≠ 0`（课件 p25 结论）。** 初值点附近 `y ≠ 0`，`∂f/∂y` 连续，定理适用 ⟹ 解在某个 `|x − x₀| < h` 内**唯一**。课件给出它的显式：

  y = (x − x₀ + y₀^(1/3))³

（取 `C = −x₀ + y₀^(1/3)` 代入通解 `y = (x + C)³` 即得。）

**情形 B：`y₀ = 0`（课件 p26）。** 此时定理不适用，实际也确实不唯一。课件列出：

- `y = (x − x₀)³` 是一个解，`y(x) ≡ 0` 也是解（后者是课件明确点出的 **singular solution**，即不出现在通解里的解）；
- 更强的是，**有无穷多个解**，由一个常数 `x̄ > x₀` 控制：

  y(x) = (x − x₀)³　（x ≤ x₀）

  y(x) = 0　（x₀ < x < x̄）

  y(x) = (x − x̄)³　（x ≥ x̄）

`[教学归纳]` 这三种写法的共同点是：**在 `y = 0` 那条水平线上"接龙"**。因为 `y ≡ 0` 本身是解，而 `y^(2/3)` 在 0 附近"允许"解以任何角度离开 0，于是可以拼出无穷多条曲线，各自满足同一个初值条件。

**课件的追问（p26 末段 + 配图）**：如果把初值改成 `y(x₁) = y₁`（图上另一点），这条解的 **唯一性区间**是什么？课件答案：**`x ≤ x₀`**。

`[教学归纳]` 读法：从 `(x₁, y₁)` 往右走，到 `x = x₀` 处遇到 `y = 0` 那条"接龙点"之前，解是唯一的；越过它之后可以改走 `y ≡ 0` 再重新接一段，唯一性就丢了。所以「唯一性区间」不是"解存在到多远"，而是"哪个范围内不会出现另一条解"。

## 4. 例 2：条件全满足，也只是局部（课件 p27）

**题目**：`y′(x) = y²(x)`，`y(0) = 1`。（课件 (19) 式）

**检查条件**：`f = y²` 连续，`∂f/∂y = 2y` 在 `ℝ²` 上连续 ⟹ 定理条件**全部满足**。

**求出来**：

  y(x) = 1/(1 − x)

代回验证：`y′(x) = (1 − x)^(−2) = y²(x)` ✓，且 `y(0) = 1` ✓。

**问题**：这个解在 `x = 1` 处**爆掉**（`y → +∞`），只在 `x < 1` 有定义。

这就是定理那句「`|x − x₀| < h`，`h` 充分小」的现实含义：**它保证的是局部，不是整体**。条件再漂亮，也不能防止解在有限距离内跑向无穷 `[教学归纳]`。

## 5. 考场题型与写法

**题型 A：判断某个初值问题是否保证存在唯一解。**

写法固定三段：
1. 写 `f`，说明它是否连续；
2. 写 `∂f/∂y`，说明它在初值点邻域是否连续；
3. 结论：满足定理 ⟹ 在 `|x − x₀| < h` 内存在唯一解（**必须写"局部"**）；不满足 ⟹ 定理不能保证，需另行分析（给例子时再举两个解）。

**题型 B：证明不唯一——给两个不同的解。**

套路：找一个使 `∂f/∂y` 发散的 `y` 值（记为 `b`），令初值 `y(x₀) = b`，然后
- 常数解 `y ≡ b`；
- 另一个从 `b` 出发的解（通常由分离变量积出来）。

两者都满足同一个初值 ⟹ 不唯一。

**题型 C：求唯一性区间。**

找出 `∂f/∂y` 失连续的 `y` 值，看解在哪个 `x` 处第一次碰到它，答案就是"碰到之前"那一段（例 1 的追问即此类）。

**题型 D：线性方程为什么可以整体讨论** `[教学归纳]`

对一阶线性 `y′ + p(x)y = q(x)`，若 `p, q` 在区间 `I` 上连续，则右端 `f = q − py` 满足 `∂f/∂y = −p(x)` 在 `I` 上连续，Lipschitz 常数可取 `max|p|`，所以唯一性在**整个区间 `I`** 上成立、不需要"`h` 充分小"。这就是线性方程比非线性方程"好说话"的根源，也是为什么这门课大量篇幅在做线性化处理。（此条为归纳；若需引用具体讲次，查课件 L4。）

## 6. 五条易错点

1. **「连续」不等于「满足条件」**：`3y^(2/3)` 处处连续，但 `∂f/∂y` 在 0 处发散 ⟹ 定理不覆盖 `y₀ = 0`。
2. **结论是局部的**：写"存在唯一解"时带上 `|x − x₀| < h`，别写成"在整个区间上唯一"。
3. **定理不适用 ≠ 一定多解**：定理只给充分条件；条件不满足时可能仍唯一，必须单独讨论（`[教学归纳]`：`f = |y|` 在 `y = 0` 处不可导，但它是 Lipschitz 的，所以解仍唯一——这属于课件判据之外的例外，考试按课件口径答即可）。
4. **别把「奇解」和「不唯一」混为一谈**：`y = (x + C)³` 的奇解 `y ≡ 0` 是**通解漏掉**的解；唯一性讨论的是"给定初值有几种可能"，两者相关的只是同一处导数发散。
5. **分段拼接要检验光滑性**：判卷时会看你拼出来的函数在接点处是否连续且可导（本例中在 `y = 0` 处 `y′ = 0`，两侧导数也都为 0，所以接得上）。

## 7. 自检（先做，答案在文末）

1. `y′ = √y`，`y(0) = 0`。定理能否保证唯一？若不能，写出两个不同的解。
2. `y′ = y^(1/3)`，`y(0) = 0`。同上。
3. `y′ = y²`，`y(1) = 2`。解是什么？它在哪个 `x` 处失效？
4. `y′ = 1/y`，`y(0) = 1`。定理条件是否满足？解是什么、在哪个区间有定义？

---

## 自检答案

1. **不能保证**。`f = √y` 在 `y = 0` 处 `∂f/∂y = 1/(2√y)` 发散。两个解：`y ≡ 0` 与 `y = x²/4`（`x ≥ 0`）。验证后者：`y′ = x/2`，`√y = x/2` ✓。
2. **不能保证**。`∂f/∂y = (1/3)y^(−2/3)` 在 0 处发散。两个解：`y ≡ 0` 与 `y = (2x/3)^(3/2)`（`x ≥ 0`）。验证：`y′ = (2x/3)^(1/2)`，而 `y^(1/3) = (2x/3)^(1/2)` ✓。
3. 分离变量：`−1/y = x + C`，由 `y(1) = 2` 得 `C = −3/2`，故

  y(x) = 2/(3 − 2x)

  它在 `x = 3/2` 处 `y → ∞`，解失效（定理只保证局部）。
4. **满足**：`f = 1/y`，`∂f/∂y = −1/y²`，在 `y = 1` 的邻域连续。解由 `y dy = dx` 得 `y² = 2x + 1`，取正支

  y(x) = √(2x + 1)，定义域 `x ≥ −1/2`
