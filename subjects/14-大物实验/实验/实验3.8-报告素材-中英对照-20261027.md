## III. Preview Questions (10) / 预习问题

### Q1. Why doesn't B follow a linear relationship with H in a ferromagnetic material?

*为什么铁磁材料的 B 与 H 不是线性关系？*

**Answer (EN):** Ferromagnetism originates from magnetic domains. Domain-wall motion and domain rotation respond nonlinearly to H: M rises quickly at first, then slows down and saturates at Ms. Since B = μ0(H + M), μ = B/H is not constant; at high H, B ≈ μ0(H + Ms) and the curve flattens.

**中文：** 铁磁性来自磁畴：畴壁移动（先可逆、后不可逆）和畴转动对 H 的响应非线性，M 先快速增大、后减慢并饱和到 Ms；由 B = μ0(H + M) 可知 μ = B/H 不是常数，高场下 B ≈ μ0(H + Ms)，曲线变平。

### Q2. Explain the magnetization curve and the hysteresis loop, with sketches.

*说明磁化曲线与磁滞回线，并画图。*

**Answer (EN):** The magnetization curve is the initial B–H curve obtained from a demagnetized state: B rises slowly, then steeply, then bends to saturation Bs. The hysteresis loop is the closed path under cyclic magnetization: O → a (positive saturation) → b (Br at H = 0) → c (Hc at B = 0) → d (negative saturation) → e (−Br) → f (−Hc) → a. Its area equals the hysteresis loss per unit volume per cycle.

**中文：** 磁化曲线是从退磁态出发的初始 B–H 曲线：B 先缓、后陡、再饱和到 Bs。磁滞回线是循环磁化下的闭合路径 O → a（正向饱和）→ b（H = 0，Br）→ c（B = 0，Hc）→ d（反向饱和）→ e（−Br）→ f（−Hc）→ a；回线面积等于每周期单位体积的磁滞损耗。

### Q3. Why do we measure the magnetization curve and the hysteresis loop?

*为什么要测磁化曲线和磁滞回线？*

**Answer (EN):** The measurements give Br, Hc, Bs and μr,max, which characterize a magnetic material. They are used to classify soft/hard materials, select cores for transformers, motors, relays and permanent magnets, estimate hysteresis loss, and check material quality.

**中文：** 测量给出 Br、Hc、Bs、μr,max 等特征参数，用于判断软磁/硬磁、选择变压器/电机/继电器/永磁体材料、估算磁滞损耗和检验材料质量。

### Q4. Explain the principle of measuring the hysteresis loop with an oscilloscope; draw the circuit and write the formulas.

*说明用示波器测磁滞回线的原理；画出电路并写出公式。*

**Answer (EN):** The primary current i1 produces U_R1 = i1R1, so H = N1U_R1/(LR1). The secondary emf ε2 = −N2S dB/dt is integrated by R2C (ωR2C ≫ 1), giving U_C = N2SB/(R2C). In X-Y mode, CH1 (U_R1) drives the X axis (H) and CH2 (U_C) the Y axis (B), so the screen shows the B–H loop. With U_R1 = Sx·x and U_C = Sy·y: B = CR2Sy·y/(N2S), H = N1Sx·x/(LR1), Br = CR2Sy·yr/(N2S), Hc = N1Sx·xc/(LR1), μr = CR2LR1Sy/(μ0N2SN1Sx)·(y/x).

**中文：** 原边电流 i1 在 R1 上产生 U_R1 = i1R1，故 H = N1U_R1/(LR1)；副边 ε2 = −N2S dB/dt 经 R2C 积分（ωR2C ≫ 1）得 U_C = N2SB/(R2C)。示波器 X-Y 模式：CH1（U_R1）作 X 轴（H），CH2（U_C）作 Y 轴（B），屏上即 B–H 回线。用 U_R1 = Sx·x、U_C = Sy·y：B = CR2Sy·y/(N2S)，H = N1Sx·x/(LR1)，Br = CR2Sy·yr/(N2S)，Hc = N1Sx·xc/(LR1)，μr = CR2LR1Sy/(μ0N2SN1Sx)·(y/x)。

### Q5. Why is demagnetization necessary before measuring, and how is it done?

*测量前为什么要退磁？怎么退？*

**Answer (EN):** The B–H curve depends on magnetic history. Residual Br would shift the starting point away from O and bias Br, Hc and μmax. With the AC excitation on, reduce the excitation current (amplitude) slowly and monotonically to zero; the loop shrinks and finally collapses to a point at the origin (AC demagnetization).

**中文：** B–H 曲线与磁化历史有关。剩磁会使起点偏离 O，使 Br、Hc、μmax 偏移。退磁时保持交流激励，把激励电流（幅度）缓慢、单调地减到零，回线逐渐缩小，最后缩成原点处一个点（交流退磁）。

### Q6. How can the sample be brought to saturation?

*怎样让样品达到饱和？*

**Answer (EN):** Increase the excitation current monotonically and watch the loop tips. Saturation is reached when further increase of current mainly moves the tip along H while B hardly increases — the loop top/bottom flattens and the tips become sharp. At that point M → Ms and only the μ0H term still grows.

**中文：** 单调增大激励电流，观察回线顶点；当继续增大电流时顶点主要沿 H 方向移动、B 几乎不变，回线顶部变平、顶点变尖，即达到饱和；此时 M → Ms，只有 μ0H 项继续增大。

### Q7. How can distortion of the hysteresis loop caused by phase error be avoided?

*怎样避免相位失真造成的回线畸变？*

**Answer (EN):** The RC integrator requires R2 ≫ 1/(ωC), i.e., ωR2C ≫ 1; otherwise U_C is phase-shifted relative to B and the loop is distorted (a linear core would even show an ellipse). Increase R2 or C, use DC coupling on both channels with matched probes, then fine-tune R2/C until the loop is smooth and closed. At 50 Hz, ωR2C ≥ 20 is a safe choice.

**中文：** RC 积分器要求 R2 ≫ 1/(ωC)，即 ωR2C ≫ 1；否则 U_C 相对 B 有相位差，回线失真（线性磁芯也会显示成椭圆）。增大 R2 或 C，两通道用 DC 耦合、探头一致，再微调 R2/C 使回线光滑闭合；50 Hz 下取 ωR2C ≥ 20 较稳妥。

### Q8. How can the saturated, undistorted loop be made to fill the oscilloscope screen?

*饱和且不失真时，怎样让回线占满屏幕？*

**Answer (EN):** First set R2/C for good integration, then increase the excitation to saturation. Adjust R1 (X amplitude, H), R2/C (Y amplitude, B) and the vertical scales Sx, Sy so that the loop is centered at (0,0) and its tips fall at (+4,+4) and (−4,−4) divisions, filling the 8×8 grid without clipping. Keep R1, R2, C, Sx, Sy fixed and record them.

**中文：** 先调 R2/C 满足积分条件，再增大激励到饱和；调 R1（X 幅度，H）、R2/C（Y 幅度，B）及示波器 Sx、Sy，使回线中心在 (0,0)、顶点落在 (±4,±4) 格，占满 8×8 屏幕且不削顶；固定并记录 R1、R2、C、Sx、Sy。

### Q9. How is the basic magnetization curve measured?

*怎样测基本磁化曲线？*

**Answer (EN):** Demagnetize first and fix Sx, Sy, R1, R2, C. Increase the excitation current monotonically in steps so that the positive vertex x-coordinate is 0, 0.40, 0.80, 1.20, 1.60, 2.00, 2.40, 3.00, 4.00 div; record the corresponding y at each step. Convert with H = N1Sx·x/(LR1) and B = CR2Sy·y/(N2S), then plot B vs H (and y/x vs x for μr).

**中文：** 先退磁，固定 Sx、Sy、R1、R2、C；单调增大激励，使回线正顶点 x 依次为 0、0.40、0.80、1.20、1.60、2.00、2.40、3.00、4.00 格，记录对应 y；用 H = N1Sx·x/(LR1)、B = CR2Sy·y/(N2S) 换算，作 B–H 曲线（以及 y/x ~ x 的 μr 曲线）。

### Q10. How is the relative permeability obtained?

*怎样得到相对磁导率？*

**Answer (EN):** At each point, μr = B/(μ0H). In screen coordinates, μr = CR2LR1Sy/(μ0N2SN1Sx)·(y/x). Plot μr vs H (or y/x vs x); the maximum of the curve gives μr,max and its coordinate gives the corresponding H.

**中文：** 逐点 μr = B/(μ0H)。用屏幕坐标：μr = CR2LR1Sy/(μ0N2SN1Sx)·(y/x)。作 μr–H（或 y/x ~ x）曲线，最大值即 μr,max，对应坐标给出 H。

## IV. Post-lab Questions (8) / 课后思考题

### Q1. Why must the sample be demagnetized before measurement? How is it done?

*为什么测量前必须退磁？怎么退？*

**Answer (EN):** The B–H curve depends on magnetic history; residual Br would shift the starting point away from O and bias Br, Hc and μmax. Demagnetize by slowly and monotonically reducing the AC excitation current to zero until the loop collapses to a point.

**中文：** B–H 曲线与磁历史有关；剩磁会使起点偏离 O，使 Br、Hc、μmax 偏移。退磁：保持交流激励，把激励电流缓慢、单调减到零，直到回线缩成一点。

### Q2. How can you tell that the sample has reached saturation?

*怎样判断样品已经饱和？*

**Answer (EN):** Further increase of the excitation mainly extends H while B hardly changes; the loop tips become sharp and the top/bottom flatten. This means M → Ms, so only the μ0H term still grows.

**中文：** 继续增大激励时主要是 H 增大而 B 几乎不变；回线顶点变尖、上下变平，说明 M → Ms，只剩 μ0H 项在增长。

### Q3. Why must R2 ≫ 1/(ωC)? What happens otherwise?

*为什么要求 R2 ≫ 1/(ωC)？不满足会怎样？*

**Answer (EN):** This condition makes the secondary current i2 ≈ ε2/R2, so U_C ∝ ∫ε2dt ∝ B. If it is not met, U_C is phase-shifted relative to B; even a linear core shows an ellipse and a ferromagnetic loop is distorted, so Br and Hc are misread.

**中文：** 该条件使副边电流 i2 ≈ ε2/R2，从而 U_C ∝ ∫ε2dt ∝ B。不满足时 U_C 与 B 有相位差，线性磁芯也会显示椭圆，铁磁回线被扭曲，Br、Hc 读不准。

### Q4. Why does the loop area represent hysteresis loss? Give the unit.

*为什么回线面积代表磁滞损耗？单位是什么？*

**Answer (EN):** Per cycle, the magnetic field does work W = ∮H dB per unit volume; for a closed loop this equals the enclosed area. The unit is J/m³; multiplying by sample volume V and frequency f gives the hysteresis power loss.

**中文：** 每周期单位体积磁场做功 W = ∮H dB，闭合回线时等于所围面积，单位 J/m³；乘样品体积 V 和频率 f 得磁滞损耗功率。

### Q5. Compare soft and hard magnetic materials; give one application for each.

*软磁与硬磁的区别和应用？*

**Answer (EN):** Soft magnets have small Hc, high μ and a narrow loop; they are easily magnetized/demagnetized and are used for transformer cores, relays and motor cores. Hard magnets have large Hc and Br and a wide loop; they are used for permanent magnets such as NdFeB, SmCo and ferrite magnets.

**中文：** 软磁 Hc 小、μ 高、回线窄，易磁化/退磁，用于变压器铁芯、继电器、电机铁芯；硬磁 Hc 大、Br 高、回线宽，用于钕铁硼、钐钴、铁氧体等永磁体。

### Q6. Why is the basic magnetization curve measured by monotonically increasing H from the demagnetized state?

*为什么基本磁化曲线要从退磁态单调增大 H 来测？*

**Answer (EN):** This keeps every point on the same initial magnetization curve. If H is increased and decreased repeatedly, the sample follows minor loops and the measured B is no longer the initial value for that H.

**中文：** 这样每个点都落在同一条初始磁化曲线上；若 H 反复增减，样品会走小回线，测到的 B 不再是该 H 对应的初始值。

### Q7. What are the main sources of error? How can they be reduced?

*主要误差来源有哪些？怎样减小？*

**Answer (EN):** Grid reading, Sx/Sy calibration, R and C tolerances, integrator phase error, frequency drift, temperature/magnetic history and non-uniform magnetization. Reduce them by repeated readings, using measured component values, ensuring ωR2C ≫ 1, demagnetizing before each run, and keeping the frequency and connections stable.

**中文：** 格数估读、Sx/Sy 校准、R/C 容差、积分器相位、频率漂移、温度/磁历史、磁路不均匀。减小办法：多次读数、用实测元件值、保证 ωR2C ≫ 1、每次测前退磁、保持频率与接线稳定。

### Q8. Why use X-Y mode instead of the normal time-base display?

*为什么用 X-Y 模式而不是普通时域波形？*

**Answer (EN):** The normal time-base shows U versus t for each channel separately, so it does not directly give B as a function of H. X-Y mode plots U_R1 (H) on the horizontal axis and U_C (B) on the vertical axis, point by point, so the screen directly shows the B–H loop.

**中文：** 普通时域是各通道的 U–t 波形，不能直接给出 B 与 H 的函数关系；X–Y 模式把 U_R1（H）作横轴、U_C（B）作纵轴逐点合成，屏上直接显示 B–H 回线。

## VI. Appendix · Key formulas

| Quantity | Formula | Unit |
|---|---|---|
| Magnetic field strength | H = N1·U_R1 / (L·R1) = N1·Sx·x / (L·R1) | A/m |
| Flux density | B = C·R2·U_C / (N2·S) = C·R2·Sy·y / (N2·S) | T |
| Residual magnetism | Br = C·R2·Sy·yr / (N2·S) | T |
| Coercive force | Hc = N1·Sx·xc / (L·R1) | A/m |
| Relative permeability | μr = B/(μ0·H) = C·R2·L·R1·Sy/(μ0·N2·S·N1·Sx)·(y/x) | — |

Checklist: (1) demagnetize to a point; (2) fix/record R1, R2, C, Sx, Sy; (3) basic curve x = 0…4.00 div; (4) loop x = −4.00…4.00 div; (5) read Br at x = 0, Hc at y = 0; (6) compute μr and μr,max; (7) repeat for sample 2 with its own L, S.
