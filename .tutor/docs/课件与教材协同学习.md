# 课件与教材协同学习

## 本学习者已确认的默认方式

目标兼顾考试、作业与理解后独立解题。课件和老师明确要求决定当前主线；必要前置与当前理解缺口纳入路线，较难且课件未涉及的教材内容列为拓展，不自动加任务或考试范围。
这里的拓展指课件没有涉及的教材额外内容；课件已经讲的方法，不因教材把它放到后面、指定阅读没覆盖或某次作业没用到就降为拓展。课件主线可分多次学，不意味着今天全部完成。暂缓课件主线要有用户决定或明确老师范围及其实际来源；不能自造“不单独考/作业不考”的权重。
首次读当前章的结构和重点，教学过程中按需要细读正文、推导、公式、例题和图表。助手多做检索、对应与整理，学习者主要负责理解、作答和指出卡点。
既有教材优先顺序、同书 v2 优先和只读知识库约定来自 `.tutor/config/knowledge-base.md`。具体课程先查该登记与相关教材索引；不要重新询问已经有答案的教材选择。知识库里的“verified”是原解构工具自评，不能当作本助手读过原书。

## 何时准备

只在首次规划/学习相关章节、资料更新、已准备内容不足以解决当前卡点时触发。/status、维护和简单续学不扫描教材库。用户给了明确题目时先定位所需概念与页码、解决问题，再补相邻结构；不要求先完成整章阅读才能辅导。
1. 在课件索引中确认本章实际文件，查缓存 `python -B tools/chapter_guide.py check --chapter <章节ID>`。ready 时读取 guide 并结合最新学习证据；不因新作答重新读一遍未变资料。
2. 缺准备时主动核目录、各节标题和摘要，检查关键定义、方法/定理条件、图表用途、例题与作业位置。目录只是定位入口；至少核读实际关键内容，才能给内容要点。若长课件没有目录，借书签/文本标题搜索定位、检查相应页，不要求学习者整理。
3. 先读指定教材的索引/对应 v2 笔记以定位，再按本次需要查教材原书。优先相关节，不逐本通读；扫描版、同义译名和章节顺序不同均可能导致文字搜索无结果。找不到时换术语、查目录、邻近章节或读图；不把无搜索命中当成不存在。
4. 建立以概念/方法为单位的对应，核对讨论对象、假设与符号，而非仅按同名标题。保存页码、来源、已查范围、要点、例题/练习位置、前置与待细读页。
保存前核查：已知教材具体章节有对应时写 shared（若原书未读则 unresolved），不能因只查了前章就写教材缺项。文字检索到的页不进入text_read_pages；只记录真正看过相应内容的页。引用具体题干/例题时先实际读图该页，核对根号、指数、导数阶数与条件，再验算关键结论；课件自身也可能有错，保留source_issues中的原文/核验/修正/待确认，不把原资料错误批成学习者错误。
5. 用当前作答、用户自述、截止和既有计划选择今天的入口。自述标来源；无独立证据不等于不会，最多做一个必要的短检查，不重做整套访谈。估计耗时标估计，不编可用时间。
6. 向学习者展示简短路线，必要时说明一个关键差异，直接进入第一个学习动作。详细地图保存在工作区，按需解释，不在开场输出整张台账或反复请求“是否继续”。
本次可用时间约30–45分钟时，优先一个主目标，最多一个可选后续；不要把多节推导、多个作业和复测都硬塞进同一短时段。耗时是估计，准备/查资料也占时间；超出时拆分并保留下一步。对用户的开场只需本章路线、一处有用差异和当前动作，不展示全部读取日志或旧台账差异，除非用户要求审计。首次准备可保存未确认对应，再在教学用到时补读；不为全章配齐教材引用才开始辅导。
提出首个学习动作时会话仍在进行：不跑收尾、不创建pause反馈、不为全部未知单元建任务。只有用户实际暂停/结束或学习已完成才走保存与收尾；只获准缓存写入的联测更不能追加观察账本或派生状态。

## 四类对应与两种补充

| 对应 | 处理 |
|---|---|
| 课件与教材共同内容 | 沿用课件符号，教材补解释、条件、推导和另一种观点；不重复讲已经理解的部分 |
| 课件在已查教材范围内独有 | 单独纳入课件主线，保留方法与题型；写清查过哪本书/哪几节，不断言所有教材没有 |
| 教材补充 | 解释为什么与当前目标有关；必要前置/理解缺口为 prerequisite，其余为 extension，不自动形成必做任务 |
| 对应未确认/有冲突 | 保留局部待确认和下一步检索位置，继续其他确定内容；只读了笔记时标候选对应，教学用到的公式/条件查原书 |

课件未列≠老师没讲，课件已列≠考试必考。确认缺项只能针对实际查过的章节/页；未检查正文时写“本章结构未列/所查页未见”，不宣称全文没有。
跨教材的符号、坐标、单位、适用条件、近似与难度差异要解释，不机械判断谁错。扫描公式读不清，只确认该局部；不让学习者全文转写。补充内容不能凭空提升考试优先级。用户要求更深入时再展开拓展。
讲解优先使用地图中已经核读的定义/条件；不为了补充观点临时引入未核验例子。共同内容的化简条件通常是充分条件，不能写成唯一必要条件。例如 E=T+U 不要求直角坐标；速度无关势、T关于广义速度齐二次时可化简。若 T=T₂+T₁+T₀，则 E=T₂−T₀+U（U速度无关），用本式检验转杆等当前模型。磁场例子不可混淆速度依赖广义势与标量势能，不因多了 A·v 就断言能量不等于 T+qφ。教材所说“局部存在唯一”只保证初值附近的一小段区间，不能扩大成整个矩形上存在解。

## 阅读工具与保存

从工作区根目录执行，source 是工作区内真实相对路径；同步知识库在 obsidian/，保持只读。

```text
python -B tools/chapter_guide.py list --subject <课程目录>
python -B tools/chapter_guide.py template --chapter <章节ID>
python -B tools/material_reader.py info --source <PDF相对路径>
python -B tools/material_reader.py read --source <PDF相对路径> --pages 1-8
python -B tools/material_reader.py find --source <PDF相对路径> --query <术语> [--pages 1-30]
python -B tools/material_reader.py render --source <PDF相对路径> --pages 6,8
python -B tools/chapter_guide.py save --file <准备结果.json>
python -B tools/chapter_guide.py show --chapter <章节ID>
```

首次提取缓存文字和书签供快速检索；read 每批最多 12 页，render 每批最多 8 页。长章节分批读取并总结，保留尚未读的位置。缓存位于 `.tutor/cache/materials/<源文件SHA256>/`，结构地图在 `learning/chapter-guides/<章节ID>.json`。缓存不写回知识库；PyMuPDF 为新增依赖。
guide 记录实际阅读收据，text_read_pages 指实际看过文本的页，不是全文提取页；visual_read_pages 指实际打开看过的图；formula_verified_pages 是图像中公式/条件已核对的子集。此工具只验证结构/引用/版本，不能证明模型真正理解，语义质量须真实辅导验收。
新建和更新地图一律先在缓存中构造待验证JSON，调用chapter_guide.py save；不直接edit/write已保存的guide，也不只补check伪装成save。source_issues是局部资料问题清单，可记录误印和OCR疑点；备课记录不改源PDF或知识库。把结论确认为资料错误前，使用计算工具独立复算等式两边/残差，保存实际计算依据；口头声称“已验算”不够。隐式解先把约束用于化简，反例点先核对满足约束与定义域，再计算两边，不把自身算术错误推给原资料或学习者。
所有页码统一用 PDF 文件第几页（1 起始）；印刷页码另标，不混用。教材版本用源路径和哈希固定，笔记索引也列为 source；资料或本协议变化后 check 会拒绝旧对应。刷新受影响内容，未变提取缓存复用。
只有资料地图缓存；“今天略过什么”和“已掌握什么”每次用当前学习证据重算。guide 不改成绩、不完成任务、不宣称课程全覆盖。

### 课件 AI 可读层（电工学，2026-10-16 建立）

老师在课堂上发的 PPT 导出件里，**电路图、波形图、特性曲线全是位图**，文字层取不到，而图就是这门课的全部信息。
因此对 `subjects/06-电工电子技术/课件/` 的 12 个 PDF 建了一层逐页可检索的转写，放在
`subjects/06-电工电子技术/课件-AI可读/`（入口 `index/INDEX.md`，说明见该目录 `README.md`）：

```text
python tools/ee-slides-run-mineru.py        # MinerU hybrid-engine（本地 GPU）版式解析；约 4.5 s/页
python tools/ee-slides-build.py build       # 组装逐页 md / 整册全文 / pages.jsonl / INDEX / 整页渲染图
python tools/ee-slides-merge-descriptions.py tasks   # 生成逐页读图任务（每批 6 页）
python tools/ee-slides-build.py refresh     # 把图区描述回填进正文并重建 INDEX
python tools/ee-materials-register.py       # 按实际产出登记 learning/materials.json 的页级读取事实
```

引用写法 `[C1-1 p17]`＝课件 id + PDF 物理页；页码与 `assets/<deck>/p###.jpg` 编号一致。
这一层是**课件的忠实转写**：不是讲义、不含答案、不构成掌握证据；公式与页面图冲突时以页面图为准。
读图前先按小节取页（`index/INDEX.md` 的「页码 → 小节」表已把节号沿页序传播），比逐页扫更快也更省。

## guide 最小结构

schema_version=1；chapter_id（沿用 curriculum 中 ID）；subject；preparation=structure/keypoints/detailed；sources；structure_refs；units；next_read。
sources 每项含 id、path、role=slides/textbook/knowledge-note、sha256。PDF 另含 page_count 与实际 text_read_pages、visual_read_pages、formula_verified_pages；笔记含 note_read=true。
引用：PDF 为 `{source: 源ID, pages: [PDF页]}`；笔记为 `{source: 源ID, heading: 实际读过的小节标题}`。
units 每项含 id、title、key_points、slide_refs、book_refs、relation（shared/slides-only-in-checked-scope/textbook-supplement/unresolved）、route（main/prerequisite/extension）。可加 prerequisites、target_ids、example_refs、exercise_refs。
已从目录/索引定位到原书对应节但尚未读正文时，填 book_candidates（教材PDF source与候选pages，可加section/located_by），relation=unresolved；候选页不能填book_refs或阅读收据。实际读正文后再改shared。不能一边把对应节写进next_read，一边因只查前章把同一单元标为slides-only-in-checked-scope。
shared 需要读过的课件和教材原书双方证据；笔记单独不足以确认。slides-only-in-checked-scope 需要 comparison_scope（包含已查教材原书引用），只查笔记时必须 unresolved。textbook-supplement 写 reason 与 slide_checked_scope（已查课件引用）；教材难且不必要时 route=extension。unresolved 写 reason 和下一步核读，不禁止其他教学。
结构地图不能自动替代 curriculum 的全范围/目标映射；范围对账仍走原工具，新增确证小节时按原 WorkspaceLock 约定更新 catalog，未知范围保持未知。完整备课不生成学习事件，真实作答仍走原入账流程。

## 教学中的使用

每次聚焦一个瓶颈：必要解释/条件 → 小例子或当前题关键步骤 → 学习者尝试一个具体动作。仍不理解就换表述、联系已懂概念并展开当前例子，不重复原提问。直接索要完整讲解时满足，不强制先猜答案。
第一次学习动作只围绕当前卡点，只用一道题的一个判断或步骤；不要一次要求多题、多判据、三行推导、多个情形和符号来源说明全部提交。普通学习没有明确测验约定时，可以先补必要解释，再核验一个局部动作，不把“不提示”当默认教学门禁。首次开场用简短课程路线、今天一个目标和当前一步即可；完整七节表、资料问题清单与教材对应明细保存到地图，用户要求时再展开。局部来源疑点由助手继续核查，不在资料已可读的情况下把“请核原页”转给学习者。
学习者已要求读资料、规划或继续学习时，主动推进，不再问“要我现在查吗/是否开始”。没有执行工具时坦诚说明尚未执行并给下一步，不把建议包装成完成。一次局部检查做对只支持该动作的初步表现，不能据此宣称整个概念“真正理解/掌握”。普通规划只给当前可执行路线，不穷举所有可能；教学回复不展示内部relation字段、schema和维护过程。
条件与坐标系相关时说清当前模型：广义能量、L的显含时间与相应守恒判断都对应当前广义坐标，不能说“守恒与选坐标无关”。dE/dt=−∂L/∂t 默认没有额外非保守广义力；有 Qᵢ 时应加 ΣQᵢq̇ᵢ，不把保守模型判据套到耗散系统。存在唯一性的偏导连续是常用充分条件，不是必要条件，反例不证明“还必须偏导连续”。只续一个卡点时不追加未经核验的四组合表和新模型，优先原题或已核例子。
等式“作为所有广义速度的函数恒等”与“某状态/轨道上数值相等”范围不同；必要性需写适用范围与假设，不能把前者逆命题无条件套给后者。量纲也要核对：位置对时间的偏导是速度，匀速转杆其大小为 |Ωr|，不是角速度Ω；方向由实际位置表达式确定。当前卡点的演示后只问同例中一个局部判断，不转到另一个旧题要求四步建模和两项说明。
共同内容压缩重复；课件额外方法明确什么时候用、怎么识别；必要前置给够即可回到原题。举例与出题沿用简单数字、自行验算。没有时间预算时给可中断的下一步，不编精确课时。暂停时保存有效步骤、卡点与下一动作，续学直接接回。
