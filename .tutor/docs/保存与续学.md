# 保存、重试与暂停

本说明补充 learning/README.md，不改变已有事实。正常作答用：

`python -B tools/append_attempt.py --file <本次事件.json> --event-id auto --submission-id <本次真实作答的唯一ID>`

同一次保存重试必须复用 submission_id，即使事件文件换了路径。成功重试返回 ALREADY SAVED，不新增事件、不重复计时。新的真实作答必须使用新 ID，包括同日重做内容相同的题。省略 ID 时按事件内容自动去重；改变同一 ID 的内容会拒绝，事实订正另走 record_correction.py。

目标级字段缺失才回退事件级；显式 null 是未知，不能被事件级 H0、correct 或 none 覆盖。目标级 final 允许 blocked/not_attempted；整题 final_result 仍按原四种结果。未知帮助史不计独立通过。

暂停时保存四要素：有效步骤、失败尝试（没有则未提供）、当前障碍、下次首个动作。没有实际作答就把真实自述写入 observations.py（kind=pause），不创建虚构错题。真实未完成作答在目标 note 保存续学点，并写 task_completed=false。partial/abandoned 保留原截止与具体题，完成全部目标或明确确认 task_completed=true 才出完成队列。能力是否通过另行判定。

`tutor_context.py` 和 `state/current.md` 展示暂停点与最新订正。恢复学习后，使用真实已存在的题目/续学计划作 artifact，调用 observations.py --resolve <ID> --artifact <路径> --reason <处理说明>。只口头说记住不算解决。

周计划按日期及明确的开放/截止时刻与可用时段取交集；9:00 和 09:00 同义。每项显示实际安排时刻，不能把未开放任务提前排入清单。

英语训练按该项目自己的计划与反馈协议。未接入音频时，发音仍为未测；自由对话、语法提示后的修改或模板模仿不自动升级独立能力。
