# 当前工作区约定

入口是根 AGENTS.md 与兼容镜像 CLAUDE.md；Harness 技能入口是 .dsh/skills/tutor-assistant/SKILL.md。模式规则在 .tutor/core/skills/ 下按需加载，执行入口只有 tools/。旧 core/scripts 与历史状态机不参与当前能力判定。

## 权威依据

| 内容 | 文件 |
|---|---|
| 教学工作流、解释规范 | .tutor/core/protocol.md；config/teaching-conventions.md |
| 已确认个人偏好 | .tutor/config/learner-profile.md |
| 原始能力事实 | learning/attempts.jsonl、corrections.jsonl、hurdles.jsonl |
| 当前能力状态 | learning/learner-state.json、state/current.md（派生） |
| 课程应覆盖范围 | learning/curriculum.json |
| 资料版本、读取事实 | learning/materials.json |
| 遗漏与新反馈 | learning/observations.jsonl |
| 记忆调度 | 概念 frontmatter 与 state/reviews.jsonl |
| 截止与容量 | plan/inputs.yml、learning/goals.yaml |

ARCHITECTURE、AUDIT、STATE、ISSUES、旧送修/交接说明及 _MANIFEST.txt 是历史记录，可能含旧入口、计数或模型名。以当前协议和生成状态为准。原压缩包保留完整历史，交付清单另生成。

## 课程范围和读取事实

curriculum.json：schema_version=1；courses 包含 subject、curriculum_complete、chapters。章节有唯一 id、title、material、structure_status（unknown/partial/verified）、inventory_complete、units；单元有 id、title、source_pages、target_ids。范围依据是实际课件或确认后的考试范围，不能只用已有题目反推全部课程。

materials.json：schema_version=1；materials 中每项有相对 path、sha256、page_count，以及 text_extracted_pages、rendered_pages、visually_read_pages、formula_verified_pages。四类事实分别记，公式核验页必须属于已读页。资料替换后更新哈希、清空失效读取证据、重新核对引用章节；目录未核全保持 inventory_complete=false。

人工更新这些结构化资料时，持有 learning 的 WorkspaceLock，核对当前内容后原子替换；运行 curriculum.py 验证。文字提取不能自动填成已读图或已核公式。本次新读图核对仅涉及 Topic 4 首页；其他历史阅读声明没有全部重新实测。

## 写入方式

- 作答：append_attempt.py --file <事件.json> --event-id auto --submission-id <本次作答ID>。重试复用，新作答换ID；换文件路径不影响去重。字段见 learning/README.md 与 `.tutor/docs/保存与续学.md`；目标显式null保留未知，字段缺失才回退。帮助、曝光逐目标记，closed_book 单独记。dry-run 不取号；写后校验和失败回滚在同一锁内。
- 订正：record_correction.py，提供唯一 correction-id、event-id、field、from/to、reason、source、evidence-ref。非字符串用 --from-json/--to-json。原始事件不改不删，随后收尾。
- 新反馈：observations.py --file <反馈.json>；包含 text、subject、evidence_ref、kind，kind 为 coverage_gap/deadline/difficulty/preference/pause。--list 看队列；--resolve obs-N --artifact <产物相对路径> --reason <理由> 解决，产物必须实际存在。没有作答的暂停用pause，真实未完成作答保留note/截止，不伪造事件。队列不会自动升级能力或改截止。
- 记忆复习：record_review.py --concept <现有概念ID> --quality <0至5>。只更新记忆调度，不改能力成绩。同日用同一天最差表现从同一日前快照计算，不能重复加次数或让提示后成功抹掉遗忘。
- 收尾：python -B tools/session-close.py，共 12 步；任一步失败不得宣告完整同步。

状态指纹涵盖作答、订正、困难、目标、策略、题目和task-windows；课程对账另核文件哈希。task-windows.json补充正文中已经明确但frontmatter遗漏的开放/截止时刻，绑定题目SHA256，原文变动即停止并要求重核。收尾各步用锁，整体不是跨文件事务；并发变化会在末尾一致性核对报失败，刷新后再使用。记忆日志与概念笔记是两个原子写入，突然中断后若不一致，先核对日志 sm2_after 再恢复，不能用旧笔记覆盖新日志。

## 环境与验证边界

Python 3.10+、PyYAML 6.x，本机已具备。换机器缺依赖才按 requirements.txt 安装。工具不绑定 OpenAI API；无需下载 OpenAI 文件。Harness 必须提供文件与命令工具才能持久化；缺工具时只能在回复中给续学点。

数学回答仍需代回、查条件或用工具核验，包括补充例题；能力等级以程序判定为准。文字读取并不证明看见图片，实际图像输入能力须单独实测。测试范围、Harness真实读写及图像联测的证据见最终升级包的验证报告；不能把一次清晰合成图成功推广为所有手写图片均可可靠识别。
