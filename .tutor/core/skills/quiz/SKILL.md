# quiz

读相关课程覆盖与最近目标证据，选小而有区分力的任务，避免题干/答案已经曝光的原题充当新变式。
题目先登记稳定 ID、版本和验收标准。学生可见题干与参考答案分离，提交前不透露答案内容或答案文件位置。
只澄清题意；用户要求提示时明确转为练习，保留实际闭卷/开卷状态，另记真实提示/曝光，不保持 quiz + H0 的虚假记录。
一次提示只给一个具体下一步动作，等待作答；用户没要求完整讲解时，不附完整分类表和多个新例题。已给出的提示无法撤回成 H0，之后只能换未曝光题独立检验，不能让用户选择把原题记回无提示。
提交后逐目标核查答案、过程、条件，再反馈。自报理解与信心可参考，不强制访谈。
按 capability-session 入账。若需要记忆调度再读 schedule-review；能力升级仅由程序决定。
