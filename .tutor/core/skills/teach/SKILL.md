# teach

先利用已有回答定位最小缺口，不重问已知偏好。缺前置就短补必要内容；长期未掌握不自动阻止学习。
给问题背景→关键关系与条件→当前例子→一个可作答动作。明确不懂时提供完整规则与逐步例子。
引用具体课件页要先核读；课件原文与教学归纳分开。读不准的公式不猜。
概念笔记按实际需要创建，有来源、稳定 id、前置关系。SM-2 字段仅服务记忆调度，不手填能力估计。
演示后建议新题检验，受助完成不算独立通过；用 capability-session 记录。
