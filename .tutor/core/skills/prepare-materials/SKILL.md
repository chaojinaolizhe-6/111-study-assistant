# 课件与教材准备

首次使用本技能先读 `.tutor/docs/课件与教材协同学习.md`，再执行；不要靠猜命令/schema试错。先确认本次章节和真实资料，沿用 `.tutor/config/knowledge-base.md` 中教材、v2 优先与只读约定。
不知道章节ID先用 `python -B tools/chapter_guide.py list --subject <课程目录>` 定位；`template --chapter <id>` 提供真实课件路径/哈希与空地图，不猜ID、页数或收据。用 `check --chapter <id>` 检查已有准备；有效就复用。首次或失效时，主动读课件目录、小节标题、关键定义/方法/条件、例题和作业位置，再定位教材对应处。默认结构与重点先行，正文在教学过程中按需细读；不为准备而通读全课程、全部参考书。
`material_reader.py` 提供 PDF 提取、逐页文本、关键词定位和页面图像；抽取/渲染不等于读图。数学符号、图表和扫描页用文件/图像工具实际查看；缺工具说明局部限制，仍继续可确定部分。
首轮达到“已核结构＋关键要点＋今天入口的原页/教材解释”就保存并进入教学；其他例题与对应处列next_read。不要因发现更多候选内容持续追加全章读图、同书多版、补充书和后续作业验算，拖住第一项学习。相关例题到实际使用时再核。
保存带来源、PDF 页码、比较范围和待细读位置的 chapter guide。双方对应、课件在已查教材范围内独有、教材补充、待确认分开；教材补充再分必要基础和可选拓展。依据当前证据调整路线，不能凭准备地图判定学习者会不会。
目录已找到教材对应节但正文未读：该单元写book_candidates与unresolved，不得仍标课件独有。开场只给本章简短路线、今天一个主目标与单题的一个局部动作；完整七节表和备课审计存地图，用户要求时再展开。
课件中的方法默认保留主线；教材后置/难/未列不能把它降为拓展。没有老师明确范围或用户决定，不写“这部分不考/作业不考”。精确引用例题/作业先看原页图像并验算，OCR文本与课件结论都可能错，冲突局部标记后继续。检索过的页不算读过，guide所有更新构造临时JSON后走 save，不直接edit已有地图。
展示简短路线，说明一个有价值的补缺/差异，直接进入第一项学习；用户不维护索引、不选择内部模式、不承担教材检索。定位明确单题时先解当前卡点，不强制等待整章准备。不能仅回复范围未知或“之后再整理”。备课后提出首个动作仍在学习中，不提前收尾、创建pause或批量建任务；对应未核部分保存待确认即可。确认资料数学错误前须计算工具复算两边/残差，不能把自己口算错误当原资料有误。
