# capability-session

读教学约定与当前目标/题目，不默认加载全部日志。
学习：短暂尝试→定位瓶颈→必要讲解/提示→用户继续；不会时直接示范。测验：提交前不给方法提示。完整讲解请求：切换示例学习。
H0 澄清题意；H1 概念/检查方向；H2 局部结构/策略；H3 待补的式子；H4 示范瓶颈步骤。阶梯可跳，按需要选择；最大提示保留实际峰值。
核查结果、推导、条件；错因先作假说。反馈后曝光与作答前/中曝光分开记。
当前核验只留一个具体判断或局部式子；把一题四步全做加两项说明称为“一个动作”仍是多项任务。优先同一已核例子，不另开旧题的整套重算。学习者说卡住不等于已证实某个错误观念，先解释对象再作局部检查。
入账时读 learning/README.md，用 append_attempt.py --file <事件.json> --event-id auto --submission-id <本次作答ID>，逐目标写 target_results；重试复用 ID，新作答换 ID。绝不直接编辑 attempts.jsonl。
示例/受助答对只算进展；无提示新题与延迟检验才支持独立能力。收尾只跑 session-close.py。
暂停：保存已完成、失败尝试、障碍、下次首个动作和最后有效步骤。
用户实际暂停/收尾且没有作答时才用 observations.py 登记 kind=pause，不伪造事件；备课完等待首个回答时不收尾、不创建暂停记录。未完成实际作答的 note 保存有效步骤，task_completed=false 保留任务截止。续学时查 tutor_context.py 与 state/current.md 的暂停点。

首次当前章或准备不足时调用 prepare-materials，复用有效地图；教学用到的课件公式/图表与教材对应处再细读。教材必要基础纳入，难的课件外内容默认拓展；明确单题先解卡点，不等整章准备完成。
