# evaluate

运行 tutor_context.py，按需要读 learner-state.json、curriculum-coverage.md 与 weekly-review.md。
比较延迟无提示表现、未见变式、提示依赖、时间成本；小样本只给有限结论，不声称学习系统已被科学证明有效。
区分未安排、未测、受助、独立通过、延迟检验。课程目录未核全时全章覆盖未知。
输出最重要瓶颈和一个具体调整建议，不强制清复习才能学新课，不修改记录。
