# diagnose

查询 curriculum.py --chapter <id> --print；章节缺结构时先用章节地图建立资料基线，不能凭已有作业推定全部考点。不因旧catalog单元/target为空就强制先建目标、练习文件和完整排期；当前首个学习动作可以使用已有课件，范围完整性保持未知。
加载 prepare-materials，主动核课件结构和重点并对应既定教材，保存带页码的地图；正文教学中按需深读。给出简短路线并直接进入首项，不把整理资料交给学习者。范围完整性、资料读取状态、学习表现分别记录。
从用户已有草稿或一两道有区分力的问题判断起点；没有测过就记未知。
完整排期请求时，把未登记目标、无题目、无独立证据各自转为具体候选任务。普通“今天从这章开始”先给一个主目标与当前动作，不为所有未知单元自动批量建任务。结合 plan/README.md 与已有时间、设备、截止做容量规划。
用户说出遗漏或截止，用 observations.py 记录并落实题目/目标/计划引用或暂缓理由；不重新建立已有课程目录。
