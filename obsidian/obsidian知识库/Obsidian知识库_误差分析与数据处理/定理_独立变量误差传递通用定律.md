> [!summary] 定理核心论断
> 若多元被测量 $q = f(x_1, x_2, \dots, x_n)$ 中各输入量 $x_i$ 统计独立（即协方差 $\sigma_{x_i x_j} = 0$，对一切 $i \neq j$），且各输入不确定度 $\sigma_{x_i}$ 足够小以保证一阶泰勒展开有效，则 $q$ 的方差为各输入方差乘以对应偏导数平方后的线性叠加，即
> $$\sigma_q^2 = \sum_{i=1}^{n} \left( \frac{\partial f}{\partial x_i} \right)^2 \sigma_{x_i}^2, \qquad \sigma_q = \sqrt{ \sum_{i=1}^{n} \left( \frac{\partial f}{\partial x_i} \right)^2 \sigma_{x_i}^2 }.$$
> 该式称为**独立变量误差传递通用定律**（均方根合成法），其统计意义是各独立随机误差源在平方意义下的正交叠加。

---

## 一、推导机理与核心数学定义

### 1.1 一阶泰勒展开（线性化近似）

设 $q = f(x_1, x_2, \dots, x_n)$ 为光滑函数，各输入量的真值记为 $\mu_i$，测量值记为 $x_i = \mu_i + \varepsilon_i$，其中 $\varepsilon_i$ 为随机误差。对 $f$ 在 $(\mu_1, \dots, \mu_n)$ 处作一阶泰勒展开：

$$q = f(\mu_1, \dots, \mu_n) + \sum_{i=1}^{n} \frac{\partial f}{\partial x_i}\bigg|_{(\mu_1,\dots,\mu_n)} \varepsilon_i + R_2,$$

其中 $R_2$ 为二阶及以上余项。当 $\varepsilon_i$ 远小于特征尺度时，$R_2$ 可忽略，于是

$$q - f(\mu_1, \dots, \mu_n) \approx \sum_{i=1}^{n} c_i \varepsilon_i, \qquad c_i \equiv \frac{\partial f}{\partial x_i}\bigg|_{(\mu_1,\dots,\mu_n)}.$$

### 1.2 方差传播的代数推导

记 $\delta q = q - f(\mu_1, \dots, \mu_n)$。对方差取期望：

$$\sigma_q^2 = \mathbb{E}\left[ (\delta q)^2 \right] = \mathbb{E}\left[ \left( \sum_{i=1}^{n} c_i \varepsilon_i \right)^2 \right].$$

展开平方项：

$$\sigma_q^2 = \mathbb{E}\left[ \sum_{i=1}^{n} c_i^2 \varepsilon_i^2 + \sum_{i \neq j} c_i c_j \varepsilon_i \varepsilon_j \right] = \sum_{i=1}^{n} c_i^2 \,\mathbb{E}[\varepsilon_i^2] + \sum_{i \neq j} c_i c_j \,\mathbb{E}[\varepsilon_i \varepsilon_j].$$

由定义 $\mathbb{E}[\varepsilon_i^2] = \sigma_{x_i}^2$，且统计独立假设给出 $\mathbb{E}[\varepsilon_i \varepsilon_j] = \sigma_{x_i x_j} = 0$（$i \neq j$），交叉项全部消去，得到

$$\sigma_q^2 = \sum_{i=1}^{n} c_i^2 \sigma_{x_i}^2 = \sum_{i=1}^{n} \left( \frac{\partial f}{\partial x_i} \right)^2 \sigma_{x_i}^2.$$

开方即得均方根合成公式：

$$\boxed{\sigma_q = \sqrt{ \sum_{i=1}^{n} \left( \frac{\partial f}{\partial x_i} \right)^2 \sigma_{x_i}^2 }}$$

### 1.3 直觉诠释

独立随机误差在平方空间中正交，因此总方差是各分量的加权平方和，而非绝对值之和。这体现了随机误差的**部分抵消性**——不同来源的误差同时偏大或偏小的概率较低，故标准偏差的合成采用几何加法而非算术加法。

## 二、⚠️ 致命失分陷阱与临界边界

### 陷阱 1：变量间存在强函数相关时直接套用公式

若 $x_1$ 与 $x_2$ 存在函数关系（如 $x_2 = 2x_1$），则 $\sigma_{x_1 x_2} \neq 0$，独立假设崩溃。此时通用公式**失效**，必须：

- **先化简**：将 $q = f(x_1, x_2)$ 中的 $x_2$ 用 $x_1$ 的表达式代入，化为单变量函数后再求导合成；或
- **引入协方差项**：使用完整传播公式

$$\sigma_q^2 = \sum_{i=1}^{n} \left( \frac{\partial f}{\partial x_i} \right)^2 \sigma_{x_i}^2 + 2\sum_{i<j} \frac{\partial f}{\partial x_i}\frac{\partial f}{\partial x_j} \sigma_{x_i x_j}.$$

**典型反例**：$q = x - y$，其中 $y = 2x$，且 $\sigma_x$ 已知。若错误套用独立公式：

$$\sigma_q^{(\text{错})} = \sqrt{(1)^2\sigma_x^2 + (-1)^2\sigma_y^2} = \sqrt{\sigma_x^2 + 4\sigma_x^2} = \sqrt{5}\,\sigma_x.$$

但正确做法是先化简 $q = x - 2x = -x$，得 $\sigma_q = \sigma_x$。错误结果被高估了 $\sqrt{5}$ 倍。

### 陷阱 2：忽略一阶近似的适用边界

当 $\sigma_{x_i}$ 相对于 $|f|$ 或特征曲率半径不可忽略时，二阶项贡献显著，一阶公式产生系统偏差。判据：若

$$\frac{1}{2}\left|\frac{\partial^2 f}{\partial x_i^2}\right|\sigma_{x_i}^2 \gtrsim \left|\frac{\partial f}{\partial x_i}\right|\sigma_{x_i},$$

则线性化失效，需保留二阶项。

### 陷阱 3：混淆极值上界法与统计合成法

- **极值上界法**（最坏情况）：$\Delta q \leq \sum_{i=1}^{n} \left| \frac{\partial f}{\partial x_i} \right| \Delta x_i$，给出误差的**绝对上界**，适用于系统误差占主导或需要安全边界的场合。
- **统计合成法**（均方根）：$\sigma_q = \sqrt{\sum \left( \frac{\partial f}{\partial x_i} \right)^2 \sigma_{x_i}^2}$，给出**标准偏差**，适用于随机误差占主导。

两者关系：上界法 $\geq$ 均方根法（由柯西-施瓦茨不等式，$\sum |c_i|\Delta x_i \geq \sqrt{\sum c_i^2 \Delta x_i^2}$）。考试中须根据题意判断要求的是"最大可能误差"还是"标准不确定度"。

### 陷阱 4：偏导数在零点处取值导致灵敏度消失

若 $\frac{\partial f}{\partial x_i}\big|_{\mu} = 0$，则 $x_i$ 的一阶误差对 $q$ 无贡献，但二阶效应可能成为主导项。此时需考察二阶偏导。

## 三、经典范例手把手演算

### 范例：圆柱体体积的误差传递

**题目**：测得圆柱半径 $r = 2.00 \pm 0.03 \ \text{cm}$，高度 $h = 5.00 \pm 0.05 \ \text{cm}$，$r$ 与 $h$ 独立。求体积 $V = \pi r^2 h$ 的标准不确定度 $\sigma_V$。

**第一步：写出函数与偏导数**

$$V = \pi r^2 h,$$

$$\frac{\partial V}{\partial r} = 2\pi r h, \qquad \frac{\partial V}{\partial h} = \pi r^2.$$

**第二步：代入标称值计算偏导数值**

$$\frac{\partial V}{\partial r}\bigg|_{(2.00, 5.00)} = 2\pi (2.00)(5.00) = 20\pi \ \text{cm}^2,$$

$$\frac{\partial V}{\partial h}\bigg|_{(2.00, 5.00)} = \pi (2.00)^2 = 4\pi \ \text{cm}^2.$$

**第三步：代入独立合成公式**

$$\sigma_V = \sqrt{ \left( \frac{\partial V}{\partial r} \right)^2 \sigma_r^2 + \left( \frac{\partial V}{\partial h} \right)^2 \sigma_h^2 } = \sqrt{ (20\pi)^2 (0.03)^2 + (4\pi)^2 (0.05)^2 }.$$

逐项计算：

$$(20\pi)^2 (0.03)^2 = 400\pi^2 \times 0.0009 = 0.36\pi^2,$$

$$(4\pi)^2 (0.05)^2 = 16\pi^2 \times 0.0025 = 0.04\pi^2.$$

**第四步：合并开方**

$$\sigma_V = \sqrt{0.36\pi^2 + 0.04\pi^2} = \sqrt{0.40\pi^2} = \pi\sqrt{0.40} = \pi \times 0.6325 \approx 1.987 \ \text{cm}^3.$$

**第五步：标称体积与终解**

$$V_0 = \pi (2.00)^2 (5.00) = 20\pi \approx 62.83 \ \text{cm}^3,$$

$$\sigma_V \approx 1.99 \ \text{cm}^3.$$

**第六步：反代验算（数值模拟核对）**

取 $r = 2.00 + 0.03 = 2.03$，$h = 5.00 + 0.05 = 5.05$，则

$$V_+ = \pi (2.03)^2 (5.05) = \pi \times 4.1209 \times 5.05 = \pi \times 20.8105 \approx 65.38 \ \text{cm}^3,$$

偏差 $V_+ - V_0 \approx 2.55 \ \text{cm}^3$。取 $r = 1.97$，$h = 4.95$，则

$$V_- = \pi (1.97)^2 (4.95) = \pi \times 3.8809 \times 4.95 = \pi \times 19.2105 \approx 60.35 \ \text{cm}^3,$$

偏差 $V_0 - V_- \approx 2.48 \ \text{cm}^3$。两偏差的均方根约为 $\sqrt{(2.55^2 + 2.48^2)/2} \approx 2.52$，与 $\sigma_V \approx 1.99$ 同量级（因单点采样而非标准差，数值略大属正常）。验算通过。
