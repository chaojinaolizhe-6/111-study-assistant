> [!summary] 核心认知先验
> 张量分析的本质在于**区分几何对象本身与其在不同坐标系下的分量表示**。协变与反变矢量遵循互逆的变换律，以确保物理量不随坐标系选择而改变。爱因斯坦求和约定将繁复的指标求和隐去，使代数结构一目了然；而度规张量 $g_{ij}$ 作为连接协变与反变分量的桥梁，其升降指标操作是广义相对论与连续介质力学的共同基石。列维-奇维塔符号 $\varepsilon_{ijk}$ 的缩并恒等式则是三维向量叉积、旋度与行列式运算的代数根源。

---

## 一、推导机理与核心数学定义

### 1.1 爱因斯坦求和约定

在同一项中，若某一指标（称为**哑指标**）出现且仅出现两次（一次上标、一次下标），则隐含对该指标在其取值范围（通常为 $1, 2, 3$ 或 $1, \dots, n$）内求和。求和号 $\sum$ 被省略。

$$a^i b_i \equiv \sum_{i=1}^{n} a^i b_i$$

**自由指标**在项中仅出现一次，表示该式对每个自由指标取值均成立，代表一组方程而非单一方程。

### 1.2 仿射变换与坐标基底变换

设两个坐标系 $\{x^i\}$ 与 $\{\bar{x}^i\}$ 之间通过非奇异的仿射变换联系：

$$\bar{x}^i = \bar{x}^i(x^1, x^2, \dots, x^n)$$

定义**变换矩阵**（雅可比矩阵）及其逆：

$$J^i_{\;j} = \frac{\partial \bar{x}^i}{\partial x^j}, \qquad (J^{-1})^i_{\;j} = \frac{\partial x^i}{\partial \bar{x}^j}$$

满足链式关系：

$$J^i_{\;k} (J^{-1})^k_{\;j} = \delta^i_{\;j}$$

其中 $\delta^i_{\;j}$ 为克罗内克符号。

### 1.3 协变矢量与反变矢量的变换律

**反变矢量**（如位置微元 $dx^i$、速度 $v^i$）的分量按雅可比矩阵变换：

$$\bar{V}^i = \frac{\partial \bar{x}^i}{\partial x^j} V^j = J^i_{\;j} V^j$$

**协变矢量**（如梯度 $\partial_i \phi$）的分量按逆雅可比矩阵的转置变换：

$$\bar{W}_i = \frac{\partial x^j}{\partial \bar{x}^i} W_j = (J^{-1})^j_{\;i} W_j$$

**判据**：上标指标（反变）随坐标同向变换；下标指标（协变）随坐标逆向变换。两者乘积 $V^i W_i$ 为标量（不变量）：

$$\bar{V}^i \bar{W}_i = J^i_{\;j} V^j (J^{-1})^k_{\;i} W_k = \delta^k_{\;j} V^j W_k = V^j W_j$$

### 1.4 度规张量与指标升降

在仿射空间中引入度规张量 $g_{ij}$（对称、非奇异），定义弧长：

$$ds^2 = g_{ij} dx^i dx^j$$

度规张量的逆记为 $g^{ij}$，满足：

$$g_{ij} g^{jk} = \delta_i^{\;k}$$

**指标升降操作**：

$$V_i = g_{ij} V^j, \qquad V^i = g^{ij} V_j$$

此操作将反变分量与协变分量一一对应，是欧氏空间中两者可混用的根本原因（此时 $g_{ij} = \delta_{ij}$）。

### 1.5 列维-奇维塔符号与缩并恒等式

三维列维-奇维塔符号 $\varepsilon_{ijk}$ 定义为完全反对称：

$$\varepsilon_{ijk} = \begin{cases} +1 & \text{若 } (i,j,k) \text{ 为偶排列} \\ -1 & \text{若 } (i,j,k) \text{ 为奇排列} \\ 0 & \text{若存在重复指标} \end{cases}$$

**核心缩并恒等式**（$\varepsilon$ 乘积的 $\delta$ 展开）：

$$\varepsilon_{ijk} \varepsilon_{imn} = \delta_{jm} \delta_{kn} - \delta_{jn} \delta_{km}$$

**推导验证**（以 $j=m$ 情形为例）：当 $j=m$ 时，左式 $\varepsilon_{ijk} \varepsilon_{ijn} = \sum_{i,j} \varepsilon_{ijk} \varepsilon_{ijn}$。固定 $k$，仅当 $i, j$ 取遍剩余两值时非零，且两非零项符号相反，故结果为 $2\delta_{kn}$。右式代入 $j=m$ 得 $\delta_{jj}\delta_{kn} - \delta_{jn}\delta_{kj} = 3\delta_{kn} - \delta_{kn} = 2\delta_{kn}$，两侧一致。

**推论恒等式**（对 $k=n$ 收缩）：

$$\varepsilon_{ijk} \varepsilon_{imk} = 2\delta_{jm}$$

$$\varepsilon_{ijk} \varepsilon_{ijk} = 6$$

## 二、⚠️ 致命失分陷阱与临界边界

### 陷阱 1：自由指标与哑指标混淆

- **自由指标**在项中仅出现一次，代表多个方程；**哑指标**出现两次（一上一下），代表求和。
- 同一方程中，各項的自由指标必须**完全一致**（同名同位置），否则方程非法。
- 哑指标可以任意重命名（只要不与自由指标冲突），但自由指标不可随意替换。

### 陷阱 2：同一指标出现超过两次

在爱因斯坦求和约定下，**一个项中同一指标出现三次或以上属于非法张量式**。例如 $a_i b_i c_i$ 无定义——无法确定哪两个指标配对求和。若确需表达三重求和，必须显式写出求和号。

### 陷阱 3：升降指标时度规的误用

- 升降指标必须使用度规张量 $g_{ij}$ 或其逆 $g^{ij}$，不可直接对指标做“上下移动”而不乘度规。
- 在非正交坐标系中，$g_{ij} \neq \delta_{ij}$，协变与反变分量数值不同，不可混用。
- 度规张量的逆 $g^{ij}$ 并非简单取倒数 $1/g_{ij}$（无求和时），而是矩阵求逆。

### 陷阱 4：列维-奇维塔符号的伪张量性质

$\varepsilon_{ijk}$ 在正交变换下保持形式不变，但在一般仿射变换（含反射或非等距缩放）下并非真张量，而是**张量密度**（权为 $+1$）。在曲线坐标中需乘以 $\sqrt{\det g}$ 或 $1/\sqrt{\det g}$ 修正。缩并恒等式 $\varepsilon_{ijk}\varepsilon_{imn} = \delta_{jm}\delta_{kn} - \delta_{jn}\delta_{km}$ 仅在**笛卡尔坐标**（$g_{ij} = \delta_{ij}$）下严格成立。

### 陷阱 5：克罗内克符号的收缩误算

$$\delta^i_{\;i} = n \quad (\text{维数，非 } 1)$$

$$\delta^i_{\;j} A^j = A^i, \qquad \delta^j_{\;i} B_j = B_i$$

## 三、经典范例手把手演算

### 范例 1：验证 $\varepsilon_{ijk} \varepsilon_{imn} = \delta_{jm}\delta_{kn} - \delta_{jn}\delta_{km}$

**步骤 1**：固定自由指标 $j, k, m, n$，考察左式 $\varepsilon_{ijk}\varepsilon_{imn}$。对哑指标 $i$ 求和。

**步骤 2**：$\varepsilon_{ijk}$ 非零要求 $i \neq j \neq k$ 且互异；$\varepsilon_{imn}$ 非零要求 $i \neq m \neq n$ 且互异。因此 $i$ 必须同时不同于 $j, k$ 和 $m, n$。

**步骤 3**：分情形讨论：

- **情形 A**：$j = m$ 且 $k = n$。此时两 $\varepsilon$ 指标排列完全相同，乘积为 $+1$（因 $\varepsilon_{ijk}^2 = 1$）。右式 $\delta_{jj}\delta_{kk} - \delta_{jk}\delta_{kj} = 1 \cdot 1 - 0 = 1$（$j \neq k$ 时）。一致。
- **情形 B**：$j = n$ 且 $k = m$。此时 $\varepsilon_{imn} = \varepsilon_{ikj} = -\varepsilon_{ijk}$（一次对换），乘积为 $-1$。右式 $\delta_{jn}\delta_{km} - \delta_{jm}\delta_{kn} = 1 \cdot 1 - 0 = 1$，但注意此时右式第一项 $\delta_{jn}\delta_{km} = 1$，第二项 $\delta_{jm}\delta_{kn} = 0$，故右式 $= 1$。**矛盾？**

**修正**：情形 B 中 $j = n$ 且 $k = m$，代入右式：

$$\delta_{jm}\delta_{kn} - \delta_{jn}\delta_{km} = \delta_{jk}\delta_{kj} - \delta_{jj}\delta_{kk} = 0 - 1 = -1$$

与左式 $-1$ 一致。**验算通过**。

**步骤 4**：其余情形（$j, k$ 与 $m, n$ 无配对相等）左右均为零。恒等式成立。

### 范例 2：叉积的 $\varepsilon$ 表示与恒等式应用

**问题**：证明向量恒等式 $\mathbf{a} \times (\mathbf{b} \times \mathbf{c}) = \mathbf{b}(\mathbf{a} \cdot \mathbf{c}) - \mathbf{c}(\mathbf{a} \cdot \mathbf{b})$。

**步骤 1**：写出第 $i$ 分量：

$$[\mathbf{a} \times (\mathbf{b} \times \mathbf{c})]_i = \varepsilon_{ijk} a_j (\varepsilon_{kmn} b_m c_n)$$

**步骤 2**：重排因子并利用恒等式（将 $\varepsilon_{ijk}\varepsilon_{kmn}$ 改写为 $\varepsilon_{kij}\varepsilon_{kmn}$，因 $\varepsilon$ 的循环置换不变）：

$$= \varepsilon_{kij}\varepsilon_{kmn} a_j b_m c_n = (\delta_{im}\delta_{jn} - \delta_{in}\delta_{jm}) a_j b_m c_n$$

**步骤 3**：展开收缩：

$$= \delta_{im}\delta_{jn} a_j b_m c_n - \delta_{in}\delta_{jm} a_j b_m c_n = a_j b_i c_j - a_j b_j c_i$$

**步骤 4**：识别点积：

$$= b_i (a_j c_j) - c_i (a_j b_j) = b_i(\mathbf{a} \cdot \mathbf{c}) - c_i(\mathbf{a} \cdot \mathbf{b})$$

**终解**：$\mathbf{a} \times (\mathbf{b} \times \mathbf{c}) = \mathbf{b}(\mathbf{a} \cdot \mathbf{c}) - \mathbf{c}(\mathbf{a} \cdot \mathbf{b})$，得证。

**反代验算**：取 $\mathbf{a} = \hat{x}$，$\mathbf{b} = \hat{y}$，$\mathbf{c} = \hat{x}$。左式 $= \hat{x} \times (\hat{y} \times \hat{x}) = \hat{x} \times (-\hat{z}) = \hat{y}$。右式 $= \hat{y}(1) - \hat{x}(0) = \hat{y}$。一致。

### 范例 3：极坐标中度规升降指标

**问题**：在二维极坐标 $(r, \theta)$ 中，度规为 $g_{ij} = \mathrm{diag}(1, r^2)$。已知反变矢量 $V^i = (V^r, V^\theta)$，求其协变分量。

**步骤 1**：写出度规矩阵及其逆：

$$g_{ij} = \begin{pmatrix} 1 & 0 \\ 0 & r^2 \end{pmatrix}, \qquad g^{ij} = \begin{pmatrix} 1 & 0 \\ 0 & r^{-2} \end{pmatrix}$$

**步骤 2**：升降指标：

$$V_r = g_{rj} V^j = g_{rr} V^r + g_{r\theta} V^\theta = 1 \cdot V^r + 0 = V^r$$

$$V_\theta = g_{\theta j} V^j = g_{\theta r} V^r + g_{\theta\theta} V^\theta = 0 + r^2 V^\theta = r^2 V^\theta$$

**步骤 3**：验证标量不变性：

$$V^i V_i = V^r V_r + V^\theta V_\theta = V^r \cdot V^r + V^\theta \cdot r^2 V^\theta = (V^r)^2 + r^2 (V^\theta)^2$$

该式恰为物理速度平方 $|\mathbf{v}|^2$（因 $ds^2 = dr^2 + r^2 d\theta^2$），验证正确。
