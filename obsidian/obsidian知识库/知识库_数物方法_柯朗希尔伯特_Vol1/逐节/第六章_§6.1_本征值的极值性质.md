# §6.1 本征值的极值性质 (Extremum Properties of Eigenvalues) 精读解构笔记

> [!summary] 本节学习目标
> 本节把第五章的微分方程本征值问题与变分原理联系起来：在二次泛函
> $D[\varphi]$（势能型）与 $H[\varphi]$（动能型，带权 $\rho$）的约束下逐级求极小，
> 得到自伴二阶椭圆型方程
>
> $$L[u] + \lambda \rho u = (p u_x)_x + (p u_y)_y - q u + \lambda \rho u = 0$$
>
> 的本征值与正交本征函数序列；给出第一个、第二个直至第 $n$ 个本征值的递推
> 极小刻画；去掉归一化条件后写成商 $D[\varphi]/H[\varphi]$（即瑞利商）的极小
> 问题；最后给出不依赖前面本征函数的 max-min 定理。前置知识是第五章的二次型
> 主轴变换、格林公式、一阶变分与自然边界条件（第四章 §7 乘子法则）。结论为
> 后续的定性比较、节点定理与存在性讨论作准备。本节涉及的关键概念：
>
> - 二次泛函 $D[\varphi]$（势能型）与 $H[\varphi]$（动能型，带权 $\rho$）
> - 自然边界条件 $\partial \varphi/\partial n + \sigma \varphi = 0$ 的“弱”解释
> - 逐级正交极小与瑞利商
> - 集中质量、对称核的推广
> - 分离区域的叠加
> - Courant max-min 原理

### 章引言：变分法与本征值问题（第411页，印刷页397）

教材在第六章开头指出：微分方程的本征值问题与二次型问题紧密相连；这些本征值
问题对应于把无穷多变元的二次型变换到主轴。以一维连续体为例，设势能与动能为
$U$ 与 $T$（原文给出的积分表达式在 OCR 中不完整，待核实；典型形式为
$U = \tfrac12 \int p u_x^2 dx$ 与 $T = \tfrac12 \int \rho u_t^2 dx$，此典型形式
属补充说明），令 $u = \sum_\nu f_\nu(t)\sin \nu x$ 并把 $p, \rho$ 展成 Fourier
级数，则 $U$ 与 $T$ 可看作无穷多个坐标 $f_\nu, f'_\nu$ 上的二次型。若存在正交
变换把变量 $f_\nu, f'_\nu$ 变为新变量 $q_\nu, q'_\nu$，使 $U$ 与 $T$ 化为

$$\sum_{\nu=1}^{\infty} \lambda_\nu q_\nu^2, \qquad \sum_{\nu=1}^{\infty} q_\nu'^2$$

的形式，则数 $\lambda_\nu$ 就是振动问题的本征值。教材指出：二次型的本征值以
简单的极值性质为特征，因此自然对二次泛函也考虑类似的刻画；不过本节将直接
表述和应用这些极值性质，而不把泛函当作有限个变元的二次型的极限。

### §6.1 经典极值性质（1. Classical Extremum Properties，第412–416页，印刷页398–402）

#### 本征值问题的微分方程形式与边界条件

教材考虑自伴二阶偏微分方程的本征值问题

$$L[u] + \lambda \rho u \equiv (p u_x)_x + (p u_y)_y - q u + \lambda \rho u = 0 \tag{1}$$

其中

$$p > 0, \qquad \rho > 0 .$$

$x, y$ 是基本域 $G$ 中的独立变量，$G$ 的边界 $\Gamma$ 由一条或几条连续曲线组成，
且切线分段连续。边界条件为

$$u = 0,$$

或一般地

$$\frac{\partial u}{\partial n} + \sigma u = 0,$$

其中 $\sigma$ 是边界 $\Gamma$ 上分段连续的位置函数，$\partial/\partial n$ 表示外法线
方向导数。

教材脚注强调：一般边界条件必须在“弱”意义下解释，即函数并不要求在 $\Gamma$ 上
处处取边界值；这一细致问题将在第二卷第七章联系存在性证明时充分讨论。此处假设
解存在，不必指定 $u$ 在边界上的行为。

#### 二次泛函与极形式

变分本征值问题的典型二次泛函为 $D[\varphi]$ 与 $H[\varphi]$（原始 OCR 中泛函的
显式表达式不完整，以下形式依据第412–413页上下文及柯朗–希尔伯特记号推断）：

$$D[\varphi] = \iint_G \Big( p(\varphi_x^2 + \varphi_y^2) + q \varphi^2 \Big) dx\,dy,$$

$$H[\varphi] = \iint_G \rho \varphi^2 \, dx\,dy .$$

相应的极形式（polar forms）为

$$D[\varphi, \psi] = \iint_G \Big( p(\varphi_x \psi_x + \varphi_y \psi_y) + q \varphi \psi \Big) dx\,dy,$$

$$H[\varphi, \psi] = \iint_G \rho \varphi \psi \, dx\,dy .$$

它们满足（原文 OCR 中该关系式严重损坏，以下按标准记号推断）

$$D[\varphi + \psi] = D[\varphi] + 2D[\varphi, \psi] + D[\psi],$$

$$H[\varphi + \psi] = H[\varphi] + 2H[\varphi, \psi] + H[\psi].$$

#### 容许函数的正则性条件

教材要求变元函数 $\varphi$ 在 $G + \Gamma$ 上连续，并在 $G$ 内具有分段连续的
一阶导数。“函数 $\varphi$ 在 $G$ 中分段连续”指：$G$ 可被切线分段连续的弧细分为
有限个区域 $G_1, G_2, \ldots, G_n$，使得 $\varphi$ 在不含这些弧为内点的每个闭子
区域上连续。若规定边界条件 $u = 0$，则 $u$ 假定在闭区域 $G + \Gamma$ 上连续且
在 $\Gamma$ 上为零。

#### 第一极小问题与基态本征值

教材给出：在条件

$$H[\varphi] = 1$$

之下使 $D[\varphi]$ 取极小的容许函数 $\varphi$，是微分方程 (1) 的一个本征函数
$u_1$，且满足自然边界条件

$$\frac{\partial \varphi}{\partial n} + \sigma \varphi = 0 ;$$

极小值 $D[\varphi]$ 就是相应的本征值 $\lambda_1$。

#### 逐次极小与正交条件

若不仅规定

$$H[\varphi] = 1,$$

还附加正交条件

$$H[\varphi, u_1] = 0,$$

则极小问题的解又是 (1) 的本征函数 $u_2$，满足同一自然边界条件；极小值
$D[u_2] = \lambda_2$ 是相应本征值。

一般地，逐次极小问题

$$D[\varphi] = \min,$$

在条件 $H[\varphi] = 1$ 及辅助条件

$$H[\varphi, u_i] = 0 \qquad (i = 1, 2, \ldots, \nu - 1)$$

之下，定义方程 (1) 在边界条件 $\partial \varphi/\partial n + \sigma \varphi = 0$
下的本征函数 $u_\nu$；相应本征值 $\lambda_\nu$ 等于极小值 $D[u_\nu]$。

#### 瑞利商形式

教材指出：可以省略归一化条件 $H[\varphi] = 1$，改为极小化商

$$\frac{D[\varphi]}{H[\varphi]}.$$

此时解只确定到任意比例因子（即容许函数可相差非零常数倍）。

若边界条件为 $u = 0$，同样一组变分问题定义本征值和本征函数，但容许性条件现在
还需加上 $\varphi = 0$；此时 $D[\varphi]$ 中的边界项自动消失（原文此处 OCR 有
损，待核实具体边界项写出形式）。

#### 变分解是本征函数的直接证明（一阶变分与格林公式）

教材指出：极小问题确有连续二阶导数解的证明将在第二卷联系直接方法时给出；这里
假定上述类型的极小问题有解。然后需证明两点：

- (a) 变分问题的解就是微分方程问题的本征函数；
- (b) 它们给出**所有**本征函数。

(b) 在 §3 中通过证明函数系 $u_1, u_2, \ldots$ 的完全性给出。(a) 可从第四章 §7 的
一般乘子法则导出，但本节直接证明。

以第一个变分问题为例。设其解 $u_1$ 满足 $H[u_1] = 1$。若 $\zeta$ 是满足与
$\varphi$ 相同条件的任意函数，$\varepsilon$ 是任意常数，则对 $u = u_1$ 与
$\lambda = \lambda_1$，对每个 $\varepsilon$ 有

$$D[u_1 + \varepsilon \zeta] - \lambda_1 H[u_1 + \varepsilon \zeta] \ge D[u_1] - \lambda_1 H[u_1] = 0,$$

这等价于关系 $D[u] = \lambda H[u]$。该二阶不等式对任意 $\varepsilon$ 成立，仅当

$$D[u_1, \zeta] - \lambda_1 H[u_1, \zeta] = 0 \tag{4}$$

成立，即表达式 $D - \lambda H$ 的一阶变分为零。接着教材按格林公式（参看第五章
§1）变换 $D[u, \zeta]$；由于 $\zeta$ 任意，立即得到方程 (1) 对 $u = u_1$ 与
$\lambda = \lambda_1$ 成立。

#### 第二极小问题与正交条件的去除

考虑带有附加条件 $H[\varphi, u_1] = 0$ 的第二极小问题。起初仅在 $\zeta$ 满足

$$H[\zeta, u_1] = 0 \tag{5}$$

时得到方程 (4) 对 $u = u_2$、$\lambda = \lambda_2$ 成立。教材的论证如下：

设 $\eta$ 是任意具有分段连续二阶导数的函数。可确定常数 $t$，使函数

$$\zeta = \eta + t u_1$$

满足条件 (5)，只需取

$$t = -H[u_1, \eta].$$

此外，把 $\zeta = u_1$ 代入关于 $u = u_2$、$\lambda = \lambda_2$ 的方程 (4)（此时
$u_1$ 满足辅助条件 $H[u_1, u_2] = 0$），并利用 $u_2$ 满足的附加条件

$$H[u_2, u_1] = 0 \tag{6}$$

立即得到

$$D[u_2, u_1] = 0 . \tag{7}$$

把 $\zeta = \eta + t u_1$ 代入 $u = u_2$、$\lambda = \lambda_2$ 的方程 (4)，得

$$D[u_2, \eta] - \lambda_2 H[u_2, \eta] + t\big( D[u_2, u_1] - \lambda_2 H[u_2, u_1] \big) = 0 .$$

由 (6)、(7) 两式，第二项为零，于是

$$D[u_2, \eta] - \lambda_2 H[u_2, \eta] = 0 . \tag{4a}$$

换言之，方程 (4) 对任意函数 $\eta$ 或 $\zeta$ 成立，而与辅助条件 (5) 无关。继续
这一归纳过程，教材得出结论：本征值方程 (4a) 对变分问题的所有解 $u_i$ 与极小值
$\lambda_i$ 普遍成立。

#### 正交归一关系与本征值单调性

对归一化解，有

$$D[u_i] = \lambda_i, \qquad H[u_i] = 1, \qquad D[u_i, u_k] = 0, \quad H[u_i, u_k] = 0 \quad (i \neq k) .$$

所得本征值满足不等式

$$\lambda_{\nu-1} \leq \lambda_\nu, \qquad \nu \ge 2, \tag{9}$$

理由是：刻画 $\lambda_\nu$ 的容许函数类是刻画 $\lambda_{\nu-1}$ 的容许函数类的
子集，所以后一极小值不会小于前一极小值。教材随即说明：变分问题产生微分方程
问题的无穷本征值与本征函数序列；反之，微分方程问题所对应的本征值与本征函数
可由这些变分本征值问题得到——这将在 §3.1 中证明。

### §6.1 推广（2. Generalizations，第416–418页，印刷页402–404）

#### Sturm–Liouville 方程与端点条件的变分刻画

教材指出，第五章讨论的其他本征值问题同样可从变分法处理；单重与多重积分、
二阶与高阶微分方程均如此。例如 Sturm–Liouville 方程

$$(p u')' - q u + \lambda \rho u = 0$$

配边界条件

$$u'(0) - h_1 u(0) = u'(\pi) + h_2 u(\pi) = 0$$

对应如下变分问题：无边界条件地求

$$D[\varphi] = \int_0^{\pi} \Big( p \varphi'^2 + q \varphi^2 \Big) dx + h_1 p(0)\,\varphi(0)^2 + h_2 p(\pi)\,\varphi(\pi)^2 = \min .$$

所有前述齐次边界条件都可通过适当选择 $h_1, h_2$ 得到；边界条件
$u(0) = u(\pi) = 0$ 可看作 $h_1 \to \infty$、$h_2 \to \infty$ 的极限情形。

#### 奇异端点问题：Legendre 多项式和 Bessel 函数

教材说明：即使 Sturm–Liouville 方程在端点有奇性，本征值和本征函数仍可由变分
问题刻画。具体给出 Legendre 多项式与 Bessel 函数的表述。

- **Legendre 多项式**：通过两端点奇异的自由问题得到（原文 OCR 中该问题的泛函
  表达式不完整，按 Legendre 方程 $(1-x^2)u'' - 2xu' + \lambda u = 0$ 的标准变分
  形式可写为）

  $$D[\varphi] = \int_{-1}^{1} (1 - x^2)\, \varphi'^2 \, dx, \qquad H[\varphi] = \int_{-1}^{1} \varphi^2 \, dx .$$

  （以上积分形式属补充推断，教材 OCR 处需待核实。）

- **零阶 Bessel 函数 $J_0(\sqrt{\lambda}\, x)$**：由如下问题产生（原文 OCR 部分
  可辨：积分区间 $0$ 到 $1$，被积函数含 $x \varphi'^2$ 与 $x \varphi^2$）

  $$D[\varphi] = \int_0^{1} x\, \varphi'^2 \, dx, \qquad H[\varphi] = \int_0^{1} x\, \varphi^2 \, dx,$$

  在 $x = 0$ 处不设边界条件（奇异端点）。

- **$m$ 阶 Bessel 函数（$m \geq 1$）**：由相应问题产生（教材 OCR 中显式泛函
  不完整，按 Bessel 方程 $(x u')' - \frac{m^2}{x}u + \lambda x u = 0$ 的标准变分
  形式推断）

  $$D[\varphi] = \int_0^{1} \left( x \varphi'^2 + \frac{m^2}{x} \varphi^2 \right) dx, \qquad H[\varphi] = \int_0^{1} x \varphi^2 \, dx,$$

  边界条件为 $\varphi(0) = 0$。正则端点 $x = 1$ 处的边界条件
  $\varphi(1) = 0$ 与固定膜问题对应。

#### 高阶方程与高维问题：振动板

高维高阶自伴微分方程同样适用，例如振动板方程

$$\Delta \Delta u - \lambda u = 0 . \tag{10}$$

处理固定板问题（参看第四章 §10）时，取

$$D[\varphi] = \iint_G (\Delta \varphi)^2 \, dx\,dy, \qquad H[\varphi] = \iint_G \varphi^2 \, dx\,dy,$$

并在边界 $\Gamma$ 上施加相应条件（原文 OCR 只写到 “on the boundary $\Gamma$ of
$G$”，固定板还需 $\varphi = 0$ 且 $\partial \varphi / \partial n = 0$，此补充条件
属标准情形，需待核实原文全句）。采用这些约定后，第1小节的讨论和公式完全保持不变。

#### 集中质量与加权正交

若回忆 $H[\varphi]$ 对应质量密度为 $\rho$ 的连续体的动能，而 $D[\varphi]$ 代表势
能，则自然可构造质量不仅连续分布在 $G$ 上、而且集中在孤立点的力学模型。对这类
模型，一维情形下代替 $H$ 的是

$$H[\varphi] = \int_G \rho\, \varphi^2 \, dx + \sum_{\nu=1}^{h} b_\nu\, \varphi(x_\nu)^2, \tag{11}$$

其中 $x_1, x_2, \ldots, x_h$ 是 $G$ 中的给定点，$b_\nu$ 是给定常数。教材约定这些
集中质量是非负的。类似地还可考虑更一般形式（原文公式 (12) 在 OCR 中不完整，
待核实）。

用与第1小节完全相同的记号和论证可得到本征值和本征函数。这些本征函数在点
$x_1, x_2, \ldots, x_h$ 之外满足微分方程

$$L[u] + \lambda \rho u \equiv (p u')' - q u + \lambda \rho u = 0, \tag{13}$$

而在这些点出现自然边界与导数的跳跃条件，它们可立即由形成第一变分得到。本征函数
乘以相应权后不再按通常意义正交，而是满足所谓“加权正交”条件（教材注：H. Kneser
建议使用“加权正交”这一术语；原文 OCR 中该条件的具体形式不完整，待核实）。

#### 对称核与积分微分方程、双正交关系

进一步的例子由表达式（原文 OCR 不完整，以下按上下文推断）

$$D[\varphi] = \int_0^{\pi} \Big( p \varphi'^2 + q \varphi^2 \Big) dx,$$

$$H[\varphi] = \int_0^{\pi} \int_0^{\pi} k(x, y)\, \varphi(x)\, \varphi(y)\, dx\,dy \tag{15}$$

给出，其中 $k(x, y)$ 是给定的对称函数；为简单起见，假定 $H[\varphi]$ 永不取负值。
用第1小节的方法，代替本征值微分方程得到积分微分方程（原文中方程 (16) 的 OCR
不完整，待核实），例如配边界条件 $u = 0$。此问题的本征函数的正交关系成为双正交
关系（教材注：“若除本征函数 $u_i(x)$ 外还引入函数
$v_i(x) = \rho u_i(x) + \int k(x, y) u_i(y) dy$，它们也可看作系统 $u_i$ 与系统
$v_i$ 之间的双正交关系”），即形如

$$\int u_i v_j \, dx = \begin{cases} 0, & i \neq j, \\ 1, & i = j . \end{cases}$$

### §6.1 分离分量区域的本征值问题（3. Eigenvalue Problems for Regions with Separate Components，第419页，印刷页405）

教材给出对一切微分方程本征值问题都成立的注记：

> 若 $G$ 由若干互不重叠的开区域 $G', G'', \ldots$ 组成，则 $G$ 的本征值与
> 本征函数的全体由所有子区域 $G', G'', \ldots$ 的本征值与本征函数组成，其中每个
> 本征函数除在一个子区域外都恒等于零。

教材指出：这代表一个显然的物理事实——若干个分离的振动系统互不作用地独立振动。
数学证明的一种方式是利用微分方程问题的本征函数定义：只需注意，对任一子区域
$G', G'', \ldots$ 定义并在该子区域外恒为零的本征函数（连同属于同一本征值的线性
组合）也是 $G$ 的本征函数；反之，$G$ 的每个本征函数必须在至少一个子区域内不为
零。另一种证明基于变分问题对特征值的定义，逐步识别总区域与子区域的本征值。

### §6.1 本征值的 max-min 性质（4. The Maximum-minimum Property of Eigenvalues，第419–420页，印刷页405–406）

#### 定理的动机

与第一章二次型的讨论类似，教材希望不用前面的本征值和本征函数，直接定义第 $n$
个本征值。考虑前述任一变分问题，保留第1小节的记号，但修改容许函数的条件：不再
规定

$$H[\varphi, u_i] = 0 \qquad (i = 1, 2, \ldots, n - 1),$$

而代之以 $n - 1$ 个**修改**条件

$$H[\varphi, v_i] = 0 \qquad (i = 1, 2, \ldots, n - 1), \tag{17}$$

其中 $v_1, v_2, \ldots, v_{n-1}$ 是 $G$ 中任意选择的分段连续函数。

#### Max-min 定理

在上述条件下，积分 $D[\varphi]$（或更一般的泛函 $D[\varphi]$）有一个最大下界
（greatest lower bound），它依赖于函数 $v_1, v_2, \ldots, v_{n-1}$，记作
$d\{v_1, v_2, \ldots, v_{n-1}\}$。教材断言如下定理：

> **定理。** 给定 $n - 1$ 个在 $G$ 中分段连续的函数 $v_1, v_2, \ldots, v_{n-1}$，
> 设 $d(v_1, v_2, \ldots, v_{n-1})$ 是 $D[\varphi]$ 在满足 $H[\varphi] = 1$ 及
> 条件
>
> $$H[\varphi, v_i] = 0 \qquad (i = 1, 2, \ldots, n - 1)$$
>
> 的连续可微函数 $\varphi$ 上取值集合的最大下界。则 $\lambda_n$ 等于这个下界
> $d$ 当 $v_1, v_2, \ldots, v_{n-1}$ 遍历所有容许函数组时所取的**最大值**。这个
> max-min 在 $u = u_n$ 与 $v_1 = u_1, v_2 = u_2, \ldots, v_{n-1} = u_{n-1}$ 处
> 达到。

在边界条件 $u = 0$ 下，变分问题不再是自由问题，而受到边界 $\Gamma$ 上
$\varphi = 0$ 的限制。

#### 定理的证明

证明分两步。

1. **下界达到 $\lambda_n$**：按定义，当 $v_i = u_i$（$1 \leq i \leq n - 1$）时，
   $$d\{u_1, u_2, \ldots, u_{n-1}\} = \lambda_n .$$

2. **对任意 $v_i$ 有 $d\{v_1, \ldots, v_{n-1}\} \leq \lambda_n$**：教材说明，只需
   确定一个满足条件 $H[\varphi, v_i] = 0$（$i = 1, \ldots, n - 1$）的特定函数
   $\varphi$，使 $D[\varphi] \leq \lambda_n$。为此，取前 $n$ 个本征函数的线性组合

   $$\varphi = \sum_{i=1}^{n} c_i u_i,$$

   常数 $c_1, c_2, \ldots, c_n$ 待定。$n - 1$ 个关系 (17) 给出 $n$ 个常数
   $c_1, \ldots, c_n$ 的 $n - 1$ 个线性齐次条件，因此总能被满足。方程

   $$H[\varphi] = \sum_{i=1}^{n} c_i^2 = 1$$

   只是确定比例因子的归一化条件。由 $D[u_i, u_k] = 0$（$i \neq k$）与
   $D[u_i] = \lambda_i$ [参看方程 (8)]，有

   $$D[\varphi] = \sum_{i,k=1}^{n} c_i c_k D[u_i, u_k] = \sum_{i=1}^{n} c_i^2 \lambda_i .$$

   由于 $\lambda_i \leq \lambda_n$（$i \leq n$）且 $\sum_{i=1}^{n} c_i^2 = 1$，得

   $$D[\varphi] = \sum_{i=1}^{n} c_i^2 \lambda_i \le \lambda_n \sum_{i=1}^{n} c_i^2 = \lambda_n .$$

   因此对任意 $v_1, \ldots, v_{n-1}$ 有 $d\{v_1, \ldots, v_{n-1}\} \leq \lambda_n$。
   结合第一步，$\max_v d\{v_1, \ldots, v_{n-1}\} = \lambda_n$，且极值在
   $u = u_n$、$v_i = u_i$（$i = 1, \ldots, n - 1$）处达到。

## 易错点与节间衔接

> [!warning] 需要留意的条件
> 1. **$D$ 与 $H$ 的角色不可互换**：$D[\varphi]$ 是势能型泛函（含 $p, q$ 与
>    导数项），$H[\varphi]$ 是动能型泛函（带权 $\rho$ 或集中质量），极小化的是
>    $D$ 而不是 $H$。注意本文中 $p > 0$ 与 $\rho > 0$ 都是正性条件。
> 2. **归一化与商形式的等价性**：若改为极小化 $D[\varphi]/H[\varphi]$，解只确定
>    到一个非零比例因子；若无归一化，$u_\nu$ 的振幅不确定。
> 3. **两类边界条件的区别**：自然边界条件 $\partial \varphi/\partial n +
>    \sigma \varphi = 0$ 是变分极小问题**自动导出**的；约束边界条件
>    $u = 0$ 则必须**加进容许性条件**，此时相应边界项自动消失。不要把二者混为
>    同一回事。
> 4. **逐级极小的子集关系**：本征值单调性 $\lambda_{\nu-1} \leq \lambda_\nu$ 来自
>    容许函数类的包含关系，而非本征值本身的任何先验信息。
> 5. **max-min 中“inf”与“max”不可交换**：$d$ 是先对 $\varphi$ 取下确界，再对
>    $v_i$ 取最大值。证明的关键是取 $\varphi = \sum_{i=1}^{n} c_i u_i$ 并利用
>    $n-1$ 个线性齐次条件保证 $n$ 个系数中至少有一个自由度。
> 6. **集中质量点的正交性**：在集中质量模型中，本征函数的正交性不是通常的
>    $\int \rho u_i u_k \, dx$，而是含质量点项的“加权正交”（Kneser 术语）。
> 7. **对称核问题的双正交**：当 $H[\varphi] = \iint k(x,y)\varphi(x)\varphi(y)$
>    时，正交关系变为 $u_i$ 与 $v_i$ 之间的双正交，而非 $u_i$ 之间的普通正交。
> 8. **分离区域时本征函数的支撑**：每个子区域的本征函数延拓到总区域时，在
>    其余子区域上必须恒为零。

**节间衔接**：本节承接第五章（微分方程本征值问题与二次型主轴变换），并用第四
章 §7 的一般乘子法则作为可选的证明路径，同时引用第五章 §1 的格林公式。可把
本节的极小原理视为有限维二次型本征值极值刻画（第一章）在无穷维泛函中的推广；
本节的 max-min 定理（Courant min-max 原理）将在后续章节用于本征值的比较定理、
节点性质与存在性（第二卷直接方法）的讨论。§6.1 最后预告的完全性证明将在
§3.1 完成。

## 补充讲解

1. **术语“瑞利商”**：教材本节写为“the quotients $D[\varphi]/H[\varphi]$”，
   未称其为 Rayleigh quotient。在现代文献中，$R[\varphi] = D[\varphi]/H[\varphi]$
   即瑞利商。第1小节的两个等价陈述——带归一化约束的极小化与商的无约束极小化——
   正是瑞利商极小原理的表现。注意本节的使用范围是自伴问题；非自伴问题的瑞利商
   要推广为包括伴随问题的形式，本节不涉及。

2. **max-min 原理即为 Courant min-max 定理**：第4小节给出的
   $\lambda_n = \max_{v_1,\ldots,v_{n-1}} \min_{\varphi \perp v_i} D[\varphi]$
   （其中 $H[\varphi] = 1$）即特征值理论中通常所称的 Courant min-max 原理
   （Fisher–Courant）。本节的证明只用了前 $n$ 个本征函数张成的 $n$ 维子空间与
   $n-1$ 个线性齐次条件的交非零，这个论证与有限维情形完全平行。需要补充的是：
   该 min-max 式子并不要求 $v_i$ 事先正交；对任意 $v_i$ 同样成立。

3. **与有限维二次型的类比**：在有限维情形，若 $A$ 是对称矩阵、$M$ 正定，则
   $\lambda_k$ 可刻画为在 $\mathbf{x}^\top M \mathbf{x} = 1$ 且与前面主方向
   $M$-正交的条件下极小化 $\mathbf{x}^\top A \mathbf{x}$。本节只是把同样的步骤
   搬到二次泛函上，并把“前面主方向”换成前面求出的本征函数 $u_i$；max-min 定理
   则进一步把前面的本征函数替换为任意试探函数 $v_i$。

4. **OCR 不完整处汇总**：由于所提供教材原文存在 OCR 损坏，本节涉及以下公式未能
   从原文逐字确认，已在相应位置标注：第411页势能/动能积分表达式、第412页
   $D[\varphi]$ 与 $H[\varphi]$ 的显式积分、第413页极形式关系式、第414页边界项、
   第416页 Legendre 问题泛函、第417页 $J_m$（$m \geq 1$）泛函、第418页公式 (12)
   与积分微分方程 (16)。上述位置均按柯朗–希尔伯特标准记号给出推断形式，标注为
   “推断/待核实”，不得视为教材原文的精确抄录。
