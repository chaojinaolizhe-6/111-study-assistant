> [!summary] 技术核心论断
> 拉普拉斯变换是求解物理学中线性常系数微分方程（组）及积分－微分动力学**因果初值问题 (IVP)** 的工业级终极武器。相比经典常微分方程“先求齐次通解 $\to$ 猜特解 $\to$ 代入初值联立代数方程组解任意常数”的繁琐流程，拉氏变换通过“**微分代数化 $\to$ 求解代数像函数 $\to$ 留数/分项分式反演**”三步标准化流水线闭环运行。其最大的物理与数学优势在于：在第一步变换时即**内嵌吸纳了全部非零初始状态**，并将外加驱动源与系统初态融为一体；反演后自然解构为**零输入响应（自由振动/本征耗散）与零状态响应（外场强迫振动）**，过程具备极高的规范性与抗错性。

## 一、推导机理与规范求解工作流

### 1.1 标准三步求解范式 (Three-Step Standard Workflow)

对于包含初始条件 $y(0) = y_0, y'(0) = y_1, \dots, y^{(n-1)}(0) = y_{n-1}$ 的 $n$ 阶线性常系数微分方程：
$$a_n y^{(n)}(t) + a_{n-1} y^{(n-1)}(t) + \dots + a_1 y'(t) + a_0 y(t) = f(t)$$

```mermaid
graph LR
    A["时域微分方程与初始条件<br/>L[y] = f(t), y(0), y'(0)"] -->|拉普拉斯正变换| B["复频域代数方程<br/>P(p)y(p) - Q(p) = f(p)"]
    B -->|代数求解像函数| C["分式像函数<br/>y(p) = Q(p)/P(p) + f(p)/P(p)"]
    C -->|反演(分项分式/留数/卷积)| D["时域唯一真实物理响应<br/>y(t) = y_zi(t) + y_zs(t)"]
```

#### 第一步：全微分代数化映射 (Forward Mapping)
两边同时施行拉普拉斯变换 $\mathcal{L}$，应用高阶微分定理代入初值：
$$a_n \left[ p^n \bar{y}(p) - \sum_{k=1}^n p^{n-k} y^{(k-1)}(0) \right] + \dots + a_1 [p \bar{y}(p) - y(0)] + a_0 \bar{y}(p) = \bar{f}(p)$$

#### 第二步：复频域代数求解 (Algebraic Solution in $p$-Domain)
提取像函数 $\bar{y}(p)$，定义系统的**特征多项式** $P(p) = \sum_{k=0}^n a_k p^k$，以及由初始条件决定的**初值伴随多项式** $Q(p)$：
$$P(p) \bar{y}(p) = Q(p) + \bar{f}(p)$$
$$\boxed{ \bar{y}(p) = \underbrace{\frac{Q(p)}{P(p)}}_{\bar{y}_{\text{zi}}(p)\text{ 零输入响应像}} + \underbrace{\frac{\bar{f}(p)}{P(p)}}_{\bar{y}_{\text{zs}}(p)\text{ 零状态响应像}} }$$
其中 $H(p) = \frac{1}{P(p)}$ 即为线性系统的**网络传递函数 (Transfer Function)**。

#### 第三步：复频域反演还原 (Inverse Mapping)
根据 $\bar{y}(p)$ 的代数结构，选用以下三种高效反演技术之一：
1. **分项分式展开法 (Partial Fractions)**：将有理分式拆为 $\frac{A}{p - p_k}$ 与 $\frac{B p + C}{(p - \alpha)^2 + \beta^2}$，对照基本变换表直接读出指数、余弦、正弦；
2. **留数反演公式法 (Residue Theorem)**：$y(t) = \sum \operatorname{Res}[\bar{y}(p) e^{pt}, p_k]$，尤其适用于高阶极点或一般形式激励；
3. **卷积定理法 (Convolution)**：当外加激励 $\bar{f}(p)$ 较复杂时，利用 $y_{\text{zs}}(t) = \int_0^t h(\tau) f(t-\tau) d\tau$，其中 $h(t) = \mathcal{L}^{-1}[H(p)]$ 为冲激响应。

### 1.2 积分－微分方程与耦合微分方程组处理

在实际物理场景（如 RLC 暂态网络、互感耦合回路、放射性衰变链、耦合减震弹簧振子）中，系统往往由一组联立的微分方程或含积分项 $\int_0^t j(\tau) d\tau$ 构成。

- **积分项的处理**：直接映射为 $\mathcal{L}\left[ \int_0^t j(\tau) d\tau \right] = \frac{\bar{j}(p)}{p}$，不仅不增加求解难度，反而保持严格代数多项式形式；
- **微分方程组代数化**：对各未知量 $y_1(t), y_2(t)$ 分别作变换，得到关于 $\bar{y}_1(p), \bar{y}_2(p)$ 的代数线性方程组：
  $$\begin{pmatrix} A_{11}(p) & A_{12}(p) \\ A_{21}(p) & A_{22}(p) \end{pmatrix} \begin{pmatrix} \bar{y}_1(p) \\ \bar{y}_2(p) \end{pmatrix} = \begin{pmatrix} F_1(p) \\ F_2(p) \end{pmatrix}$$
  利用克莱姆法则 (Cramer's Rule) 或矩阵逆直接解出各分量的像函数，然后分别反演。

## 二、⚠️ 致命失分陷阱与临界边界

> [!warning] 陷阱 1：微分定理展开时的阶数幂次与初值符号错漏
> 考场最高频失误出现在二阶及三阶导数的初值展开项：
> - 正确：$\mathcal{L}[y''] = p^2 \bar{y} - p y(0) - y'(0)$
> - 正确：$\mathcal{L}[y'''] = p^3 \bar{y} - p^2 y(0) - p y'(0) - y''(0)$
> 常见致命失误是将减号写成加号，或者将 $p$ 的降幂写反（如写成 $p y'(0) + y(0)$）。初值项符号反转会导致系统的自由衰减模式被误算为能量自发增益发散！

> [!caution] 陷阱 2：分项分式重根展开时的待定系数设定不全
> 当特征方程存在重根（例如阻尼振动达到**临界阻尼**，极点为 $(p + \lambda)^2$）时：
> - 正确展开式：$\frac{A}{p + \lambda} + \frac{B}{(p + \lambda)^2}$，反演后对应 $(A + B t) e^{-\lambda t}$；
> - 致命失分：漏设一阶项，仅写成 $\frac{B}{(p + \lambda)^2}$，导致方程解的自由度不足，无法匹配初始速度 $y'(0)$！

> [!danger] 陷阱 3：含延迟阶跃激励 $H(t-t_0)$ 反演时的因果性截断遗漏
> 若微分方程右端受外加脉冲或延迟阶跃激励，像函数中出现指数相位因子 $e^{-p t_0} \bar{F}_0(p)$：
> - 反演时必须严格遵循延迟定理：$\mathcal{L}^{-1}[e^{-p t_0} \bar{F}_0(p)] = f_0(t - t_0) H(t - t_0)$；
> - 考场典型错误：直接写出 $f_0(t - t_0)$，而漏乘阶跃函数 $H(t - t_0)$！这会导致在 $t < t_0$ 的未激发时段算出非零的虚假响应，严重违背物理因果律。

## 三、经典范例手把手演算

### 题目 1（交流 RL 电路暂态响应全解——梁昆淼 §6.3 例 1 原型）：
在 $t = 0$ 时将交流电压源 $E(t) = E_0 \sin(\omega t)$ 接入由电感 $L$ 和电阻 $R$ 串联的闭合电路。初始电流 $j(0) = 0$。
1. 建立微分方程并利用拉普拉斯变换求出像电流 $\bar{j}(p)$；
2. 利用分项分式与留数法反演求出真实瞬态电流 $j(t)$；
3. 严格手把手反代微分方程验算，并从物理上剖析稳态阻抗项与暂态指数衰减项的能量消长机制。

#### 【演算步骤】

**第一步：列写物理方程并执行拉氏变换**
根据基尔霍夫电压定律 (KVL)，电路微分方程为：
$$L \frac{dj}{dt} + R j = E_0 \sin(\omega t), \quad j(0) = 0$$
两边施加拉普拉斯变换：
$$L [p \bar{j}(p) - j(0)] + R \bar{j}(p) = E_0 \mathcal{L}[\sin \omega t] = E_0 \frac{\omega}{p^2 + \omega^2}$$
代入初值 $j(0) = 0$：
$$(L p + R) \bar{j}(p) = \frac{E_0 \omega}{p^2 + \omega^2}$$

**第二步：代数求解像函数**
$$\bar{j}(p) = \frac{E_0 \omega}{(L p + R)(p^2 + \omega^2)} = \frac{E_0}{L} \cdot \frac{\omega}{(p + \frac{R}{L})(p^2 + \omega^2)}$$

**第三步：分项分式反演分解**
记 $\lambda = \frac{R}{L}$。将有理分式展开：
$$\frac{\omega}{(p + \lambda)(p^2 + \omega^2)} = \frac{A}{p + \lambda} + \frac{B p + C}{p^2 + \omega^2}$$
- 求 $A$（掩模法，乘以 $p + \lambda$ 令 $p = -\lambda$）：
  $$A = \frac{\omega}{(-\lambda)^2 + \omega^2} = \frac{\omega}{\lambda^2 + \omega^2} = \frac{\omega}{\frac{R^2}{L^2} + \omega^2} = \frac{\omega L^2}{R^2 + \omega^2 L^2}$$
- 求 $B, C$：通分比较分子系数：
  $$\omega = A(p^2 + \omega^2) + (Bp + C)(p + \lambda) = (A + B)p^2 + (B\lambda + C)p + (A\omega^2 + C\lambda)$$
  对比 $p^2$ 系数：$A + B = 0 \implies B = -A = -\frac{\omega L^2}{R^2 + \omega^2 L^2}$。
  对比 $p$ 系数：$B\lambda + C = 0 \implies C = -B\lambda = A\lambda = \frac{\omega L^2}{R^2 + \omega^2 L^2} \cdot \frac{R}{L} = \frac{R \omega L}{R^2 + \omega^2 L^2}$。

将各系数代入：
$$\bar{j}(p) = \frac{E_0}{L} \left[ \frac{\omega L^2}{R^2 + \omega^2 L^2} \frac{1}{p + \frac{R}{L}} - \frac{\omega L^2}{R^2 + \omega^2 L^2} \frac{p}{p^2 + \omega^2} + \frac{R \omega L}{R^2 + \omega^2 L^2} \frac{1}{p^2 + \omega^2} \right]$$
提取公因式 $\frac{E_0}{R^2 + \omega^2 L^2}$，各项分别查表反演：
1. $\mathcal{L}^{-1}\left[ \frac{1}{p + R/L} \right] = e^{-(R/L)t}$；
2. $\mathcal{L}^{-1}\left[ \frac{p}{p^2 + \omega^2} \right] = \cos(\omega t)$；
3. $\mathcal{L}^{-1}\left[ \frac{\omega}{p^2 + \omega^2} \right] = \sin(\omega t)$。

整理得到电路电流的完全时域解析解：
$$\boxed{ j(t) = \underbrace{\frac{E_0}{R^2 + \omega^2 L^2} \left[ R \sin(\omega t) - \omega L \cos(\omega t) \right]}_{j_{\text{steady}}(t)\text{ 交流稳态受迫响应}} + \underbrace{\frac{E_0 \omega L}{R^2 + \omega^2 L^2} e^{-(R/L)t}}_{j_{\text{transient}}(t)\text{ 瞬态自由衰减响应}} }$$

**第四步：手把手反代验证**
1. **核验初始条件 $t = 0$**：
   $$j(0) = \frac{E_0}{R^2 + \omega^2 L^2} [ R \cdot 0 - \omega L \cdot 1 ] + \frac{E_0 \omega L}{R^2 + \omega^2 L^2} \cdot 1 = -\frac{E_0 \omega L}{R^2 + \omega^2 L^2} + \frac{E_0 \omega L}{R^2 + \omega^2 L^2} = 0$$
   初值严格成立！
2. **核验微分方程恒等性**：
   求导：
   $$\frac{dj}{dt} = \frac{E_0}{R^2 + \omega^2 L^2} [ R\omega \cos\omega t + \omega^2 L \sin\omega t ] - \frac{E_0 \omega L}{R^2 + \omega^2 L^2} \frac{R}{L} e^{-(R/L)t}$$
   计算 $L \frac{dj}{dt} + R j$：
   - 指数衰减项系数：$L \left( -\frac{E_0 \omega R}{R^2 + \omega^2 L^2} \right) + R \left( \frac{E_0 \omega L}{R^2 + \omega^2 L^2} \right) = 0$（指数项在方程内部严格精确对消！）；
   - 正弦项系数：$L \left( \frac{E_0 \omega^2 L}{R^2 + \omega^2 L^2} \right) + R \left( \frac{E_0 R}{R^2 + \omega^2 L^2} \right) = \frac{E_0 (R^2 + \omega^2 L^2)}{R^2 + \omega^2 L^2} \sin\omega t = E_0 \sin\omega t$；
   - 余弦项系数：$L \left( \frac{E_0 R\omega}{R^2 + \omega^2 L^2} \right) + R \left( -\frac{E_0 \omega L}{R^2 + \omega^2 L^2} \right) = 0$。
   合成总和严格恒等于 $E_0 \sin\omega t$！解完全精确。

### 题目 2（二阶非齐次常微分方程初值问题——梁昆淼 §6.3 习题 1(2)）：
求解初值问题：
$$\frac{d^2 y}{dt^2} + 9 y = 30 \cosh t, \quad y(0) = 3, \quad y'(0) = 0$$

#### 【演算步骤】
1. **微分代数化**：
   已知双曲余弦 $\cosh t = \frac{e^t + e^{-t}}{2}$，其拉氏变换为：
   $$\mathcal{L}[\cosh t] = \frac{p}{p^2 - 1} \quad (|p| > 1)$$
   对方程两边施加拉普拉斯变换：
   $$[p^2 \bar{y}(p) - p y(0) - y'(0)] + 9 \bar{y}(p) = 30 \frac{p}{p^2 - 1}$$
2. **代入初值并整理像函数**：
   代入 $y(0) = 3, y'(0) = 0$：
   $$(p^2 + 9) \bar{y}(p) - 3p = \frac{30p}{p^2 - 1}$$
   $$(p^2 + 9) \bar{y}(p) = 3p + \frac{30p}{p^2 - 1} = \frac{3p(p^2 - 1) + 30p}{p^2 - 1} = \frac{3p^3 - 3p + 30p}{p^2 - 1} = \frac{3p(p^2 + 9)}{p^2 - 1}$$
3. **关键化简与反演**：
   两边同时约去公因子 $(p^2 + 9)$（此乃物理系统的共振极点与外激励初值完美对消！）：
   $$\bar{y}(p) = \frac{3p}{p^2 - 1}$$
4. **时域反演**：
   直接查基本变换对：
   $$\mathcal{L}^{-1}\left[ \frac{p}{p^2 - 1} \right] = \cosh t$$
   因此解极其优美：
   $$\boxed{ y(t) = 3 \cosh t }$$
5. **极速复核验算**：
   - 代入初值：$y(0) = 3 \cosh 0 = 3$；$y'(t) = 3 \sinh t \implies y'(0) = 0$。均吻合！
   - 代入方程：$y''(t) + 9y(t) = 3 \cosh t + 9(3\cosh t) = 30 \cosh t$。完全恒等！
