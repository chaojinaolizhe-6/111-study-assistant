> [!summary] 定理核心论断
> 变系数线性常微分方程是特殊函数（勒让德多项式、贝塞尔函数、厄米多项式等）的共同数学发源地。对于无法用初等函数显式求解的二阶变系数方程，在复分析视野下基于**奇点拓扑结构分类的级数解法**构成了最系统、最强大的解析求解武器。柯西存在定理保证了在**常点邻域内解必定可展开为解析泰勒级数**，其收敛半径精确受控于复平面上最近奇点的欧几里得距离；而在**正则奇点邻域**，福克斯 (Fuchs) 定理与弗罗贝尼乌斯 (Frobenius) 广义幂级数法通过求解**指标方程**，精准判别并重构了两解之差为非整数、重根以及差为正整数时伴随**对数奇性 $\ln(x - x_0)$** 的完全基底解系。

## 一、推导机理与核心数学定义

### 1.1 常点与奇点的严格解析定义

将二阶齐次变系数线性常微分方程化为首一标准型：
$$y''(x) + P(x) y'(x) + Q(x) y(x) = 0$$

1. **常点 (Ordinary Point)**：
   若系数函数 $P(x)$ 与 $Q(x)$ 在点 $x_0$ 处均**全纯（解析，Analytic）**，即均可在 $|x - x_0| < R$ 内展开为收敛的泰勒级数，则称 $x_0$ 为方程的常点。
2. **正则奇点 (Regular Singular Point / 弱奇点)**：
   若 $x_0$ 不是常点（即 $P(x)$ 或 $Q(x)$ 在 $x_0$ 处至少有一个不解析），但极限乘积：
   $$p(x) = (x - x_0) P(x) \quad \text{与} \quad q(x) = (x - x_0)^2 Q(x)$$
   在 $x_0$ 处均是**严格全纯解析**的（即 $P$ 处的极点阶数最多为 1 阶，$Q$ 处的极点阶数最多为 2 阶），则称 $x_0$ 为方程的正则奇点。
3. **不正规奇点 (Irregular Singular Point / 强奇点)**：
   若 $x_0$ 处的极点阶数超过上述限制，则称 $x_0$ 为不正规奇点。

> [!tip] 无穷远点 $x = \infty$ 的分类判据
> 令自变量作倒数反演变换 $x = \frac{1}{z}$（即 $z \to 0$），将原方程转换为关于 $z$ 的微分方程：
> $$\frac{d^2 y}{dz^2} + \left[ \frac{2}{z} - \frac{1}{z^2} P\left(\frac{1}{z}\right) \right] \frac{dy}{dz} + \frac{1}{z^4} Q\left(\frac{1}{z}\right) y = 0$$
> 若 $z = 0$ 是新方程的常点（正则奇点），则原方程的无穷远点 $x = \infty$ 即为常点（正则奇点）。

### 1.2 常点邻域的泰勒级数解法与柯西存在定理

> **柯西存在与收敛定理 (Cauchy's Theorem for ODEs)**：
> 若 $x_0$ 是方程的常点，则在以 $x_0$ 为中心、半径为 $R$ 的圆盘域内，方程严格存在两个线性无关的完全解析解：
> $$y_1(x) = \sum_{n=0}^\infty a_n (x - x_0)^n, \quad y_2(x) = \sum_{n=0}^\infty b_n (x - x_0)^n$$
> **收敛半径 $R$ 的几何判据**：收敛半径 $R$ 至少等于从基准点 $x_0$ 到方程系数函数 $P(x)$ 或 $Q(x)$ 在**复平面上的最近奇点的欧氏直线距离**！

#### 标准求解操作流：
1. 设未知解为 $y(x) = \sum_{n=0}^\infty a_n (x - x_0)^n$；
2. 逐项微商：$y' = \sum n a_n (x-x_0)^{n-1}, y'' = \sum n(n-1) a_n (x-x_0)^{n-2}$；
3. 代入原方程，将所有乘积项的自变量幂次统一平移对齐为 $(x - x_0)^k$；
4. 令每一阶幂次 $(x - x_0)^k$ 的总和系数严格为零，建立待定系数的**递推关系式 (Recurrence Relation)**；
5. 将所有高阶系数 $a_n$ 表达为前两个自由初始常数 $a_0 = y(x_0)$ 与 $a_1 = y'(x_0)$ 的线性组合，从而合成两个基本解。

### 1.3 正则奇点邻域的弗罗贝尼乌斯方法 (Frobenius Method)

设 $x = 0$ 为正则奇点，则 $x P(x) = \sum_{k=0}^\infty p_k x^k, x^2 Q(x) = \sum_{k=0}^\infty q_k x^k$ 解析。
将方程两边乘以 $x^2$：
$$x^2 y'' + x [x P(x)] y' + [x^2 Q(x)] y = 0$$

#### 1. 广义幂级数设定与指标方程 (Indicial Equation)
设广义幂级数解为：
$$y(x) = x^r \sum_{n=0}^\infty a_n x^n = \sum_{n=0}^\infty a_n x^{n+r} \quad (a_0 \neq 0)$$
求导代入方程，考察 $x^r$（即最低幂次 $n = 0$）的系数：
$$a_0 [r(r - 1) + p_0 r + q_0] = 0$$
因设定 $a_0 \neq 0$，导出决定指标 $r$ 的代数二次方程——**指标方程**：
$$\boxed{ F(r) \equiv r(r - 1) + p_0 r + q_0 = 0 }$$
解出两个指标根 $r_1, r_2$（约定 $\operatorname{Re} r_1 \ge \operatorname{Re} r_2$）。

#### 2. 第二解对数奇性三大分类准则 (Fuchs' Classification)

1. **第一类：$r_1 - r_2 \neq \text{整数}$**
   两个指标根互不相差整数。直接代入 $r_1$ 与 $r_2$ 可分别算出两组递推系数，得到两个完全独立的纯广义幂级数解：
   $$y_1(x) = x^{r_1} \sum_{n=0}^\infty a_n x^n, \quad y_2(x) = x^{r_2} \sum_{n=0}^\infty b_n x^n$$
2. **第二类：$r_1 = r_2 = r$（二重指标根）**
   只能通过常规方法求出一个纯幂级数解 $y_1(x)$。第二个解**必然带有对数奇性 $\ln x$**，其精确结构为：
   $$\boxed{ y_2(x) = y_1(x) \ln x + x^r \sum_{n=1}^\infty c_n x^n }$$
   （数学推导源于指标导数法 $y_2(x) = \left. \frac{\partial y(x, r)}{\partial r} \right|_{r=r_1}$，$\frac{\partial}{\partial r}(x^r) = x^r \ln x$ 自然唤醒了对数因子）。
3. **第三类：$r_1 - r_2 = N$（两根之差为正整数 $N \in \mathbb{Z}^+$）**
   较大根 $r_1$ 始终能顺畅算出第一解 $y_1(x)$。但在用较小根 $r_2$ 计算第 $N$ 阶递推系数时，分母会出现因子 $F(r_2 + N) = F(r_1) = 0$（零除危机！）。第二解的一般形式包含对数项：
   $$\boxed{ y_2(x) = C y_1(x) \ln x + x^{r_2} \sum_{n=0}^\infty d_n x^n }$$
   （常数 $C$ 可能为 0，若为 0 则无对数项，如半奇数阶贝塞尔函数；若 $C \neq 0$ 则对数项不可消除，如整数阶贝塞尔函数 $Y_n(x)$）。

## 二、⚠️ 致命失分陷阱与临界边界

> [!warning] 陷阱 1：收敛半径判定中遗漏复数域内的虚奇点
> 考察方程 $(x^2 + 4) y'' + x y' - y = 0$ 在常点 $x_0 = 0$ 处的级数解：
> - 许多考生误认为在实数轴上 $x^2 + 4 > 0$ 处处无奇点，从而得出“收敛半径为 $\infty$”的荒谬结论；
> - 规范判定必须放眼**复平面**：奇异点是使最高阶系数为零的点，即 $x^2 + 4 = 0 \implies x = \pm 2i$；
> - 从基准点 $0$ 到复奇点 $\pm 2i$ 的复距离为 $|2i - 0| = 2$，因此级数解的真实收敛半径恰好是**有限的 $R = 2$**！

> [!caution] 陷阱 2：两指标根差为正整数时强行代入较小根
> 当指标方程根为 $r_1 = 1, r_2 = -1$（差为 $N = 2$）时：
> - 考场典型错误：直接把 $r_2 = -1$ 代入递推公式算 $a_1, a_2, \dots$；
> - 在算到 $a_2$ 时，分母必定出现 $F(-1+2) = F(1) = 0$，强行计算导致分母除以零崩溃；
> - 必须清醒认识到：**必须先求较大根 $r_1$ 的解**，较小根必须引入对数待定项或采用导数技巧求解！

> [!danger] 陷阱 3：变系数幂级数递推关系中求和指标的幂次未对齐
> 在将 $y, y', y''$ 代入求和式时：
> - 例如代入 $x^2 y''$（幂次仍为 $x^n$）与代入 $y''$（幂次为 $x^{n-2}$）；
> - 绝对不能直接把系数相加！必须通过更名换元（如令 $m = n - 2$）使所有项的**自变量幂次完全对齐为同一种 $x^k$** 后，方可合并同类项提取系数。

## 三、经典范例手把手演算

### 题目（勒让德常微分方程在常点邻域的级数解与多项式截断）：
勒让德方程形式为：
$$(1 - x^2) \frac{d^2 y}{dx^2} - 2x \frac{dy}{dx} + l(l + 1) y = 0 \quad (l \ge 0)$$
1. 验证 $x = 0$ 为方程的常点，并求其复数域收敛半径；
2. 设 $y = \sum_{n=0}^\infty a_n x^n$，严格推导系数递推关系式；
3. 证明当且仅当参数 $l$ 取非负整数时，级数必然在 $n = l$ 处截断为 $l$ 次勒让德多项式。

#### 【演算步骤】

**第一步：奇点判定与收敛半径**
化为标准型：$y'' - \frac{2x}{1 - x^2} y' + \frac{l(l+1)}{1 - x^2} y = 0$。
- 系数函数 $P(x) = -\frac{2x}{1 - x^2}, Q(x) = \frac{l(l+1)}{1 - x^2}$ 在 $x = 0$ 处均可作泰勒展开，因此 **$x = 0$ 是严格的常点**。
- 方程的奇异点为分母零点：$1 - x^2 = 0 \implies x = \pm 1$。
- 从常点 $x_0 = 0$ 到奇点 $\pm 1$ 的距离为 $R = 1$。根据柯西定理，级数解在区间 $|x| < 1$ 内绝对收敛！

**第二步：逐项代入与幂次平移对齐**
设 $y(x) = \sum_{n=0}^\infty a_n x^n$。求导得：
$$y'(x) = \sum_{n=1}^\infty n a_n x^{n-1}, \quad y''(x) = \sum_{n=2}^\infty n(n - 1) a_n x^{n-2}$$
代入原方程 $(1 - x^2) y'' - 2x y' + l(l+1) y = 0$：
$$\sum_{n=2}^\infty n(n - 1) a_n x^{n-2} - \sum_{n=2}^\infty n(n - 1) a_n x^n - 2 \sum_{n=1}^\infty n a_n x^n + l(l+1) \sum_{n=0}^\infty a_n x^n = 0$$

对第一项作指标平移（令 $k = n - 2 \implies n = k + 2$）：
$$\sum_{n=2}^\infty n(n - 1) a_n x^{n-2} = \sum_{k=0}^\infty (k + 2)(k + 1) a_{k+2} x^k$$
将所有项的求和变量均改记为 $k$：
- 注意后三项中，$k=0$ 时：$-0 - 0 + l(l+1)a_0$；$k=1$ 时：$-0 - 2a_1 + l(l+1)a_1$。这与通式完全兼容。
将同幂次 $x^k$ 的系数整体合并：
$$\sum_{k=0}^\infty \left[ (k + 2)(k + 1) a_{k+2} - k(k - 1) a_k - 2k a_k + l(l+1) a_k \right] x^k = 0$$
化简方括号内 $a_k$ 的组合系数：
$$-k(k - 1) - 2k + l(l+1) = -k^2 + k - 2k + l^2 + l = l^2 - k^2 + l - k = (l - k)(l + k) + (l - k) = (l - k)(l + k + 1)$$
令每一阶 $x^k$ 的系数恒为零：
$$(k + 2)(k + 1) a_{k+2} + (l - k)(l + k + 1) a_k = 0$$
导出著名的**勒让德递推关系式**：
$$\boxed{ a_{k+2} = -\frac{(l - k)(l + k + 1)}{(k + 1)(k + 2)} a_k \quad (k = 0, 1, 2, \dots) }$$

**第三步：解的结构剖析（偶解与奇解）**
由递推关系可知，$a_{k+2}$ 仅与同奇偶性的 $a_k$ 相关：
1. **偶次级数解 $y_1(x)$（由自由初值 $a_0$ 激发）**：
   $a_2 = -\frac{l(l+1)}{2} a_0$；
   $a_4 = -\frac{(l - 2)(l + 3)}{12} a_2 = \frac{l(l - 2)(l + 1)(l + 3)}{4!} a_0$；
   $$y_1(x) = a_0 \left[ 1 - \frac{l(l+1)}{2!} x^2 + \frac{l(l-2)(l+1)(l+3)}{4!} x^4 - \dots \right]$$
2. **奇次级数解 $y_2(x)$（由自由初值 $a_1$ 激发）**：
   $a_3 = -\frac{(l - 1)(l + 2)}{6} a_1$；
   $a_5 = \frac{(l - 1)(l - 3)(l + 2)(l + 4)}{5!} a_1$；
   $$y_2(x) = a_1 \left[ x - \frac{(l-1)(l+2)}{3!} x^3 + \frac{(l-1)(l-3)(l+2)(l+4)}{5!} x^5 - \dots \right]$$

**第四步：有限截断为勒让德多项式 $P_l(x)$**
考察递推分子中的因子 $(l - k)$：
- 若参数 $l$ 是一个非负整数（$l = 0, 1, 2, 3, \dots$）：
  当递推进行到 $k = l$ 时，分子中出现 $(l - l) = 0$！
  $$\implies a_{l+2} = 0 \implies a_{l+4} = 0 \implies a_{l+6} = 0 = \dots$$
  **该奇偶性支路上的所有更高阶系数自此全部截断为零！**
- 无穷级数坍缩为最高次项为 $x^l$ 的**有限阶多项式**！
  - 若 $l$ 为偶数，偶次级数 $y_1(x)$ 截断为 $l$ 次偶多项式；
  - 若 $l$ 为奇数，奇次级数 $y_2(x)$ 截断为 $l$ 次奇多项式。
经过标准化系数归一（令 $x = 1$ 时 $P_l(1) = 1$），即诞生了统治球坐标数理方程的核心柱石——**勒让德多项式 $P_l(x)$**！
