# 偏振态完全分类与马吕斯定律

> [!summary] 核心认知先验
> 光的干涉、衍射表明光是波动，但只有偏振现象直接显示光是横波。教材第六章 §1 以“机械波栏杆”类比引入偏振片透振方向，把常见光按电矢量在波面内的振动状态分为自然光、线偏振光、部分偏振光、圆偏振光、椭圆偏振光五类；马吕斯定律定量给出线偏振光经检偏器后的强度变化，偏振度则定量衡量部分偏振光的偏振程度。两者共同构成偏振态分类与偏振光检测的基础。

<!-- unit:u06_01_polarization_states -->
## 定义、条件与直观

### 1. 偏振现象与光的横波性

教材以橡皮绳横波通过两个栏杆 $G_1$、$G_2$ 的机械模型作类比：两缝平行时振动无阻碍通过，两缝垂直时波动被挡住。只有横波的振动方向才能被“栏杆方向”选择性通过，纵波不受影响。

光学上，让光依次通过偏振片 $P_1$、$P_2$，固定 $P_1$、绕光线轴转动 $P_2$：透射光强周期变化，每隔 $90^\circ$ 出现一次最大和一次消光。教材指出这反映偏振片存在一个“特殊方向”（透振方向），也说明光波中的振动方向与传播方向垂直，即光是横波。

教材注明：历史上马吕斯于 1809 年实验发现偏振现象；在光的电磁理论建立以前，光的横波性使“以太”模型面临极大困难，电磁理论建立后才完满说明。电磁理论预言自由空间电磁波是纯横波，常以电矢量作为光波中振动矢量的代表。

### 2. 五种偏振态及直观

**自然光**：普通光源大量原子或分子发出的光波初相位无关联、振动方向杂乱。宏观上入射光含所有横方向振动，对传播方向轴对称，各方向无优先。特点：波面内取向分布概率各向同性，彼此无固定相位关联。用偏振片检验，透射光强不随透振方向变化。

自然光 $I_0$ 经理想偏振片后，只留下沿透振方向的分量：
$$I = \frac{1}{2} I_0.$$
教材强调：自然光沿任何方向的分量造成的强度均为总强度 $I_0$ 之半。

**线偏振光**：透过偏振片后只剩与其透振方向平行的振动，只包含单一振动方向。振动方向与传播方向构成的平面叫振动面；因振动矢量维持在振动面内，故线偏振光也称平面偏振。

**部分偏振光**：振动各方向都有，但不同方向振幅大小不同。用检偏器检验，透射光强每转 $90^\circ$ 交替极大/极小，但极小不为 $0$，不出现消光。偏振度定义为：
$$P = \frac{I_{\max}-I_{\min}}{I_{\max}+I_{\min}}. \tag{6.2}$$
分母是两个相互垂直分量的强度之和，即部分偏振光原来的总强度；分子是极大、极小强度之差。自然光 $P=0$（非偏振光），线偏振光 $P=1$（全偏振光）。

**圆偏振光**：电矢量在波面内瞬时值的大小不变，方向以角速度 $\omega$ 匀速旋转，端点轨迹为圆。两个等幅、相位差 $\pm\pi/2$ 的相互垂直简谐振动合成为旋转矢量。教材给出分量：
$$\begin{cases}
E_x = A\cos\omega t,\\
E_y = A\cos\left(\omega t \pm \dfrac{\pi}{2}\right).
\end{cases} \tag{6.3}$$
电矢量：
$$\boldsymbol{\mathcal E} = \mathcal E_x\hat{\boldsymbol x}+\mathcal E_y\hat{\boldsymbol y}
= A\cos\omega t\,\hat{\boldsymbol x}
+ A\cos\left(\omega t \pm \dfrac{\pi}{2}\right)\hat{\boldsymbol y}. \tag{6.4}$$

左右旋判定（光学约定）：迎着光的传播方向观察，电矢量逆时针旋转为左旋圆偏振光，顺时针旋转为右旋圆偏振光。教材注明 (6.4) 式中 $\pi/2$ 前取正号对应右旋，负号对应左旋。教材还特别注明：微波技术中左右旋偏振相对波束传播方向定义，与光学习惯相反。

教材注记：迎着圆偏振光传播方向放一偏振片并旋转，透射光强不变；圆偏振光可分解为任意互相垂直方向的两个等幅线偏振光，一个分量通过、另一个不通过，故
$$I = A_x^2 = A^2 = \frac12 I_0. \tag{6.5}$$
因此仅用一块偏振器不能区分圆偏振光与自然光，鉴别方法在 §5 讨论。

**椭圆偏振光**：电矢量端点在波面内轨迹为椭圆。椭圆运动可看作两个相互垂直简谐振动合成，但振幅不等或相位差不等于 $\pm\pi/2$。教材给出两个分量：
$$\begin{cases}
E_x = A_x\cos\omega t,\\
E_y = A_y\cos(\omega t+\delta).
\end{cases} \tag{6.6}$$
电矢量：
$$\boldsymbol{\mathcal E} = \mathcal E_x\hat{\boldsymbol x}+\mathcal E_y\hat{\boldsymbol y}
= A_x\cos\omega t\,\hat{\boldsymbol x}
+ A_y\cos(\omega t+\delta)\hat{\boldsymbol y}. \tag{6.7}$$
椭圆长、短轴的大小和取向与 $A_x,A_y$ 和相位差 $\delta$ 有关。图 6-10 给出不同 $\delta$ 的椭圆轨迹。

> [!note] 补充讲解：椭圆轨迹方程
> 教材原文并未写出消去时间参数的显式椭圆方程。作为补充，由 (6.6) 消去 $t$ 可得标准形式：
> $$\frac{E_x^2}{A_x^2}+\frac{E_y^2}{A_y^2}-2\frac{E_x E_y}{A_x A_y}\cos\delta=\sin^2\delta.$$
> 该式只用于说明轨迹确为椭圆；教材的判定依据是“两个垂直简谐振动的合成”和退化条件。

退化条件（教材原文）：
- 椭圆偏振光退化为圆偏振光：$A_x=A_y$ 且 $\delta=\pm\pi/2$；
- 退化为线偏振光：$A_x=0$ 或 $A_y=0$，或 $\delta=0,\pm\pi$。

因此线偏振光与圆偏振光都可看成椭圆偏振光的特例。椭圆偏振光左、右旋定义与圆偏振光相同：迎着光的传播方向看。

## 定义、条件与直观

### 马吕斯定律的严格推导

教材用图 6-2 装置：偏振片 P1 产生线偏振光，称为起偏器；P2 检验线偏振光，称为检偏器。设通过 P1、P2 的振动矢量分别为 $\boldsymbol{\mathcal E}_1,\boldsymbol{\mathcal E}_2$，振幅分别为 $A_1,A_2$，强度 $I_1=A_1^2$、$I_2=A_2^2$。固定 P1，改变 P2 透振方向：

- 当 P2 透振方向与 P1 平行，$\boldsymbol{\mathcal E}_1 \parallel \boldsymbol{\mathcal E}_2$，$A_2=A_1$，$I_2=I_1$；
- 当 P2 相对 P1 转过角度 $\theta$，$\boldsymbol{\mathcal E}_2$ 是 $\boldsymbol{\mathcal E}_1$ 在 P2 透振方向上的投影：
$$A_2 = A_1\cos\theta,$$
$$I_2 = A_2^2 = A_1^2\cos^2\theta = I_1\cos^2\theta. \tag{6.1}$$

$\theta=90^\circ$ 时 $A_2=0,I_2=0$（消光）。公式 (6.1) 即马吕斯定律。

### 偏振度

部分偏振光的偏振程度用偏振度 $P$ 衡量：
$$P = \frac{I_{\max}-I_{\min}}{I_{\max}+I_{\min}}. \tag{6.2}$$

- $I_{\max}=I_{\min}$ 时 $P=0$：自然光；
- $I_{\min}=0$ 时 $P=1$：线偏振光（全偏振光）。

### 级联偏振透射流

教材把自然光、起偏器、检偏器三者联系起来：自然光 $I_0$ 先经理想起偏器 P1，只保留透振方向分量，光强变为
$$I_1 = \frac12 I_0,$$
且出射光成为线偏振光；此后该线偏振光再通过检偏器 P2，才按马吕斯定律变化：
$$I_2 = I_1\cos^2\theta = \frac12 I_0 \cos^2\theta.$$
这里 $\theta$ 是 P1、P2 透振方向之间的夹角。教材原文分别给出“自然光经偏振片减半”（§1.3）和“线偏振光经检偏器服从 (6.1)”（§1.4），上式为这两个教材结论的组合，不是单独编号的教材公式。

## 性质与教材例子

- 图 6-6 马吕斯定律：给出平行、夹角 $\theta$、垂直三种几何关系；
- 图 6-7 部分偏振光：各方向振幅不同导致透射光强极大/极小但不消光；
- 日常现象：晴朗日子蔚蓝色天空散射的日光多半是部分偏振光，散射光与入射光方向越接近垂直，偏振度越高（详见第七章 4.3 节）。

> [!warning] 易混概念与适用边界
> - 马吕斯定律 $I=I_0\cos^2\theta$ 只适用于已经起偏后的线偏振光通过检偏器；不能直接用于自然光第一次通过偏振片。自然光第一次经理想偏振片必须先把光强变为 $I_0/2$，之后第二片偏振片才适用 $\cos^2\theta$。这是最常见的致命失分陷阱。
> - 自然光与圆偏振光单独用一块偏振片观察时透射光强都不随转角变化、均为入射强度一半，不能区分；教材指出鉴别方法在 §5 讨论。
> - 偏振度 $P$ 只描述部分偏振光的“偏振程度”，$P=0$ 对应自然光、$P=1$ 对应全偏振光；它对圆偏振光、椭圆偏振光的左右旋不加区分。
> - 左右旋判定的光学约定是“迎着光束看”；微波技术恰好相反，教材已特别注明。
