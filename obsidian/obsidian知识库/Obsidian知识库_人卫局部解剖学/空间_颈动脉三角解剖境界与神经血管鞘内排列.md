# 空间_颈动脉三角解剖境界与神经血管鞘内排列

> [!summary] 空间架构与核心心智模型
> 颈动脉三角是由胸锁乳突肌前缘、二腹肌后腹与肩胛舌骨肌上腹围成的血管神经门户。其核心心智模型为“浅面三层覆盖、深面椎前筋膜托底、鞘内三结构呈外静脉-内动脉-后神经排列、神经跨动脉表面交叉”。颈动脉窦与颈动脉体位于颈总动脉分叉部，是压力感受与化学感受区，也是穿刺和手术操作的高风险区。

## 空间闭合边界

| 边界 | 构成 |
| --- | --- |
| 上壁 | 二腹肌后腹 |
| 前壁 | 肩胛舌骨肌上腹 |
| 后壁/外侧壁 | 胸锁乳突肌前缘 |
| 内侧壁/尖 | 二腹肌后腹与肩胛舌骨肌上腹的筋膜汇聚区，三角尖朝向舌骨方向 |
| 顶/浅面 | 皮肤、浅筋膜、颈阔肌、颈深筋膜浅层；面神经颈支与颈横神经行于浅面 |
| 底/深面 | 椎前筋膜及其深面椎前肌；椎前筋膜浅面有交感干与颈交感节 |

## 穿行内容物

### 颈动脉鞘立体排列

颈动脉鞘内主要结构呈“外静脉、内动脉、后神经”的固定排列：

- 外侧：颈内静脉
- 内侧：颈总动脉及其延续的颈内动脉
- 后方沟内：迷走神经，位于颈内静脉与颈总/颈内动脉之间的后方

颈总动脉分叉部包含：

- 颈动脉窦：位于颈总动脉末端与颈内动脉起始部管壁膨大，为压力感受器所在
- 颈动脉体：位于分叉处后方，为化学感受器

### 神经交叉关系

- 舌下神经：自二腹肌后腹深面进入颈动脉三角，越颈内、外动脉浅面向前下走行，并发出降支，即颈袢上根
- 副神经：在二腹肌后腹深面穿出，行向后下方，进入胸锁乳突肌深面
- 交感干与颈交感节：位于颈动脉鞘后方、椎前筋膜浅面，不进入颈动脉鞘内

## 临床警示

> [!danger] 颈动脉窦反射与穿刺盲区
> 在颈动脉三角触压颈总动脉分叉处可压迫颈动脉窦，诱发心率减慢、血压骤降甚至心搏骤停，严禁同时按压双侧。颈内静脉穿刺时若针尖偏向内侧或穿入过深，可误伤颈总动脉，形成血肿、假性动脉瘤或动静脉瘘，也可能伤及后方迷走神经。

> [!warning] 颈动脉鞘分离与分叉部手术风险
> 手术中纵向切开颈动脉鞘时，迷走神经位于动、静脉后方沟内，视野不清时易被牵拉或误扎。颈总动脉分叉部是颈动脉体瘤和动脉粥样硬化斑块的好发位置，分离时颈动脉窦压力感受反射可导致循环波动。舌下神经在动脉浅面走行，处理颈外动脉分支前须先辨认并保护。副神经与交感干位于分离平面后外侧或深面，过度向后深分离可致斜方肌功能受损或 Horner 综合征。金标准预防措施为：以胸锁乳突肌前缘为标志，在超声引导下区分颈内静脉与颈总动脉；直视下先确认迷走神经再分离鞘内结构；避免挤压颈动脉窦；保护舌下神经降支及副神经。
