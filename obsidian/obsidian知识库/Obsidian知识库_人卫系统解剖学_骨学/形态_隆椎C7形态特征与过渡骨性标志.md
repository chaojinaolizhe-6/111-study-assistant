# 形态_隆椎C7形态特征与过渡骨性标志

![[images/Vertebra_prominens_C7.png|500]]

> 图注：第7颈椎(隆椎)形态构造、细长水平棘突与颈胸过渡特征图解。可见棘突长而水平、末端结节状不分叉，横突孔较小，关节突向胸椎型过渡。

## 认知先验

> [!summary] 空间架构与核心心智模型
> C7 是颈椎与胸椎之间的形态过渡站台。其核心辨识逻辑为：**棘突最长、最水平、末端不分叉、皮下最突出**。与 C3–C6 的短而分叉棘突截然不同，C7 的结节状长棘突在颈后正中形成恒定可触及的最高隆起。同时，横突前结节退化使 C7 横突整体纤细，横突孔缩小且不再容纳椎动脉，标志着椎动脉由 C6 横突孔穿出后绕过 C7 外侧上行进入枕骨大孔的路径特征。关节突关节面开始由冠状位向胸椎冠状—矢状混合位倾斜过渡，成为颈胸交界力学转换的形态基础。

## 形态学属性

| 属性 | 特征描述 |
|------|----------|
| 椎体 | 大小介于颈椎与胸椎之间，椎体上面两侧仍保留钩突，下面两侧有斜坡样唇缘 |
| 椎孔 | 较 C3–C6 略小，呈三角形，适应颈膨大下端脊髓过渡形态 |
| 棘突 | 长而粗大，水平伸向后方，末端不分叉呈结节状，皮下可清晰触及 |
| 横突 | 较细小，横突前结节明显退化或缺如，后结节存在；横突孔小 |
| 横突孔内容物 | 通常无椎动脉穿经，仅容纳副椎静脉，偶有椎静脉属支 |
| 上关节突 | 关节面朝向后上，接近颈椎模式 |
| 下关节突 | 关节面朝向前下，逐渐向胸椎型转化 |
| 整体过渡意义 | 为颈胸交界的形态与力学转换枢纽 |

## 起点与止点

| 附着结构 | 附着部位 |
|----------|----------|
| 项韧带 | 止于 C7 棘突末端结节，为项韧带下界主要锚点 |
| 斜方肌 | 部分纤维起于 C7 棘突及项韧带下端 |
| 菱形肌 | 小菱形肌起自 C7 棘突，向肩胛骨内侧缘走行 |
| 上后锯肌 | 部分腱性纤维起于 C7 棘突 |
| 夹肌 | 头夹肌与颈夹肌部分纤维起于 C7 棘突及邻近项韧带 |
| 多裂肌 | 起于 C7 下关节突及横突，向上跨越节段附着 |
| 回旋肌 | 起于 C7 横突，向上附着于上位椎骨棘突根部 |

## 神经支配

- 感觉神经：C7 脊神经后内侧支分布于棘突周围皮肤与筋膜
- 运动神经：C7 脊神经后支支配多裂肌、回旋肌等椎旁深层肌节段性运动
- 窦椎神经：分布至椎体后方、后纵韧带及硬膜外间隙，负责 C7 节段本体感觉与痛觉

## 血管供应

- 动脉：由椎动脉颈段发出的节段性脊髓支、颈深动脉降支及甲状颈干分支共同营养 C7 椎体与附件
- 静脉：椎内静脉丛与椎外静脉丛经椎间静脉引流，横突孔内副椎静脉向下汇入椎静脉系统
- 淋巴：经颈深淋巴结群外侧组引流

## 体表触诊

- 体位：受检者坐位或俯卧位，颈前屈使颈后棘突间距增大
- 触诊顺序：自枕外隆凸向下推移，第一明显高突的骨性隆起即为 C7 棘突
- 验证方法：嘱受检者缓慢左右旋转头部，C7 棘突在旋转时移动幅度极小或不移动，而 C6 棘突可触及轻微旋转移动
- 计数意义：以 C7 棘突为基准向上计数 C1–C6，向下计数 T1–T12，为临床椎骨定位、胸椎穿刺、针刺取穴的首要骨性标志

## 功能与立体空间关联

- 支撑：C7 棘突是项韧带力学汇合点，传递头颈后伸与旋转应力至胸椎
- 运动枢纽：C7–T1 构成颈胸过渡运动节段，参与头颈后伸、侧屈及旋转的末端稳定
- 椎动脉路径：椎动脉通常由 C6 横突孔穿出后，不经 C7 横突孔，而是沿 C7 横突前外侧上行，经寰枕后膜入颅
- 臂丛出口关联：C7 神经根经 C7 椎弓根上方与 C7 横突之间穿出，与 C8、T1 共同构成臂丛下干或参与中干形成

## 异常警示与临床误伤区

> [!danger] 临床误伤与手术盲区
> 1. **颈肋误判**：C7 横突前结节偶发过度生长形成颈肋，可向前外延伸压迫臂丛下干与锁骨下动脉，出现胸廓出口综合征。影像判读时需将 C7 横突与颈肋清晰区分，避免将细长横突误判为颈肋而误导手术入路。
> 2. **C7 棘突定位偏差**：过度肥胖或颈椎前凸增大者，C7 与 T1 棘突均可高突，若未用旋转验证法区分，可导致胸椎节段计数错误，引起胸椎穿刺平面偏移或椎弓根螺钉置入节段错误。
> 3. **颈胸交界手术盲区**：C7–T1 为前路手术深部盲区，胸骨柄遮挡使椎体显露困难。需注意 C7 横突孔虽小，但副椎静脉穿行其中，横突周围剥离时易损伤静脉导致出血。
> 4. **椎动脉走行变异**：少数个体椎动脉可经 C7 横突孔穿行，C7 横突暴露及侧块螺钉置入时若未识别该变异，有损伤椎动脉风险。

> [!warning] 体表触诊陷阱
> - 颈后隆起最明显者不一定为 C7，关节突关节炎导致的 C6 或 T1 棘突代偿性隆突、皮下脂肪瘤、棘上韧带钙化结节均可混淆触诊
> - 呼吸配合下自 T1 以下棘突可随呼吸轻度起伏，C7 棘突无明显呼吸起伏，可作为辅助区分
> - 儿童颈部皮下脂肪较厚，C7 棘突触诊不清，需结合活动验证与影像定位

## 与其他椎体的对比鉴别

| 特征 | C3–C6 | C7 | T1 |
|------|-------|----|----|
| 棘突形态 | 短、末端分叉 | 长、水平、末端结节状不分叉 | 长、斜向后下、末端结节状 |
| 皮下触诊 | 深在，不易单独触及 | 最易触及，颈后最高突起 | 可触及，但低于 C7 |
| 横突孔 | 大，有椎动脉穿经 | 小，仅副椎静脉 | 无横突孔 |
| 椎体侧面 | 有钩突 | 有钩突 | 无钩突，出现肋凹 |
| 关节突 | 冠状位为主 | 开始向胸椎过渡 | 冠状位与矢状位混合 |

## 记忆锚点

- **C7 口诀**：七棘长平结节尖，横孔小无椎动脉，颈胸过渡标志点，枕下向下第一突。
- **计数逻辑**：C7 = 颈后最高恒定突起 = 椎骨序数计数的“零公里碑”。
