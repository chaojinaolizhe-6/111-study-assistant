# 空间_寰枕与寰枢关节连结及韧带稳定复合体

![[images/Atlantoaxial_ligament_complex.png|500]]

> 图：寰枕与寰枢关节连结复合体、寰椎横韧带与翼状韧带截面图解

> [!summary] 空间架构与核心心智模型
> 寰枕-寰枢复合体是颅颈交界区的“骨-韧带环形扣锁装置”。寰枕关节为成对椭圆关节，主导点头与仰头；寰枢关节由 2 个寰枢外侧关节和 1 个寰齿正中关节构成，围绕齿突旋转。寰椎横韧带从后方扣锁齿突，翼状韧带限制过度旋转，覆膜作为后纵韧带延续兜底。核心心智模型：齿突是旋转轴，横韧带是安全带，翼状韧带是限位器，覆膜是后方兜底。

## 空间边界与内容物

| 边界 | 结构 |
| --- | --- |
| 顶 | 枕骨髁、枕骨大孔前外侧缘 |
| 底 | 枢椎上关节面、齿突根部 |
| 前壁 | 寰椎前弓、寰枕前膜、前纵韧带 |
| 后壁 | 覆膜、十字韧带纵束、寰椎横韧带 |
| 内侧壁 | 齿突及寰齿正中关节 |
| 外侧壁 | 寰枕关节囊、寰枢外侧关节囊、翼状韧带 |

内容物/紧邻穿行结构：齿突、关节软骨、滑膜与滑液、齿突尖韧带、十字韧带；椎动脉 V3 段紧邻侧方，C1/C2 神经根及脊髓位于后方。

## 韧带稳定复合体

| 韧带 | 起止 | 力学作用 |
| --- | --- | --- |
| 寰椎横韧带 | 寰椎两侧块内侧结节 | 约束齿突向后移位，维持寰齿间隙 |
| 十字韧带 | 横韧带 + 上下纵束 | 强化齿突后方扣锁，连接枕骨与枢椎 |
| 翼状韧带 | 齿突后外侧 → 枕骨髁内侧面 | 限制过度旋转与侧屈 |
| 齿突尖韧带 | 齿突尖 → 枕骨大孔前缘 | 辅助维持齿突-枕骨对位 |
| 覆膜 | 后纵韧带向上延续 | 覆盖齿突及韧带后方，限制屈曲并保护脊髓 |

## 运动学

寰枕关节：屈伸为主，允许轻度侧屈。  
寰枢关节：以齿突为轴旋转为主，寰椎与头部共同旋转。

> [!danger] 临床陷阱与手术盲区
> 寰齿间隙（ADI）是横韧带完整性的关键指标：成人正常通常 < 3 mm，儿童 < 5 mm（影像学参考）；ADI 增宽提示寰椎横韧带功能不全，存在寰枢不稳与颈髓压迫风险。经口咽入路处理齿突或寰椎前弓时，后方紧邻横韧带、覆膜和硬膜，需严格中线操作；后路螺钉或植骨若突破寰椎外侧壁，易损伤椎动脉 V3 段。
