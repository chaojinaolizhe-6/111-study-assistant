图：第1颈椎(寰椎)上面观骨性标志、侧块与椎动脉沟解剖图解。图中可见前弓、前结节、后弓、后结节、侧块上关节凹、横突及横突孔，后弓上面为椎动脉沟，体现寰椎无椎体的环形结构与椎动脉的骨性通道。

> [!summary] 认知先验
> 寰椎是承上启下的骨性环。它没有椎体、棘突和关节突，而是由前弓、后弓和侧块围成寰椎孔。前弓后方的齿突凹与枢椎齿突形成旋转轴，两侧侧块上关节凹承接枕髁，形成寰枕关节。椎动脉经横突孔上行，再弯过后弓上面的椎动脉沟，构成颅颈交界处最易受牵拉或压迫的骨性导轨。

## MedSchoolAtlas 解剖属性

| 属性 | 内容 |
|---|---|
| 骨性构成 | 前弓、后弓、侧块、横突 |
| 起点/关节面连接 | 上关节凹：与枕髁构成寰枕关节；下关节面：与枢椎上关节面构成寰枢外侧关节；齿突凹：与枢椎齿突构成寰枢正中关节 |
| 止点/骨性标志 | 前结节：前弓前面正中突起；后结节：后弓后面正中突起，是枕下肌群附着点 |
| 韧带附着 | 侧块内侧面结节：寰椎横韧带附着，将齿突压向前弓齿突凹；前弓前结节：前纵韧带附着 |
| 毗邻神经 | 第1颈神经经后弓上面的椎动脉沟与椎动脉伴行，其后支为枕下神经，支配枕下肌群 |
| 毗邻血管 | 椎动脉穿横突孔上行，再行经椎动脉沟入颅，是该区域主要骨性通道 |
| 体表触诊 | 横突尖可在乳突尖与下颌角之间深部触诊；后弓后结节位于枕外隆凸下方深部 |
| 功能 | 承托颅骨，参与寰枕关节点头运动与寰枢关节旋转运动，保护延髓与脊髓移行处 |
| 立体空间关联 | 上方与枕髁形成寰枕关节，下方与枢椎形成寰枢关节；寰椎孔容纳延髓、脊髓移行处及硬膜囊；横突孔与椎动脉沟形成椎动脉通道 |

> [!danger] 临床误伤警示
> 后弓上面的椎动脉沟是椎动脉与第1颈神经走行的骨性凹槽。后路寰椎后弓减压或枕颈部操作时，若剥离超过后弓上缘向外侧过度延伸，可损伤椎动脉与第1颈神经。经口咽入路以寰椎前结节为中线骨性标志，偏斜操作可导致深部神经血管损伤。椎动脉沟处存在骨桥或弓形孔变异时，椎动脉走行改变，术前影像学评估为必要措施。

> [!warning] 手术盲区
> 寰椎横突较长且横突孔穿经椎动脉，颈椎后路固定或侧块螺钉置入时，横突孔外侧区域是椎动脉易损伤区。寰椎前弓后方的齿突凹与寰椎横韧带共同形成骨纤维环，齿突骨折脱位时可直接压迫延髓与脊髓移行处。
