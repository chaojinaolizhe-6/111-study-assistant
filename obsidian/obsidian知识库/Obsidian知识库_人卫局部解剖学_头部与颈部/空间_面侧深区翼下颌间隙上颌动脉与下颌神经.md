> [!summary] 认知先验与立体空间脉络
> 面侧深区 / Deep Lateral Facial Region 是颅底与下颌支之间的“血管神经十字路口”：外侧以下颌支骨壁为挡板，内侧以翼突外侧板和咽侧壁为界，前邻上颌骨后面，后隔腮腺鞘与茎突诸肌。其核心内容是翼内肌 / Medial Pterygoid、翼外肌 / Lateral Pterygoid 构成的“翼肌门户”，上颌动脉 / Maxillary Artery 三段绕行翼外肌，下颌神经 / Mandibular Nerve (CN V3) 自卵圆孔 / Foramen Ovale 出颅后在此分干，翼丛 / Pterygoid Venous Plexus 将面部静脉与海绵窦 / Cavernous Sinus 连成无瓣膜静脉通路。理解该区域的关键是抓住“下颌支—翼外肌—翼内肌”三层夹心结构：神经主干在深面分干，动脉在中层分段走行，静脉丛在肌间隙内包绕动脉，形成“静脉最浅、动脉居中、神经偏深”的立体空间布局；其下方延续为翼下颌间隙 / Pterygomandibular Space，构成下牙槽神经阻滞麻醉和牙源性感染扩散的解剖舞台。

## MedSchoolAtlas 解剖属性

| 属性 | 核心解剖规范内容 |
|---|---|
| 层次与六壁/四壁境界 | **面侧深区境界**：前界为上颌骨后面，后界为腮腺鞘和茎突诸肌，外侧界为下颌支内侧面，内侧界为翼突外侧板和咽侧壁，顶为蝶骨大翼颞下面，底为下颌骨下缘平面。<br>**由浅入深层次**：皮肤与浅筋膜 → 腮腺咬肌筋膜 / Parotideomasseteric Fascia → 腮腺与咬肌 → 下颌支骨壁 → 颞肌腱与冠突 → 翼外肌、翼内肌及神经血管。<br>**翼下颌间隙 / Pterygomandibular Space 六壁**：前界为颞肌与颊肌，后界为腮腺鞘，外侧界为下颌支内侧面，内侧界为翼内肌外侧面，上界为翼外肌下缘，下界为翼内肌附着于下颌角处。 |
| 筋膜鞘与腔隙隔板 | 腮腺咬肌筋膜覆于咬肌浅面并形成腮腺鞘；颞筋膜 / Temporal Fascia 覆盖颞肌；颊咽筋膜 / Buccopharyngeal Fascia 衬于咽侧壁与颊肌。翼内肌、翼外肌表面存在薄层翼筋膜，将面侧深区分隔为肌束间蜂窝组织腔。翼下颌间隙由下颌支骨膜与翼内肌筋膜围成，属狭长疏松组织腔；其内下牙槽神经血管束被脂肪和蜂窝组织包绕，可沿神经管道向颊间隙、舌下间隙及咽旁间隙扩展。 |
| 穿行内容与管道排列 | **上颌动脉三段**：第1段——下颌段 / Mandibular part，位于髁突颈深面，发脑膜中动脉 / Middle Meningeal Artery 经棘孔 / Foramen Spinosum 入颅，发下牙槽动脉 / Inferior Alveolar Artery 入下颌孔；第2段——翼肌段 / Pterygoid part，行于翼外肌浅面或深面，发咬肌动脉、颞深前/后动脉、翼肌支及颊动脉；第3段——翼腭段 / Pterygopalatine part，经翼上颌裂 / Pterygomaxillary Fissure 入翼腭窝 / Pterygopalatine Fossa，发上牙槽后动脉 / Posterior Superior Alveolar Artery、眶下动脉 / Infraorbital Artery、蝶腭动脉 / Sphenopalatine Artery
