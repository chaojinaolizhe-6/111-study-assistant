> [!summary] 认知先验与立体空间脉络
> 胸膜腔（pleural cavity）如同一只被负压压紧的双层浆膜囊：外层壁胸膜（parietal pleura）衬贴于胸壁内面、纵隔两侧与膈上面，内层脏胸膜（visceral pleura）紧裹肺表面，两层在肺门（hilum of lung）处相互移行，并在肺门下方移行为肺韧带（pulmonary ligament）。该潜在腔隙左右各一、互不相通，静息时内含少量浆液形成“水膜密封”，使肺在呼吸时既可滑动又不至于脱离胸壁。壁胸膜上端形成胸膜顶（cupula pleurae / cervical pleura），经胸廓上口突入颈根部，像一顶帐篷尖高出锁骨内侧1/3上方2~3 cm。下外方则是胸膜腔最低处——肋膈隐窝（costodiaphragmatic recess / phrenicocostal sinus），为肋胸膜与膈胸膜返折形成的半月形盲袋，即使深吸气时肺下缘也不能充填，因而成为积液、积血最先沉积与穿刺引流的首选区域。

## MedSchoolAtlas 解剖属性

| 属性 | 核心解剖规范内容 |
|---|---|
| 层次与六壁/四壁境界 | - 胸膜腔由脏、壁胸膜围成，为密闭负压潜在腔隙，左右各一。<br>- 上界/顶：胸膜顶（cupula pleurae / cervical pleura）经胸廓上口突入颈根部，高出锁骨内侧1/3上方2~3 cm。<br>- 外侧界：肋胸膜（costal pleura）衬于胸骨、肋骨、肋间肌及胸内筋膜内面。<br>- 内侧界：纵隔胸膜（mediastinal pleura）覆于纵隔两侧，包绕肺根并移行为脏胸膜；肺门下方双层纵隔胸膜构成肺韧带（pulmonary ligament）。<br>- 下界：膈胸膜（diaphragmatic pleura）覆于膈上面，与膈纤维层紧密愈着。<br>- 前/后返折：肋胸膜前缘与纵隔胸膜返折形成肋纵隔隐窝；后部沿肋骨颈内侧返折为椎旁纵隔胸膜。 |
| 筋膜鞘与腔隙隔板 | - 胸内筋膜（endothoracic fascia）介于壁胸膜与胸壁内结构之间，是胸膜外手术剥离平面；胸膜顶上方增厚为胸膜上膜（suprapleural membrane / Sibson's fascia），悬吊并保护胸膜顶。<br>- 胸膜腔本身无实质性隔板，由壁胸膜返折形成胸膜隐窝：肋膈隐窝（costodiaphragmatic recess）与肋纵隔隐窝（costomediastinal recess）。<br>- 脏胸膜紧贴肺实质，叶间胸膜分隔肺叶；肺韧带内含有小血管、淋巴管，构成肺根活动与纵隔交通的系膜样结构。 |
| 穿行内容与管道排列 | - 胸膜顶周围穿行：锁骨下动脉、锁骨下静脉、臂丛、膈神经、迷走神经、交感干及星状神经节等，借胸膜上膜与颈根部结构分隔。<br>- 胸腔穿刺路径层次：皮肤 → 浅筋膜 → 深筋膜/胸壁肌 → 肋间外肌 → 肋间内肌 → 肋间最内肌 → 胸内筋膜 → 壁胸膜。<br>- 肋间隙血管神经排列：肋角外侧沿上位肋骨下缘肋沟走行，由上至下为肋间静脉、肋间动脉、肋间神经（VAN）；肋角内侧则走行于肋间隙中部，位置较不固定。<br>- 肋间后动脉与胸廓内动脉肋间前支在肋间隙形成吻合弓，是肋间出血易成喷射性或持续出血的解剖基础。 |
| 神经支配与血管分支 | - 壁胸膜神经：肋胸膜及膈胸膜周围部由肋间神经支配；纵隔胸膜及膈胸膜中央部由膈神经（phrenic nerve，C3~C5）支配。壁胸膜对痛、触敏感，尤其肋膈隐窝受刺激可致局部锐痛。<br>- 脏胸膜神经：由肺丛自主神经分布，交感叹号来自T2~T4，副交感来自迷走神经，痛觉较迟钝，但牵拉、炎症可产生钝痛或牵涉痛。<br>- 血供：壁胸膜由肋间后动脉、胸廓内动脉、膈上动脉及支气管动脉分支供应；静脉回流至奇静脉、半奇静脉、胸廓内静脉。<br>- 淋巴引流：至肋间淋巴结、胸骨旁淋巴结、纵隔淋巴结及膈淋巴结。 |
| 体表投影与骨性软骨标志 | - 胸膜顶：锁骨内侧1/3上方2~3 cm。<br>- 胸膜下界：锁骨中线第8肋、腋中线第10肋、肩胛线第12肋、后正中线第12胸椎棘突。<br>- 肺下缘：锁骨中线第6肋、腋中线第8肋、肩胛线第10肋、后正中线第10胸椎棘突。<br>- 肋膈隐窝：位于肺下缘与胸膜下界之间，腋中线处约深两个肋间隙；少量积液即可使肋膈角变钝。<br>- 胸腔穿刺标准定位：坐位前倾、双前臂伏于椅背或床桌；肩胛线或腋后线第7~8肋间隙，紧贴下一肋骨上缘进针。 |
| 三维空间交通路 | - 向上：经胸膜顶与颈根部血管神经鞘、臂丛及锁骨下血管周围筋膜交通，颈部感染、锁骨下静脉穿刺气胸可波及胸膜顶。<br>- 向下：与膈下腹膜腔仅隔膈；膈肌淋巴管可跨膈交通，肝脓肿、膈下脓肿可穿入胸膜腔形成脓胸。<br>- 向内侧：与纵隔直接相邻，纵隔气肿、食管破裂、血肿或假性动脉瘤可破入胸膜腔。<br>- 向外/后：沿肋间隙、胸内筋膜与胸壁肌层相邻，肋骨骨折可刺破壁胸膜及脏胸膜造成气胸、血胸。<br>- 经肺韧带：肺门与纵隔淋巴结、支气管血管
