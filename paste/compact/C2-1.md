- 图1：电路图（串联 RLC 支路，与第 39、40 页右上角同一张）。元件与标注：电阻 R（绿色实心方框，标 u_R）、电感 L（线圈，标 u_L）、电容 C（两条平行短线，标 u_C），支路端电压 u、电流 i。连接关系：R、L、C 自上而下串联，共用电流 i，i 箭头在支路上端指向右侧，自 + 端流经 R、L、C 回到 − 端。极性/参考方向：上端 +、下端 −，u、u_R、u_L、u_C 均上 + 下 −。过程：此图为本页推导 Z 的电路依据，本身不含波形与动作。版面文字：标题「❸ About the impedance」、页眉「2.4 Series AC circuits / 2.4.1 Series RLC circuits」、水印「大连理工大学」；公式链 U̇ = (R + j (X_L − X_C)) İ；Z = R + j (X_L − X_C) = R + j X，旁注「rectangular form」（X 下划蓝色横线）；再由 = √(R² + X²) ∠ arctan (X / R) 引出两支向下箭头，分别指向紫色方框「|Z|」（下方注「Modulus」）与「φ」（下方注「impedance angle」）；右侧写 Z = |Z| ∠ φ，旁注「polar form」（蓝色），并列出 R —— Real part、X —— imaginary part（以上均为版面文字）。

读图要点：这页把串联 RLC 的阻抗拆成直角坐标式 Z = R + jX 与极坐标式 Z = |Z| ∠ φ 两种写法；读图盯住向下两支箭头——实部 R 与虚部 X 分别合成模 |Z| = √(R² + X²) 和阻抗角 φ = arctan(X/R)。


### [C2-1 p42]

图区内容（共 3 处版面图区）：

- 图1：相量图（左边一幅，电阻性情形）。坐标与参考方向：以水平向右为电流 i 的正方向并作横轴，纵轴表示感抗电压/容抗电压方向；U̇_R 与 U̇（红色）都画在水平轴上、方向与 i 一致，二者重合；U̇_L（绿色）竖直向上，U̇_C（绿色）竖直向下，长度相等故互相抵消；横轴右端标 i。过程/结论：φ = 0°，即电压 U̇ 与电流 i 同相，电路呈电阻性。版面文字：本幅下方标「φ = 0°」与「Resistive」（红棕色，版面文字）。

- 图2：相量图（中间一幅，电感性情形）。坐标与参考方向：横轴沿电流 i 的正方向、右端标 i；U̇_L（绿色）竖直向上、长度大于 U̇_C（橙黄色）向下的长度，二者合成为水平方向的 U̇_X = U̇_L + U̇_C；U̇_R 沿横轴向右；U̇（红色）自原点斜向右上，在原点处与横轴之间用弧线标出夹角 φ，虚线把 U̇ 的箭头端与横轴上的分量对成直角三角形。过程/结论：电压 U̇ 超前电流 i，0 < φ < 90°，电感电压未被完全抵消，电路呈电感性。版面文字：本幅下方标「0 < φ < 90°」与「Inductive」（橙色，版面文字）；分量标注「U̇_X = U̇_L + U̇_C」（版面文字）。

- 图3：相量图（右边一幅，电容性情形）。坐标与参考方向：横轴沿电流 i 的正方向、右端标 i；U̇_L（绿色）竖直向上、长度小于 U̇_C（蓝色）向下的长度，故合成量 U̇_X = U̇_L + U̇_C 为向下的短竖段（蓝色）；U̇_R（橙色）沿横轴向右；U̇（红色）自原点斜向右下，在原点处与水平方向之间用弧线标出夹角 φ。过程/结论：电压 U̇ 滞后电流 i，−90° < φ < 0°，容性电压占优，电路呈电容性。版面文字：本幅下方标「− 90° < φ < 0°」与「Capacitive」（红色，版面文字）；分量标注「U̇_X = U̇_L + U̇_C」（版面文字）。

读图要点：这页用三幅相量图把阻抗角 φ 的符号翻译成电路性质：看 U̇_L 与 U̇_C 谁高，就决定 U̇ 是斜向上（感性）还是斜向下（容性）、还是与 i 重合（阻性）。读图盯住 U̇ 与 i 横轴之间的夹角 φ 及其正负。


### [C2-1 p43]

图区内容（共 1 处版面图区）：

- 图1：阻抗三角形（直角三角形结构示意，绿色描边）。元件与标注：水平直角边标 R（电阻 resistance），竖直直角边标 X（电抗 reactance），斜边标 |Z|（阻抗模 modulus），左下角 R 与 |Z| 之间用红色小圆弧标出夹角 φ（阻抗角 impedance angle）。连接关系/方向：三角形自左下角的 φ 顶点出发，沿水平边向右量得 R，在该右端点竖直向上量得 X，斜边由原点连到顶端，构成 |Z| = √(R² + X²)、φ = arctan(X/R) 的几何关系。过程：用三角形合成的方式由各元件的电阻与电抗求串联 RLC 电路的总阻抗。版面文字：标题「❺ About the impedance triangle」、页眉「2.4 Series AC circuits / 2.4.1 Series RLC circuits」、水印「大连理工大学」；公式 φ = ψ_u − ψ_i 与 φ = arctan (X / R)（X / R 为红色）；正文段落「The total impedance of an RLC series circuit can be found using impedance triangle. First of all, we have to consider the resistance and reactance of each component then put them into the impedance triangle to find the total impedance of the RLC circuit.」（以上均为版面文字）。

读图要点：这页把 |Z|、R、X 三者的数量关系搬进一个直角三角形，说明总阻抗的模与阻抗角可由 R、X 用勾股与反正切一并求出；读图盯住哪条边是 R、哪条边是 X、φ 夹在 R 与斜边 |Z| 之间。
